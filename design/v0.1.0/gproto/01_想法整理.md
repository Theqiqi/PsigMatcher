# 01 想法整理文档（静态库 psig）

- 版本：v0.1.0
- 保存目录：`design/v0.1.0/gproto/`

## 想法

为"针对 Windows 进程批量匹配特征码"的 GUI 程序提供**业务静态库**：负责进程枚举、进程内存读取、特征码（字节模式，支持通配）匹配，以及特征码表/匹配结果的 CSV、SQLite(.db)、TXT 导入导出。

## 定位

- 纯 C++ 静态库（无 Qt 依赖），Windows x64。
- 只暴露公共 API；GUI 通过公共 API 调用。
- 线程安全，支持并发扫描与取消。

## 命名

- 静态库名：**`psig`**（process-signature），产出 `psig.lib`。
