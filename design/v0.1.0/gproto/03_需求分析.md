# 03 需求分析文档（psig）

- 版本：v0.1.0
- 前置：`01_想法整理.md`、`02_跨流程需求接收.md`

## 1. 领域问题

操作系统提供"按进程读取内存"与"枚举进程"的原语；用户需要"给定一组字节模式，在若干进程的内存中批量定位命中地址"。

## 2. 需求（领域模型应用）

| 需求 | 说明 |
| --- | --- |
| N1 进程枚举 | 得到可扫描进程的集合（pid/名称/路径/可访问性） |
| N2 模式解析 | 把文本模式串转为（字节序列 + 掩码），支持 `??`/`?A`/`A?` |
| N3 内存扫描 | 在进程可读内存区域中定位模式，产出命中（地址/模块/字节/时间） |
| N4 批量与并发 | 多进程 × 多模式；可并发、可取消、可进度回调 |
| N5 数据交换 | 特征码表与结果表的 CSV/SQLite/TXT 读写 |
| N6 动态列 | 特征码表列可自由增删（导入导出须保留列定义） |

## 3. 边界

- 仅用户态、仅 Windows。
- 不做 UI、不做网络、不做驱动。
- 不依赖 Qt。
