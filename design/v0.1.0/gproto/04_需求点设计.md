# 04 需求点设计文档（psig）

- 版本：v0.1.0
- 前置：`03_需求分析.md`

| 需求点 | 目标 | 关键点 |
| --- | --- | --- |
| RP1 进程枚举 | 提供进程集合 | 使用系统进程快照/枚举 API；标记可访问性（能否 OpenProcess 读） |
| RP2 模式解析 | 文本 → 字节+掩码 | 支持 `??`（整字节通配）、`?N`/`N?`（半字节通配）；非法 token 报错 |
| RP3 区域枚举 | 找可读内存区域 | 遍历地址空间，筛 `MEM_COMMIT` 且可读的 `MEM_PRIVATE/MEM_IMAGE/MEM_MAPPED` |
| RP4 模式匹配 | 在缓冲区定位 | 朴素/优化匹配（掩码比较）；返回全部命中或每模式上限 |
| RP5 批量扫描 | 编排多进程×多模式 | 组装 RP1/RP3/RP4；进度回调、取消标志 |
| RP6 模块归属 | 命中地址→模块 | 枚举进程模块，定位命中落在哪个模块及模块基址 |
| RP7 表格数据交换 | 特征码表读写 | CSV + SQLite；保留列定义 |
| RP8 结果数据交换 | 结果表读写 | CSV + SQLite + TXT |
| RP9 动态列模型 | 列定义集合 | `ColumnDef` 列表 + 行（cells 对齐列） |
