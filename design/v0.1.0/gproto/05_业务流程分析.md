# 05 业务流程分析文档（psig）

- 版本：v0.1.0
- 前置：`04_需求点设计.md`

## BF1 进程枚举业务流程
1. 获取系统进程 id 列表。
2. 对每个 pid 尝试打开（查询/读权限）→ 成功标记 accessible。
3. 取进程名与路径。
4. 汇总为 `ProcessInfo` 列表返回。

## BF2 特征码扫描业务流程（核心）
1. 接收请求：目标 pid 列表 + 模式列表（+ 每模式上限 + 取消标志 + 进度回调）。
2. 对每个模式解析为（bytes, mask）；非法模式跳过并记录。
3. 对每个目标进程：
   a. 打开进程（读权限）。
   b. 枚举模块表（用于命中归属）。
   c. 遍历可读内存区域。
   d. 读取区域数据，逐模式匹配。
   e. 命中 → 组装 `MatchResult`（含模块归属、匹配字节、时间）。
   f. 回调进度。
   g. 检查取消标志，置位则提前返回已收集结果。
4. 汇总返回全部命中。

## BF3 特征码表导入业务流程
1. 判断格式（CSV/DB）。
2. 读取列定义 + 行数据。
3. 校验必要内置列（name、pattern）。
4. 返回 `Table`；失败置错误信息。

## BF4 特征码表导出业务流程
1. 接收 `Table`。
2. 按格式写出列定义（schema）+ 行数据。
3. 返回成功/失败。

## BF5 匹配结果导出业务流程
1. 接收 `MatchResult` 列表。
2. CSV/DB：写固定列；TXT：写人类可读文本（每命中一段）。
3. 返回成功/失败。

## 正常/异常路径
- 正常：按上述流程完成。
- 异常：进程打开失败→跳过；区域读取失败→跳过该区域；文件 I/O 失败→置错误并返回失败；取消→返回部分结果。
