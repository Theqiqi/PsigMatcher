## 功能点

| 功能点 | 说明 | 对应业务流程 |
| --- | --- | --- |
| FP1 EnumerateProcesses | 枚举进程 | BF1 |
| FP2 ParsePattern | 解析模式串 | BF2.2 |
| FP3 OpenProcessHandle | 打开进程句柄（原子） | BF2.3a |
| FP4 EnumerateRegions | 枚举可读内存区域（原子） | BF2.3c |
| FP5 ReadMemory | 读取内存块（原子） | BF2.3d |
| FP6 MatchPattern | 掩码匹配（算法） | BF2.3d |
| FP7 EnumerateModules | 枚举模块（原子） | BF2.3b |
| FP8 LocateModule | 地址→模块归属（算法） | BF2.3e |
| FP9 ScanProcesses | 批量扫描编排（接口） | BF2 |
| FP10 RequestCancel | 取消（接口） | BF2.3g |
| FP11 ImportSignaturesCsv/Db | 导入特征码表 | BF3 |
| FP12 ExportSignaturesCsv/Db | 导出特征码表 | BF4 |
| FP13 ExportResultsCsv/Db/Txt | 导出结果 | BF5 |
