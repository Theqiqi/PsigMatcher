# 07 功能分析文档（psig）

- 版本：v0.1.0
- 前置：`06_功能点设计.md`

| 功能点 | 流程 | 输入 | 输出 | 失败处理 |
| --- | --- | --- | --- | --- |
| FP1 EnumerateProcesses | 取 pid 列表→逐个取名称/路径/可访问 | — | ProcessInfo[] | 单项失败标记 accessible=false |
| FP2 ParsePattern | 分词→逐 token 转字节+掩码 | raw,name | Pattern | 非法 token→valid=false,error |
| FP3 OpenProcessHandle | OpenProcess(PROCESS_VM_READ\|QUERY) | pid | handle | 失败→返回空句柄 |
| FP4 EnumerateRegions | VirtualQueryEx 循环 | handle | Region[] | 到末端/失败→停止 |
| FP5 ReadMemory | ReadProcessMemory | handle,addr,size | bytes | 失败→该区域跳过 |
| FP6 MatchPattern | 掩码比较滑动窗口 | data,mask | offsets | 无命中→空 |
| FP7 EnumerateModules | 模块快照 | pid | Module[] | 失败→空 |
| FP8 LocateModule | 地址落在哪模块区间 | addr,modules | Module,base | 无→空模块 |
| FP9 ScanProcesses | 编排 FP2–FP8 + 进度 + 取消 | ScanRequest | MatchResult[] | 单进程/区域失败跳过 |
| FP10 RequestCancel | 置原子标志 | bool | — | — |
| FP11 Import* | 解析 CSV/DB | path | Table | 置 err |
| FP12 Export* | 写 CSV/DB | path,Table | bool | 置 err |
| FP13 ExportResults* | 写 CSV/DB/TXT | path,results | bool | 置 err |
