# 08 功能流程图与 API 接口列表文档（psig）

- 版本：v0.1.0
- 前置：`07_功能流程分析.md`
- 功能流程图（SVG）：`design/v0.1.0/functionflow/psig_functionflow.svg`

## 1. API 接口列表（公共 API）

| API | 签名 | 说明 |
| --- | --- | --- |
| EnumerateProcesses | `std::vector<ProcessInfo> EnumerateProcesses()` | 枚举进程 |
| ParsePattern | `Pattern ParsePattern(const std::string& raw, const std::string& name)` | 解析模式串 |
| ScanProcesses | `std::vector<MatchResult> ScanProcesses(const ScanRequest&, ProgressCallback, const std::atomic_bool*)` | 批量扫描 |
| RequestCancel | `void RequestCancel(bool flag)` | 请求取消（全局标志） |
| ImportSignaturesCsv | `Table ImportSignaturesCsv(const std::string&, std::string& err)` | 导入 CSV |
| ImportSignaturesDb | `Table ImportSignaturesDb(const std::string&, std::string& err)` | 导入 DB |
| ExportSignaturesCsv | `bool ExportSignaturesCsv(const std::string&, const Table&, std::string& err)` | 导出 CSV |
| ExportSignaturesDb | `bool ExportSignaturesDb(const std::string&, const Table&, std::string& err)` | 导出 DB |
| ExportResultsCsv | `bool ExportResultsCsv(const std::string&, const std::vector<MatchResult>&, std::string& err)` | 导出结果 CSV |
| ExportResultsDb | `bool ExportResultsDb(const std::string&, const std::vector<MatchResult>&, std::string& err)` | 导出结果 DB |
| ExportResultsTxt | `bool ExportResultsTxt(const std::string&, const std::vector<MatchResult>&, std::string& err)` | 导出结果 TXT |
| BuiltinSignatureColumns | `std::vector<ColumnDef> BuiltinSignatureColumns()` | 内置列定义 |

## 2. 功能流程图

见 `design/v0.1.0/functionflow/psig_functionflow.svg`：FP9 ScanProcesses 编排 FP3→FP7→FP4→FP5→FP6→FP8，进度回调与取消分支。

## 3. 接口分组（模块）

- 进程模块：EnumerateProcesses、ScanProcesses、RequestCancel
- 模式模块：ParsePattern、BuiltinSignatureColumns
- 数据交换模块：Import*/Export*
