# 09 模块分析文档（psig）

- 版本：v0.1.0
- 前置：`08_功能设计.md`

## 分层架构（数据层 / 接口层 / 算法层 / 原子化底层）

| 层 | 模块 | 职责 |
| --- | --- | --- |
| 数据层 data | types | 公共数据结构定义（ProcessInfo/Pattern/MatchResult/ColumnDef/Table/ScanRequest/ScanProgress） |
| 数据层 data | codec | 纯编解码（hex 编解码、时间格式化、字节→字符串） |
| 算法层 algorithm | pattern | 纯算法：ParsePattern、MatchPattern |
| 算法层 algorithm | module_locate | 纯算法：LocateModule（地址落在哪个模块区间） |
| 算法层 algorithm | csv | 纯算法：CSV 文本 ↔ Table |
| 原子化底层 atomic | win_process | WinAPI：枚举 pid、打开进程、枚举区域、读内存、枚举模块、取进程名/路径 |
| 原子化底层 atomic | sqlite_io | SQLite：读写 `.db`（特征码表、结果表） |
| 原子化底层 atomic | file_io | 文件读写（文本/二进制） |
| 接口层 api | psig | 组装原子+算法+数据，实现公共 API（psig.h） |

## 依赖方向

```
api → algorithm → data
api → atomic → data
algorithm ↛ atomic/api   (算法层纯粹，无 I/O)
```

## 按职责拆分接口

- 进程模块：EnumerateProcesses、ScanProcesses、RequestCancel
- 模式模块：ParsePattern、BuiltinSignatureColumns
- 数据交换模块：Import*/Export*
