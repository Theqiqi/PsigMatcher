# 10 职责和边界说明文档（psig）

- 版本：v0.1.0
- 前置：`09_模块设计.md`

## 各层职责与禁止项

| 层 | 职责 | 禁止项 |
| --- | --- | --- |
| data | 定义数据结构；纯编解码 | 禁止 I/O、禁止调用 WinAPI/SQLite、禁止业务编排 |
| algorithm | 纯计算（解析、匹配、模块归属、CSV 文本↔Table） | 禁止 include/call `atomic/*`、`api/psig.h`；禁止 I/O、WinAPI、进程读写 |
| atomic | 封装底层能力（WinAPI、SQLite、文件 I/O） | 禁止业务编排；禁止 include `algorithm/*`、`api/psig.h`；禁止 Qt |
| api | 组装 atomic+algorithm+data，实现公共 API | 禁止直接写裸 WinAPI（须经 atomic）；禁止 Qt；禁止绕过算法自行实现匹配 |

## 边界

- 静态库不引用 Qt，不依赖 GUI。
- 公共接口仅 `include/psig.h`；内部头文件不外泄。
- 线程安全由 api/atomic 层保证（无共享可变全局状态，取消标志用 `std::atomic`）。
