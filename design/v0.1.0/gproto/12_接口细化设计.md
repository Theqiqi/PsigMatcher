# 12 接口细化设计文档（psig）

- 版本：v0.1.0
- 前置：`11_api接口分析.md`
- 产物：数据结构列表、算法列表、原子化 api 列表、api 接口异常设计

## A. 数据结构列表

| 结构 | 字段 |
| --- | --- |
| ProcessInfo | pid:u32, name:wstring, path:wstring, accessible:bool |
| Pattern | name:string, raw:string, bytes:vector<u8>, mask:vector<u8>, valid:bool, error:string |
| MatchResult | patternName:string, pid:u32, processName:wstring, address:u64, moduleName:wstring, moduleBase:u64, matchedBytes:string, hitTime:string |
| ColumnDef | key:string, title:string, type:string, builtin:bool |
| TableRow | cells:vector<string> |
| Table | columns:vector<ColumnDef>, rows:vector<TableRow> |
| ScanRequest | pids:vector<u32>, patterns:vector<Pattern>, maxResultsPerPattern:size_t |
| ScanProgress | currentPid:u32, done:size_t, total:size_t, hits:size_t |
| Region | base:u64, size:u64, protect:u32 |
| ModuleInfo | name:wstring, base:u64, size:u64 |

## B. 算法列表

| 算法 | 函数 | 纯计算 |
| --- | --- | --- |
| 模式解析 | `algorithm::ParsePatternBytes(raw, name)` | 是 |
| 掩码匹配 | `algorithm::FindAll(data, size, bytes, mask)` → offsets | 是 |
| 模块归属 | `algorithm::LocateModule(addr, modules)` | 是 |
| CSV 解析 | `algorithm::ParseCsv(text)` → Table | 是 |
| CSV 序列化 | `algorithm::SerializeCsv(table)` → string | 是 |
| 掩码生成 | `algorithm::TokenToByteMask(token)` | 是 |

## C. 原子化 API 列表

| 原子 API | 说明 |
| --- | --- |
| `atomic::EnumProcessIds()` | 枚举系统 pid |
| `atomic::OpenForRead(pid)` | 打开进程（读权限）→ 句柄 |
| `atomic::CloseHandle(h)` | 关闭句柄 |
| `atomic::ProcessNamePath(pid)` | 取进程名/路径 |
| `atomic::EnumRegions(h)` | 枚举可读区域 |
| `atomic::ReadMemory(h, addr, size)` | 读内存块 |
| `atomic::EnumModules(pid)` | 枚举模块 |
| `atomic::ReadTextFile(path)` / `WriteTextFile(path,text)` | 文本 I/O |
| `atomic::SqliteOpen/CreateTable/Insert/Query/Close` | SQLite 原语 |

## D. API 接口异常设计

| 接口 | 异常/错误 | 表达方式 |
| --- | --- | --- |
| EnumerateProcesses | 枚举失败 | 返回空列表（不抛） |
| ParsePattern | 非法模式 | valid=false + error（不抛） |
| ScanProcesses | 单进程失败 | 跳过（记录），不抛 |
| Import* | 解析/IO 失败 | err 出参 + 空 Table（不抛） |
| Export* | IO 失败 | 返回 false + err（不抛） |

统一原则：公共 API 不抛异常，用返回值/出参表达错误，便于跨线程与跨模块使用。
