# 13 数据结构分析文档（psig）

- 版本：v0.1.0
- 前置：`12_接口细化设计.md`

## ProcessInfo
- 用途：进程列表项。
- 字段：pid(u32)、name(wstring)、path(wstring)、accessible(bool，是否可读打开)。
- 不变量：pid>0。

## Pattern
- 用途：解析后的模式。
- 字段：name、raw、bytes(每字节期望值)、mask(每字节掩码，0xFF 全匹配，0x00 全通配，半字节如 0xF0/0x0F)、valid、error。
- 不变量：`bytes.size()==mask.size()`。

## MatchResult
- 用途：一条命中。
- 字段：patternName、pid、processName、address(u64 虚拟地址)、moduleName、moduleBase、matchedBytes(hex 串)、hitTime(ISO8601)。
- 不变量：address 在进程地址空间内。

## ColumnDef / TableRow / Table
- ColumnDef：key(唯一)、title(显示)、type(text/int/enum)、builtin(内置列不可删)。
- TableRow：cells 与 columns 一一对应（长度对齐）。
- Table：columns + rows。

## ScanRequest / ScanProgress
- ScanRequest：pids、patterns、maxResultsPerPattern。
- ScanProgress：currentPid、done(已处理模式数)、total、hits。

## Region / ModuleInfo
- Region：base、size、protect（WinAPI 保护位）。
- ModuleInfo：name、base、size。
