# 14 算法分析文档（psig）

- 版本：v0.1.0
- 前置：`12_接口细化设计.md`

## A1 TokenToByteMask(token) → (byte, mask)
- 输入：2 字符 token。
- 规则：`??`→(0x00,0x00)；`XY`→(XY,0xFF)；`?Y`→(0Y,0x0F)；`X?`→(X0,0xF0)。
- 非法：长度≠2 或非 hex/`?` → 失败。

## A2 ParsePatternBytes(raw, name) → Pattern
- 归一化分隔（空格、逗号、无分隔连续）。
- 逐 token 调 A1；任一失败→valid=false。
- 输出 bytes/mask。

## A3 FindAll(data, size, bytes, mask) → offsets
- 滑动窗口：对每个起点 i∈[0, size-m]，检查所有 j：`(data[i+j] & mask[j]) == (bytes[j] & mask[j])`。
- 命中记录 i；可带上限。
- 复杂度 O(n*m)；m 为模式长度。

## A4 LocateModule(addr, modules) → (ModuleInfo, base)
- 在 modules 中找 `base ≤ addr < base+size`。
- 命中返回该模块；否则空。

## A5 ParseCsv(text) → Table
- 支持引号包裹、逗号分隔、CRLF/LF、首行=列定义。
- 首行为列标题；据此生成 ColumnDef（builtin 按内置键判定）。

## A6 SerializeCsv(table) → text
- 首行列标题，逐行转义写出。

## 边界条件
- 空数据、空模式、模式长于数据、全通配模式。
- CSV：空字段、含逗号/引号/换行字段。
