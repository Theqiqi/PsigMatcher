# 16 技术选型文档（psig）

- 版本：v0.1.0
- 前置：`01_想法整理.md`

## 默认技术选型

| 项 | 选型 |
| --- | --- |
| 程序类型 | 静态库（非 exe） |
| 语言 | C++20 |
| 框架 | Windows 平台 |
| 跨平台 | 否 |
| 静态库命名 | `psig`（进程特征码匹配类，非 pmem） |
| 构建 | CMake + CMakePresets |
| 生成器 | Ninja |
| 工具链 | MSVC（cl.exe，vcvars64） |
| 运行时 | Debug=/MDd（MultiThreadedDebugDLL）、Release=/MT（MultiThreaded） |
| 三方依赖 | SQLite3（vcpkg manifest，`sqlite3`），gtest（测试） |
| Qt 依赖 | 无（静态库不引用 Qt） |

## 说明

- 使用 Windows API（tlhelp32/psapi、VirtualQueryEx、ReadProcessMemory）实现进程与内存原语。
- SQLite 用于 `.db` 读写；经 vcpkg manifest 管理。
- 产出 `psig.lib`（Debug/Release），公共头 `include/psig.h`。
