# 19 代码规范文档（psig）

- 版本：v0.1.0
- 前置：统一要求

## 通用

- 语言 C++20；命名空间 `psig`（公共）、`psig::data`、`psig::algorithm`、`psig::atomic`、`psig::api`（内部）。
- 头文件保护用 `#pragma once`；`#include` 只用 `名字/名字.h` 形式，禁止 `../` 相对路径；搜索路径由 CMake `target_include_directories` 提供。
- 文件编码 UTF-8（BOM 可选）；行尾 LF。

## 分层规范

- data：仅类型与纯编解码；不含 I/O、不含 WinAPI。
- algorithm：纯函数，无 I/O、无 `atomic/*`、无 `psig.h` 依赖。
- atomic：封装 WinAPI/SQLite/文件 I/O；不 include `algorithm/*`、`psig.h`。
- api：组装算法+原子+数据；不写裸 WinAPI。

## 代码风格

- 类型名 `PascalCase`；函数 `PascalCase`（公共） / `camelCase`（内部工具）；成员 `m_` 前缀；常量 `k` 前缀。
- 函数体不超过 ~80 行；嵌套不超过 3 层；错误后提前返回。
- 单一职责：一个函数只做一件事。

## 异常与错误

- 公共 API 不抛异常；用返回值/出参 `err` 表达。
- 内部如需异常，必须在 API 边界捕获并转为错误返回。

## 线程安全

- 不共享可变全局状态；取消标志用 `std::atomic_bool`。
- 算法层无状态、可重入。

## 依赖

- 允许：C/C++ 标准库、Windows API（仅 atomic 层）、SQLite（仅 atomic 层）。
- 禁止：Qt、其它三方库（测试代码除外）。
