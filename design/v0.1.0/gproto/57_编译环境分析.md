# 57 编译环境需求文档（psig）

- 版本：v0.1.0
- 前置：`16_技术选型.md`

## 编译工具与版本

| 工具 | 要求 | 本机 |
| --- | --- | --- |
| CMake | ≥3.20（用 CMakePresets） | 4.2.3（WSL）/ 由 bat 调用 Windows cmake |
| 编译器 | MSVC cl.exe（VS2022） | MSVC 14.44.35207（VS2022 Community） |
| 生成器 | Ninja | 已装（WSL 与 Windows 侧） |
| vcpkg | VS 自带 | `C:/Program Files/Microsoft Visual Studio/2022/Community/VC/vcpkg/vcpkg.exe` |
| SQLite3 | 经 vcpkg manifest（`sqlite3`） | 待 restore |
| gtest | 经 vcpkg manifest（`gtest`） | 待 restore |

## vcpkg 可用性检测

- 检测到 VS 自带 `vcpkg.exe` → **已配置 vcpkg**，三方依赖走 vcpkg manifest（禁止 vendored）。

## 运行时策略

- Debug：`CMAKE_MSVC_RUNTIME_LIBRARY=MultiThreadedDebugDLL`（/MDd），triplet `x64-windows`。
- Release：`CMAKE_MSVC_RUNTIME_LIBRARY=MultiThreaded`（/MT），triplet `x64-windows-static`。

## 构建流程

- WSL → cmd.exe → .bat → vcvars64.bat → cmake --preset → MSVC 编译。
