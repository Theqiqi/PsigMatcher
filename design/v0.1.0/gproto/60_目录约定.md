# 60 目录约定（psig）

- 版本：v0.1.0
- 前置：`16_技术选型.md`

## 根目录

- 仅保留：`psig/`、`gui/`（平级，互不嵌套）、`design/`、`.flow/`、配置文件（`.gitignore`、`.idea.md`）。
- 根目录不得有 CMakeLists.txt / CMakePresets.json / script/ / install/ / out/ / third_party/ / workspace/。

## psig/ 子目录（自包含）

```
psig/
├── CMakeLists.txt
├── CMakePresets.json
├── vcpkg.json
├── include/psig.h              # 公共头
├── src/
│   ├── CMakeLists.txt
│   ├── data/                   # types.h, codec.*
│   ├── algorithm/              # pattern.*, module_locate.*, csv.*
│   ├── atomic/                 # win_process.*, sqlite_io.*, file_io.*
│   └── api/                    # psig.cpp
├── test/
│   ├── target/                 # 测试目标程序
│   ├── unit/                   # 单元测试
│   └── integration/            # 集成测试
├── script/                     # build_debug.bat 等
└── out/                        # 构建输出（bin/lib/<配置>）
```

- 无其它依赖的 psig 静态库**不配置 install/**，不写安装脚本。
