# 01 想法分析文档（想法收集）

- 版本：v0.1.0
- 程序类型：新建程序（Windows 桌面 Qt6 GUI 单体程序 + 业务静态库）
- 输入：`.idea.md`

## 1. 用户想法原文要点

> 写一个针对 windows 进程批量匹配特征码的程序。大概是以表格的形式编辑来批量搜索，支持模糊匹配，可以自由添加表格列，可以导出为表格格式和数据库格式（使用 sqlite，数据库后缀名为 `.db`），也可以导入导出支持的格式。输入的主要是特征码表格，输出的主要是匹配后的表。都支持软件查看和编辑以及导出；导入只支持特征码表格和数据库。导出的匹配后的表也支持保存为 txt 文本格式。

## 2. 目标（程序要解决什么）

对 Windows 目标进程，按用户维护的**特征码表格**批量进行内存特征匹配（签名扫描），把命中结果汇总为**匹配结果表**，并支持对输入/输出数据集的编辑、导入、导出。

## 3. 问题与需求方向（不限定程序类型）

1. **输入数据**：特征码表格（多行、多列、列可自由增删），支持模糊匹配（通配符）。
2. **批量搜索**：对多个进程 / 多条特征码批量扫描。
3. **输出数据**：匹配结果表（特征码 × 进程 → 命中地址等）。
4. **数据交换**：
   - 导出：表格格式（CSV）、数据库格式（SQLite `.db`）、匹配结果额外支持 TXT。
   - 导入：仅支持特征码表格（CSV）与数据库（`.db`）。
5. **编辑能力**：输入表与输出表均可在软件内查看、编辑、导出。

## 4. 范围界定

- 平台：Windows（依赖 Windows 进程内存访问能力）。
- 交互形态：可视化窗口、表格编辑、鼠标/键盘交互、实时反馈 → 适合 GUI。
- 输入数据源与输出数据源都必须能"查看/编辑/导出"。

## 5. 不在本想法范围

- 不涉及远程/网络进程内存读取。
- 不涉及驱动级操作（用户态读取）。
- 不涉及除 CSV / SQLite(.db) / TXT 之外的数据格式。

## 6. 关键名词

| 名词 | 含义 |
| --- | --- |
| 特征码（签名/Pattern） | 形如 `48 8B ?? 05 ?? ?? ?? ??` 的字节序列，`??` 为单字节通配，`?A`/`A?` 为半字节通配 |
| 模糊匹配 | 特征码通配符匹配；以及表格文本列的包含式过滤 |
| 匹配结果 | 某条特征码在某进程某地址命中的记录 |
| 特征码表格 | 用户维护的输入表，列可自由增删 |
| 匹配结果表 | 扫描输出表，只读查询结果 |
