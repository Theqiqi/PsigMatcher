# 02 领域模型文档（领域分析）

- 版本：v0.1.0
- 前置：`01_想法分析.md`

## 1. 业务对象

| 业务对象 | 说明 | 关键属性 |
| --- | --- | --- |
| 特征码 Signature | 一条待扫描的字节模式 | id、名称、模式串、备注、用户自定义列值 |
| 列定义 ColumnDef | 特征码表的列（内置列 + 用户自由添加列） | key、标题、类型（文本/整数/枚举）、是否内置、是否可编辑 |
| 进程 Process | 可被扫描的 Windows 进程 | pid、名称、路径、位数、是否可访问 |
| 匹配结果 MatchResult | 一条命中记录 | patternId、patternName、pid、processName、地址、模块、匹配字节、命中时间 |
| 扫描任务 ScanTask | 一次批量扫描（多进程 × 多特征码） | 目标进程集合、特征码集合、进度、状态 |

## 2. 数据集合（建模重点）

领域模型必须建模数据集合及其元素操作，作为交互模式设计依据。

### 集合 A：特征码表 SignatureCollection（可编辑条目集）
- 元素：Signature。
- 元素操作：查看、复制、编辑（双击/右键）、删除（单条/批量）、批量添加（从 CSV/DB 导入、手工新增行）。
- 可写性：**可编辑**（增删改）。
- 形态：条目多、多列、可滚动 → **表格**。

### 集合 B：列定义集 ColumnCollection（可编辑 schema）
- 元素：ColumnDef。
- 元素操作：查看、添加列、重命名列、删除列、调整顺序。
- 可写性：**可编辑**（结构变更）。
- 形态：条目少、固定 → **对话框中的列表/表格**。

### 集合 C：进程列表 ProcessList（只读查询结果）
- 元素：Process。
- 元素操作：查看、复制、刷新（重新枚举）、**多选**作为扫描目标（Ctrl/Shift、全选）。
- 可写性：**只读**（由系统枚举得出，不允许在结果上直接改数据）。
- 形态：条目多、多列 → **表格（多选）**。

### 集合 D：匹配结果表 ResultCollection（只读查询结果）
- 元素：MatchResult。
- 元素操作：查看、复制、导出（CSV/DB/TXT）、批量删除结果（清空/按条件删除，属于结果集自身管理，不是改数据）。
- 可写性：**只读**（查询结果，不允许直接修改命中数据）。
- 形态：条目多、多列 → **表格**。

### 集合 E：历史日志 LogCollection（只读追加序列）
- 元素：日志条目（时间、级别、内容）。
- 元素操作：查看、复制、清空。
- 可写性：**只读追加**（由程序追加，用户只可清空）。
- 形态：可滚动、可追溯 → **日志区**。

## 3. 参与者

| 参与者 | 职责 |
| --- | --- |
| 操作员（用户） | 维护特征码表与列定义、选择进程、发起扫描、查看/编辑/导出结果 |
| Windows 系统 | 提供进程枚举与进程内存访问能力（经静态库封装） |

## 4. 操作流程（高层）

1. 维护特征码：新增/编辑/删除特征码行，自由增删列；可导入 CSV/DB。
2. 选择目标进程：枚举进程列表，多选目标。
3. 批量扫描：对（选中进程 × 特征码表）执行匹配，进度反馈，产出匹配结果表。
4. 查看结果：查看/复制结果，导出 CSV / DB / TXT。
5. 导入：仅特征码表支持从 CSV / DB 导入。

## 5. 集合与操作清单（供交互模式设计）

| 集合 | 性质 | 单选/多选 | 可写性 | 关键元素操作 |
| --- | --- | --- | --- | --- |
| 特征码表 | 可编辑条目集 | 多选 | 增删改 | 查看/复制/编辑/删除/批量添加/批量删除 |
| 列定义集 | 可编辑 schema | 单选 | 增删改 | 查看/添加/重命名/删除/排序 |
| 进程列表 | 只读查询结果 | 多选 | 只读 | 查看/复制/刷新/多选 |
| 匹配结果表 | 只读查询结果 | 多选 | 只读 | 查看/复制/导出/批量清空 |
| 历史日志 | 只读追加序列 | 不适用 | 只读 | 查看/复制/清空 |

## 6. 约束满足说明

- 已建模数据集合（特征码表、进程列表、匹配结果表等）及其元素操作（查看/复制/编辑/删除/批量添加/批量删除），满足"领域模型必须建模数据集合及元素操作"约束。
- 未停留在零散对象层面，已给出集合性质与形态。
