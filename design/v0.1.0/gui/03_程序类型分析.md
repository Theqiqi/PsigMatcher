# 03 程序类型分析文档（程序类型判断）

- 版本：v0.1.0
- 前置：`02_领域模型.md`

## 1. 判断目标

判断本程序是否适合 Qt GUI 形式（是否需要可视化窗口交互）。

## 2. 判定

| 判定项 | 结论 | 依据 |
| --- | --- | --- |
| 需要可视化窗口 | 是 | 特征码表格编辑、进程选择、结果展示都需要多窗口/多页面 |
| 鼠标/键盘交互 | 是 | 表格增删改、双击编辑、右键菜单、多选、快捷键 |
| 实时反馈 | 是 | 扫描进度、命中数量、状态提示、日志 |
| 多控件协作 | 是 | 菜单栏、工具栏按钮、多个表格、对话框、状态栏、日志区协作 |
| 纯自动化任务 | 否 | 需要人工编辑与决策 |
| 仅简单输入输出 | 否 | 输入/输出均为可编辑多列表格 |
| 需要全屏文本界面 | 否 | 表格与对话框更适合图形界面 |

## 3. 结论

**适合 Qt GUI 形式**。程序为 Windows 桌面应用程序（exe），采用 Qt6 Widgets 构建可视化窗口，交互密集、控件协作多。

## 4. 静态库边界（本步仅判断类型，不展开设计）

实际的进程内存读取与特征匹配属于计算/系统能力，不由 GUI 直接实现，交由业务静态库提供公共 API（后续步骤确定）。

## 5. 完成标准

- 程序类型分析文档产出。
- 判定为适合 GUI，未触发"跳回领域分析"。
