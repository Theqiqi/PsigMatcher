# 04 GUI 需求分析文档

- 版本：v0.1.0
- 前置：`03_程序类型分析.md`、`02_领域模型.md`

## 1. 需求概述

为操作员提供"编辑特征码 → 选择进程 → 批量扫描 → 查看/导出结果"的可视化工作台。

## 2. 功能需求（含可视化反馈）

| 编号 | 需求 | 可视化反馈 |
| --- | --- | --- |
| R1 | 特征码表格：多行多列，单元格可编辑 | 单元格就地编辑，修改后行标记为"已修改" |
| R2 | 自由添加/删除/重命名表格列 | 列头变化即时反映；列管理对话框 |
| R3 | 特征码增删：新增行、删除选中行、批量删除 | 行数变化、状态栏提示 |
| R4 | 模糊匹配：特征码通配符（`??`、`?A`、`A?`） | 非法模式串行标红并在状态栏提示 |
| R5 | 导入特征码：CSV / SQLite `.db` | 导入进度、成功条数、错误提示 |
| R6 | 导出特征码：CSV / SQLite `.db` | 导出结果提示（路径） |
| R7 | 进程枚举与多选 | 进程表刷新、可访问性标记 |
| R8 | 批量扫描（多进程 × 多特征码） | 进度条、当前扫描进程/特征码、命中数实时累加 |
| R9 | 匹配结果表：查看/复制 | 命中行展示，支持多选复制 |
| R10 | 导出结果：CSV / SQLite `.db` / TXT | 导出完成提示 |
| R11 | 历史日志：记录关键操作 | 日志区滚动、可复制、可清空 |
| R12 | 持久状态：当前目标进程数、特征码数、扫描状态 | 状态栏固定区域 |

### 3.2 对话框

- 列管理对话框 ColumnManagerDialog：增删改列。
- 导入/导出文件对话框：QFileDialog。

## 4. 用户操作路径（点击流程）

- **编辑特征码**：切到"特征码编辑"页 → 双击单元格编辑 / 工具栏[新增行] / 选中行右键[删除] → 状态栏提示。
- **添加列**：菜单 编辑→列管理 → 对话框内[添加列] → 确定 → 表格列更新。
- **导入特征码**：文件→导入→选择 CSV/DB → 进度与结果提示。
- **选择进程**：切到"进程选择"页 → [刷新进程] → Ctrl/Shift 多选 → 状态栏显示已选数量。
- **扫描**：工具栏[开始扫描] → 进度条推进 → 结果页自动展示命中。
- **导出结果**：结果页 [导出CSV]/[导出DB]/[导出TXT] 或 文件→导出。
- **日志**：查看底部日志区，[清空日志]。

## 5. 可视化反馈要求

- 进度：扫描期间显示进度条与当前进度文本。
- 结果：命中数实时累加。
- 错误：非法模式串、导入失败、无权限读取等 → 瞬时反馈或对话框。
- 持久状态：目标进程数、特征码条数、扫描状态固定在状态栏左侧。
