# 06 交互模式设计文档

- 版本：v0.1.0
- 前置：`02_领域模型.md`、`05_GUI功能列表与窗口定义.md`

## 1. 设计原则

对每个数据集合判定性质 → 由性质决定可写性与交互入口；布局与交互必须有领域模型依据，禁止 demo 式随意摆放控件。

## 2. 集合 → 性质 → 交互 一览

| 集合 | 性质 | 选择模式 | 可写性 | 集合形态 | 操作入口分级 |
| --- | --- | --- | --- | --- | --- |
| 特征码表 | 可编辑条目集 | **多选** | 增删改 | 表格 + 行编辑 | 高频全局→工具栏；元素级→双击(主)/右键(增删改)；低频→菜单 |
| 列定义集 | 可编辑 schema | 单选 | 增删改 | 对话框内表格 | 低频管理→菜单"编辑→列管理"打开对话框 |
| 进程列表 | 只读查询结果 | **多选** | 只读 | 表格 | 刷新→按钮；选择→多选 |
| 匹配结果表 | 只读查询结果 | **多选** | 只读 | 表格 | 导出→按钮/菜单；复制→右键/Ctrl+C；清空→右键 |
| 历史日志 | 只读追加序列 | 不适用 | 只读 | 日志区 | 清空→右键/按钮 |

## 3. 选择模式判定

- **特征码表**：删除、批量删除、复制可作用于多个对象 → **必须支持多选**（Ctrl/Shift 扩展、全选）与批量执行，禁止只能处理单行。
- **进程列表**：扫描目标可为多个进程 → **必须支持多选**（Ctrl/Shift、全选），批量作为扫描目标。
- **匹配结果表**：复制/清空/导出可作用于多条 → 支持多选。
- **列定义集**：结构操作作用于单列 → 单选。

## 4. 操作入口分级

- **高频全局操作 → 按钮（工具栏）**：
  - 导入特征码、导出特征码、刷新进程、开始扫描、取消扫描、导出结果（CSV/DB/TXT）。
- **元素级操作 → 双击（主操作）+ 右键上下文菜单**：
  - 特征码行：双击进入编辑（就地编辑单元格）；右键菜单 = 新增行 / 删除 / 复制 / 编辑。
  - 结果行：双击查看详情（对话框）；右键 = 复制 / 导出选中 / 清空。
- **低频管理操作 → 菜单栏**：
  - 文件→导入/导出/退出；编辑→列管理/新增行/删除行；扫描→刷新进程/开始/取消；帮助→关于。
- **同一操作不重复提供多个入口**：同一操作在按钮与菜单中择一为主入口，另一处为菜单镜像（允许"按钮=高频，菜单=同义镜像"），但不在同一层级重复堆叠。

## 5. 可写性规则

- **只读集合（进程列表、匹配结果表）**：只允许查看、复制、导出、把结果添加到其它集合；**禁止在结果上直接修改数据**（表格 `setEditTriggers(NoEditTriggers)`）。
- **可编辑集合（特征码表、列定义集）**：允许增删改；编辑经双击/右键/对话框进入，不把编辑流程堆成面板按钮。

## 6. 集合形态规则

- 条目少且固定 → 下拉/单选控件（本程序列类型选择用 QComboBox）。
- 条目多、可滚动、需多列 → 表格（特征码表、进程列表、结果表）。
- **可编辑多行集合（特征码表）用表格 + 行编辑**，不用"单行输入框 + 添加按钮"表达多条目数据。
- 列定义（条目少）→ 对话框内小表格。

## 7. 每个窗口的控件与领域依据

### SignatureEditorPage
| 控件 | 领域依据 |
| --- | --- |
| QTableView（可编辑） | 特征码表：可编辑条目集，多列 → 表格 |
| 新增行按钮 | 批量添加特征码（高频） |
| 删除行按钮/右键 | 单条/批量删除 |
| 列管理按钮 | 列定义集 schema 管理 |
| 双击单元格 | 元素级主操作=编辑 |

### ProcessSelectionPage
| 控件 | 领域依据 |
| --- | --- |
| QTableView（只读、多选） | 进程列表：只读查询结果，多选 |
| 刷新按钮 | 重新枚举进程 |
| 过滤框 | 模糊匹配（文本包含过滤） |
| 全选按钮 | 多选便捷操作 |

### ResultPage
| 控件 | 领域依据 |
| --- | --- |
| QTableView（只读、多选） | 匹配结果表：只读查询结果 |
| 导出 CSV/DB/TXT 按钮 | 导出为表格/数据库/文本格式 |
| 清空按钮/右键 | 结果集批量管理（非改数据） |

## 8. 约束满足说明

- 每个数据集合判定性质并据此定可写性与交互入口。
- 可批量操作对象均支持多选与批量执行。
- 操作入口按高频/元素级/低频分级，元素级操作经双击+右键。
- 只读集合无直接修改入口；可编辑多行集合用表格+行编辑。
- 每个控件均可说明领域模型依据（对应集合、操作、入口）。
