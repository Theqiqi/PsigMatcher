# 07 状态与反馈信息设计文档

- 版本：v0.1.0
- 前置：`06_交互模式设计.md`、`04_GUI需求分析.md`

## 1. 三类反馈信息与唯一显示位置

| 类别 | 定义 | 唯一显示位置 | 是否留存 |
| --- | --- | --- | --- |
| 持久状态 | 跨操作保持的状态（目标进程数、特征码数、扫描状态） | 状态栏**左侧固定区域**（专用标签） | 保持，随状态变化更新 |
| 瞬时反馈 | 当前操作结果/进度/短暂错误 | 状态栏**右侧反馈文本区** | 不留存，每次操作覆盖 |
| 历史日志 | 操作记录序列，可追溯 | 底部**日志 Dock（QPlainTextEdit 只读）** | 留存，可滚动/复制/清空 |

## 2. 分区原则

- **持久状态**：只在一个固定位置显示（状态栏左侧专用标签区）。同一持久状态不得同时出现在专用控件与状态栏两处。
- **瞬时反馈**：集中在状态栏反馈区，每次操作覆盖旧反馈，不留存历史。
- **历史日志**：用独立日志 Dock 承载（可滚动、可复制、可清空），**不得写入状态栏**。
- 状态栏**不得同时承担日志与瞬时反馈两类职责**：状态栏只有"持久状态区 + 瞬时反馈区"，日志一律进 Dock。

## 3. 错误提示分派

| 错误类型 | 呈现方式 | 位置 |
| --- | --- | --- |
| 短暂性错误（非法模式串、导出失败、读取失败） | 瞬时反馈（状态栏反馈区，红色文本） | 状态栏右侧 |
| 需要用户决策的错误（导入格式不符需选择、覆盖确认、无权限需提权提示） | 对话框 QMessageBox | 模态弹窗 |
| 同一错误只在一个位置呈现 | 瞬时反馈或对话框，二选一 | — |

## 4. 每个窗口的反馈信息点清单

### MainWindow / 全局
| 操作 | 产生反馈 | 显示位置 |
| --- | --- | --- |
| 应用启动 | 持久状态"进程 - / 特征码 - / 就绪" | 状态栏左 |
| 任意操作完成 | 瞬时文本 | 状态栏右 |
| 关键操作（导入/导出/扫描/错误） | 日志条目 | 日志 Dock |

### SignatureEditorPage
| 操作 | 反馈 | 位置 |
| --- | --- | --- |
| 新增/删除行 | "已新增行 / 已删除 N 行" | 状态栏右（瞬时）+ 日志 |
| 单元格编辑 | 持久状态"特征码 M"更新 | 状态栏左 |
| 非法模式串 | "特征码第 N 行模式非法"（红） | 状态栏右（瞬时） |
| 添加/删除列 | "列已更新" | 状态栏右（瞬时）+ 日志 |

### ProcessSelectionPage
| 操作 | 反馈 | 位置 |
| --- | --- | --- |
| 刷新进程 | "已枚举 N 个进程" | 状态栏右（瞬时）+ 日志 |
| 多选变化 | 持久状态"目标进程 K"更新 | 状态栏左 |
| 枚举失败 | 错误对话框 | 弹窗 |

### ResultPage
| 操作 | 反馈 | 位置 |
| --- | --- | --- |
| 扫描中 | 进度条 + "正在扫描 pid=X (i/N)" | 状态栏右（瞬时） |
| 扫描完成 | "命中 H 条" | 状态栏右（瞬时）+ 日志 |
| 导出完成 | "已导出: <路径>" | 状态栏右（瞬时）+ 日志 |
| 清空结果 | "结果已清空" | 状态栏右（瞬时）+ 日志 |

## 5. 无重复无遗漏核对

- 持久状态（进程数/特征码数/扫描状态）仅出现在状态栏左，未在其它控件重复。
- 瞬时反馈仅在状态栏右，不写入日志 Dock（日志 Dock 只记关键操作条目，属"历史日志"类）。
- 日志仅出现在日志 Dock，未写入状态栏。
- 每个窗口的全部反馈信息点已列出，无重复显示。

## 6. 约束满足说明

- 三类反馈各自唯一显示位置；状态栏不混合日志与瞬时反馈；同一持久状态不两处显示；错误按短暂/决策分派；每窗口反馈点齐全。
