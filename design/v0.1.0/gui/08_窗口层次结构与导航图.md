# 08 窗口层次结构与导航图

- 版本：v0.1.0
- 前置：`05_GUI功能列表与窗口定义.md`、`06_交互模式设计.md`、`07_状态与反馈信息设计.md`

## 1. Qt 控件层次结构

```
QApplication
└── MainWindow : QMainWindow
    ├── QMenuBar
    │   ├── 文件 : QMenu  (导入特征码 / 导出特征码 / 退出)
    │   ├── 编辑 : QMenu  (新增行 / 删除行 / 列管理…)
    │   ├── 扫描 : QMenu  (刷新进程 / 开始扫描 / 取消扫描)
    │   └── 帮助 : QMenu  (关于)
    ├── QToolBar
    │   ├── QAction 导入特征码 / 导出特征码
    │   └── QAction 刷新进程 / 选择进程 / 开始扫描 / 取消扫描
    ├── QStackedWidget (centralWidget)
    │   ├── SignatureEditorPage : QWidget
    │   │   ├── QVBoxLayout
    │   │   │   ├── QHBoxLayout (工具栏行)
    │   │   │   │   ├── QPushButton 新增行
    │   │   │   │   ├── QPushButton 删除行
    │   │   │   │   └── QPushButton 列管理
    │   │   │   └── QTableView  (SignatureTableModel, 可编辑)
    │   ├── ProcessSelectionPage : QWidget
    │   │   ├── QVBoxLayout
    │   │   │   ├── QHBoxLayout
    │   │   │   │   ├── QLineEdit 过滤
    │   │   │   │   ├── QPushButton 刷新进程
    │   │   │   │   └── QPushButton 全选
    │   │   │   └── QTableView (ProcessTableModel, 只读, ExtendedSelection)
    │   └── ResultPage : QWidget
    │       ├── QVBoxLayout
    │       │   ├── QHBoxLayout
    │       │   │   ├── QPushButton 导出CSV
    │       │   │   ├── QPushButton 导出DB
    │       │   │   ├── QPushButton 导出TXT
    │       │   │   └── QPushButton 清空
    │       │   └── QTableView (ResultTableModel, 只读)
    ├── QDockWidget "历史日志" (bottom)
    │   └── QPlainTextEdit (只读)
    └── QStatusBar
        ├── QLabel 持久状态区 (左, permanent widget)
        ├── QProgressBar 扫描进度
        └── QLabel 瞬时反馈区 (右)

弹出:
    QDialog ColumnManagerDialog
    QFileDialog (导入/导出)
    QMessageBox (决策型错误/确认)
```

## 2. 导航图

```
[启动]
   └─> MainWindow 显示 → 默认页 = SignatureEditorPage

菜单/工具栏 → 页面切换 (QStackedWidget.setCurrentIndex)
   (特征码编辑) <──> (进程选择) <──> (匹配结果)

SignatureEditorPage
   ├─ 新增行/删除行/双击编辑  → 就地编辑
   ├─ 列管理 → ColumnManagerDialog (模态)
   └─ 文件→导入/导出 → QFileDialog

ProcessSelectionPage
   ├─ 刷新进程 → 进程列表刷新
   └─ 多选 → 目标集合

ResultPage
   ├─ 导出CSV/DB/TXT → QFileDialog
   └─ 清空 → 结果集清空

扫描: 工具栏[开始扫描] → 进度反馈 → 完成 → 自动切到 ResultPage
```

## 3. 页面与集合对应

| 页面 | 数据集合 | 模型类 |
| --- | --- | --- |
| SignatureEditorPage | 特征码表、列定义集 | SignatureTableModel |
| ProcessSelectionPage | 进程列表 | ProcessTableModel |
| ResultPage | 匹配结果表 | ResultTableModel |
| 日志 Dock | 历史日志 | （QPlainTextEdit 直接承载） |

## 4. 约束满足说明

- 使用 Qt 控件术语（QMainWindow、QWidget、QDockWidget、QTableView、QStackedWidget 等）描述层次与导航。
