# 12 用户流程文档

- 版本：v0.1.0
- 前置：`11_GUI执行路径.md`、`10_GUI功能流程图.md`

> 用户流程 = VM 接收 View 事件触发业务流程（调静态库）的过程在 GUI 层的体现。
> 每个用户操作对应一个用户流程，覆盖正常/错误/取消路径。本文档是用户流程测试与 E2E 测试的依据。

## UF-01 导入特征码（CSV）
- 用户操作：点击工具栏[导入特征码] → 选择 `.csv`。
- View：`importAction` 触发。
- VM：`onImportSignatures()` → `psig::ImportSignaturesCsv(path)`。
- 反馈：成功 → 状态栏"已导入 N 条"，表格出现数据。
- 路径：正常=解析成功；错误=文件格式错误（红字/弹窗）；取消=对话框取消。
- 测试用例：`test_user_flow` UF01 正常/错误/取消。

## UF-02 导入特征码（DB）
- 同 UF-01，调用 `psig::ImportSignaturesDb(path)`；正常/错误/取消。

## UF-03 导出特征码（CSV/DB）
- 用户操作：点击[导出特征码] → 选文件。
- VM：`onExportSignatures()` → `psig::ExportSignatures{Csv,Db}`。
- 反馈：成功"已导出: path"；错误红字；取消无副作用。

## UF-04 编辑特征码单元格
- 用户操作：双击单元格 → 改值 → 回车。
- View：`QTableView` 提交 → `Model.setData`。
- 反馈：单元格更新；持久状态"特征码 M"不变（行数）；日志可选。
- 路径：正常=提交成功；错误=模式串非法（行标红 + 状态栏提示）。

## UF-05 新增特征码行
- 用户操作：点击[新增行]。
- VM：`Model.addRow()` → View 刷新。
- 反馈：新行出现；"特征码 M"更新。

## UF-06 删除特征码行（含批量）
- 用户操作：多选行 → 点击[删除行]。
- VM：取选中行 → `Model.removeRows()`。
- 路径：正常=删除 N 行；错误=未选行（提示）；无取消。

## UF-07 列管理
- 用户操作：编辑→列管理 → 增删改列 → 确定/取消。
- VM：取回列定义 → `Model.setColumns()`。
- 路径：正常=列更新；取消=不变。

## UF-08 刷新进程
- 用户操作：进程页点击[刷新进程]。
- VM：`QtConcurrent::run(psig::EnumerateProcesses)` → 结果回主线程 → `Model.setProcesses()`。
- 反馈：进程表刷新；"进程 N"。
- 路径：正常=枚举成功；错误=枚举失败。

## UF-09 选择目标进程（多选）
- 用户操作：Ctrl/Shift 多选 / 全选。
- VM：读 `selectionModel()` → 记录目标集合。
- 反馈：持久状态"目标进程 K"更新。

## UF-10 开始批量扫描
- 用户操作：点击[开始扫描]。
- VM：校验 → `QtConcurrent::run(psig::ScanProcesses(targets, patterns, cb))` → 进度信号 → `Model.setResults()` → 切结果页。
- 反馈：进度条、命中数、"命中 H 条"。
- 路径：正常=完成出结果；错误=校验失败/读取失败；取消=用户取消扫描。

## UF-11 取消扫描
- 用户操作：扫描中点击[取消扫描]。
- VM：`psig::RequestCancel()` → 后台返回部分结果 → 展示 → "已取消"。

## UF-12 导出匹配结果（CSV）
- 用户操作：结果页点击[导出CSV] → 选文件。
- VM：`psig::ExportResultsCsv(path, results)`。
- 路径：正常/错误（空结果、写失败）/取消。

## UF-13 导出匹配结果（DB）
- 同 UF-12 → `psig::ExportResultsDb`。

## UF-14 导出匹配结果（TXT）
- 同 UF-12 → `psig::ExportResultsTxt`。

## UF-15 清空结果
- 用户操作：点击[清空] → 确认。
- VM：`Model.clear()`。
- 路径：正常=清空；取消=弹窗选否。

## UF-16 查看/清空日志
- 用户操作：查看日志区 / 点击[清空日志]。
- VM/View：日志区清空。

## 用户流程 → 业务流程对应

| 用户流程 | 触发的静态库业务流程 |
| --- | --- |
| UF-01/02 | 导入特征码表（CSV/DB 解析） |
| UF-03 | 导出特征码表 |
| UF-08 | 枚举进程 |
| UF-10/11 | 批量特征码扫描 |
| UF-12/13/14 | 导出匹配结果 |
