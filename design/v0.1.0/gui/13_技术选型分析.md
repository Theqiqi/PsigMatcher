# 13 技术选型分析文档

- 版本：v0.1.0
- 前置：`05_GUI功能列表与窗口定义.md`

## 1. 默认技术栈（约束）

| 项 | 选型 |
| --- | --- |
| 程序类型 | Windows 桌面应用程序（exe） |
| 语言 | C++20 |
| 窗口框架 | Qt6 Widgets |
| Qt 模块 | Qt6::Widgets、Qt6::Concurrent |
| UI 构建 | 代码构建 Widget（优先） |
| 异步模型 | QtConcurrent::run + QFutureWatcher / QThread + 信号 |
| 资源管理 | .qrc 文件 |
| 测试框架 | gtest + QTest |
| 包管理 | vcpkg manifest（gtest）；Qt6 独立安装目录 |
| 静态库 | 独立静态库项目，经 find_library 引用其 out/lib/<配置> |

## 2. 本程序的技术选型理由

- 表格密集型界面 → Qt Widgets 的 QTableView + QAbstractTableModel 最合适。
- 进程内存扫描为耗时操作 → Qt6::Concurrent 异步 + 进度信号回主线程。
- 动态列（用户自由添加列）→ 自定义 QAbstractTableModel 支持可变列。
- 数据格式：CSV（表格）、SQLite `.db`（数据库）、TXT（结果文本）。
  - SQLite 属三方能力，**由静态库提供**（GUI 生产代码禁止三方库，只能经静态库公共 API）。
- 静态库命名：本程序为**进程特征码匹配**类，静态库命名为 **`psig`**（process-signature），不得命名为 `pmem`。

## 3. 分层（预览，详细见模块设计）

```
View (Qt Widgets)  ← 只画 UI
   ↑ 经公开 getter / 公开 UI 方法
ViewModel (QObject) ← 持 View* 指针，connect 控件信号，调静态库
   ↓ 调公共 API
Model (QAbstractTableModel) ← 纯数据
   ↓
psig 静态库 (无 Qt 依赖) ← Windows API + SQLite
```

## 4. 约束满足说明

- 符合默认技术选型；静态库命名依据程序类型（psig），未使用 pmem。
