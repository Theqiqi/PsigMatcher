# 18 静态库流程交接记录

- 版本：v0.1.0
- 发起方：GUI 入口系统流程（`.flow/带GUI的单体程序的GUI入口系统.md`）
- 跳转目标：**静态库流程的"跨流程需求接收"步骤**（`.flow/带GUI的单体程序的业务系统静态库.md` 第 2 步）
- 关联文档：`17_API缺失需求.md`、`14_API能力需求.md`

## 1. 交接内容

| 项 | 内容 |
| --- | --- |
| 缺失能力清单 | M1–M10（见 `17_API缺失需求.md`） |
| 期望公共 API | 见 `17_API缺失需求.md` 表格 |
| 输入输出 | 见 `17_API缺失需求.md` |
| 异常要求 | 失败经返回值/错误码/PsigError；不跨线程抛 |
| 验收标准 | 见 `17_API缺失需求.md` |
| 静态库命名 | `psig`（进程特征码匹配类；非 pmem） |
| 目标平台 | Windows x64，C++20，MSVC + Ninja |
| 三方依赖 | SQLite（静态库内部使用，vcpkg manifest 管理）；静态库**不得依赖 Qt** |

## 2. 交接要求

- 静态库流程须从"跨流程需求接收"开始，逐项接收 M1–M10，纳入静态库需求。
- 静态库实现必须使用真实底层能力（Windows API + SQLite），禁止模拟数据、硬编码结果、伪造 API。
- 静态库完成后须输出**静态库完成契约**（公共头文件、API 列表、out/lib/<配置> 产物、能力覆盖结果、测试结果），并跳回 GUI 流程的"静态库完成回退检查"。

## 3. GUI 侧冻结要求

- 在收到静态库完成契约前，GUI **停止 ViewModel 层对静态库调用的编码**。
- 不得使用模拟数据或假接口继续实现 ViewModel。
- View/Model 层可先行实现（不依赖静态库）。

## 4. 约束满足说明

- 已生成交接记录，明确跳转目标为静态库流程"跨流程需求接收"步骤；未宣称静态库流程已触发（待其完成契约）。
