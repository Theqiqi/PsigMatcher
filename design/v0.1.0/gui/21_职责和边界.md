# 21 GUI 职责和边界说明文档

- 版本：v0.1.0
- 前置：`20_GUI模块分析.md`

## View 层

- 职责：创建控件、布局、样式；暴露控件 getter（供 VM connect）；暴露公开 UI 方法（供 VM 更新界面）。
- 禁止：不 include ViewModel/静态库头文件；不声明 signals、不含 private slots、不写事件处理；不调业务；不 findChild 业务控件。
- 可单独编译（仅依赖 Qt + Model 层头文件）。

## Model 层

- 职责：管理数据（QAbstractTableModel 子类）；提供 data()/setData() 与结构方法。
- 禁止：不含业务逻辑；不调静态库；不持有 View/ViewModel；不做 I/O。

## ViewModel 层

- 职责：继承 QObject（含 Q_OBJECT）；持 `MainWindow* m_view`（绑定引用不拥有）；在 `install(MainWindow*)` 中集中 connect 控件信号；持 Model 指针并唯一负责其生命周期；调静态库公共 API；经 View 公开方法刷新 UI；耗时操作经 QtConcurrent::run 异步。
- 禁止：不 findChild 访问交互控件；不直接访问 View 私有成员；不自行实现静态库已有能力；不编造数据；不在主线程阻塞等待后台。

## main.cpp

- 职责：创建 Model → 创建 View（setModel）→ 创建 ViewModel（install(view)）→ show() → exec()。
- 禁止：不含业务逻辑。

## 静态库边界

- GUI 只经 `psig.h` 公共 API 调用；静态库不引用 Qt。

## 约束满足说明

- 每层定义清晰禁止项；View 不依赖 ViewModel/静态库，可单独编译；ViewModel 经 View* 指针操控 View 并链接事件。
