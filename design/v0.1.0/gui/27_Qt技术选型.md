# 27 Qt 技术选型文档

- 版本：v0.1.0
- 前置：`08_窗口层次结构与导航图.md`、`13_技术选型分析.md`

| 项 | 选型 |
| --- | --- |
| 程序类型 | Windows 桌面应用程序（exe），名 `psig_gui.exe` |
| 语言 | C++20 |
| 窗口框架 | Qt6 Widgets |
| Qt 版本 | Qt6（6.10.2）：Debug 共享版、Release 静态版（独立安装，非 vcpkg） |
| Qt 模块 | Qt6::Widgets、Qt6::Concurrent |
| UI 构建 | 代码构建 Widget |
| 异步 | QtConcurrent::run + QFutureWatcher |
| 资源 | res/resources.qrc（图标 + .qss） |
| 测试 | gtest + Qt6::Test（QSignalSpy/QTRY_VERIFY） |
| 包管理 | vcpkg manifest（gtest；Qt 独立安装） |
| 静态库链接 | find_library 引用 `../psig/out/lib/<配置>/psig.lib`，公共头 `../psig/include/psig.h` |

## Qt 环境变量

- Debug：`QT6_DEBUG_DIR` 默认 `C:/d/ccpplib/qt6.10.2-windows-x86_64-msvc2022-shared_debug`
- Release：`QT6_RELEASE_DIR` 默认 `C:/d/ccpplib/Qt_6.10.2-static-Release_msvc2022_64/msvc2022_64`

## 静态库命名

- 依据程序类型：`psig`（非 pmem）。

## 约束满足说明

- 符合默认技术选型；Qt6、代码构建 Widget、QtConcurrent、gtest+QTest；find_library 引用 psig 产物。
