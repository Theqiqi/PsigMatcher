# 30 编译环境需求（步骤 89）

- 版本：v0.1.0
- 前置：`27_Qt技术选型.md`、`gui/CMakePresets.json`

## 工具链需求

| 项 | 要求 |
| --- | --- |
| 操作系统 | Windows（x64） |
| 生成器 | Ninja（唯一允许；由 `gui/CMakePresets.json` 各预设 `generator` 决定） |
| 编译器 | MSVC（cl.exe），经 `vcvars64.bat` 初始化；不允许 mingw/gcc/clang |
| CMake | ≥ 3.20（实测 VS2022 自带 3.31） |
| C++ 标准 | C++20 |
| 构建桥接 | WSL → cmd.exe → `.bat` → `vcvars64.bat` → MSVC + Ninja |

## Qt6（独立安装，非 vcpkg）

| 配置 | 版本与形态 | 定位变量 | 默认路径 |
| --- | --- | --- | --- |
| Debug | Qt 6.10.2 共享版（/MDd） | `QT6_DEBUG_DIR` | `C:/d/ccpplib/qt6.10.2-windows-x86_64-msvc2022-shared_debug` |
| Release | Qt 6.10.2 静态版（/MT） | `QT6_RELEASE_DIR` | `C:/d/ccpplib/Qt_6.10.2-static-Release_msvc2022_64/msvc2022_64` |

- Qt 模块：`Qt6::Widgets`、`Qt6::Concurrent`、`Qt6::Test`（测试）。
- 经 `gui/CMakePresets.json` 的 `CMAKE_PREFIX_PATH`（Debug=`$env{QT6_DEBUG_DIR}`、Release=`$env{QT6_RELEASE_DIR}`）接入，不经过 vcpkg。
- 编译脚本内置兜底值，允许以持久化系统/用户环境变量覆盖。

## 三方库（vcpkg manifest）

| 项 | 要求 |
| --- | --- |
| 包管理 | vcpkg manifest（`gui/vcpkg.json`），经 `CMAKE_TOOLCHAIN_FILE` 接入 |
| 依赖 | 仅 `gtest`（测试用）；不得出现 `qtbase` |
| Triplet | Debug=`x64-windows`（/MDd）；Release=`x64-windows-static`（/MT） |
| 基线 | `builtin-baseline` 与 `psig/vcpkg.json` 一致 |
| 下载规避 | 脚本在 vcpkg/CMake 操作前设 `GIT_SSL_NO_VERIFY=1` |

## 静态库链接

- `find_library(PSIG_LIB NAMES psig PATHS ${CMAKE_SOURCE_DIR}/../psig/out/lib/${CMAKE_BUILD_TYPE})`。
- 公共头：`../psig/include/psig.h`。
- 需先编译 `psig`（Debug/Release 对应产物存在）。

## 运行时库策略

- Debug：`CMAKE_MSVC_RUNTIME_LIBRARY=MultiThreadedDebugDLL`（/MDd），共享 Qt。
- Release：`CMAKE_MSVC_RUNTIME_LIBRARY=MultiThreaded`（/MT），静态 Qt。
