# 33 管理员权限指南（跨进程扫描）

- 版本：v0.1.0
- 适用：集成测试 / 用户流程测试 / E2E 中涉及「跨进程读取其他进程内存」的用例

## 何时需要管理员权限

`psig` 打开目标进程使用 `OpenProcess(PROCESS_QUERY_INFORMATION | PROCESS_VM_READ, ...)`。对以下目标需要 **SeDebugPrivilege（管理员令牌）** 才能成功：

- 以更高完整性级别运行 / 系统会话中的进程（如 `services.exe`、其他用户会话进程）；
- 受保护进程（PPL）。

对 **本进程自身** 及同用户、同完整性级别的普通进程，无需管理员权限即可扫描。

## 各用例的权限需求

| 用例 | 目标 | 是否需管理员 |
| --- | --- | --- |
| 集成测试 `test_mvvm_flow`（扫描自身 marker） | 本进程 | 否 |
| 用户流程测试 `test_user_flow`（扫描自身后导出） | 本进程 | 否 |
| E2E 扫描自身 / `psig_gui_target.exe` | 本进程 / 同用户测试目标 | 否 |
| E2E 扫描系统进程（如需） | 系统/其他用户进程 | 是 |

> 本项目的自动化用例默认扫描 **自身** 或同用户测试目标，因此**默认无需管理员权限即可全部通过**。仅当人工验证「扫描系统进程」场景时才需要提权。

## 提权方式

- **Windows GUI**：`Start-Process -Verb RunAs`（UAC 弹窗点「是」；UAC「从不通知」时静默提权）。
  - 便捷启动脚本：`gui/script/run_gui_admin.bat`（Release）、`run_gui_admin_debug.bat`（Debug）。
- **WSL 驱动脚本**：`sudo` / `wsl -u root`。

## 环境跳过约定

- 若当前无管理员令牌且用例目标是受保护/系统进程 → 该用例标记 **「环境跳过」** 并在结果中如实报告，不计为失败。
- 项目当前用例集合均不需要提权，故不触发环境跳过。
