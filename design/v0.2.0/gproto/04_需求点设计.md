# 04 需求点设计（psig v0.2.0）

> 前置：`03_需求分析.md`

## 需求点 → 设计

| 需求点 | 设计要点 |
| --- | --- |
| R-1 | `Table` 增 `std::string templateText`。CSV：文件最前写入一条模板记录 `#psig-template,<转义模板>`；导入时若首条记录首字段为 `#psig-template` 则提取模板，其余按 CSV 解析。DB：新增 `sig_meta(key,value)` 表，`key='template'`。 |
| R-2 | `MatchResult` 增 `std::string custom`。 |
| R-3 | 结果导出新增 `ResultExportOptions{ templateText, columns }`（默认参数）。TXT：模板置于文件最前；CSV：前置 `#psig-template,<转义模板>`；DB：`result_meta(key,value)`。 |
| R-4 | `ResultExportOptions.columns` 为结果列键列表；空=全部；导出时按序过滤表头与行值。 |

## 结果列键（用于列选择）

| 键 | 标题 |
| --- | --- |
| pattern_name | 特征码名 |
| process_name | 进程 |
| pid | PID |
| address | 地址 |
| module_name | 模块 |
| module_base | 模块基址 |
| matched_bytes | 匹配字节 |
| hit_time | 命中时间 |
| custom | 自定义 |

> 十进制地址为 GUI 显示派生列，不进入导出（避免数据重复）。

## 约束满足说明

- 仅设计改动点对应需求点。
