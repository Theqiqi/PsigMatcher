# 05 业务流程变更（psig v0.2.0）

> 前置：`04_需求点设计.md`、`design/v0.1.0/gproto/05_业务流程分析.md`（基线）

## 变更业务流程

### BP-1 特征码表导出（含模板）
输入 Table（含 templateText）→ 组织 CSV：写入模板前置记录 → 写入表头/数据 → 落盘；或组织 DB：建 `sig_columns`/`sig_rows`/`sig_meta` → 写入 → 关闭。

### BP-2 特征码表导入（含模板）
读文件 → 若 CSV 首记录为模板记录 → 提取模板，其余解析为表；若 DB 含 `sig_meta` → 读模板 → 组装 Table。

### BP-3 结果导出（含模板/自定义列/选列）
输入 results（含 custom）+ options（templateText/columns）→ 按选中列过滤 → 写模板（TXT 最前 / CSV 前置记录 / DB 元数据）→ 写数据行 → 落盘。

## 约束满足说明

- 仅列出受改动影响的业务流程；其余（枚举/扫描）不变，引用 v0.1.0。
