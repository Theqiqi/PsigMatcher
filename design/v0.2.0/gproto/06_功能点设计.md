## 功能点

| 功能点 | 说明 |
| --- | --- |
| FP-1 模板前置记录序列化 | CSV 文件最前写入/解析 `#psig-template` 记录 |
| FP-2 DB 元数据读写 | `sig_meta`/`result_meta` 读写模板 |
| FP-3 结果自定义列写入 | `MatchResult.custom` 参与结果行组织 |
| FP-4 结果列选择 | 按 `columns` 过滤表头与行值 |
| FP-5 结果模板写入 | TXT/CSV/DB 三格式写入模板 |
