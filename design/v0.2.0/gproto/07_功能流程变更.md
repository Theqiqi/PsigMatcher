# 07 功能流程变更（psig v0.2.0）

> 前置：`06_功能点设计.md`

## 功能流程

### FP-1 模板前置记录序列化（CSV）
```
导出：Table → [有 templateText?] --是--> 写 "#psig-template," + EscapeField(template) + CRLF
                              --否--> 跳过
       → 写表头 → 写数据行 → 落盘
导入：读文本 → 取首条 CSV 记录 → [首字段 == "#psig-template"?]
                              --是--> templateText = 第二字段；rest = 其余文本 → ParseCsv(rest)
                              --否--> templateText = ""；ParseCsv(全文)
```

### FP-2 DB 元数据读写
```
导出特征码：建 sig_columns/sig_rows/sig_meta → sig_meta('template', templateText)
导入特征码：[表 sig_meta 存在?] --是--> 读 value → templateText
导出结果：建 results/result_meta → result_meta('template', templateText)
```

### FP-3 结果自定义列写入
```
ResultRow(m) → {…, m.custom}（追加为末列）
```

### FP-4 结果列选择
```
columns 空 → 用全部列键
columns 非空 → 按列键顺序过滤 headers 与每行值
```

### FP-5 结果模板写入
```
TXT：首行写 templateText（非空时）+ 分隔线，再写结果列表
CSV：前置 "#psig-template," 记录，再写表头/数据
DB：result_meta 存储
```
