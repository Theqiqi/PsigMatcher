## API 接口列表（变更）

| API | 变更 |
| --- | --- |
| `ImportSignaturesCsv(path, err) -> Table` | 返回 `Table`（含 `templateText`） |
| `ImportSignaturesDb(path, err) -> Table` | 同上 |
| `ExportSignaturesCsv(path, table, err) -> bool` | 写入 `table.templateText` |
| `ExportSignaturesDb(path, table, err) -> bool` | 同上（`sig_meta`） |
| `ExportResultsCsv(path, results, err, options = {}) -> bool` | **签名变更**：新增 `ResultExportOptions` |
| `ExportResultsDb(path, results, err, options = {}) -> bool` | 同上 |
| `ExportResultsTxt(path, results, err, options = {}) -> bool` | 同上 |
| `MatchResult` | **字段变更**：+ `custom` |
| `Table` | **字段变更**：+ `templateText` |
| `ResultExportOptions` | **新增结构**：`templateText` + `columns` |
