# 12 接口细化设计（psig v0.2.0）

> 前置：`11_api接口分析.md`
> 产物：数据结构列表、算法列表、原子化 API 列表、API 接口异常设计。

## 1. 数据结构列表（变更）

| 结构 | 变更 |
| --- | --- |
| `Table` | + `std::string templateText` |
| `MatchResult` | + `std::string custom` |
| `ResultExportOptions` | 新增：`std::string templateText`、`std::vector<std::string> columns` |

## 2. 算法列表（变更）

| 算法 | 层 | 职责 |
| --- | --- | --- |
| `EncodeTemplateRecord(template)` | algorithm | 生成 `#psig-template,<escaped>\r\n` 前置记录 |
| `ParseTemplateRecord(text, template, rest)` | algorithm | 解析前置记录；无则 template 空、rest=原文 |
| `ResultColumnDefs()` | algorithm | 结果列键/标题表 |
| `FilterResultColumns(keys, headers, rows)` | algorithm | 按列键过滤表头与行 |

## 3. 原子化 API 列表（变更）

| API | 变更 |
| --- | --- |
| `SqliteExec/SqliteRun/SqliteQuery` | 复用（建 `sig_meta`/`result_meta`） |
| `ReadTextFile/WriteTextFile` | 复用 |

> 无新增原子化 API（现有能力足够）。

## 4. API 接口异常设计

| 场景 | 处理 |
| --- | --- |
| 文件不可读写 | 置 `err`，返回空表 / false |
| 旧 CSV 无模板记录 | `templateText=""`，不报错 |
| 旧 DB 无 `sig_meta`/`result_meta` | 模板为空，不报错 |
| `columns` 为空 | 视为全部列 |
| `columns` 含未知键 | 忽略该键（静态库流程定：忽略，不报错） |
| 模板含 `,`/`"`/换行 | 由 CSV 转义（`""`/引号包裹）保证往返一致 |

## 约束满足说明

- 已提取数据结构/算法/原子化 API 并设计异常。
