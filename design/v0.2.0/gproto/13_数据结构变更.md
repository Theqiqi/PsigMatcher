# 13 数据结构变更（psig v0.2.0）

> 前置：`12_接口细化设计.md`、`design/v0.1.0/gproto/13_数据结构分析.md`（基线）

## 变更（定义在公共头 `psig/include/psig.h`）

```cpp
struct Table {
    std::vector<ColumnDef> columns;
    std::vector<TableRow> rows;
    std::string templateText;   // 新增
};

struct MatchResult {
    std::string patternName;
    uint32_t pid = 0;
    std::wstring processName;
    uint64_t address = 0;
    std::wstring moduleName;
    uint64_t moduleBase = 0;
    std::string matchedBytes;
    std::string hitTime;
    std::string custom;         // 新增
};

struct ResultExportOptions {    // 新增
    std::string templateText;
    std::vector<std::string> columns;
};
```

## 独立性

- 均为纯数据（POD + std 容器），不依赖 Qt、不依赖平台 API。

## 约束满足说明

- 数据结构独立、无平台依赖。
