# 06 交互模式设计（v0.2.0，增量）

> 前置：`02_领域模型.md`、`05_GUI功能列表与窗口定义.md`、`design/v0.1.0/gui/06_交互模式设计.md`（基线）
> 说明：仅重新设计**受改动影响的集合/窗口**；其余引用 v0.1.0。

## 1. 操作入口分级原则（本次应用）

| 级别 | 定义 | 本次落点 |
| --- | --- | --- |
| 高频全局 | 全局/跨页常用 | 工具栏动作（按页显隐） |
| 元素级 | 作用于表格中「选中的行」 | **表格右键菜单**（+ 双击） |
| 低频 | 偶尔使用 | 菜单栏 |

依据：v0.1.0 需求「操作入口分级：高频全局→按钮；元素级→双击+右键；低频→菜单」。
本次将「元素级」操作（增删行、列管理、导出、批量填充）统一收敛到**表格右键菜单**，正是对既有分级原则的贯彻。

## 2. 各集合的交互设计（增量）

### 集合 A：特征码表（可编辑条目集，多选）
- 选择模式：多选（`ExtendedSelection`，按行选择）——不变。
- 操作入口（**修改**）：
  - `新增行`：表格**右键菜单**（元素级）＋ 菜单栏「编辑」＋ 快捷键 Ctrl+N。
  - `删除选中行`：表格**右键菜单**（支持单行/多选批量）＋ 菜单栏「编辑」。
  - `列管理`：表格**右键菜单**＋ 菜单栏「编辑」＋ 快捷键 Ctrl+M。
  - **移除**页面顶部按钮条（原 `新增行/删除行/列管理` 按钮）。
- 可写性：可编辑（增删改）——不变。

### 集合 D：匹配结果表（**受限可编辑结果集**，多选）
- 选择模式：多选（`ExtendedSelection`，按行选择）。
- 操作入口（**新增/修改**）：
  - `删除选中行`：表格**右键菜单**（单行/多选批量）。
  - `导出 ▸ {CSV, DB, TXT}`：表格**右键菜单**的二级子菜单（**移除**顶部导出按钮）。
  - `选择导出列…`：右键菜单（打开列勾选对话框）。
  - `批量填充自定义列`：右键菜单（对选中/全部行填充模板文本或指定文本）。
  - `清空结果`：右键菜单＋ 结果页工具栏。
- 可写性：**受限可写**——仅**末列「自定义」**可写（单格双击编辑 / 多选/全选批量填充）；命中数据列只读。
- 形态：表格（多选），末列可编辑；顶部附**多行模板文本编辑区**（表级元数据）。

### 集合 C：进程列表（只读查询结果，多选）
- 选择模式：多选——不变。
- 操作入口（**新增**）：
  - `确认选择（进入特征码页）`：**双击**进程行 / 表格**右键菜单**「以此进程为目标」/ 工具栏动作。
  - `刷新进程`、`全选`：进程页工具栏动作（**移除**页面内按钮）。
- 可写性：只读——不变。

## 3. 窗口级交互（增量）

### 主窗口导航（C-04）
- 启动：当前页 = 进程页；视图菜单中「进程选择」项禁用/隐藏（已处于该页），「特征码编辑」「匹配结果」不可用（未选定进程前）。
- 选定进程后：自动切到特征码页；隐藏「进程选择」导航项与进程相关工具栏动作；显示「重新选择进程」。
- 回退：点「重新选择进程」→ 切回进程页，恢复进程页入口，清空/保留目标（保留已选，便于再次确认）。

### 关于（C-10）
- 低频 → 菜单栏「帮助 → 关于」→ 模态对话框。

### 导入前置询问（C-11）
- 元素级流程前置：导入触发后，表非空 → 三选一询问（保存 / 不保存 / 取消）。

## 4. 约束满足说明

- 集合性质决定可写性与入口：结果集受限可写 → 仅末列编辑与行删除；其余只读。
- 可批量操作（删除、填充）均支持多选与批量执行。
- 操作入口分级已贯彻：全局高频→工具栏；元素级→右键/双击；低频→菜单。
- 仅重设计受改动影响的集合/窗口，其余引用 v0.1.0。
