# 07 状态与反馈信息设计（v0.2.0，增量）

> 前置：`06_交互模式设计.md`、`04_GUI需求分析.md`、`design/v0.1.0/gui/07_状态与反馈信息设计.md`（基线）
> 说明：三类反馈信息各自唯一显示位置；本次新增功能产生的反馈点必须补齐设计。

## 1. 三类反馈信息的唯一显示位置（沿用 + 增量）

| 类别 | 唯一显示位置 | 本次变更 |
| --- | --- | --- |
| 持久状态 | 状态栏左侧持久区（`persistentLabel`） | 增加「目标进程」维度：`就绪 \| 目标 <名称/pid 或 -> \| 进程 N \| 特征码 M` |
| 瞬时反馈 | 状态栏右侧瞬时区（`transientLabel`） | 保留；**移除**原「关于」信息写入此区的用法（改为对话框） |
| 历史日志 | 底部「历史日志」Dock（`logEdit`） | 新增事件：确认目标进程、重新选择进程、删除结果行、批量填充、导入前询问结果、模板文本更新 |

## 2. 新增/变更反馈点清单

| 触发 | 类别 | 分派 | 文案/表现 |
| --- | --- | --- | --- |
| 确认选择进程（C-04） | 持久 + 瞬时 + 日志 | 状态栏 + 日志 | 持久区「目标 pid=…」；瞬时「已选定目标：<name> (pid)」；日志 `[导航] 选定目标 …` |
| 重新选择进程（C-04） | 瞬时 + 日志 | 状态栏 + 日志 | 瞬时「请重新选择目标进程」；日志 `[导航] 返回进程页` |
| 特征码删行（C-06） | 瞬时 + 日志 | 状态栏 + 日志 | 无选择时瞬时错误「请先选择要删除的行」；成功「已删除 N 行」 |
| 结果删行（C-06） | 瞬时 + 日志 | 状态栏 + 日志 | 同上（作用于结果集） |
| 末列自定义编辑（C-08） | 持久（表内即反馈） | 表格 | 单格编辑即时显示；批量填充后瞬时「已填充 N 行自定义列」 |
| 模板文本更新（C-07） | 瞬时 + 日志 | 状态栏 + 日志 | 「模板文本已更新」；日志 `[结果] 模板文本 N 字` |
| 选择导出列（C-07） | 瞬时 | 状态栏 | 「将导出 N 列」 |
| 导出结果（C-05） | 瞬时 + 日志 | 状态栏 + 日志 | 「已导出: <path>」/ 失败「导出失败: <err>」 |
| 关于（C-10） | **需决策/信息** | **模态对话框** | 弹出 AboutDialog（程序/版本/静态库/Qt） |
| 导入前询问（C-11） | **需决策** | **模态对话框** | 「当前特征码表可能未保存，是否先保存？」保存/不保存/取消 |

## 3. 错误分派原则（沿用 v0.1.0，本次适用点）

- **短暂性错误**（可继续操作）→ 瞬时反馈区（红色）：如「无结果可导出」「未选择目标进程」「特征码模式非法」。
- **需决策错误 / 需用户确认**→ 模态弹窗：如导入前保存询问、清空结果确认、关于信息。

## 4. 约束满足说明

- 三类反馈各自唯一位置：持久→状态栏左区；瞬时→状态栏右区；日志→历史日志 Dock。
- 错误按短暂性/需决策分派弹窗或瞬时反馈。
- 本次新增功能（确认进程、删行、批量填充、选列导出、模板文本、关于弹窗、导入前询问）的反馈信息点已全部补齐。
