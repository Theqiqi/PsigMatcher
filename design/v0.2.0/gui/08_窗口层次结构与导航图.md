## 1. 窗口层次（增量，Qt 控件术语）

```
QMainWindow (MainWindow)
├── QMenuBar
│   ├── 文件(&F): 导入特征码 / 导出特征码 / 退出
│   ├── 编辑(&E): 新增行 / 删除选中行 / 列管理          [修改：删除行拆出]
│   ├── 扫描(&S): 刷新进程 / 开始扫描 / 取消扫描
│   ├── 视图(&V): 进程选择* / 特征码编辑 / 匹配结果 / 重新选择进程* / 清空日志   [修改：新增 重新选择进程，进程选择可隐藏]
│   └── 帮助(&H): 关于                                  [修改：→ 弹窗]
├── QToolBar（主工具栏，ToolButtonIconOnly）             [修改：图标化 + 按页显隐]
│   ├── 进程页组: 刷新进程 / 全选 / 确认选择
│   ├── 特征码页组: 导入 / 导出 / 开始扫描 / 取消扫描 / 重新选择进程
│   └── 结果页组: 清空结果 / 重新选择进程
├── QStackedWidget (centralWidget)
│   ├── [0] SignatureEditorPage
│   │   └── QTableView（+ 右键 QMenu: 新增行/删除选中行/列管理）   [修改：移除按钮条]
│   ├── [1] ProcessSelectionPage
│   │   ├── QLineEdit 过滤
│   │   └── QTableView（+ 右键 QMenu: 以此进程为目标/刷新/全选）    [修改：移除按钮]
│   └── [2] ResultPage
│       ├── QPlainTextEdit 模板文本区                             [新增]
│       └── QTableView（+ 右键 QMenu: 导出▸{CSV,DB,TXT}/选择导出列/删除选中行/清空）  [新增]
├── QDockWidget「历史日志」: QPlainTextEdit
└── QStatusBar: persistentLabel | progressBar | transientLabel
```

对话框：
```
ColumnManagerDialog (QDialog)               [不变]
AboutDialog (QDialog)                       [新增]
QFileDialog / QMessageBox                   [复用]
```

## 2. 导航图（增量）

```
[启动] ──► 进程页(ProcessPage)
             │  双击进程行 / 工具栏「确认选择」 / 右键「以此进程为目标」
             ▼
          特征码页(SignaturePage)  ◄──►  结果页(ResultPage)
             │                                   ▲
             │ 开始扫描                           │ 扫描完成自动跳转
             └───────────────────────────────────┘

任意时点：工具栏/视图菜单「重新选择进程」──► 进程页
```

- **启动落点变更**：由 v0.1.0 的「特征码页」改为**进程页**。
- **显隐规则**：未确认目标进程前，视图菜单「进程选择」不可用、特征码/结果页入口置灰；确认后隐藏「进程选择」入口，显示「重新选择进程」。

## 3. 约束满足说明

- 使用 Qt 控件术语（QMainWindow、QStackedWidget、QTableView、QPlainTextEdit、QToolBar、QMenu、QDockWidget、QStatusBar）。
- 仅更新受影响窗口（主窗口/三页/关于对话框）的层次与导航关系，其余引用 v0.1.0。
