# 12 用户流程（v0.2.0，增量）

> 前置：`11_GUI执行路径.md`、`10_GUI功能流程图.md`、`design/v0.1.0/gui/12_用户流程.md`（基线）
> 说明：每个用户操作对应一个用户流程；覆盖正常/错误/取消路径；作为用户流程测试与 E2E 测试依据。

## 流程模板

`用户操作 → View 发射信号 → VM 接收事件 → 业务流程（含 psig 调用）→ 结果反馈 → View 刷新`

## 新增/修改用户流程

### UF-A1 启动进入进程页（C-04，正常）
用户启动程序 → MainWindow 构建 → VM::install → `applyToolbarForPage(进程页)` + `setProcessSelectionLocked(false)` → View 显示进程页，仅进程页工具栏 → 状态栏「就绪 | 目标 - | 进程 0 | 特征码 N」。

### UF-A2 选择目标进程（C-04，正常/错误）
- 正常：进程页 `刷新进程` → `EnumerateProcesses()`（QtConcurrent）→ `onProcessesEnumerated` → ProcessTableModel::setProcesses → 表格显示；用户过滤/多选 → 双击/确认 → `onConfirmProcessSelection` → 记录目标 → `setProcessSelectionLocked(true)` + `showSignaturePage()` → 特征码页可见，进程页入口隐藏，状态栏显示目标。
- 错误：未选行点确认 → View 信号 `QAction::triggered` → VM 校验 → 瞬时错误「请先选择目标进程」，停留进程页。
- 取消：不触发确认（停留在进程页）。

### UF-A3 重新选择进程（C-04，正常）
特征码/结果页点「重新选择进程」→ `onReselectProcess` → `setProcessSelectionLocked(false)` + `showProcessPage()` → 进程页恢复入口 → 瞬时/日志。

### UF-A4 特征码表行操作（C-02/C-06，正常/错误/取消）
- 正常：右键特征码表格 → 菜单 → `新增行`/`删除选中行`/`列管理` → 对应 VM 槽 → Model 变更 + View 刷新 + 反馈。
- 错误：`删除选中行` 无选中 → 瞬时错误。
- 取消：菜单 ESC；列管理 Cancel。

### UF-A5 结果表行操作与末列编辑（C-06/C-08，正常/错误/取消）
- 正常：右键结果表格 → `删除选中行`/`批量填充自定义列`；或双击末列单格编辑 → Model 更新 + 刷新 + 反馈。
- 错误：批量填充无选中 → 瞬时错误。
- 取消：编辑 ESC。

### UF-A6 结果导出（右键二级，C-05，正常/错误/取消）
- 正常：右键 → 导出▸CSV/DB/TXT → 选路径 → `ExportResults*`（携带模板 + 自定义列 + 选中列）→ 瞬时「已导出」。
- 错误：无结果（导出项禁用）；psig 失败 → 瞬时错误。
- 取消：文件对话框取消。

### UF-A7 模板文本维护与随表携带（C-07，正常）
结果页编辑模板区 → `onTemplateTextChanged` → 暂存 → 导出时写入；导入特征码表（含 templateText）→ `applyTableToModel` 后回填模板区 → View 刷新。

### UF-A8 选择导出列（C-07，正常/错误/取消）
右键 → 选择导出列… → 勾选 → 确认 → 记录 → 反馈；未勾选 → 错误；Cancel → 保持。

### UF-A9 关于弹窗（C-10，正常/取消）
帮助→关于 → `onAbout` → AboutDialog::exec → 显示信息 → 确定/ESC 关闭。

### UF-A10 导入前保存询问（C-11，正常/错误/取消）
- 正常：导入触发 → 表非空 → 询问「保存」→ 保存成功 → 选文件 → 导入成功（表 + 模板回填）。
- 错误：导入失败 → 瞬时「导入失败: <err>」。
- 取消：询问「取消」或保存对话框取消 → 中止导入。
