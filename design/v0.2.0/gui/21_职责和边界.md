# 21 职责和边界（v0.2.0，增量）

> 前置：`20_GUI模块分析.md`、`design/v0.1.0/gui/21_职责和边界.md`（基线）

## 各层职责与禁止项（本次适用点）

| 层 | 职责 | 禁止项 |
| --- | --- | --- |
| View | 构建控件、暴露控件 getter 与**公开 UI 方法**、提供**右键菜单 getter**（QMenu + QAction）与对话框类；执行显隐（`setProcessSelectionLocked`、`applyToolbarForPage`） | **不写 connect**、无 signals/private slots、不 include ViewModel/psig、不调业务 |
| Model | `ResultTableModel`：列定义、`data/setData/flags`、`removeRows/setCustom`；纯 Qt | 不依赖 psig、不含业务格式化（十进制地址为派生显示，允许） |
| ViewModel | 持 `View*`；集中 connect（含右键菜单 QAction）；调 psig 公共 API；更新 Model；调 View 公开方法刷新 | 不用 findChild 访问交互控件；不自行实现静态库能力 |
| 静态库 | psig 提供模板/自定义列/选列能力 | 不依赖 Qt |

## 边界确认（本次）

- View 提供 `QMenu* xxxContextMenu()` getter；菜单内 `QAction` 由 View 创建，**connect 在 ViewModel**（满足「View 零 connect」）。
- View 提供 `void setProcessSelectionLocked(bool)`、`void applyToolbarForPage(...)` 等公开方法，由 VM 调用以切换显隐。
- 关于/选列对话框由 View 定义；VM 负责 `exec()` 并读取结果（对话框 getter）。
- 模板文本由 View（QPlainTextEdit）承载、VM 读写；`psig::Table.templateText` 由 VM 传递。

## 约束满足说明

- 每层禁止项清晰；View 不依赖 ViewModel/静态库；ViewModel 经 `View*` 指针操控 View。
