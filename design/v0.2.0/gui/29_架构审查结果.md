# 29 架构审查结果（步骤 31）

- 版本：v0.2.0
- 前置：`design/v0.2.0/gui/21_职责和边界.md`、`22_View层接口.md`、`24_ViewModel接口.md`、`design/v0.1.0/gui/29_实现审查结果.md`（基线）
- 说明：修改型流程，仅审查本次改动涉及的 View/ViewModel/Model 文件；其余沿用 v0.1.0 审查结论。
- 审查对象：`gui/src/{view,model,viewmodel}`、`gui/src/main.cpp`

## 检查项与结论（均通过）

### 1. View 纯净可独立编译 — 通过
- `src/view/` 无 `signals:`/`slots:`/`Q_SIGNALS`/`Q_SLOTS`（grep 无命中）。
- `src/view/` 无 `connect(`（grep 无命中），View 不承载任何事件逻辑。
- 新增 `aboutdialog.*`、`exportcolumnsdialog.*` 仅创建控件 + 布局，无业务逻辑。
- 独立目标 `psig_test_view` 仅链接 `Qt6::Widgets Qt6::Test GTest`，源文件为 View + Model，不链接 ViewModel/`psig`；Debug/Release 均编译链接通过。

### 2. VM 持指针链接事件 — 通过
- `MainViewModel` 持 `MainWindow* m_view`（绑定引用、不拥有），经 `install(MainWindow*)` 注入。
- 页面/控件指针全部经 View 公开 getter 获取（`m_view->signaturePage()->addRowAction()` 等），不缓存私有成员，无 `findChild`（grep 无命中）。

### 3. 后台执行不阻塞 — 通过
- 耗时操作（`psig::EnumerateProcesses`、`psig::ScanProcesses`）经 `QtConcurrent::run` 后台执行，用 `QFutureWatcher::finished` 回主线程。
- 主线程无 `QThread::wait()`；仅析构函数 `~MainViewModel` 中 `waitForFinished()`（退出路径，非热路径）。
- 扫描进度经 `QMetaObject::invokeMethod(..., Qt::QueuedConnection)` 回主线程刷新 UI。

### 4. Model 纯净 — 通过
- `model/resulttablemodel.*` 只 `#include` Qt 与 `model/types.h`；新增的「地址(十进制)」列与「自定义」列格式化/可编辑逻辑均在 Model 内，不含业务逻辑、不 include `psig.h`。

### 5. 事件集中 connect — 通过
- 全部控件信号（`QAction::triggered`、`QLineEdit::textChanged`、`QPlainTextEdit::textChanged`、`QTableView::doubleClicked`、`QWidget::customContextMenuRequested`、`QFutureWatcher::finished`）均在 VM 的 `install()/bind*()` 中 connect。
- `bindContextMenus()` 集中绑定三页表格的 `customContextMenuRequested`；无重复 connect。

### 6. 页面拆分 — 通过
- 页面为独立类独立文件：`SignatureEditorPage`、`ProcessSelectionPage`、`ResultPage`；对话框独立文件：`ColumnManagerDialog`、`AboutDialog`、`ExportColumnsDialog`。
- `MainWindow` 仅骨架（`QStackedWidget` + 菜单/工具栏 + 状态栏/日志），不内联页面控件。
- 页面切换经 `MainWindow::showSignaturePage()/showProcessPage()/showResultPage()` 由 VM 调用。

### 7. 控件 getter 暴露 — 通过
- 需绑定控件均有公开 getter：`SignatureEditorPage::table()/contextMenu()/addRowAction()/deleteRowsAction()/manageColumnsAction()`；`ProcessSelectionPage::table()/filterEdit()/contextMenu()/useAsTargetAction()/refreshAction()/selectAllAction()`；`ResultPage::table()/templateEdit()/contextMenu()/export*Action()/selectColumnsAction()/deleteRowsAction()/fillCustomAction()/clearAction()`；`MainWindow` 全局动作与状态控件 getter。

### 8. connect 归属 — 通过
- 右键菜单动作（`addRowAction` 等）由 VM connect；View 只提供 `contextMenu()` 供 VM `exec()`（`onSignatureContextMenu` 等），菜单弹出时机属交互事件、由 VM 控制。

### 9. 布局交互合理性 — 通过
- 工具栏 `ToolButtonIconOnly` 图标化；`applyToolbarForPage()` 按当前页显隐动作；`setProcessSelectionLocked()` 控制「进程选择/重新选择进程」显隐，与导航一致。

### 10. main.cpp 固定流程 — 通过
- 顺序为：创建 `MainWindow view` → 创建 `MainViewModel viewModel` → `viewModel.install(&view)` → `view.show()` → `app.exec()`。

## 结论

本次改动涉及的架构检查项全部通过；无需回退。
