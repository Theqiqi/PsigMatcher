## 检查项与结论（均通过）

### 1. 真实数据与接口来源 — 通过
- 无 mock/fake/stub/硬编码结果：`grep -niE "mock|fake|stub|hardcode" src/` 无命中。
- 数据来源真实：
  - 进程表 ← `psig::EnumerateProcesses()` 异步枚举。
  - 匹配结果 ← `psig::ScanProcesses(req, cb, cancelPtr)` 真实扫描目标进程内存。
  - 特征码表导入/导出 ← `psig::ImportSignatures{Csv,Db}` / `ExportSignatures{Csv,Db}`。
  - 结果导出 ← `psig::ExportResults{Csv,Db,Txt}`。
- 无伪造 API：所有 `psig::` 调用均对应 `psig.h` 公共声明。

### 2. 重复实现检查 — 通过
- GUI 未重复实现静态库已有能力：
  - 结果选列导出：GUI 仅组装 `psig::ResultExportOptions{templateText, columns}` 并传给 `ExportResults*`，列选择/过滤由静态库 `SelectResultKeys/FilterResultColumns` 完成（见 `design/v0.2.0/gproto/`）。
  - 模板文本编解码：由静态库 `EncodeTemplateRecord/ParseTemplateRecord` 完成，GUI 仅透传字符串。
  - 特征码解析：GUI 调 `psig::ParsePattern`，不自写模式解析。
- 「地址(十进制)」列仅为展示层格式化（`QString::number(address)`），不涉及业务算法，属 Model 展示职责，非重复实现。

### 3. 平台相关与第三方库 — 通过
- GUI 生产代码 `src/` 无平台 API（`windows.h|tlhelp32|OpenProcess|ReadProcessMemory` 无命中）、无第三方库（`boost|sqlite|gtest` 无命中）。
- 平台相关实现全部封装在 `psig` 静态库内，GUI 经公共 API 调用。

## 结论

数据来源真实、无重复实现、无越界依赖；无需回退。
