# 03 需求分析（psig v0.2.0）

> 前置：`02_跨流程需求接收.md`、`design/v0.1.0/gproto/03_需求分析.md`（基线）
> 模式：修改型，增量分析。

## 1. 领域模型（增量）

| 概念 | 变更 |
| --- | --- |
| 表 Table | 增加**表级模板文本** `templateText`（多行自定义文字，随表持久化） |
| 匹配结果 MatchResult | 增加**自定义列值** `custom` |
| 结果导出选项 ResultExportOptions | **新增**：模板文本 + 列选择 |

## 2. 需求点（自然语言 → 需求）

- **R-1**：特征码表在 CSV/DB 导出时把表级模板文本写入文件（置于最前/元数据），导入时读回；旧文件无模板不报错。
- **R-2**：匹配结果行可携带一段自定义文本（`custom`），随结果导出写入 CSV/DB/TXT。
- **R-3**：结果导出可携带表级模板文本（TXT 置于最前；CSV 前置模板记录；DB 存入元数据）。
- **R-4**：结果导出可选择列子集（按列键），空表示全部。

## 3. 非功能需求

- 不抛异常，用返回值/出参表达错误；线程安全（沿用）。
- 向后兼容：旧 CSV/DB 无模板/无自定义列时正常导入。

## 4. 约束满足说明

- 文档保存于 `design/v0.2.0/`；仅增量分析改动点。
