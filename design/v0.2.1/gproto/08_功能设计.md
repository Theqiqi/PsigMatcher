## API 接口列表（变更）

| API | 变更 |
| --- | --- |
| `ExportSignaturesCsv(path, table, err) -> bool` | **行为变更**：写 UTF-8 BOM |
| `ImportSignaturesCsv(path, err) -> Table` | **行为变更**：剥离 BOM |
| `ExportResultsCsv(path, results, err, options = {}) -> bool` | **行为变更**：写 UTF-8 BOM |
| `ProcessIcon(pid) -> IconBitmap` | **新增** |
| `DefaultProcessIcon() -> IconBitmap` | **新增** |
| `IconBitmap` | **新增结构**：`width` / `height` / `pixels`(BGRA) / `valid()` |
