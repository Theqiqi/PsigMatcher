# 09 模块变更（psig v0.2.0）

> 前置：`08_功能设计.md`、`design/v0.1.0/gproto/09_模块设计.md`（基线：data/algorithm/atomic/api 四层）

## 模块变更

| 层 | 模块 | 变更 |
| --- | --- | --- |
| data | `data/types.h` | 无（Table/MatchResult 定义在公共头 psig.h） |
| algorithm | `algorithm/csv.h/.cpp` | **新增**模板前置记录的序列化/解析（纯字符串） |
| atomic | `atomic/sqlite_io.*` | 复用（建表/查询/执行已足够） |
| atomic | `atomic/file_io.*` | 复用 |
| api | `api/psig.cpp` | 修改特征码导入/导出、结果导出 |

## 分层保持

- 仍为 data / algorithm / atomic / api 四层；新增逻辑按纯度归位：模板前置记录的字符串处理归**算法层**（无 I/O）；DB/文件读写归**原子化层**；组装归**接口层**。

## 约束满足说明

- 仅列出受改动影响的模块；分层不变。
