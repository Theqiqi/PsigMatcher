# 09 模块变更（psig v0.2.1）

> 前置：`08_功能设计.md`、`design/v0.2.0/gproto/09_模块变更.md`（基线：data/algorithm/atomic/api 四层）

## 模块变更

| 层 | 模块 | 变更 |
| --- | --- | --- |
| data | `data/types.h` | 无（`IconBitmap` 定义在公共头 psig.h） |
| algorithm | `algorithm/csv.h/.cpp` | **新增** `Utf8Bom` / `HasUtf8Bom` / `StripUtf8Bom`（纯字符串） |
| atomic | `atomic/win_icon.h/.cpp` | **新增**：Win32 图标提取与转 BGRA 位图（`ExtractProcessIcon` / `ExtractDefaultIcon`） |
| atomic | `atomic/win_process.*` | 复用（可取进程路径） |
| atomic | `atomic/file_io.*` | 复用 |
| api | `api/psig.cpp` | 修改特征码/结果 CSV 导出（加 BOM）、特征码 CSV 导入（剥 BOM）；新增 `ProcessIcon`/`DefaultProcessIcon` 组装 |

## 分层保持

- 仍为 data / algorithm / atomic / api 四层；新增逻辑按纯度归位：BOM 字符串处理归**算法层**（无 I/O）；图标 Win32 提取与位图转换归**原子化层**；组装归**接口层**。

## 约束满足说明

- 仅列出受改动影响的模块；分层不变。
