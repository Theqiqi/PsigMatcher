# 12 接口细化设计（psig v0.2.1）

> 前置：`11_api接口分析.md`
> 产物：数据结构列表、算法列表、原子化 API 列表、API 接口异常设计。

## 1. 数据结构列表（变更）

| 结构 | 变更 |
| --- | --- |
| `IconBitmap` | 新增：`int width`、`int height`、`std::vector<uint8_t> pixels`（BGRA）、`bool valid() const` |

## 2. 算法列表（变更）

| 算法 | 层 | 职责 |
| --- | --- | --- |
| `Utf8Bom()` | algorithm | 返回 UTF-8 BOM 字节串 `"\xEF\xBB\xBF"` |
| `HasUtf8Bom(text)` | algorithm | 判断文本是否以 BOM 开头 |
| `StripUtf8Bom(text)` | algorithm | 若以 BOM 开头则返回去掉 BOM 的文本 |

## 3. 原子化 API 列表（变更）

| API | 变更 |
| --- | --- |
| `ExtractProcessIcon(pid)` | **新增**：Win32 提取指定进程图标 → BGRA 位图 |
| `ExtractDefaultIcon()` | **新增**：Win32 取系统默认可执行文件图标 → BGRA 位图 |
| `ReadTextFile/WriteTextFile` | 复用 |

## 4. API 接口异常设计

| 场景 | 处理 |
| --- | --- |
| 文件不可读写 | 置 `err`，返回空表 / false |
| 导入 CSV 无 BOM | 不剥离，正常解析 |
| 导入 CSV 有 BOM | 先剥离再解析（不污染首列/模板记录） |
| 进程不存在/无权限 | `ProcessIcon` 返回 invalid（不抛异常） |
| 图标提取失败 | 返回 invalid |
| `DefaultProcessIcon` | 始终返回有效位图（系统默认） |
| 图标无 alpha 通道 | 用掩码合成 alpha=255/0（保证可见） |

## 约束满足说明

- 已提取数据结构/算法/原子化 API 并设计异常。
