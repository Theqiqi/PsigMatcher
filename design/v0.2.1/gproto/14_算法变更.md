# 14 算法变更（psig v0.2.0）

> 前置：`13_数据结构变更.md`

## 新增/变更算法（`algorithm/` 层，纯函数）

| 算法 | 签名 | 说明 |
| --- | --- | --- |
| EncodeTemplateRecord | `std::string EncodeTemplateRecord(const std::string& tmpl)` | 返回 `"#psig-template," + EscapeField(tmpl) + "\r\n"`；tmpl 空返回 `""` |
| ParseTemplateRecord | `bool ParseTemplateRecord(const std::string& text, std::string& tmpl, std::string& rest)` | 若首条 CSV 记录首字段为 `#psig-template` → tmpl=第二字段、rest=余下文本、返回 true；否则 tmpl 空、rest=text、返回 false |
| ResultColumnDefs | `std::vector<std::pair<std::string,std::string>> ResultColumnDefs()` | 结果列 (key,title) 表 |
| FilterResultColumns | `void FilterResultColumns(const std::vector<std::string>& keys, std::vector<std::string>& headers, std::vector<std::vector<std::string>>& rows)` | 按 keys 过滤（空=全部） |

## 纯度

- 均为纯字符串处理，无 I/O、无平台 API、无全局状态。

## 约束满足说明

- 算法独立、纯净。
