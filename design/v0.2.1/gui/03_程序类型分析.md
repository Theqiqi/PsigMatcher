# 03 程序类型分析（v0.2.1）

> 前置：`02_领域模型.md`
> 模式：**修改/添加功能**

## 结论

**沿用既有程序类型：Qt6 桌面 GUI 单体程序（Windows exe）**。

## 依据

- 本流程为修改型，程序类型不变，不做重复判断（流程步骤 8 约束：「修改模式沿用既有类型，跳过本步或直接记录"沿用"」）。
- 既有程序 `psig_gui` 满足 GUI 判定标准（可视化窗口 / 鼠标键盘交互 / 实时反馈 / 多控件协作），类型自 v0.1.0 已确定，见 `design/v0.1.0/gui/03_程序类型分析.md`。
- 本次改动均为既有窗口内的交互修复/增强（对话框按钮、i18n、进程表排序与图标、新增行、配色统一）与构建产物形态（Release 去控制台），不改变「桌面 GUI」这一类型。

## 影响

- 后续设计（窗口结构、交互、Model/View 绑定）沿用 Qt Widgets 方案，仅针对改动点更新。
- Release 取消控制台后，程序仍是标准 Windows GUI 子系统可执行文件（`/SUBSYSTEM:WINDOWS`），类型判定不变。
