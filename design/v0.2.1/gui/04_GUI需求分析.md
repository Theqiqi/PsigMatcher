## 2. 窗口布局变更（用户可见）

### 2.1 主窗口工具栏（C-01 / C-03 / C-04）

- 工具栏采用 **ToolButtonIconOnly**（图标），图标取 QStyle 标准图标（`SP_BrowserReload` 刷新、`SP_MediaPlay` 扫描、`SP_MediaStop` 取消、`SP_DialogOpenButton` 导入、`SP_DialogSaveButton` 导出、`SP_FileDialogDetailedView` 列管理、`SP_DialogOkButton` 确认等）；tooltip 与菜单文字保留。
- 按页显示：
  - **进程页**：`刷新进程`、`全选`、`确认选择（进入特征码页）`
  - **特征码页**：`导入特征码`、`导出特征码`、`开始扫描`、`取消扫描`、`重新选择进程`
  - **结果页**：`清空结果`、`重新选择进程`
- **未选定进程前**（初始态）：仅显示进程页工具栏项；选定后进程页入口（视图菜单项 + 进程工具栏项）隐藏，出现特征码页工具栏项。

### 2.2 特征码编辑页（C-02）

- 移除顶部「新增行/删除行/列管理」按钮条，表格占满页面。
- 表格右键菜单：`新增行` / `删除选中行` / `列管理`（`列管理` 打开既有 ColumnManagerDialog）。

### 2.3 匹配结果页（C-05 / C-06 / C-07 / C-08 / C-09）

- 顶部：**多行模板文本编辑区**（QPlainTextEdit，占位提示「模板文本（随导出携带）」）+ `清空结果` 动作。
- 表格列（新增/调整顺序）：`特征码名` / `进程` / `PID` / **`地址(十进制)`** / `地址(十六进制)` / `模块` / `模块基址` / `匹配字节` / `命中时间` / **`自定义`（可编辑，末列）**。
- 表格右键菜单：`导出 ▸ {CSV, DB, TXT}` / `选择导出列…` / `删除选中行` / `清空结果`。
- 末列「自定义」：可双击单格编辑；选中多行右键「批量填充自定义列」或用模板文本填充；支持全选后批量填充。

### 2.4 关于对话框（C-10）

- 内容：程序名「进程特征码批量匹配器」、版本 **v0.2.0**、说明「基于 psig 静态库」、构建配置（Debug/Release）、Qt 版本。按钮「确定」。

### 2.5 导入前置询问（C-11）

- 触发导入（菜单/工具栏/快捷键）后，若当前特征码表非空，先弹 `QMessageBox::question`：「当前特征码表可能未保存，是否先保存？」→ `保存`（走导出特征码流程后继续导入）/ `不保存`（直接继续导入）/ `取消`（中止导入）。

## 3. 用户操作路径（点击流程）

1. 启动 → 进程页 → `刷新进程` → 过滤/多选 → 双击进程行或点 `确认选择` → **特征码页**（进程页入口隐藏）。
2. 特征码页：右键 `新增行`/`删除选中行`/`列管理`；`导入特征码`（先询问是否保存）；`导出特征码`；`开始扫描`。
3. 结果页：编辑末列自定义列（单格/多选/全选批量）；编辑模板文本；右键 `导出 ▸ CSV/DB/TXT`；右键 `删除选中行`/`清空结果`。
4. 任意时点：`重新选择进程` 回到进程页重新选择。
5. 帮助 → 关于 → 弹窗。

## 4. 可视化反馈要求

- 工具栏图标化后，每个动作**必须有 tooltip**；禁用态（如无结果时导出）置灰。
- 结果表末列编辑后，行状态即时刷新（`dataChanged`）。
- 页面切换、进程确认、删除、批量填充、导入前询问、关于弹窗均有明确反馈（详见 `07_状态与反馈信息设计.md`）。

## 5. 变更对既有需求的覆盖关系

- 覆盖 v0.1.0「结果表只读」需求：结果集改为**受限可写**（仅末列 + 行删除）。
- 覆盖 v0.1.0「启动进入特征码页」：改为**启动进入进程页**。
- 其余 v0.1.0 需求（进程枚举/特征码解析/扫描/导出格式）保持不变。
