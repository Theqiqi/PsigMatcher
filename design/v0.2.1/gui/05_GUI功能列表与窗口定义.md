# 05 GUI 功能列表与窗口定义（v0.2.0，增量）

> 前置：`04_GUI需求分析.md`、`design/v0.1.0/gui/05_GUI功能列表与窗口定义.md`（基线）
> 说明：仅列出**受本次改动影响**的窗口与功能；未列出的窗口/功能沿用 v0.1.0。

## 1. 窗口清单（增量）

| 窗口/组件 | 类型 | 变更 |
| --- | --- | --- |
| 主窗口 MainWindow | QMainWindow | 修改：工具栏图标化 + 按页显隐 + 启动流程；视图菜单项显隐 |
| 进程选择页 ProcessSelectionPage | QWidget | 修改：增加「确认选择」入口；移除/调整按钮为工具栏动作；表格右键菜单 |
| 特征码编辑页 SignatureEditorPage | QWidget | 修改：移除按钮条，改表格右键菜单 |
| 匹配结果页 ResultPage | QWidget | 修改：顶部模板文本区；末列可编辑；十进制地址列；表格右键菜单 |
| 列管理对话框 ColumnManagerDialog | QDialog | 不变 |
| 关于对话框 AboutDialog | QDialog（新增） | 新增：显示程序/版本/静态库信息 |
| 导入前询问对话框 | QMessageBox（复用） | 新增：保存/不保存/取消 |

## 2. 功能列表（增量）

| 功能编号 | 功能 | 入口 | 触发 | 输出/反馈 |
| --- | --- | --- | --- | --- |
| F-01 | 工具栏图标化 | 主窗口工具栏 | 常驻 | 图标 + tooltip |
| F-02 | 按页工具栏 | 主窗口 | 页面切换 | 工具栏项随页显隐 |
| F-03 | 确认选择进程 | 进程页（工具栏/双击/右键） | 用户操作 | 记录目标 pid，跳特征码页，隐藏进程页入口 |
| F-04 | 重新选择进程 | 特征码页/结果页工具栏 | 用户操作 | 回到进程页，恢复进程页入口 |
| F-05 | 特征码行右键菜单 | 特征码表格 | 右键 | 新增行/删除选中行/列管理 |
| F-06 | 结果行右键菜单 | 结果表格 | 右键 | 导出▸CSV/DB/TXT、选择导出列、删除选中行、清空结果 |
| F-07 | 多选/单行删除 | 特征码页、结果页 | 右键「删除选中行」 | Model 移除行 + 状态反馈 |
| F-08 | 结果末列自定义编辑 | 结果表格末列 | 双击单格 / 右键批量填充 / 全选填充 | 更新自定义列值 |
| F-09 | 模板文本编辑 | 结果页顶部 | 文本编辑 | 保存表级模板文本（随导出携带） |
| F-10 | 选择导出列 | 结果页右键「选择导出列…」 | 用户勾选 | 仅导出选中列子集 |
| F-11 | 十进制地址列 | 结果表格 | 常驻显示 | 地址列前显示十进制地址 |
| F-12 | 关于对话框 | 帮助→关于 | 点击 | 弹出信息对话框 |
| F-13 | 导入前保存询问 | 导入触发 | 表非空 | 保存/不保存/取消 |

## 3. 与静态库的接口关系（能力需求，详见步骤 16-21）

| 功能 | 依赖静态库能力 | 既有 API 是否覆盖 |
| --- | --- | --- |
| F-09 模板文本随特征码表导入/导出 | 表级模板文本读写 | **否**（需扩展） |
| F-08/F-09/F-10 结果导出携带模板/自定义列/选列 | 结果导出携带元数据与列选择 | **否**（需扩展） |
| F-05/F-07 行删除 | 无（Model 层操作） | 不涉及 |
| 其余（图标/右键/显隐/关于/十进制列） | 无（纯 View/Model/VM） | 不涉及 |
