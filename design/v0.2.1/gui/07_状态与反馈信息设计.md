# 07 状态与反馈信息设计（v0.2.1，增量）

> 前置：`06_交互模式设计.md`、`04_GUI需求分析.md`、`design/v0.2.0/gui/07_状态与反馈信息设计.md`（基线）
> 说明：三类反馈信息各自唯一显示位置；本次新增功能产生的反馈点必须补齐设计。

## 1. 三类反馈信息的唯一显示位置（沿用 + 增量）

| 类别 | 唯一显示位置 | 本次变更 |
| --- | --- | --- |
| 持久状态 | 状态栏左侧持久区（`persistentLabel`） | 不变（`就绪 \| 目标 … \| 进程 N \| 特征码 M`） |
| 瞬时反馈 | 状态栏右侧瞬时区（`transientLabel`） | 新增：语言切换、排序、新增多行、刷新+筛选 的反馈；颜色点缀（信息/错误） |
| 历史日志 | 底部「历史日志」Dock（`logEdit`） | 新增事件：语言切换、新增多行、按列排序（可选）；按级别**着色点缀**（C-14） |

## 2. 新增/变更反馈点清单

| 触发 | 类别 | 分派 | 文案/表现 |
| --- | --- | --- | --- |
| 切换语言（C-02） | 瞬时 + 日志 | 状态栏 + 日志 | 瞬时「语言已切换为 中文/English」；日志 `[设置] 语言 → …`；界面即时重译 |
| 默认语言判定（C-02） | 持久（菜单勾选态） | 菜单 | 「语言」菜单当前项打勾 |
| 新增一行（C-06/C-08） | 瞬时 + 日志 | 状态栏 + 日志 | 「已新增 1 行」；日志 `[编辑] 新增特征码 1 行` |
| 新增多行（C-06） | 瞬时 + 日志 | 状态栏 + 日志 | 「已新增 N 行」；日志 `[编辑] 新增特征码 N 行`；取消→无动作 |
| 进程自动枚举（C-09） | 瞬时 + 日志 | 状态栏 + 日志 | 枚举中「正在枚举进程…」；完成「已枚举 N 个进程」；日志 `[进程] 枚举 N 个` |

## 3. 颜色点缀与统一风格（C-13 / C-14）

- **基底**：全部面板/输入框/表格/日志统一**白底**（`#ffffff`），边框浅灰，选中蓝（沿用 `#3a6ea5`）。
- **日志着色**（`logEdit`，只读）：日志行由 VM 追加**语言无关的 ASCII 级别标签**（`[tag] ` 前缀），View 按标签着色——
  - `[startup]` / `[settings]` 信息色（灰蓝，`#455a64`）
  - `[scan]` / `[process]` / `[edit]` / `[result]` / `[nav]` 常规色（深灰，`#333333`）
  - `[export]` / `[import]` 成功色（绿，`#2e7d32`）
  - `[error]` 错误色（红，`#c62828`）
  - 说明：标签取 ASCII（不随界面语言变化），着色判断稳定；标签后的描述文本经 `tr()` 随语言切换。
- **状态栏分区**：持久区常规色；瞬时区错误时红色、信息时深灰（沿用）。
- 统一字体：界面用默认 UI 字体；日志用等宽（Consolas）但白底。

## 4. 错误分派原则（沿用 v0.2.0，本次适用点）

- **短暂性错误**（可继续操作）→ 瞬时反馈区（红色）：如「无结果可导出」「未选择目标进程」。
- **需决策错误 / 需用户确认**→ 模态弹窗：新增多行数量输入、清空结果确认、关于信息、选择导出列。

## 5. 约束满足说明

- 三类反馈各自唯一位置：持久→状态栏左区/菜单勾选；瞬时→状态栏右区；日志→历史日志 Dock。
- 错误按短暂性/需决策分派弹窗或瞬时反馈。
- 本次新增功能（语言切换、新增多行、自动枚举、排序、图标、对话框按钮）的反馈信息点已全部补齐。
