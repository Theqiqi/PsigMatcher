# 11 GUI 执行路径（v0.2.0，增量）

> 前置：`10_GUI功能流程图.md`
> 说明：每个改动功能补齐**正常路径 / 错误路径 / 取消路径**三类（事件驱动独立路径）。未列出的沿用 v0.1.0。

## F-03 确认选择进程

- **正常**：选中 ≥1 进程行 → 触发确认 → 记录目标 pid → 隐藏进程页入口/进程动作 → 切特征码页 → 状态/日志更新。
- **错误**：未选中任何进程行 → 瞬时错误「请先选择目标进程」，停留进程页。
- **取消**：用户未触发确认（不适用取消）；若确认对话框（无）。

## F-04 重新选择进程

- **正常**：触发 → 恢复进程页入口 → 切进程页 → 瞬时/日志。
- **错误**：无（幂等）。
- **取消**：不适用。

## F-05 特征码行右键菜单

- **正常**：右键表格 → 弹出菜单 → 选择动作 → 执行（新增行/删除选中行/列管理）。
- **错误**：「删除选中行」无选中 → 瞬时错误「请先选择要删除的行」；「列管理」对话框取消 → 不改动。
- **取消**：右键菜单点空白/ESC 关闭；列管理对话框 Cancel。

## F-06 结果导出（右键二级）

- **正常**：有结果 → 右键 导出▸CSV/DB/TXT → 选路径 → psig::ExportResults* → 瞬时「已导出」+ 日志。
- **错误**：无结果 → 瞬时错误「无结果可导出」（右键导出项禁用）；psig 返回失败 → 瞬时「导出失败: <err>」+ 日志。
- **取消**：文件对话框取消 → 不导出。

## F-07 删除结果行 / 特征码行

- **正常**：选中 1..N 行 → 删除 → Model 移除 → 瞬时「已删除 N 行」+ 日志。
- **错误**：无选中 → 瞬时错误提示。
- **取消**：不适用（删除即执行；清空结果另有确认弹窗 → 取消则不删）。

## F-08 末列自定义编辑

- **正常**：双击单格编辑 / 右键批量填充 → `setData`/`setCustom` → dataChanged → 显示刷新 → 批量时瞬时「已填充 N 行」。
- **错误**：批量填充时无选中且未选择「全部」→ 瞬时错误「请选择要填充的行」。
- **取消**：编辑中按 ESC → 放弃该格编辑（Qt 默认）。

## F-09 模板文本编辑

- **正常**：编辑模板区 → textChanged → 暂存 → 导出时携带；导入时回填。
- **错误**：无。
- **取消**：无（实时暂存）。

## F-10 选择导出列

- **正常**：右键 → 勾选列 → 确认 → 记录选中列 → 瞬时「将导出 N 列」。
- **错误**：未勾选任何列 → 瞬时错误「至少选择一列」。
- **取消**：对话框 Cancel → 保持原选择。

## F-12 关于

- **正常**：帮助→关于 → AboutDialog::exec → 点「确定」关闭。
- **错误**：无。
- **取消**：ESC/关闭 → 关闭对话框。

## F-13 导入前置询问

- **正常**：表非空 → 询问「保存」→ 用户完成保存 → 继续选文件 → 导入成功 → 应用表 + 模板回填 + 瞬时「已导入 N 条」。
- **错误**：导入失败（psig 置 err）→ 瞬时「导入失败: <err>」+ 日志，保留原表。
- **取消**：询问选「取消」→ 中止导入；选「保存」但保存对话框取消 → 中止导入；文件对话框取消 → 不导入。

## F-01/F-02/F-11 工具栏图标化 / 按页工具栏 / 十进制地址列

- **正常**：常驻生效（图标 + tooltip；按页显隐；地址列前显示十进制）。
- **错误**：无。
- **取消**：不适用。

## 约束满足说明

- 每个改动功能均给出正常/错误/取消三类路径（事件驱动独立路径）。
- 涉及管理员权限的用例（本次改动均为进程内自身操作，**无需提权**）；若后续扩展真实抓包类用例，参照 `design/v<版本>/gui/33_admin_capture_guide.md`（v0.1.0 为 `design/v0.1.0/gui/33_admin_privilege_guide.md`）。
