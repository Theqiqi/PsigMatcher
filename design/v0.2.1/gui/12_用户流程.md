# 12 用户流程（v0.2.1，增量）

> 前置：`11_GUI执行路径.md`、`10_GUI功能流程图.md`、`design/v0.2.0/gui/12_用户流程.md`（基线）
> 说明：每个用户操作对应一个用户流程；覆盖正常/错误/取消路径；作为用户流程测试与 E2E 测试依据。

## 流程模板

`用户操作 → View 发射信号 → VM 接收事件 → 业务流程（含 psig 调用）→ 结果反馈 → View 刷新`

## 新增/修改用户流程

### UF-B1 界面语言切换（C-02，正常/错误）
- 正常：菜单「语言」→ 选中文/English/跟随系统 → `onLanguageSelected` → 卸载旧 `QTranslator` + 装载 `:/i18n/psig_gui_<code>.qm` → `retranslateUi()` → 界面文案即时刷新 + 状态/日志反馈 + 菜单勾选更新。
- 错误：`.qm` 缺失 → 回退内置中文 + 瞬时提示，不崩溃。
- 取消：不适用（可再切回）。

### UF-B2 默认语言自动判定（C-02，正常）
启动 → `install()` 依据 `QLocale::system()` 选择 `zh_CN`/`en_US` → 装载对应翻译 + 菜单勾选对应项。

### UF-B3 对话框按钮生效（C-01 / C-04 / C-05，正常/错误/取消）
- 正常：打开对话框 → 点 OK/Cancel/内部按钮 → 正确应用/关闭（选择导出列记录列；列管理增删移列；关于关闭）。
- 错误：选择导出列未勾选 → 接受后错误提示并保持原选择。
- 取消：Cancel/ESC → 放弃。

### UF-B4 新增一行 / 新增多行（C-06 / C-08，正常/取消）
- 正常：特征码页 `新增一行` → 追加 1 行（进程列填目标进程名）；`新增多行…` → 输入 n → 追加 n 行（同上填充）。
- 错误：无（行数输入受 1..N 约束）。
- 取消：新增多行对话框取消 → 不新增。

### UF-B5 启动自动枚举 + 筛选保持（C-09 / C-10，正常/错误）
- 正常：启动即自动枚举 → 进程表填充；若筛选框有文本，刷新后仅显示匹配项。
- 错误：枚举为空 → 空表 + 「已枚举 0 个进程」。
- 取消：不适用。

### UF-B6 进程表排序 + 图标（C-11 / C-12，正常/错误）
- 正常：点击列头 → 按该列排序（再点切换方向）；每行名称列显示进程图标。
- 错误：图标提取失败 → 用系统默认图标。
- 取消：不适用。

### UF-B7 导出 CSV 中文表头（C-03，正常/错误/取消）
- 正常：结果页右键 导出▸CSV → 选路径 → `ExportResultsCsv`（写 UTF-8 BOM）→ 用 Excel 打开中文表头正常 → 再导入本程序可解析。
- 错误：写失败 → 瞬时「导出失败」。
- 取消：文件对话框取消。

### UF-B8 配色统一与日志着色（C-13 / C-14，正常）
启动 → `setStyleSheet(":/style.qss")`（白底）→ 结果页模板框/日志框白底；日志按级别着色；Release 无控制台。
