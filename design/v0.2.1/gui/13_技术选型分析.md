# 13 技术选型分析（v0.2.1）

> 前置：`05_GUI功能列表与窗口定义.md`、`design/v0.2.0/gui/13_技术选型分析.md`（基线）
> 模式：修改/添加功能 → **沿用既有技术栈**，不重新选型。

## 结论

**沿用既有技术栈**：C++20 / Qt6::Widgets / Qt6::Concurrent / Windows / CMake / vcpkg（manifest）。

## 确认（既有栈仍满足本次改动）

| 维度 | 选型 | 本次是否满足 | 说明 |
| --- | --- | --- | --- |
| 语言 | C++20 | 是 | 无新语言特性需求 |
| GUI | Qt6::Widgets | 是 | 对话框按钮（QDialogButtonBox）、i18n（QTranslator）、表格排序（QHeaderView）、DecorationRole 图标、QInputDialog 均为 Widgets 既有能力 |
| 异步 | Qt6::Concurrent | 是 | 进程枚举/扫描/图标提取异步 |
| 平台 | Windows | 是 | 进程枚举/图标提取依赖 Windows API（在静态库内） |
| 构建 | CMake + Ninja | 是 | 新增 `Qt6::LinguistTools`（Qt 组件，非第三方）用于 `.ts`→`.qm` |
| 包管理 | vcpkg manifest（gtest） | 是 | 无新增第三方依赖 |
| 静态库 | psig（无 Qt 依赖，内置 SQLite） | 是（需扩展） | 见步骤 16-21（CSV BOM、进程图标） |

## 新增依赖评估

- **无新增第三方依赖**：i18n 使用 Qt 自带 `Qt6::LinguistTools`（`lupdate`/`lrelease`，已随 Qt 独立安装提供）；进程图标由 psig 用 Windows API 提取（psig 内既有 Win32 依赖）；配色/日志着色使用 Qt 样式表。

## 约束满足说明

- 已确认既有技术栈仍满足本次全部改动，标注「沿用」，不重复选型。
- `Qt6::LinguistTools` 属 Qt 官方组件（非第三方库），不违反「GUI 禁止 Qt 以外第三方库」。
