# 13 技术选型分析（v0.2.0）

> 前置：`05_GUI功能列表与窗口定义.md`、`design/v0.1.0/gui/13_技术选型分析.md`（基线）
> 模式：修改/添加功能 → **沿用既有技术栈**，不重新选型。

## 结论

**沿用既有技术栈**：C++20 / Qt6::Widgets / Qt6::Concurrent / Windows / CMake / vcpkg（manifest）。

## 确认（既有栈仍满足本次改动）

| 维度 | 选型 | 本次是否满足 | 说明 |
| --- | --- | --- | --- |
| 语言 | C++20 | 是 | 无新语言特性需求 |
| GUI | Qt6::Widgets | 是 | 工具栏图标（QStyle 标准图标）、右键菜单（QMenu）、模板文本区（QPlainTextEdit）、关于对话框（QDialog）均为 Widgets 既有能力 |
| 异步 | Qt6::Concurrent | 是 | 扫描/枚举异步不变 |
| 平台 | Windows | 是 | 进程内存扫描依赖 Windows API（在静态库内） |
| 构建 | CMake + Ninja | 是 | 不变 |
| 包管理 | vcpkg manifest（gtest） | 是 | 无新增依赖 |
| 静态库 | psig（无 Qt 依赖，内置 SQLite） | 是（需扩展） | 见步骤 16-21 |

## 新增依赖评估

- **无新增第三方依赖**：图标采用 `QStyle::standardIcon(...)` 标准图标，不引入图标资源库；模板文本区使用既有 Qt 控件。

## 约束满足说明

- 已确认既有技术栈仍满足本次全部改动，标注「沿用」，不重复选型。
