# 18 静态库流程交接记录（v0.2.0）

> 前置：`17_API缺失需求.md`
> 跳转目标：`.flow/带GUI的单体程序的业务系统静态库.md` 的 **步骤 2「跨流程需求接收」**。

## 1. 交接原因

GUI 改动点 C-07/C-08 需要「表级模板文本」「结果自定义列」「结果导出携带元数据与列选择」等能力，`psig` 现有公共 API **不覆盖**（见 `16_API充分性审查.md`）。

## 2. 交接内容（逐项）

| 缺失能力 | 期望公共 API | 输入 | 输出 | 异常要求 | 验收标准 |
| --- | --- | --- | --- | --- | --- |
| M-1 模板+CSV | `Table` 增 `templateText`；`Import/ExportSignaturesCsv` 读写 | 路径 + Table | 模板回填/写入文件最前 | 无标记不报错 | 往返逐字一致 |
| M-2 模板+DB | `Import/ExportSignaturesDb` 读写模板 | 同上 | 同上 | 旧库兼容 | 往返一致 |
| M-3 自定义列 | `MatchResult` 增 `custom` | 结果数据 | 导出含 custom | 默认空串 | 可随导出 |
| M-4 导出带模板 | 结果导出接受模板参数 | 路径+结果+模板 | 文件含模板 | 空模板正常 | 可核验 |
| M-5 选列导出 | 结果导出接受列选择 | 列键列表 | 仅选中列 | 空=全部 | 仅选中列 |

## 3. 约束

- 静态库实现必须使用真实底层能力，**禁止**模拟数据、硬编码结果或伪造 API。
- 静态库流程完成后必须输出**静态库完成契约**，并**跳回** GUI 流程的「静态库完成回退检查（步骤 21）」，不得直接跳到 GUI 接口实现。
- GUI 在契约返回前**停止 ViewModel 层相关编码**。
