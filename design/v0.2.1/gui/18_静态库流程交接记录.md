# 18 静态库流程交接记录（v0.2.1）

> 前置：`17_API缺失需求.md`
> 跳转目标：`.flow/带GUI的单体程序的业务系统静态库.md` 的 **步骤 2「跨流程需求接收」**。

## 1. 交接原因

GUI 改动点 C-03（CSV 乱码）与 C-12（进程图标）需要「CSV 写 UTF-8 BOM / 导入剥离 BOM」与「进程图标提取」能力，`psig` 现有公共 API **不覆盖**（见 `16_API充分性审查.md`）。

## 2. 交接内容（逐项）

| 缺失能力 | 期望公共 API | 输入 | 输出 | 异常要求 | 验收标准 |
| --- | --- | --- | --- | --- | --- |
| M-1 CSV BOM | `ExportSignaturesCsv`/`ExportResultsCsv` 写 BOM；`ImportSignaturesCsv` 剥离 BOM | 路径 + 数据 | 文件首 `EF BB BF`；导入不受 BOM 污染 | 旧文件兼容；不可读写置 err | 首 3 字节 = `EF BB BF`；Excel 不乱码；往返一致 |
| M-2 进程图标 | `IconBitmap ProcessIcon(pid)` + `IconBitmap DefaultProcessIcon()` | pid | 宽/高 + BGRA 字节 | 取不到返回 invalid，不抛异常 | 有图标进程 valid；无 pid invalid；默认图标 valid；可建 QImage |

## 3. 约束

- 静态库实现必须使用真实底层能力，**禁止**模拟数据、硬编码结果或伪造 API。
- 静态库流程完成后必须输出**静态库完成契约**，并**跳回** GUI 流程的「静态库完成回退检查（步骤 21）」，不得直接跳到 GUI 接口实现。
- GUI 在契约返回前**停止 ViewModel 层相关编码**。
