# 26 异常处理与错误显示策略（v0.2.0，增量）

> 前置：`24_ViewModel接口.md`、`design/v0.1.0/gui/26_异常处理与错误显示策略.md`（基线）

## 策略（沿用 + 本次适用点）

| 场景 | 分派 | 表现 |
| --- | --- | --- |
| 特征码模式非法 | 瞬时反馈（错误） | 「特征码错误: 第 N 行…」 |
| 未选择目标进程 | 瞬时反馈（错误） | 「请先选择目标进程」 |
| 未选择要删除的行 | 瞬时反馈（错误） | 「请先选择要删除的行」 |
| 批量填充无选中且未选「全部」 | 瞬时反馈（错误） | 「请选择要填充的行」 |
| 未选择导出列 | 瞬时反馈（错误） | 「至少选择一列」 |
| 无结果可导出 | 瞬时反馈（错误）+ 菜单项禁用 | 「无结果可导出」 |
| psig 导入/导出失败 | 瞬时反馈（错误）+ 日志 | 「导入/导出失败: <err>」 |
| 导入前询问是否保存 | **模态弹窗** | `QMessageBox::question`（保存/不保存/取消） |
| 清空结果确认 | **模态弹窗** | `QMessageBox::question` |
| 关于信息 | **模态弹窗** | AboutDialog |

## 后台线程异常

- 扫描/枚举在 `QtConcurrent::run` 执行；结果经 `QFutureWatcher::finished` 回主线程处理，**不跨线程抛异常**。
- psig 不抛异常（出参表达错误），VM 在回主线程后统一处理 err。

## 约束满足说明

- 短暂性错误走瞬时反馈；需决策/需确认走模态弹窗；错误提示位置唯一（状态栏右区/日志）。
