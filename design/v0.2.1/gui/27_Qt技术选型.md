# 27 Qt 技术选型（v0.2.0）

> 前置：`08_窗口层次结构与导航图.md`、`13_技术选型分析.md`、`design/v0.1.0/gui/27_Qt技术选型.md`（基线）

## 结论：沿用

| 维度 | 选型 |
| --- | --- |
| 程序类型 | Windows 桌面 exe |
| 语言 | C++20 |
| GUI | Qt6::Widgets（代码构建 Widget，无 .ui） |
| 异步 | Qt6::Concurrent（QtConcurrent::run + QFutureWatcher） |
| 测试 | gtest（+ Qt 事件环境） |
| 构建 | CMake + Ninja + MSVC；vcpkg manifest（gtest）；find_library 引用 psig |
| 静态库命名 | psig（依据程序类型命名，非既有 pmem） |

## 本次新增控件/类

- `QToolBar` 图标化（`QStyle::standardIcon`，ToolButtonIconOnly）。
- `QMenu` 右键菜单（表格 `CustomContextMenu`）。
- `QPlainTextEdit`（模板文本区）、`QDialog`（AboutDialog / ExportColumnsDialog）。
- 均属 Qt6::Widgets 既有能力，无新依赖。

## 约束满足说明

- 沿用既有 Qt 技术选型；静态库命名依据程序类型（psig）。
