# 30 职责审查结果（步骤 32）

- 版本：v0.2.0
- 前置：`design/v0.2.0/gui/21_职责和边界.md`、`25_静态库API调用映射.md`
- 说明：审查 main/View/Model/ViewModel 职责划分，以及静态库 API 的真实性与隔离性。审查对象为本次改动涉及文件。

## 检查项与结论（均通过）

### 1. main 职责 — 通过
- `src/main.cpp` 只做组装：创建 View/ViewModel、`install`、`show`、`exec`，并加载 `:/style.qss` 与窗口图标；不含业务逻辑。

### 2. View 职责 — 通过
- View 只画 UI：创建控件、布局、`setContextMenuPolicy`、`setSelectionMode` 等展示属性。
- View 不含业务：新增 `AboutDialog`（`setInfo/info/buttonBox`）、`ExportColumnsDialog`（`setColumns/selectedKeys/list/buttonBox`）均为纯展示与数据存取。
- View 不 include ViewModel/静态库（grep 无命中）。

### 3. Model 职责 — 通过
- Model 只维护行集合与 `data()/setData()/flags()/headerData()`；`ResultTableModel` 新增十进制地址格式化与末列可编辑判定，属展示层职责，未越界。

### 4. ViewModel 职责 — 通过
- VM 槽函数统一为「校验 → 调静态库 API → 更新 Model → 刷新 View」：
  - `onImportSignatures`：非空表先弹窗询问保存 → 选择文件 → `psig::ImportSignatures{Csv,Db}` → `applyTableToModel`。
  - `onExportResults*`：空结果提前返回错误 → 选择文件 → `psig::ExportResults{Csv,Db,Txt}(..., opt)`。
  - `onConfirmProcessSelection`：校验选中 → 记录目标 → `setProcessSelectionLocked(true)` → `showSignaturePage()`。
- VM 不直接访问 View 私有成员，不 `findChild`。

### 5. 静态库 API 真实性 — 通过
- VM 调用的 psig 公共 API 均真实存在于 `psig/include/psig.h`：`BuiltinSignatureColumns`、`ParsePattern`、`ImportSignaturesCsv/Db`、`ExportSignaturesCsv/Db`、`EnumerateProcesses`、`ScanProcesses`、`RequestCancel`、`ExportResultsCsv/Db/Txt`、`ResultExportOptions`。
- v0.2.0 新增能力（模板文本、自定义列、结果选列导出）由静态库流程实现并回退检查通过（见 `19_API能力匹配分析.md`）。

### 6. 隔离性 — 通过
- GUI 只经 `#include "psig.h"` 公开头文件调用静态库；`psig.h` 仅在 `src/viewmodel/mainviewmodel.h` 出现（grep 命中 1 处）。
- 静态库不引用 Qt（psig 侧审查结论沿用，见 `design/v0.2.0/gproto/`）。
- GUI 生产代码无平台 API/第三方库（grep `windows.h|tlhelp32|OpenProcess|ReadProcessMemory|boost|sqlite|gtest` 在 `src/` 无命中）。

## 结论

职责划分清晰、静态库调用真实且隔离良好；无需回退。
