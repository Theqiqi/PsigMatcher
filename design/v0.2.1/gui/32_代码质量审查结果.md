# 32 代码质量审查结果（步骤 34）

- 版本：v0.2.0
- 前置：`design/v0.2.0/gui/21_职责和边界.md`、`26_异常处理与错误显示策略.md`
- 说明：审查异步执行、生命周期、跨线程异常、输入校验、内存管理、资源路径、空指针、嵌套深度、提前返回、头文件越界、单一职责。审查对象为本次改动涉及文件。

## 检查项与结论（均通过）

### 1. 异步执行 — 通过
- `onRefreshProcesses` / `onStartScan` 用 `QtConcurrent::run` 提交后台任务，`QFutureWatcher` 在 `finished` 回主线程处理结果；UI 线程不阻塞。

### 2. 生命周期 — 通过
- `m_sigModel/m_procModel/m_resultModel` 与两个 `QFutureWatcher` 均以 `this`（VM）为 parent，随 VM 析构；`~MainViewModel` 先 `waitForFinished()` 再析构，避免任务回调访问已析构对象。
- `m_view` 为绑定引用（不拥有），随 `MainWindow` 生命周期。

### 3. 跨线程异常 — 通过
- 后台任务不抛异常：psig API 以返回错误字符串/空结果表达失败；扫描进度经 `QMetaObject::invokeMethod(..., Qt::QueuedConnection)` 回主线程，无跨线程异常。

### 4. 输入校验 — 通过
- 特征码解析失败：`collectPatterns` 返回错误 → 瞬时错误反馈并中止扫描。
- 空特征码表 / 未选进程 / 空结果导出 / 未选行删除：均有校验并提前返回（含错误提示）。
- 导入前非空表：弹窗询问保存/不保存/取消，取消路径中止导入。

### 5. 内存管理 — 通过
- 新增控件（`QLabel`、`QDialogButtonBox`、`QListWidget`、`QListWidgetItem`）均指定 parent，Qt 父子机制回收；无 `new` 泄漏、无裸 `delete`。

### 6. 资源路径 — 通过
- `:/style.qss`、`:/app.png` 经 `.qrc` 资源访问，无硬编码磁盘路径。

### 7. 空指针 — 通过
- `install` 首行 `if (!view) return;`；`setTemplateText` 中 `if (m_view)` 保护；析构中 watcher 判空；`onDelete*Rows` 对 `selectionModel()` 判空；`selectRow` 校验 model/行号范围。

### 8. 嵌套深度 — 通过
- `onImportSignatures` 最深 3 层（非空表 → 保存 → 文件对话框），未超三重嵌套；其余槽函数 ≤ 2 层。

### 9. 提前返回 — 通过
- 各槽函数在错误/取消分支均提前 `return`（如空路径、空选择、解析错误、用户取消），避免深层嵌套。

### 10. 头文件越界 — 通过
- View 头文件仅依赖 Qt 与前置声明；`psig.h` 仅出现在 `src/viewmodel/mainviewmodel.h`（VM 层，允许）。
- 无 `#include "../`（grep 无命中）。

### 11. 单一职责 — 通过
- `ResultTableModel` 只负责数据与格式化；`MainViewModel` 只负责编排；对话框只负责展示/存取。职责边界清晰。

## 结论

质量检查项全部通过；无需回退。
