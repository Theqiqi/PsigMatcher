## 检查项与结论（均通过）

### 1. 代码规范符合性 — 通过
- View 只画 UI（无 `connect`/`signals`/`slots`）；Model 纯净；VM 集中 connect 并经 View* 操控；`Q_OBJECT` 宏齐备（MainWindow、各 Page、各 Dialog、各 Model、MainViewModel）。
- UI 线程不阻塞（QtConcurrent 异步）；后台不直接操作 UI（`invokeMethod` 回主线程）。

### 2. 独立子目录 — 通过
- `gui/` 与 `psig/` 平级互不嵌套；根目录仅含 `.flow/`、`.idea/`、`design/`、`gui/`、`psig/` 与配置文件。

### 3. 项目自包含 — 通过
- `gui/` 含自身 `CMakeLists.txt`、`CMakePresets.json`、`vcpkg.json`、`script/`、`src/`、`test/`、`res/`；不依赖根目录配置。

### 4. 根目录配置隔离 — 通过
- 根目录无 `CMakeLists.txt` / `CMakePresets.json`（检查无命中）。

### 5. 构建产物归属 — 通过
- 产物输出到 `gui/out/{bin,lib,build}` 与 `psig/out/...`；根目录无 `*.obj/*.exe/*.lib/*.log/*.pdb` 散落（检查无命中）。

### 6. 三方依赖归属 — 通过
- `gui/vcpkg.json` 与 `psig/vcpkg.json` 各自声明 `gtest`；Qt6 经独立安装（`QT6_DEBUG_DIR`/`QT6_RELEASE_DIR`）不纳入 manifest；无共享 `third_party/`。

### 7. 跨项目依赖 — 通过
- GUI 经 `find_library(PSIG_LIB ... ../psig/out/lib/<配置>)` 引用静态库产物，并经 `../psig/include` 使用公共头；无源码级耦合。

### 8. 测试层级 — 通过
- `test/unit`（Model/View/ViewModel/错误弹窗）、`test/integration`（MVVM 链路 + 用户流程）、`test/target`（被扫描目标）、`test/e2e`（真实启动/注入/断言）齐备且非空。

### 9. e2e 独立性 — 通过

### 10. 测试非空 — 通过

### 11. 头文件包含风格 — 通过
- 全部 `#include "名字/名字"` 形式，无 `#include "../`（grep 无命中）；系统/第三方头用 `<>`。
