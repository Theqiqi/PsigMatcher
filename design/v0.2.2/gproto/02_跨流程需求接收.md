# 02 跨流程需求接收（psig v0.2.2）

- 来源：GUI 流程步骤 16-21（API 能力需求 / 静态库存在性匹配 / 充分性审查 / 缺失能力 / 跨流程接收）。
- 目标静态库：`psig`（v0.2.1，已存在；本轮为**能力增强**，非新建能力）。
- 跳转目标：静态库流程「跨流程需求接收」步骤。

## 需求清单（来自 gui/14_API能力需求.md）

### R-01 结果导出支持十进制地址列（C-01）
- 公共 API 变更：`psig::algorithm::ResultColumnDefs()` 增加键 `address_dec`（默认标题「地址(十进制)」）。
- `psig::ResultRowValues(const MatchResult&, const std::string& key)` 对 `address_dec` 返回 `std::to_string(r.address)`（十进制）。
- 验收：调用方在 `ResultExportOptions.columns` 含 `address_dec` 时，导出该列为十进制。

### R-02 结果导出表头可由调用方指定语言（C-05）
- `psig::ResultExportOptions` 新增字段 `std::vector<std::string> headers;`（与 `columns` 等长可空）。
- `ExportResultsCsv/Db/Txt`：若 `headers` 非空且长度等于 `columns`，使用 `headers[i]`；否则回落 `ResultColumnDefs()` 中文默认。
- 向后兼容：不传 headers → 行为与 v0.2.1 一致（中文）。

### R-03 结果默认表头「自定义」改名「备注」（C-01）
- `ResultColumnDefs()` 中 `{"custom","自定义"}` → `{"custom","备注"}`。键 `custom` 不变。

### R-04 特征码导入支持英文标题回映射（C-06）
- `psig::BuiltinKeyFromTitle(const std::string& title)`：在中文映射基础上新增英文映射（Name/Signature/Remarks/Note → name/pattern/note），保证英文 UI 导出的特征码 CSV 可被中文 UI 正确导入。

## 能力覆盖判定
- 静态库已存在，上述均为对既有 API 的**增量扩展/字段新增**；不需要新增原子能力，但需要改动 `algorithm/result_columns.cpp`、`api/psig.cpp`、`include/psig.h`。
- GUI 不自行实现上述能力、不调用平台 API；全部经扩展后的 `psig` 公共 API。

## 交付契约（见 77_静态库完成契约.md）
- 公共头变更：`psig/include/psig.h`（`ResultExportOptions::headers`、`ResultColumnDefs` 新增键、`BuiltinKeyFromTitle` 双语）。
- 库产物：`psig/out/lib/<配置>/psig.lib`（Debug/Release 重建）。
- 验收：psig 单测 + 集成测试覆盖 R-01..R-04；Debug/Release 全绿。
