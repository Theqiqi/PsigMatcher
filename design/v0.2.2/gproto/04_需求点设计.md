# 04 需求点设计（psig v0.2.1）

> 前置：`03_需求分析.md`

## 需求点 → 设计

| 需求点 | 设计要点 |
| --- | --- |
| R-1 | 算法层提供 `Utf8Bom()`（返回 `"\xEF\xBB\xBF"`）；接口层在 CSV 导出文本最前拼接 BOM（在模板记录**之前**）。 |
| R-2 | 算法层提供 `HasUtf8Bom(text)` / `StripUtf8Bom(text)`；`ImportSignaturesCsv` 读入后先剥离 BOM，再解析模板记录与 CSV。 |
| R-3 | 新增公共结构 `IconBitmap{ int width; int height; std::vector<uint8_t> pixels; bool valid() const; }`；新增 API `IconBitmap ProcessIcon(uint32_t pid)`。原子化层用 Win32 提取图标并转 32bpp BGRA。 |
| R-4 | 新增 API `IconBitmap DefaultProcessIcon()`；原子化层取系统默认可执行文件图标（`SHGetFileInfoW` + `SHGFI_USEFILEATTRIBUTES`）。 |

## 编码约定（供接口/算法/原子化层一致）

- BOM 字节：`0xEF 0xBB 0xBF`，仅在**文件最前**，CSV 导出写、导入剥。
- 图标像素格式：**BGRA（小端 ARGB32）**，每像素 4 字节，行序自上而下；`pixels.size() == width*height*4`。
- 尺寸：优先 32×32（`SHGFI_LARGEICON`）；无则回退可用尺寸。

## 约束满足说明

- 仅设计改动点对应需求点；不引入伪造 API。
