# 05 业务流程变更（psig v0.2.1）

> 前置：`04_需求点设计.md`、`design/v0.2.0/gproto/05_业务流程变更.md`（基线）

## 变更业务流程

### BP-1 CSV 导出（加 BOM）
输入 Table/results → 组织文本（模板记录 + CSV）→ **在最前拼接 UTF-8 BOM** → 落盘。

### BP-2 特征码 CSV 导入（剥 BOM）
读文件 → **若以 BOM 开头则剥离** → 解析模板记录（若有）→ 解析 CSV → 组装 Table。

### BP-3 进程图标提取
输入 pid → 打开进程取可执行文件路径 → 提取图标 → 转 32bpp BGRA 位图 → 返回 IconBitmap（失败返回 invalid）。

### BP-4 系统默认图标
无输入 → 取系统默认可执行文件图标 → 转 32bpp BGRA 位图 → 返回 IconBitmap（始终有效）。

## 约束满足说明

- 仅列出受改动影响的业务流程；其余（枚举/扫描/结果导出主体）不变，引用 v0.2.0。
