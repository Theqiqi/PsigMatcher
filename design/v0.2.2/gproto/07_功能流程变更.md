# 07 功能流程变更（psig v0.2.1）

> 前置：`06_功能点设计.md`

## 功能流程

### FP-1 CSV BOM 写入
```
导出：text = EncodeTemplateRecord(tmpl) + SerializeCsv(headers, rows)
      → text = Utf8Bom() + text      // BOM 在最前
      → WriteTextFile(path, text)
```

### FP-2 CSV BOM 剥离
```
导入：ReadTextFile(path) → text
      → [HasUtf8Bom(text)?] --是--> text = StripUtf8Bom(text)
      → ParseTemplateRecord(text, tmpl, rest) → ParseCsv(rest)
```

### FP-3 进程图标提取
```
ProcessIcon(pid):
  path = 查询进程可执行文件路径(pid)        // QueryFullProcessImageNameW
  [path 空?] --是--> 返回 invalid
  hIcon = SHGetFileInfoW(path, SHGFI_ICON|SHGFI_LARGEICON)
  [hIcon 空?] --是--> 返回 invalid
  bmp = IconToArgbBitmap(hIcon)             // GetIconInfo + GetDIBits(32bpp)
  DestroyIcon(hIcon)
  返回 bmp
```

### FP-4 默认图标
```
DefaultProcessIcon():
  hIcon = SHGetFileInfoW("a.exe", SHGFI_ICON|SHGFI_LARGEICON|SHGFI_USEFILEATTRIBUTES)
  bmp = IconToArgbBitmap(hIcon); DestroyIcon(hIcon); 返回 bmp
```
