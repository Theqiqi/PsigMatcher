# 10 职责和边界说明（psig v0.2.1）

> 前置：`09_模块变更.md`、`design/v0.2.0/gproto/10_职责和边界变更.md`（基线）

## 各层职责（本次适用点）

| 层 | 职责 | 本次边界 |
| --- | --- | --- |
| 算法层 | 纯函数：BOM 常量/检测/剥离（字符串） | 不碰文件/DB；不依赖平台 API |
| 原子化层 | Win32 图标提取、位图转 BGRA；文件读写 | 不含业务语义（不知「进程图标」在 GUI 的用途） |
| 接口层 | 组装：读文件→剥 BOM→解析；取 pid→提取图标→返回 | 不含 Win32 细节（委托原子化层）、不含字符串细节（委托算法层） |

## 禁止项

- 算法层禁止 I/O 与平台 API。
- 原子化层禁止业务语义。
- 接口层禁止直接调用 Win32 图标 API（委托 `atomic/win_icon`）。
- 静态库禁止依赖 Qt。

## 约束满足说明

- 明确每模块职责与边界；改动未破坏既有边界。
