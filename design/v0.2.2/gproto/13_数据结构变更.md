# 13 数据结构变更（psig v0.2.1）

> 前置：`12_接口细化设计.md`、`design/v0.2.0/gproto/13_数据结构变更.md`（基线）

## 变更（定义在公共头 `psig/include/psig.h`）

```cpp
struct IconBitmap {              // 新增
    int width = 0;
    int height = 0;
    std::vector<uint8_t> pixels; // BGRA（小端 ARGB32），长度 = width*height*4
    bool valid() const {
        return width > 0 && height > 0 &&
               pixels.size() == static_cast<size_t>(width) * height * 4;
    }
};
```

## 编码约定

- 像素：每像素 4 字节，顺序 **B,G,R,A**（小端 ARGB32，可直接映射 Qt `QImage::Format_ARGB32`）。
- 行序：自上而下（top-down），无行填充（stride = width*4）。

## 独立性

- 纯数据（POD + std 容器），不依赖 Qt、不依赖平台 API（Win32 细节在原子化层）。

## 约束满足说明

- 数据结构独立、无平台依赖（头文件层面）。
