# 16 技术选型（psig v0.2.1）

> 前置：`12_接口细化设计.md`、`design/v0.2.0/gproto/16_技术选型.md`（基线）

## 结论：沿用

- C++20；无 Qt 依赖；Windows API（本次图标提取使用 `shellapi.h`/`windows.h`，属既有平台约束）；内置 SQLite amalgamation（本次不涉及）。
- 构建：CMake + Ninja + MSVC；包管理 vcpkg manifest（gtest）。

## 本次新增依赖评估

- **无新增第三方依赖**：BOM 用 std 字符串；图标提取用 Windows 系统库（`shell32`、`user32`、`gdi32`），均为系统组件。
- 需在 `psig/src/CMakeLists.txt` 链接 `shell32`（`SHGetFileInfoW`）等系统库。

## 约束满足说明

- 沿用既有选型，不重复分析；新增系统库链接属平台既有范畴。
