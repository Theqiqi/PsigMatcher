# 19 代码规范（psig v0.2.1）

> 前置：统一要求、`design/v0.2.0/gproto/19_代码规范.md`（基线）

## 结论：沿用既有规范

- 命名：类型 PascalCase、函数 PascalCase、成员变量 `m_` 前缀（psig 内部）；公共 API 沿用既有风格。
- 分层：data / algorithm / atomic / api，逐层依赖，禁止反向依赖。
- 算法层纯函数、无 I/O；原子化层无业务语义；接口层组装。
- 不抛异常，用返回值/出参表达错误。
- 头文件包含使用 `名字/名字` 形式，禁止 `../` 相对路径。
- 禁止依赖 Qt；平台调用集中在原子化层。

## 本次补充

- Win32 句柄（HICON/HGDIOBJ）必须成对释放（`DestroyIcon`/`DeleteObject`）。
- 图标像素统一 BGRA 自上而下，stride = width*4。

## 约束满足说明

- 沿用既有规范，本次改动遵循之。
