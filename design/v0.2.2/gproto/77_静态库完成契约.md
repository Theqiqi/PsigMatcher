# 77 静态库完成契约（psig v0.2.2）

- 需求来源：gui/14_API能力需求.md、gproto/02_跨流程需求接收.md（R-01..R-04）。
- 交付范围：对既有 `psig` 公开 API 的**增量扩展**，不改既有行为（向后兼容）。

## 公共接口变更（psig/include/psig.h）
- `ResultExportOptions` 新增字段 `std::vector<std::string> headers;`（与 `columns` 等长，可空；非空时优先作为导出表头，用于跟随界面语言）。
- `algorithm::ResultColumnDefs()` 新增键 `address_dec`（默认标题「地址(十进制)」）；`custom` 默认标题由「自定义」改为「备注」。
- `BuiltinKeyFromTitle()` 新增英文标题映射（Name/Signature/Remarks/Note → name/pattern/note）。
- 新增公开 API（供界面按当前语言构造导出表头）：`psig::ResultColumnDefs()`、`psig::SelectResultKeys(requested)`（语义同 `algorithm` 层同名函数）。

## 行为变更与验收
| 能力 | 验收 |
| --- | --- |
| R-01 十进制导出列 | `SelectResultKeys({})` 默认不含 `address_dec`；显式选 `address_dec` 时导出值为十进制；`ResultColumnDefs` 含 `address_dec`。 |
| R-02 表头随语言 | `ExportResultsCsv/Db/Txt` 在 `options.headers` 非空且与 `columns` 等长时使用调用方表头；为空回落中文默认（向后兼容）。 |
| R-03 备注改名 | 默认 `custom` 表头为「备注」。 |
| R-04 英文标题回映射 | `BuiltinKeyFromTitle("Name")=="name"` 等；英文标题导出的特征码 CSV 可被中文 UI 正确导入。 |
