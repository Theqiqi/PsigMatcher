# 01 想法分析（v0.2.1）

> 输入：`.idea/v0.2.1.md`
> 模式：**修改/添加功能**（对既有 `psig_gui` + `psig` 的调整与修复）
> 上一版本：`v0.2.0`（design/v0.2.0/），本次全部改动写入 `design/v0.2.1/`
> 相关既有文档：`design/v0.2.0/gui/01_想法分析.md`、`04_GUI需求分析.md`、`05_GUI功能列表与窗口定义.md`、`08_窗口层次结构与导航图.md`、`12_用户流程.md`；静态库 `design/v0.2.0/gproto/77_静态库完成契约.md`

## 一、输入想法原文要点

1. 「选择导出列」对话框的 OK 与 Cancel 点击无效；按钮语言应统一。
2. 新增中/英两种界面语言；默认语言随系统语言自动切换；菜单栏合适位置可手动切换语言。
3. 导出的 CSV 出现乱码（中文表头变为乱码），需修复。
4. 特征码页「列管理」中的所有按钮都没有效果，需修复。
5. 「关于」弹窗的 OK 按钮不起作用，需修复。
6. 特征码管理页「新增行」需扩展为「新增一行」与「新增多行」。
7. Release 与 Debug 的 GUI 都有黑色命令窗口；Debug 可保留作调试窗口，Release 需取消（或都取消）。
8. 既已选定进程，特征码管理页的「进程」列应在每次新增行时自动填充对应进程名。
9. 进程列表应在最开始自动刷新一次（而非手动刷新才显示）；筛选框应移到底部而非顶部。
10. 筛选框有值时点击刷新进程会混入不相干的进程。
11. 点击进程的 PID、名称等列头时，应按对应列排序。
12. 进程选择页中的进程应显示对应进程图标；无图标或用默认图标的应显示 Windows 默认进程图标。
13. 当前 UI 风格/配色不统一（结果页输入框与日志框为黑色，其余为白色），应统一为白色。
14. 页面显示（如日志）应用颜色点缀，其他组件也需颜色点缀并统一风格。

## 三、已澄清的关键决策（用户确认）

- **i18n 方案**：采用 **Qt 标准翻译体系**（`tr()` + `.ts`/`.qm` + `QTranslator`）；`lupdate`/`lrelease` 由 Qt 独立安装自带（步骤 37 记录）。
- **C-12 进程图标**：**扩展 psig 提供图标**——架构规则禁止 GUI 生产代码调用平台 API，故图标须由静态库提供，按流程触发静态库流程（步骤 20）。
- **C-07 控制台窗口**：**仅 Release 取消**（WIN32 子系统），Debug 保留控制台便于调试。

## 四、期望行为（用户视角）

- 各对话框（选择导出列、列管理、关于）的 OK/Cancel 及功能按钮**点击立即生效**并正确关闭。
- 界面支持**中/英双语**：首次启动按系统语言自动选择；菜单栏提供「语言」菜单可随时切换（中文/English），切换后界面即时刷新。
- 导出的 CSV 用 Excel 等打开**中文表头不乱码**；再导入本程序仍能正确解析。
- 特征码页可**新增一行**或**一次新增多行**；新增的行「进程」列自动填入当前目标进程名。
- 进程页**启动即自动枚举**一次进程；筛选框位于**列表底部**；筛选状态下刷新只显示匹配项；点击列头按该列排序；每行显示进程图标。
- Release 版**无黑色控制台窗口**；整体配色**统一为白色基调**，日志等区域用颜色点缀。

## 五、范围与不做项

- 不新增程序类型、不改技术栈（Qt6 + psig 静态库 + CMake/vcpkg）。
- 不改动已归档版本目录（`design/v0.2.0/` 及更早）。
- 与改动无关的既有功能（进程枚举/特征码解析/扫描/导入导出格式主体/日志）保持行为不变。
