# 01 想法分析（v0.2.2）

- 模式：**修改/添加功能**（沿用 v0.2.1 的 `psig_gui` + `psig` 静态库）。
- 输入：`.idea/v0.2.2.md`（9 个改动点 + 版本号声明）。
- 目标：在 v0.2.1 基础上修复/增强导出、列管理、进程列表显示、重新选择进程提示、语言一致性、列宽、日志开关、权限图标等。

## 改动点（源自 .idea/v0.2.2.md）

| 编号 | 原文要点 | 归类 |
| --- | --- | --- |
| C-01 | 导出结果缺「十进制地址」列选项；「自定义」应改名「备注」 | 导出/命名 |
| C-02 | 列管理「键/类型」应为下拉选择而非自由输入；新增列不影响匹配 | 列管理 |
| C-03 | 进程列表 PID 0/4 等名称为空（仅默认图标），需修复 | 进程显示 |
| C-04 | 重新选择进程前/后弹窗提示是否保存当前特征码表 | 流程 |
| C-05 | 界面英文时导出结果 CSV 表头仍中文，需随语言 | i18n/导出 |
| C-06 | 特征码列：可编辑/自定义列不随语言；默认列随语言；导出随界面语言；自定义（备注）不随语言 | i18n/列 |
| C-07 | 调整进程列宽：Name×2，Accessible=PID，余下给 Path；仍可调 | 布局 |
| C-08 | 视图菜单缺日志开关；「清空日志」应移到日志窗口右键菜单 | 日志 |
| C-09 | 进程按读写权限用图标区分（有权限显示图标，无权限不显示）；不阻止选择 | 权限指示 |

## 影响范围

- 静态库 `psig`：C-01 十进制导出列、C-05/C-06 导出表头随语言 → 需扩展 `ResultExportOptions`、增 `address_dec`、双语 `BuiltinKeyFromTitle`。
- GUI（View/Model/ViewModel/资源）：C-01~C-09 全部涉及。
- 不涉及：核心扫描算法、MVVM 分层架构、构建系统框架（沿用 v0.2.1）。

## 约束

- 沿用既有分层与代码规范（View 纯净、ViewModel 集中 connect、Model 纯净、GUI 不调平台 API）。
- 任何缺失能力须经静态库跨流程（见 14_API能力需求.md、gproto/）。
