# 02 领域模型（增量，v0.2.1）

> 前置：`01_想法分析.md`、`design/v0.2.0/gui/02_领域模型.md`（基线领域模型）
> 说明：修改模式——仅对既有领域模型做增量更新，标注「新增/修改/删除」；与改动无关的内容引用 v0.2.0，不重复分析。

## 1. 业务对象（增量）

| 对象 | 变更 | 说明 | 关键属性 |
| --- | --- | --- | --- |
| 进程 Process | **修改** | 增加「图标」显示属性 | pid/name/path/accessible、**icon（ARGB 位图，可空）** |
| 应用设置 AppSettings | **新增** | 界面偏好（本次为语言） | **language（zh_CN / en_US / 跟随系统）** |
| 特征码表 Table | 不变 | 引用 v0.2.0（含 templateText） | columns/rows/templateText |
| 匹配结果表 ResultSet | 不变 | 引用 v0.2.0（含 templateText/customColumn） | results/templateText/customColumn |
| 列定义 ColumnDef | 不变 | 引用 v0.2.0 | key/title/type/builtin |

> 「图标 icon」为**派生显示属性**（由静态库从进程可执行文件提取），不参与匹配/导入导出，仅用于进程表展示。
> 「语言 language」为**界面偏好**，影响全部 `tr()` 文案与内置字符串（列标题等）。

## 2. 数据集合（增量更新）

### 集合 A：特征码表 SignatureCollection（可编辑条目集）
- 变更：**元素操作扩展**——「新增」由「新增一行」扩展为「新增一行」+「新增多行（一次 N 行）」。
- 变更：新增行时「进程」列**默认值** = 当前目标进程名（若已选定）；用户仍可编辑覆盖。
- 其余（编辑、删除、批量删除、导入导出、模板文本）不变。

### 集合 C：进程列表 ProcessList（只读查询结果）
- 变更：**元素属性新增** 图标（每行显示进程图标，无图标用系统默认）。
- 变更：**元素操作新增**「按列排序」（点击列头，按 PID/名称/路径/可访问排序）。
- 变更：**加载时机**——程序启动即自动枚举一次（原需手动刷新）。
- 变更：**筛选位置**——筛选框置于列表**底部**（原顶部）；筛选与刷新组合时仅保留匹配项（修复既有缺陷）。
- 可写性：只读（不变）。

### 集合 B / D / E：列定义集 / 匹配结果表 / 历史日志
- 不变（引用 v0.2.0）。历史日志新增「颜色点缀」的**表现**约定（见 07/28 文档），不改变集合语义。

## 3. 参与者（增量）

| 参与者 | 职责变更 |
| --- | --- |
| 操作员（用户） | 新增：切换界面语言；新增特征码行时使用自动填充的进程名；在进程页按列排序/查看图标 |

## 4. 操作流程（高层，增量）

1. 启动 → 进程页**自动枚举**进程（新增）。
2. 查看图标 / 按列排序 / 底部筛选 / 多选目标进程 → 确认进入特征码页（新增排序与图标）。
3. 维护特征码：**新增一行/新增多行**（新增行自动填充进程名）（扩展）。
4. 批量扫描 → 结果表（不变）。
5. 结果查看/编辑/导出（不变）；导出 CSV 中文表头不再乱码（修复）。
6. 任意时点：菜单栏切换**界面语言**（新增）。
