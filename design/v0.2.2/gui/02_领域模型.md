# 02 领域模型（增量，v0.2.2）

- 模式：修改型。在 v0.2.1 领域模型基础上标注增量集合与操作。
- 数据集合（沿用）：进程集合、特征码集合、匹配结果集合。
- 增量（仅展示/元数据层，不影响扫描业务）：
  - **进程集合**：新增「名称兜底」展示规则（PID 0/4 → 系统进程名）；新增「权限图标」展示属性（accessible 决定 DecorationRole 是否有图标）。
  - **特征码集合（列）**：列管理由「自由输入键/类型」改为「下拉选择」；列定义含 builtin 标记（builtin 列随语言、自定义列不随语言）。
  - **匹配结果集合**：导出列新增「地址(十进制)」；导出表头随语言。
- 集合操作（沿用）：查看/复制/编辑/删除/批量。新增操作的语义见 06/11/12。
- 与 v0.2.1 一致：扫描只消费 `pattern`/`name`，列元数据不影响匹配（C-02 确认）。
