## 2. 窗口布局变更（用户可见）

### 2.1 主窗口菜单栏（C-02）

- 新增「**语言 / Language**」菜单，位于「帮助」之前（或「视图」之后），项：
  - `中文`（checkable）
  - `English`（checkable）
  - `跟随系统 / System`（checkable）
  - 三者互斥（QActionGroup），当前语言项选中。
- 切换后立即重建/重译界面（`QTranslator` 装载 + `retranslateUi` 刷新各控件文案）。

### 2.2 进程选择页（C-09 / C-10 / C-11 / C-12）

- 布局由上到下：**进程表** → **筛选框**（`模糊过滤进程名 / 路径…`）。
- 进程表列：`PID` / `名称`（含进程图标，`Qt::DecorationRole`）/ `路径` / `可访问`；点击列头排序。
- 启动后自动枚举一次（无需手动点刷新）。

### 2.3 特征码编辑页（C-06 / C-08）

- 右键菜单/编辑菜单/工具栏：`新增一行`、`新增多行…`、`删除选中行`、`列管理`。
- 新增多行：弹出 `QInputDialog::getInt` 询问行数（1..N），一次性插入 N 行。
- 新增的每一行「进程」列填入当前目标进程名。

### 2.4 匹配结果页（C-01 / C-13）

- 模板文本输入区与表格背景统一为白色（C-13）。
- 「选择导出列」对话框 OK/Cancel 生效（C-01）。

### 2.5 对话框（C-01 / C-04 / C-05）

- 选择导出列 / 列管理 / 关于：OK、Cancel 及内部按钮全部接线生效；按钮文案本地化。

### 2.6 日志区（C-14）

- 日志 Dock 保持白底，但按内容**着色点缀**（如 `[扫描]`/`[导出]`/`[导入]`/错误行不同颜色），字号/行距统一。

## 3. 用户操作路径（点击流程）

1. 启动 → 进程页**自动列出**进程（含图标）→ 可点击列头排序 → 底部筛选框过滤 → 多选/双击 → 进入特征码页。
2. 特征码页：右键 `新增一行` / `新增多行…`（新行自动填进程名）/ `删除选中行` / `列管理`（对话框按钮生效）。
3. 扫描 → 结果页：编辑模板文本/自定义列 → 右键 `导出 ▸ CSV`（中文表头不乱码）/ `选择导出列…`（OK/Cancel 生效）。
4. 任意时点：菜单栏「语言」切换中/英；帮助 → 关于（OK 生效）。
5. Release 启动无控制台窗口。

## 4. 可视化反馈要求

- 语言切换后所有界面文案即时更新；对话框按钮文案与语言一致。
- 列排序后表头显示排序指示符（▲/▼）。
- 进程图标缺失时显示系统默认图标（不出现空白/错位）。
- 配色统一为白色基调；日志按级别着色（信息/成功/警告/错误）。

## 5. 变更对既有需求的覆盖关系

- 覆盖 v0.2.0「日志框/模板框深色」表现：改为白底 + 颜色点缀（C-13/C-14）。
- 覆盖 v0.2.0「需手动刷新进程」：改为启动自动枚举（C-09）。
- 覆盖 v0.2.0「筛选框在顶部」：移到列表底部（C-09）。
- 其余 v0.2.0 需求保持不变。
