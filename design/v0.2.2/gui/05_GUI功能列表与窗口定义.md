# 05 GUI 功能列表与窗口定义（v0.2.2，增量）

> 窗口结构沿用 v0.2.1：主窗口（QMainWindow，栈式三页 + 菜单/工具栏 + 状态栏 + 日志停靠窗）。

## 受影响功能点

| 功能 | 窗口/部件 | 变更 |
| --- | --- | --- |
| 导出匹配结果 | 导出列选择对话框 + 结果导出 | 增「地址(十进制)」选项；表头随语言（C-01/C-05） |
| 特征码列管理 | ColumnManagerDialog | 键/类型改下拉；新增列不影响匹配（C-02） |
| 进程列表 | ProcessSelectionPage / ProcessTableModel | 空名兜底（C-03）；权限图标（C-09）；列宽（C-07） |
| 重新选择进程 | 主窗口工具栏/扫描菜单 → onReselectProcess | 保存提示弹窗（C-04） |
| 特征码表导出 | 导出特征码 CSV | 表头随语言；自定义列不翻译（C-06） |
| 日志 | 日志停靠窗 + 视图菜单 | 视图菜单增日志开关、移除清空项；日志右键清空（C-08） |

## 窗口定义（不变部分）
- 三页：进程选择页、特征码编辑页、匹配结果页。
- 主窗口菜单：文件/编辑/扫描/视图/语言/帮助。视图菜单本轮变更见上。
