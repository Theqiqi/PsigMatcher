# 05 GUI 功能列表与窗口定义（v0.2.1，增量）

> 前置：`04_GUI需求分析.md`、`design/v0.2.0/gui/05_GUI功能列表与窗口定义.md`（基线）
> 说明：仅列出**受本次改动影响**的窗口与功能；未列出的窗口/功能沿用 v0.2.0。

## 1. 窗口清单（增量）

| 窗口/组件 | 类型 | 变更 |
| --- | --- | --- |
| 主窗口 MainWindow | QMainWindow | 修改：新增「语言」菜单；集中接线（对话框按钮）；配色/日志着色 |
| 进程选择页 ProcessSelectionPage | QWidget | 修改：筛选框移到底部；表格含图标列、可点列头排序；启动自动刷新 |
| 特征码编辑页 SignatureEditorPage | QWidget | 修改：右键菜单新增「新增一行/新增多行…」 |
| 匹配结果页 ResultPage | QWidget | 修改：模板框/表格白底；选择导出列对话框生效 |
| 列管理对话框 ColumnManagerDialog | QDialog | 修改：全部按钮接线生效 |
| 选择导出列对话框 ExportColumnsDialog | QDialog | 修改：OK/Cancel 接线生效 |
| 关于对话框 AboutDialog | QDialog | 修改：OK 接线生效 |

## 2. 功能列表（增量）

| 功能编号 | 功能 | 入口 | 触发 | 输出/反馈 |
| --- | --- | --- | --- | --- |
| F-01 | 界面语言切换 | 菜单栏「语言」 | 选择中文/English/跟随系统 | QTranslator 装载 + 界面重译 |
| F-02 | 默认语言自动判定 | 启动 | 依据 `QLocale::system()` | 自动选中对应语言项 |
| F-03 | 对话框按钮生效 | 各对话框 | 点击 OK/Cancel/功能按钮 | 正确接受/取消/执行并关闭 |
| F-04 | 新增一行 | 特征码页右键/编辑菜单/工具栏 | 用户操作 | 追加 1 行，进程列填目标进程名 |
| F-05 | 新增多行 | 特征码页右键/编辑菜单 | 用户输入行数 | 追加 N 行，进程列填目标进程名 |
| F-06 | 进程列自动填充 | 新增行时 | 已选定目标进程 | 新行「进程」列 = 目标进程名 |
| F-07 | 进程启动自动枚举 | 启动 | install() | 自动枚举一次并填充进程表 |
| F-08 | 进程表按列排序 | 进程页表头 | 点击列头 | 按 PID/名称/路径/可访问排序（含指示符） |
| F-09 | 进程图标显示 | 进程页表 | 常驻 | 每行显示图标（缺省用系统默认） |
| F-10 | 筛选保持 | 进程页筛选框 | 刷新进程时 | 刷新后重新应用筛选（仅显示匹配项） |
| F-11 | 导出 CSV 编码 | 结果页右键导出 | 导出 CSV | 写 UTF-8 BOM，中文表头不乱码 |
| F-12 | 配色统一 + 日志着色 | 全局 | 常驻 | 白底基调；日志/状态栏颜色点缀 |
| F-13 | Release 去控制台 | 构建 | 编译 Release | 无控制台窗口（WIN32 子系统） |

## 3. 与静态库的接口关系（能力需求，详见步骤 16-21）

| 功能 | 依赖静态库能力 | 既有 API 是否覆盖 |
| --- | --- | --- |
| F-11 CSV 编码（UTF-8 BOM） | CSV 导出写 BOM + 导入剥离 BOM | **否**（需扩展） |
| F-09 进程图标 | 提取进程图标位图 | **否**（需扩展） |
| F-01/F-02 语言 | 无（Qt i18n） | 不涉及 |
| F-03 对话框按钮 | 无（View/VM 接线） | 不涉及 |
| F-04/F-05/F-06 新增行 | 无（Model/VM） | 不涉及 |
| F-07/F-08/F-10 进程页 | 无（Model/VM/View） | 不涉及 |
| F-12/F-13 配色/构建 | 无（资源/构建） | 不涉及 |
