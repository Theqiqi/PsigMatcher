# 06 交互模式设计（v0.2.1，增量）

> 前置：`02_领域模型.md`、`05_GUI功能列表与窗口定义.md`、`design/v0.2.0/gui/06_交互模式设计.md`（基线）
> 说明：仅重新设计**受改动影响的集合/窗口**；其余引用 v0.2.0。

## 1. 操作入口分级原则（沿用，本次应用）

| 级别 | 定义 | 本次落点 |
| --- | --- | --- |
| 高频全局 | 全局/跨页常用 | 工具栏动作、菜单栏（含「语言」） |
| 元素级 | 作用于表格中「选中的行」 | 表格右键菜单（+ 双击） |
| 低频 | 偶尔使用 | 菜单栏 / 对话框 |

## 2. 各集合的交互设计（增量）

### 集合 A：特征码表（可编辑条目集，多选）
- 选择模式：多选（不变）。
- 操作入口（**扩展**）：
  - `新增一行`：右键菜单 / 编辑菜单 / 工具栏（Ctrl+N）。
  - `新增多行…`：右键菜单 / 编辑菜单（弹出数量输入对话框，1..N）。
  - `删除选中行`、`列管理`：不变。
- 默认值（**新增**）：新增行时「进程」列默认 = 当前目标进程名（未选定则空）。
- 可写性：可编辑（不变）。

### 集合 C：进程列表（只读查询结果，多选）
- 选择模式：多选（不变）。
- 操作入口（**扩展**）：
  - `按列排序`：**点击列头**（PID/名称/路径/可访问；图标列不排序），表头显示排序指示符。
  - `筛选`：底部筛选框，逐字符即时过滤；**刷新后重新应用**（修复 C-10）。
  - `图标显示`：每行显示进程图标（缺省用系统默认）。
  - 启动即自动枚举一次（无需手动刷新）。
- 可写性：只读（不变）。

### 应用设置：界面语言（**新增**）
- 入口：菜单栏「语言」菜单（低频→菜单）。
- 选择模式：三选一互斥（中文 / English / 跟随系统）。
- 生效：切换后即时重译全部界面（不改数据、不重启）。

### 对话框（C-01 / C-04 / C-05）
- 选择导出列 / 列管理 / 关于：**模态**对话框，OK 接受、Cancel 取消、内部功能按钮即时作用于对话框内表格/列表。
- 交互约束：按钮点击必须产生可见结果（接受→返回并应用；取消→放弃）。

## 3. 窗口级交互（增量）

### 进程页（C-09 / C-10 / C-11 / C-12）
- 布局：上=进程表（含图标列），下=筛选框。
- 启动：自动枚举；枚举中显示瞬时反馈「正在枚举进程…」。

### 语言切换（C-02）
- 菜单栏切换 → 立即应用；当前语言项以 checkable 标记。

## 4. 约束满足说明

- 集合性质决定可写性与入口：进程列表只读（排序/筛选/图标为视图层能力）；特征码表可写（新增行扩展）。
- 可批量操作（新增多行、删除）支持数量/多选执行。
- 操作入口分级已贯彻：全局高频→工具栏/菜单；元素级→右键/双击；低频→菜单/对话框。
- 仅重设计受改动影响的集合/窗口，其余引用 v0.2.0。
