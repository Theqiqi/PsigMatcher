# 08 窗口层次结构与导航图（v0.2.1，增量）

> 前置：`05_GUI功能列表与窗口定义.md`、`06_交互模式设计.md`、`07_状态与反馈信息设计.md`、`design/v0.2.0/gui/08_窗口层次结构与导航图.md`（基线）
> 说明：仅更新受影响窗口的层次/导航关系。

## 1. 窗口层次（增量，Qt 控件术语）

```
QMainWindow (MainWindow)
├── QMenuBar
│   ├── 文件(&F): 导入特征码 / 导出特征码 / 退出
│   ├── 编辑(&E): 新增一行 / 新增多行… / 删除选中行 / 列管理      [修改：新增多行]
│   ├── 扫描(&S): 刷新进程 / 开始扫描 / 取消扫描
│   ├── 视图(&V): 进程选择* / 特征码编辑 / 匹配结果 / 重新选择进程* / 清空日志
│   ├── 语言(&L): 中文 / English / 跟随系统（QActionGroup 互斥）   [新增]
│   └── 帮助(&H): 关于
├── QToolBar（主工具栏，ToolButtonIconOnly，按页显隐）
│   ├── 进程页组: 刷新进程 / 确认选择
│   ├── 特征码页组: 导入 / 导出 / 开始扫描 / 取消扫描 / 新增一行 / 重新选择进程
│   └── 结果页组: 清空结果 / 重新选择进程
├── QStackedWidget (centralWidget)
│   ├── [0] SignatureEditorPage
│   │   └── QTableView（+ 右键 QMenu: 新增一行/新增多行…/删除选中行/列管理）
│   ├── [1] ProcessSelectionPage
│   │   ├── QTableView（可点列头排序；名称列含图标 DecorationRole）
│   │   │   └── + 右键 QMenu: 以此进程为目标/刷新/全选
│   │   └── QLineEdit 筛选框                              [修改：移到底部]
│   └── [2] ResultPage
│       ├── QPlainTextEdit 模板文本区（白底）             [修改：配色]
│       └── QTableView（白底；右键 QMenu: 导出▸{CSV,DB,TXT}/选择导出列/删除选中行/清空）
├── QDockWidget「历史日志」: QPlainTextEdit（白底 + 按级别着色）  [修改：配色/着色]
└── QStatusBar: persistentLabel | progressBar | transientLabel
```

对话框：
```
ColumnManagerDialog (QDialog)      [修改：按钮接线生效]
ExportColumnsDialog (QDialog)      [修改：OK/Cancel 接线生效]
AboutDialog (QDialog)              [修改：OK 接线生效]
QInputDialog / QFileDialog / QMessageBox   [复用]
```

## 2. 导航图（增量）

```
[启动] ──► 进程页(ProcessPage)  ──自动枚举一次──► 填充进程表(含图标)
             │  双击进程行 / 工具栏「确认选择」 / 右键「以此进程为目标」
             ▼
          特征码页(SignaturePage)  ◄──►  结果页(ResultPage)
             │                                   ▲
             │ 开始扫描                           │ 扫描完成自动跳转
             └───────────────────────────────────┘

任意时点：工具栏/视图菜单「重新选择进程」──► 进程页
任意时点：菜单栏「语言」切换中/英 ──► 界面即时重译（不改数据）
```

- **启动落点**：进程页（沿用 v0.2.0）；**启动即自动枚举**（本次新增）。
- **显隐规则**：沿用 v0.2.0（确认目标后隐藏「进程选择」入口并显示「重新选择进程」）。
- **语言切换**：全局生效，不改变当前页面与导航状态。

## 3. 约束满足说明

- 使用 Qt 控件术语（QMainWindow、QStackedWidget、QTableView、QPlainTextEdit、QToolBar、QMenu、QMenuBar、QDockWidget、QStatusBar、QDialog）。
- 仅更新受影响窗口（主窗口/三页/三个对话框）的层次与导航关系，其余引用 v0.2.0。
