# 11 GUI 执行路径（v0.2.1，增量）

> 前置：`10_GUI功能流程图.md`
> 说明：每个改动功能补齐**正常路径 / 错误路径 / 取消路径**三类（事件驱动独立路径）。未列出的沿用 v0.2.0。

## F-01 / F-02 界面语言切换（C-02）

- **正常**：菜单选择中文/English/跟随系统 → 装载对应 `QTranslator` → `retranslateUi()` 刷新全部文案 → 瞬时/日志反馈 → 菜单勾选态更新。
- **错误**：目标 `.qm` 缺失 → 回退到内置中文（源字符串），瞬时提示「语言资源缺失，已回退」；不崩溃。
- **取消**：不适用（选择即生效）；再切回原语言即恢复。

## F-03 对话框按钮生效（C-01 / C-04 / C-05）

- **正常**：打开对话框 → 点击 OK → `accepted→accept` → `exec()==Accepted` → VM 应用结果（选择导出列：记录列；列管理：更新列定义；关于：仅关闭）。
- **错误**：选择导出列未勾选任何列 → 接受后瞬时错误「至少选择一列」并保持原选择；列管理产生非法列（空键）→ 校验后提示并保持对话框打开（或忽略空行）。
- **取消**：点击 Cancel / ESC → `rejected→reject` → `exec()==Rejected` → 放弃，不改动。

## F-04 / F-05 新增一行 / 新增多行（C-06）

- **正常**：`新增一行` → 追加 1 行；`新增多行…` → 输入行数 n → 追加 n 行；新行「进程」列填目标进程名；状态/日志反馈。
- **错误**：新增多行输入非法（≤0 或超上限）→ `QInputDialog` 约束为 1..N（无非法值）；无。
- **取消**：新增多行对话框取消 → 不新增。

## F-06 进程列自动填充（C-08）

- **正常**：已选定目标进程 → 新增行的「进程」列 = 目标进程名。
- **错误**：未选定目标进程（如直接进入特征码页）→ 进程列留空，不报错。
- **取消**：不适用。

## F-07 / F-10 进程自动枚举 + 筛选保持（C-09 / C-10）

- **正常**：启动 → 自动枚举 → 进程表填充；若筛选框已有文本，刷新后仅显示匹配项。
- **错误**：枚举失败/返回空 → 进程表为空，瞬时「已枚举 0 个进程」，不崩溃。
- **取消**：不适用（枚举为后台任务，随程序退出结束）。

## F-08 / F-09 列排序 + 图标显示（C-11 / C-12）

- **正常**：点击列头 → 按该列升/降序排序（再点切换方向）；名称列显示进程图标。
- **错误**：图标提取失败 → 显示系统默认图标，不报错。
- **取消**：不适用。

## F-11 导出 CSV 编码（C-03）

- **正常**：导出 CSV → 文件以 UTF-8 BOM 开头 → Excel 打开中文表头正常 → 再导入本程序可正确解析（导入剥离 BOM）。
- **错误**：写文件失败 → 瞬时「导出失败: <err>」。
- **取消**：文件对话框取消 → 不导出。

## F-12 / F-13 配色统一 / Release 去控制台（C-13 / C-14 / C-07）

- **正常**：程序以白底基调显示；日志按级别着色；Release 无控制台窗口。
- **错误**：无。
- **取消**：不适用。

## 约束满足说明

- 每个改动功能均给出正常/错误/取消三类路径（事件驱动独立路径）。
- 本次改动均为进程内自身操作（含 psig 本地调用），**无需管理员提权**；若后续扩展真实抓包类用例，参照 `design/v<版本>/gui/33_admin_capture_guide.md`。
