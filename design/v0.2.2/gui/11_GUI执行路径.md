# 11 GUI 执行路径（v0.2.2，增量）

- 正常/错误/取消三类路径（事件驱动独立路径，沿用 v0.2.1）。

## 重新选择进程（C-04）
正常：触发 → 保存提示 →（保存）写文件成功 → 进入进程页。
取消：触发 → 保存提示 → 取消 → 停留在当前页，无副作用。
错误：保存时导出失败 → 日志报错（红），仍进入进程页（不阻断）。

## 列管理（C-02）
正常：下拉选键/类型 → 确定 → setColumns 生效。
取消：对话框 rejected → 丢弃改动。

## 导出（C-01/C-05/C-06）
正常：选列（含 address_dec）→ 导出 → psig 写文件（十进制列 + 语言表头）→ 日志绿色成功。
错误：路径不可写 → psig 抛异常/返回错误 → 日志红色失败。

## 进程列表（C-03/C-09）
正常：枚举 → 空名兜底 → 仅 accessible 注入图标。
无阻断错误路径：图标获取失败 → 该行无图标（默认行为）。
