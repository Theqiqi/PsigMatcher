# 12 用户流程（v0.2.2，增量）

> 每个用户操作对应一个用户流程，覆盖正常/错误/取消。作为用户流程测试与 E2E 依据。

## UF-01 列管理下拉选择（C-02）
用户：特征码页右键 → 列管理 → 键/类型下拉选择 → 确定。
结果：列元数据更新；执行扫描结果不变（新增列不影响匹配）。

## UF-02 重新选择进程保存提示（C-04）
用户：工具栏/扫描菜单「重新选择进程」。
结果：弹窗 → 保存（写文件）/不保存（直接切换）/取消（中止）。

## UF-03 进程空名兜底（C-03）
用户：启动自动刷新 → 观察进程列表。
结果：PID 0/4 显示「系统空闲进程/系统」而非空白。

## UF-04 权限图标区分（C-09）
用户：观察进程列表图标。
结果：有读写权限进程显示图标；无权限进程无图标；均可被选择。

## UF-05 导出十进制列 + 语言表头（C-01/C-05）
用户：结果页 → 导出 → 勾选「地址(十进制)」→ 导出。
结果：文件含十进制地址列；表头语言跟随界面语言（英文→英文）。

## UF-06 特征码导出语言策略（C-06）
用户：英文 UI → 导出特征码 CSV。
结果：builtin 列表头为英文；自定义（备注）列标题不变；中文 UI 导入仍正确识别。

## UF-07 日志开关与右键清空（C-08）
用户：视图菜单勾选「历史日志」→ 日志窗显隐；日志窗右键 → 清空。
结果：日志窗可开关；清空仅经右键，视图菜单无清空项。

## UF-08 进程列宽（C-07）
用户：启动 → 观察列宽；拖拽调整。
结果：名称更宽、PID=可访问宽度、路径剩余；可调整。
