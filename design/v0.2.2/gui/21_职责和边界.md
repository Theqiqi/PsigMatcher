# 21 职责和边界（v0.2.1，增量）

> 前置：`20_GUI模块分析.md`、`design/v0.2.0/gui/21_职责和边界.md`（基线）

## 各层职责与禁止项（本次适用点）

| 层 | 职责 | 禁止项 |
| --- | --- | --- |
| View | 构建控件（含「语言」菜单、底部筛选框）、暴露控件 getter（含对话框 `buttonBox()`/内部按钮 getter）、公开 UI 方法（`retranslateUi()`、`appendLog` 着色）；执行显隐 | **不写 connect**、无 signals/private slots、不 include ViewModel/psig、不调业务；不调用平台 API 取图标 |
| Model | `ProcessTableModel`：`DecorationRole` 图标、`sort()`；`SignatureTableModel`：`addRow/addRows`；纯 Qt | 不依赖 psig、不含业务格式化；图标以 `QIcon` 承载（由 VM 注入） |
| ViewModel | 持 `View*`；集中 connect（含**对话框按钮**、语言菜单、新增多行）；调 psig 公共 API（含 `ProcessIcon`/`DefaultProcessIcon`）；把图标字节转 `QIcon` 注入 Model；装载 `QTranslator` 触发 `retranslateUi` | 不用 findChild 访问交互控件；不自行实现静态库能力；不直接调用 Win32 取图标 |
| 静态库 | psig 提供 CSV BOM 与进程图标能力 | 不依赖 Qt |

## 边界确认（本次）

- **对话框按钮接线在 VM**：VM 在 `exec()` 前 `connect(dlg.buttonBox(), accepted/rejected, dlg, accept/reject)`；列管理内部按钮同样由 VM 连接（View 零 connect）。
- **i18n**：`QTranslator` 由 VM（或 main）装载；View 提供 `retranslateUi()` 刷新文案；字符串一律走 `tr()`。
- **图标**：psig 返回 BGRA 字节；VM 转 `QImage(Format_ARGB32)` → `QIcon` → Model `setIcon`；View 仅通过 `DecorationRole` 显示。
- **排序**：Model 实现 `sort()`；View 仅 `setSortingEnabled(true)`。

## 约束满足说明

- 每层禁止项清晰；View 不依赖 ViewModel/静态库；ViewModel 经 `View*` 指针操控 View。
- 平台能力（图标）经 psig 提供，GUI 生产代码不调用平台 API。
