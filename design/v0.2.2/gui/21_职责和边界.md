# 21 职责和边界（v0.2.2，增量）

> 前置：`20_GUI模块分析.md`、`design/v0.2.1/gui/21_职责和边界.md`（上一版本）

## 各层职责与禁止项（本次适用点）

| 层 | 职责 | 禁止项 |
| --- | --- | --- |
| View | 构建控件（含日志开关动作、日志右键菜单、列管理下拉框）、暴露控件 getter（含 `keyCombo()`/`typeCombo()`/`logContextMenu()`/`toggleLogAction()`）、公开 UI 方法（初始列宽 `setDefaultColumnWidths`、`retranslateUi`）；执行显隐 | **不写 connect**、无 signals/private slots、不 include ViewModel/psig、不调业务；不调用平台 API 取图标 |
| Model | `ProcessTableModel`：`DecorationRole` 仅对 `accessible` 行返回图标（C-09）、名称空时按 PID 兜底（C-03）；`ResultTableModel`：末列标题 `tr("备注")`；`SignatureTableModel`：内置列表头走 `tr()`、自定义列用 `title`（C-06）；纯 Qt | 不依赖 psig、不含业务格式化；图标以 `QIcon` 承载（由 VM 注入）；不自行决定权限语义 |
| ViewModel | 持 `View*`；集中 connect（含日志开关、日志右键、列管理下拉、重新选择进程提示）；调 psig 公共 API（`BuiltinSignatureColumns`、`ProcessIcon`/`DefaultProcessIcon`、结果导出带 `headers`）；把图标字节转 `QIcon` 且仅对 `accessible` 行注入；构造导出表头（随语言） | 不用 findChild 访问交互控件；不自行实现静态库能力；不直接调用 Win32 取图标 |
| 静态库 | psig 提供 `address_dec` 列、`ResultExportOptions.headers`、英文标题回映射、`custom`→备注 | 不依赖 Qt |

## 边界确认（本次）

- **列管理下拉（C-02）**：键选项 = `psig::BuiltinSignatureColumns()` 的键（去重，避免自由输入拼写错误）；类型选项固定枚举。View 仅暴露 `QComboBox` getter；选中值经 getter 读取、由 VM 处理。新增列仅改特征码表列元数据，**不参与扫描匹配**（扫描只读取 `pattern`/`name`）。
- **进程名兜底与权限图标（C-03/C-09）**：`ProcessTableModel::data()` 名称列为空时返回兜底名（PID 0→`tr("系统空闲进程")`，PID 4→`tr("系统")`，其余空→`tr("未知进程")`）；`DecorationRole` 仅在该行 `accessible==true` 时返回图标，无权限进程仅显示文本（不阻止选择）。
- **重新选择进程保存提示（C-04）**：`onReselectProcess` 在切换前若特征码表存在未保存改动，弹 `QMessageBox::question`（保存 / 不保存 / 取消）；取消则中止切换。
- **导出表头随语言（C-05/C-06）**：VM 在 `exportOptions()` 中按当前语言构造 `headers` 向量（内置列用对应语言标题，自定义「备注」列固定中文/不随语言）传入 `psig::ResultExportOptions.headers`，静态库优先使用。特征码表表头：内置列随 `retranslateUi` 经 `tr()` 变化，自定义列保持 `title` 不变。
- **日志开关与右键清空（C-08）**：视图菜单仅保留「显示/隐藏日志」开关动作；「清空日志」从视图菜单移除，改为 `m_logEdit` 右键菜单项；两者连接均在 VM。

## 约束满足说明

- 每层禁止项清晰；View 不依赖 ViewModel/静态库；ViewModel 经 `View*` 指针操控 View。
- 平台能力（图标、列键枚举）经 psig 提供，GUI 生产代码不调用平台 API。
