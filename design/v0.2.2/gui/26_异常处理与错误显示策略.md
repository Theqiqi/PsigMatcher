# 26 异常处理与错误显示策略（v0.2.2，增量）

> 前置：`24_ViewModel接口.md`、`design/v0.2.1/gui/26_异常处理与错误显示策略.md`（上一版本）

## 策略（沿用 + 本次适用点）

| 场景 | 分派 | 表现 |
| --- | --- | --- |
| 特征码模式非法 | 瞬时反馈（错误） | 「特征码错误: 第 N 行…」 |
| 未选择目标进程 | 瞬时反馈（错误） | 「请先选择目标进程」 |
| 未选择要删除的行 | 瞬时反馈（错误） | 「请先选择要删除的行」 |
| 未选择导出列 | 瞬时反馈（错误） | 「至少选择一列」 |
| 无结果可导出 | 瞬时反馈（错误）+ 菜单项禁用 | 「无结果可导出」 |
| psig 导入/导出失败 | 瞬时反馈（错误）+ 日志 | 「导入/导出失败: <err>」 |
| 新增多行数量取消 | **无动作**（取消路径） | 不新增，不报错 |
| 语言资源 `.qm` 缺失 | 瞬时反馈（错误，可回退） | 回退内置中文，提示「语言资源缺失」 |
| 进程图标提取失败 | **静默回退** | 使用系统默认图标，不报错 |
| 导入前询问是否保存 | **模态弹窗** | `QMessageBox::question`（保存/不保存/取消） |
| 重新选择进程前保存提示（C-04） | **模态弹窗** | `QMessageBox::question`（保存/不保存/取消）；取消→中止切换 |
| 清空结果确认 | **模态弹窗** | `QMessageBox::question` |
| 关于 / 选择导出列 / 列管理 | **模态弹窗** | 对应 QDialog |
| 列管理下拉选择（C-02） | **无错误路径** | 键/类型从下拉选择，杜绝自由输入非法键 |
| 进程名兜底（C-03） | **无错误** | 空名按 PID 显示系统进程名，不视为异常 |
| 权限无图标（C-09） | **无错误** | 无权限进程仅文本显示，不阻止选择 |

## 后台线程异常

- 扫描/枚举/图标提取在 `QtConcurrent::run` 执行；结果经 `QFutureWatcher::finished`（或 `invokeMethod` QueuedConnection）回主线程处理，**不跨线程抛异常**。
- psig 不抛异常（出参表达错误）；图标提取失败返回 invalid，VM 回退默认图标。

## 约束满足说明

- 短暂性错误走瞬时反馈；需决策/需确认走模态弹窗；错误提示位置唯一（状态栏右区/日志）。
- 本次新增的 C-02/C-03/C-04/C-08/C-09 异常路径已覆盖：下拉选择无非法输入、空名兜底非异常、重新选择提示可取消、日志清空改为右键且仍走既有 `onClearLog`、无权限仅文本不报错。
