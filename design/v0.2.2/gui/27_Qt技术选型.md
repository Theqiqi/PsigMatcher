# 27 Qt 技术选型（v0.2.2）

> 前置：`08_窗口层次结构与导航图.md`、`13_技术选型分析.md`、`design/v0.2.1/gui/27_Qt技术选型.md`（上一版本）

## 结论：沿用

| 维度 | 选型 |
| --- | --- |
| 程序类型 | Windows 桌面 exe |
| 语言 | C++20 |
| GUI | Qt6::Widgets（代码构建 Widget，无 .ui） |
| 异步 | Qt6::Concurrent（QtConcurrent::run + QFutureWatcher） |
| 国际化 | **Qt6::LinguistTools**（`lupdate`/`lrelease`）+ `QTranslator` + `.ts`/`.qm` |
| 测试 | gtest（+ Qt 事件环境） |
| 构建 | CMake + Ninja + MSVC；vcpkg manifest（gtest）；find_library 引用 psig |
| 静态库命名 | psig（依据程序类型命名） |

## 本次使用的既有控件/类（沿用 v0.2.1）

- `QTranslator` + `QLocale::system()`、`QActionGroup`（语言互斥菜单）。
- `QDialogButtonBox`（对话框按钮接线）、`QInputDialog::getInt`（新增多行数量）。
- `QHeaderView` 排序（`setSortingEnabled`）、`Qt::DecorationRole`（进程图标）。
- `QImage`/`QPixmap`/`QIcon`（由 psig 的 `IconBitmap` 转换）。
- **本次新增控件（仍属 Qt6::Widgets 既有能力）**：
  - `QComboBox`（列管理键/类型下拉，C-02）。
  - `QMenu` 作为 `QPlainTextEdit` 的自定义右键菜单（`setContextMenuPolicy(CustomContextMenu)`，C-08）。
  - `QHeaderView::setColumnWidth` / `setSectionResizeMode(Stretch)`（进程列宽，C-07）。

## 构建要点（沿用）

- Release：`set_target_properties(psig_gui PROPERTIES WIN32_EXECUTABLE $<CONFIG:Release>)`（去控制台）；Debug 保留控制台。
- i18n：`qt_add_lupdate`/`qt_add_translations` 或自定义命令由 `lrelease` 生成 `.qm` 并加入 `.qrc`；本次需补充「备注」「地址(十进制)」及英文 `Name/Signature/Remarks` 等翻译条目。

## 约束满足说明

- 沿用既有 Qt 技术选型；静态库命名依据程序类型（psig）；i18n 用 Qt 官方组件，无 Qt 以外第三方；本次新增下拉/右键菜单/列宽均属 Qt6::Widgets 既有能力。
