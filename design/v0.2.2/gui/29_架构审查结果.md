# 29 架构审查结果（步骤 31，v0.2.1）

- 版本：v0.2.1
- 前置：`design/v0.2.1/gui/21_职责和边界.md`、`22_View层接口.md`、`23_Model层接口.md`、`24_ViewModel接口.md`、`design/v0.2.0/gui/29_架构审查结果.md`（基线）
- 说明：修改型流程，仅审查本次改动涉及的 View/ViewModel/Model 文件；其余沿用 v0.2.0/v0.1.0 审查结论。
- 审查对象：`gui/src/{view,model,viewmodel}`、`gui/src/main.cpp`

## 检查项与结论（均通过）

### 1. View 纯净可独立编译 — 通过
- `src/view/` 无 `signals:`/`slots:`/`Q_SIGNALS`/`Q_SLOTS`（grep 无命中）。
- `src/view/` 无 `connect(`（grep 无命中）；对话框 OK/Cancel 与内部按钮的接线全部在 VM。
- 新增 `retranslateUi()` 到三页：仅重设自身控件文案，无事件逻辑。
- 对话框按钮文案（`确定/取消`）在 View 内以 `tr()` 设置；对话框为每次调用新建、随当前语言构造。
- 独立目标 `psig_test_view` 仅链接 `Qt6::Widgets Qt6::Test GTest`，源文件为 View + Model，不链接 ViewModel/`psig`；Debug/Release 均编译链接通过。

### 2. VM 持指针链接事件 — 通过
- `MainViewModel` 持 `MainWindow* m_view`（绑定引用、不拥有），经 `install(MainWindow*)` 注入。
- 页面/控件指针全部经 View 公开 getter 获取；语言菜单动作、`addSignatureRowsAction` 等经 getter 取得；无 `findChild`（grep 无命中）。

### 3. 后台执行不阻塞 — 通过
- 耗时操作（`psig::EnumerateProcesses`、`psig::ScanProcesses`、`psig::ProcessIcon`/`DefaultProcessIcon`）经 `QtConcurrent::run` 后台执行。
- 枚举/扫描经 `QFutureWatcher::finished` 回主线程；图标逐条经 `QMetaObject::invokeMethod(..., Qt::QueuedConnection)` 回主线程回填。
- 主线程无 `QThread::wait()`；仅析构函数 `~MainViewModel` 中 `waitForFinished()`（退出路径）。

### 4. Model 纯净 — 通过
- `model/` 仅 `#include` Qt 与 `model/types.h`；`ProcessRow` 新增 `QIcon` 为纯 Qt 类型。
- `ProcessTableModel::sort()`、`setIcon()`、三 Model 的 `retranslate()` 均为纯展示逻辑，不含业务逻辑、不 include `psig.h`。

### 5. 事件集中 connect — 通过
- 全部控件信号（`QAction::triggered`、`QLineEdit::textChanged`、`QPlainTextEdit::textChanged`、`QTableView::doubleClicked`、`QHeaderView::sortIndicatorChanged`、`QWidget::customContextMenuRequested`、`QFutureWatcher::finished`）均在 VM 的 `install()/bind*()` 中 connect。
- 对话框按钮（`QDialogButtonBox::accepted/rejected`、列管理内部按钮 `clicked`）在 VM 创建对话框处经 `wireDialog()` 与 `connect` 完成；无重复 connect。

### 6. 页面拆分 — 通过
- 页面为独立类独立文件；`MainWindow` 仅骨架（`QStackedWidget` + 菜单/工具栏 + 状态栏/日志）。
- 语言菜单与视图菜单均在 `MainWindow` 中构建、以 getter 暴露给 VM。

### 7. 控件 getter 暴露 — 通过
- 新增 getter：`MainWindow::languageZhAction()/languageEnAction()/languageSystemAction()/languageGroup()/addSignatureRowsAction()`；`SignatureEditorPage::addRowsAction()`；对话框 `buttonBox()`/内部按钮 getter（既有）。
- 页面 `retranslateUi()` 为公开 UI 方法（供 MainWindow 在语言切换后调用）。

### 8. connect 归属 — 通过
- 右键菜单动作、语言菜单动作、对话框按钮均由 VM connect；View 仅提供 `contextMenu()`/`buttonBox()` 与内部按钮 getter。
- `MainWindow::retranslateUi()` 由 VM 的 `applyLanguage()` 调用（属 UI 更新、由 VM 驱动）。

### 9. 布局交互合理性 — 通过
- 进程页布局：表格（伸缩）在上、筛选框在下（C-09）；表头可点排序（C-11）。
- 语言菜单位于「视图」与「帮助」之间，三项互斥（`QActionGroup`），当前项勾选（C-02）。
- 工具栏按页显隐逻辑保持；新增「新增多行」并入编辑菜单与右键菜单（C-06）。

### 10. main.cpp 固定流程 — 通过
- 顺序为：创建 `MainWindow view` → 创建 `MainViewModel viewModel` → `viewModel.install(&view)` → `view.show()` → `app.exec()`。
- 默认语言在 `install()` 内装载（`applyLanguage(QString(), false)`）；`main.cpp` 未变。

## 结论

本次改动涉及的架构检查项全部通过；无需回退。
