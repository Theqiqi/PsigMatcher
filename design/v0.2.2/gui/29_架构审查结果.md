- 前置：`design/v0.2.2/gui/21_职责和边界.md`、`22_View层接口.md`、`23_Model层接口.md`、`24_ViewModel接口.md`、`design/v0.2.1/gui/29_架构审查结果.md`（基线）

- 审查对象：`gui/src/{view,model,viewmodel}`、`gui/src/main.cpp`

## 检查项与结论（均通过）

### 1. View 纯净可独立编译 — 通过
- `src/view/` 无 `signals:`/`slots:`/`Q_SIGNALS`/`Q_SLOTS`（grep 无命中）。
- `src/view/` 无 `connect(`（grep 无命中）；列管理对话框 OK/Cancel 与内部按钮的接线全部在 VM。
- `ColumnManagerDialog` 键/类型改为下拉：`setKeyOptions(QStringList)` 由 VM 注入（View 不依赖 `psig`）。
- `MainWindow` 视图菜单新增 `toggleLogAction`（可勾选）；`logEdit` 设为 `CustomContextMenu`，由 VM 接管显示 `logContextMenu`。
- `ProcessSelectionPage::setDefaultColumnWidths()` 为新公开 UI 方法（VM 调用），不涉及事件。
- 独立目标 `psig_test_view` 仅链接 `Qt6::Widgets Qt6::Test GTest`，Debug/Release 均编译链接通过。

### 2. VM 持指针链接事件 — 通过
- `MainViewModel` 持 `MainWindow* m_view`（绑定引用、不拥有），经 `install(MainWindow*)` 注入。
- 新增 `bindLogActions()`：连接 `toggleLogAction` → `onToggleLog`、`logEdit::customContextMenuRequested` → `onLogContextMenu`、`clearLogAction` → `onClearLog`。
- 页面/控件指针全部经 View 公开 getter 获取（`toggleLogAction/logEdit/logContextMenu/logDockVisible/...`）；无 `findChild`（grep 无命中）。

### 3. 后台执行不阻塞 — 通过
- `startIconLoad`（C-09）改为：仅 `accessible==true` 的 PID 提交后台取图标；`applyProcessIcon` 仅对 accessible 行注入。其余沿用 `QtConcurrent::run` + `QFutureWatcher`/`invokeMethod`。
- 主线程无 `QThread::wait()`；仅析构函数中 `waitForFinished()`（退出路径）。

### 4. Model 纯净 — 通过
- `ProcessTableModel::data()` 新增空名兜底（PID 0/4/其他 → 系统进程名）—— 仅展示层逻辑，不引入业务/平台依赖。
- `ResultTableModel` 末列 `headerData` 由 `tr("自定义")` 改为 `tr("备注")`（C-01）。

### 5. 事件集中 connect — 通过
- 全部新增/修改信号（`toggleLogAction::triggered`、`logEdit::customContextMenuRequested`、`clearLogAction::triggered`）均在 VM 的 `bindLogActions()` 中 connect。
- 列管理对话框键/类型下拉当前值由 VM 通过 `dlg.columns()` 读取（不订阅控件信号），与既有按钮接线一致。

### 6. 页面拆分 — 通过
- 页面为独立类独立文件；`MainWindow` 仅骨架。
- `MainWindow::logDockVisible/setLogDockVisible/setToggleLogChecked` 为新公开 UI 方法（VM 调用）。

### 7. 控件 getter 暴露 — 通过
- 新增 getter：`MainWindow::toggleLogAction()/logContextMenu()/logDockVisible()/setLogDockVisible()/setToggleLogChecked()`；`ProcessSelectionPage::setDefaultColumnWidths()`；`ColumnManagerDialog::setKeyOptions(QStringList)`。

### 8. connect 归属 — 通过
- 视图菜单新增「日志」开关、清空日志动作、日志右键菜单均由 VM connect；View 仅提供 getter 与 `logContextMenu`。

### 9. 布局交互合理性 — 通过
- 进程页列宽（PID 基准 90）：Name=PID×2、Accessible=PID、Path 占用剩余（仍可手动调整）。
- 视图菜单结构：进程页 / 特征码页 / 结果页 / —— / 「日志」（勾选切换 dock 显隐）；「清空日志」仅在日志窗口右键菜单。
- 「重新选择进程」保存提示沿用既有 `QMessageBox::question` 模式（保存/不保存/取消 → 取消则中止切换，C-04）。

### 10. main.cpp 固定流程 — 通过
- 顺序不变：View → ViewModel → install → show → exec；默认语言装载在 `install()`。

## 结论

本次改动涉及的架构检查项全部通过；无需回退。
