# 30 职责审查结果（步骤 32，v0.2.2）

- 版本：v0.2.2
- 前置：`design/v0.2.2/gui/21_职责和边界.md`、`25_静态库API调用映射.md`、`design/v0.2.1/gui/30_职责审查结果.md`（基线）
- 说明：审查 main/View/Model/ViewModel 职责划分，以及静态库 API 的真实性与隔离性。审查对象为本次改动涉及文件。

## 检查项与结论（均通过）

### 1. main 职责 — 通过
- `src/main.cpp` 仅做组装（View/ViewModel/install/show/exec）；本版未改动。

### 2. View 职责 — 通过
- View 只画 UI：
  - `ColumnManagerDialog` 新增 `setKeyOptions`（VM 注入下拉项）+ `buildRow`（按行构造标题项 + 键/类型 `QComboBox`）；不依赖 `psig`。
  - `ProcessSelectionPage::setDefaultColumnWidths()` 仅设列宽与 `Stretch/Interactive` 模式，不涉及事件。
  - `MainWindow` 视图菜单调整（日志开关 + 移除清空日志）、`logEdit` 右键策略与 `logContextMenu` 构造、`logDockVisible/setLogDockVisible/setToggleLogChecked` 公开方法。
- View 不 include ViewModel/静态库（grep 无命中）；无 `connect`/`signals`/`slots`。

### 3. Model 职责 — 通过
- `ProcessTableModel::data()` 空名兜底（C-03）属展示层 i18n/字符串逻辑，未引入业务。
- `ResultTableModel` 末列 `tr("备注")` 替代 `tr("自定义")`，沿用既有 `tr()` 模式。
- 三 Model 的 `retranslate()` 与 `sort()` 沿用 v0.2.1 结论。

### 4. ViewModel 职责 — 通过
- 新增槽/方法：
  - `bindLogActions()` / `onToggleLog`（C-08 视图菜单日志开关）；
  - `onLogContextMenu`（C-08 日志窗口右键 → 显示 `logContextMenu`）；
  - `markSignatureDirty`（C-04 标记未保存改动）；
  - `askSaveBeforeReselect()` 返回 `bool`（false 表示「取消」，中止重新选择）。
- `exportOptions()`（C-05）：按当前 `m_language` 构造 `headers`，键序由 `psig::SelectResultKeys(options.columns)` 保证。
- `tableFromModel()`（C-06）：内置列标题按当前语言经 `signatureHeaderForKey` 的 `tr()` 输出；自定义列沿用 `ColumnDef.title`。
- `startIconLoad` / `applyProcessIcon`（C-09）：仅 `accessible==true` 进程取图标并回填，不阻止选中。
- `onManageColumns`（C-02）：向 `ColumnManagerDialog` 注入 `setKeyOptions(BuiltinSignatureColumns().keys)`。

### 5. 静态库 API 真实性 — 通过
- VM 调用的 psig 公共 API 均真实存在于 `psig/include/psig.h`：
  - 既有：`EnumerateProcesses / ProcessIcon / DefaultProcessIcon / ScanProcesses / RequestCancel / ParsePattern / BuiltinSignatureColumns / ImportSignaturesCsv|Db / ExportSignaturesCsv|Db / ExportResultsCsv|Db|Txt / ResultExportOptions`。
  - **本版新增**：`psig::ResultColumnDefs()`、`psig::SelectResultKeys(requested)`（见 `design/v0.2.2/gproto/77_静态库完成契约.md`）。

### 6. 隔离性 — 通过
- GUI 只经 `#include "psig.h"` 公开头文件调用静态库；`psig.h` 仅在 `src/viewmodel/mainviewmodel.h` 出现（VM 层）。
- `src/view/` 与 `src/model/` 无 `windows.h`/`shell32`/`shlobj` 等平台 API（grep 无命中）；`IconBitmap → QImage/QIcon` 转换在 VM 完成。
- 静态库不引用 Qt（沿用 v0.2.1 psig 审查结论）。
- GUI 生产代码无 Qt 以外第三方库（grep `windows.h|tlhelp32|OpenProcess|ReadProcessMemory|boost|sqlite|gtest` 在 `src/` 无命中）。

## 结论

职责划分清晰、静态库调用真实且隔离良好；无需回退。
