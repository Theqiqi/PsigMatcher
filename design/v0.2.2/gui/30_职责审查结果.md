# 30 职责审查结果（步骤 32，v0.2.1）

- 版本：v0.2.1
- 前置：`design/v0.2.1/gui/21_职责和边界.md`、`25_静态库API调用映射.md`、`design/v0.2.0/gui/30_职责审查结果.md`（基线）
- 说明：审查 main/View/Model/ViewModel 职责划分，以及静态库 API 的真实性与隔离性。审查对象为本次改动涉及文件。

## 检查项与结论（均通过）

### 1. main 职责 — 通过
- `src/main.cpp` 只做组装：创建 View/ViewModel、`install`、`show`、`exec`，并加载 `:/style.qss` 与窗口图标；不含业务逻辑。
- 默认语言在 VM 的 `install()` 内装载；`main.cpp` 本版未改动。

### 2. View 职责 — 通过
- View 只画 UI：控件创建、布局、`setContextMenuPolicy`、`setSelectionMode`、`setSortingEnabled`、`setIconSize` 等展示属性。
- 新增 `retranslateUi()`（三页 + MainWindow）只重设文案，属展示职责；对话框按钮文案 `确定/取消` 由 View 设置。
- View 不 include ViewModel/静态库（grep 无命中）；无 `connect`/`signals`/`slots`。

### 3. Model 职责 — 通过
- Model 只维护行集合与 `data()/setData()/flags()/headerData()`；本版新增 `ProcessTableModel::sort()`（展示顺序）、`setIcon()`（DecorationRole）、三 Model 的 `retranslate()`（表头刷新），均属展示层职责，未越界。
- `SignatureTableModel::headerData` 对内置键返回 `tr()` 标题，属展示层 i18n，未引入业务逻辑。

### 4. ViewModel 职责 — 通过
- VM 槽函数统一为「校验 → 调静态库 API → 更新 Model → 刷新 View」：
  - `onAddSignatureRow/onAddSignatureRows`：`addRow/addRows(m_targetName)`（C-06/C-08），无 psig 依赖（Model/VM 内）。
  - `onProcessesEnumerated`：`setProcesses` → `applyProcessFilter` → `startIconLoad`（`psig::ProcessIcon`/`DefaultProcessIcon`）。
  - `applyLanguage`：`QTranslator` 装载/卸载 → `retranslateUi` → Model `retranslate` → `setLanguageChecked`。
- VM 不直接访问 View 私有成员，不 `findChild`；对话框经 View 公开 getter（`buttonBox()`/内部按钮）接线。

### 5. 静态库 API 真实性 — 通过
- VM 调用的 psig 公共 API 均真实存在于 `psig/include/psig.h`：`BuiltinSignatureColumns`、`ParsePattern`、`ImportSignaturesCsv/Db`、`ExportSignaturesCsv/Db`、`EnumerateProcesses`、`ProcessIcon`、`DefaultProcessIcon`、`ScanProcesses`、`RequestCancel`、`ExportResultsCsv/Db/Txt`、`ResultExportOptions`。
- 本版新增能力（CSV UTF-8 BOM、进程图标）由静态库流程实现并回退检查通过（见 `design/v0.2.1/gproto/77_静态库完成契约.md`、`19_API能力匹配分析.md`）。

### 6. 隔离性 — 通过
- GUI 只经 `#include "psig.h"` 公开头文件调用静态库；`psig.h` 仅在 `src/viewmodel/mainviewmodel.h` 出现。
- 进程图标必须来自 psig（`ProcessIcon`/`DefaultProcessIcon`）：`src/view/` 与 `src/model/` 无 `windows.h`/`shell32`/`shlobj` 等平台 API（grep 无命中）；`IconBitmap → QImage/QIcon` 转换在 VM 完成。
- 静态库不引用 Qt（psig 侧审查结论沿用，见 `design/v0.2.1/gproto/`）。
- GUI 生产代码无 Qt 以外第三方库（grep `windows.h|tlhelp32|OpenProcess|ReadProcessMemory|boost|sqlite|gtest` 在 `src/` 无命中）。

## 结论

职责划分清晰、静态库调用真实且隔离良好；无需回退。
