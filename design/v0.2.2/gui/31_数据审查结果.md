# 31 数据审查结果（步骤 33，v0.2.2）

- 版本：v0.2.2
- 前置：`design/v0.2.2/gui/25_静态库API调用映射.md`、`26_异常处理与错误显示策略.md`、`design/v0.2.1/gui/31_数据审查结果.md`（基线）
- 说明：审查真实数据与接口来源、是否存在重复实现、平台相关与第三方库使用。审查对象为本次改动涉及的生产代码。

## 检查项与结论（均通过）

### 1. 真实数据与接口来源 — 通过
- 无 mock/fake/stub/硬编码结果：`grep -niE "mock|fake|stub|hardcode" src/` 无命中。
- 数据来源真实：
  - 进程表 ← `psig::EnumerateProcesses()` 异步枚举。
  - 进程图标 ← `psig::ProcessIcon(pid)`，失败回退 `psig::DefaultProcessIcon()`；仅对 `accessible==true` 的进程取图（C-09）。
  - 匹配结果 ← `psig::ScanProcesses(req, cb, cancelPtr)` 真实扫描目标进程内存。
  - 特征码表导入/导出 ← `psig::ImportSignatures{Csv,Db}` / `ExportSignatures{Csv,Db}`（CSV 自动剥/写 UTF-8 BOM）。
  - 结果导出 ← `psig::ExportResults{Csv,Db,Txt}`，`options.headers` 由 GUI 按当前语言构造（C-05）。
  - 结果列键序 ← `psig::SelectResultKeys(options.columns)`（C-05/C-06 与静态库列序对齐）。
- 无伪造 API：所有 `psig::` 调用均对应 `psig.h` 公共声明。

### 2. 重复实现检查 — 通过
- GUI 未重复实现静态库已有能力：
  - 结果列选择与键序推导：调用 `psig::SelectResultKeys`；GUI 不自行实现列标准化逻辑（C-05）。
  - 内置列标题翻译：GUI 仅以 `tr()` 提供各语言映射；不预生成全语言标题表（依赖 Qt 的运行时翻译）。
  - CSV BOM / 进程图标提取：沿用 v0.2.1 结论（GUI 不处理字节序标记、不调用任何平台 API）。
- 「地址(十进制)」列、`ProcessTableModel` 空名兜底、列管理下拉、日志 dock 显隐、日志右键菜单、进程列宽、权限图标区分均为展示层逻辑，非业务算法重复实现。

### 3. 平台相关与第三方 — 通过
- GUI 生产代码 `src/` 无平台 API（`windows.h|shell32|shlobj|tlhelp32|OpenProcess|ReadProcessMemory` 无命中）、无第三方库（`boost|sqlite|gtest` 无命中）。
- 平台相关实现全部封装在 `psig` 静态库内，GUI 经公共 API 调用；进程图标能力同样经 psig 提供。

## 结论

数据来源真实、无重复实现、无越界依赖；无需回退。
