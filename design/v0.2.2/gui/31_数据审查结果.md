# 31 数据审查结果（步骤 33，v0.2.1）

- 版本：v0.2.1
- 前置：`design/v0.2.1/gui/25_静态库API调用映射.md`、`26_异常处理与错误显示策略.md`、`design/v0.2.0/gui/31_数据审查结果.md`（基线）
- 说明：审查真实数据与接口来源、是否存在重复实现、平台相关与第三方库使用。审查对象为本次改动涉及的生产代码。

## 检查项与结论（均通过）

### 1. 真实数据与接口来源 — 通过
- 无 mock/fake/stub/硬编码结果：`grep -niE "mock|fake|stub|hardcode" src/` 无命中。
- 数据来源真实：
  - 进程表 ← `psig::EnumerateProcesses()` 异步枚举。
  - 进程图标 ← `psig::ProcessIcon(pid)`，失败回退 `psig::DefaultProcessIcon()`（C-12）。
  - 匹配结果 ← `psig::ScanProcesses(req, cb, cancelPtr)` 真实扫描目标进程内存。
  - 特征码表导入/导出 ← `psig::ImportSignatures{Csv,Db}` / `ExportSignatures{Csv,Db}`（CSV 自动剥/写 UTF-8 BOM，C-03）。
  - 结果导出 ← `psig::ExportResults{Csv,Db,Txt}`。
- 无伪造 API：所有 `psig::` 调用均对应 `psig.h` 公共声明。

### 2. 重复实现检查 — 通过
- GUI 未重复实现静态库已有能力：
  - CSV BOM：由静态库 `Utf8Bom/HasUtf8Bom/StripUtf8Bom` 与导入/导出实现；GUI 不自行处理字节序标记（C-03）。
  - 进程图标提取：由静态库 `win_icon`（`SHGetFileInfoW` 等）完成；GUI 只做 `IconBitmap → QImage → QIcon` 的展示层转换（C-12），不调用任何平台 API。
  - 结果选列导出 / 模板文本 / 特征码解析：沿用 v0.2.0 结论（GUI 仅组装 `ResultExportOptions`、透传模板、调用 `ParsePattern`）。
- 「地址(十进制)」列、进程表排序、筛选均为展示层逻辑，非业务算法重复实现。

### 3. 平台相关与第三方库 — 通过
- GUI 生产代码 `src/` 无平台 API（`windows.h|shell32|shlobj|tlhelp32|OpenProcess|ReadProcessMemory` 无命中）、无第三方库（`boost|sqlite|gtest` 无命中）。
- 平台相关实现全部封装在 `psig` 静态库内，GUI 经公共 API 调用；进程图标能力同样经 psig 提供。

## 结论

数据来源真实、无重复实现、无越界依赖；无需回退。
