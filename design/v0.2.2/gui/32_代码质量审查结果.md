- 前置：`design/v0.2.2/gui/21_职责和边界.md`、`26_异常处理与错误显示策略.md`、`design/v0.2.1/gui/32_代码质量审查结果.md`（基线）
- 说明：审查异步执行、生命周期、跨线程异常、输入校验、内存管理、资源路径、空指针、嵌套深度、提前返回、头文件越界、单一职责。审查对象为本次改动涉及文件。

## 检查项与结论（均通过）

### 1. 异步执行 — 通过
- 进程图标 `startIconLoad`（C-09）在后台逐条取图（仅 `accessible==true`），经 `QMetaObject::invokeMethod(..., Qt::QueuedConnection)` 回主线程回填，不阻塞 UI。
- 其余沿用 `QtConcurrent::run` + `QFutureWatcher::finished`。

### 2. 生命周期 — 通过
- `bindLogActions()` 中连接 `logEdit::customContextMenuRequested` 与 `toggleLogAction::triggered`、`clearLogAction::triggered`；随 VM 析构自动断开（Qt 父子机制）。
- 图标后台任务持 `std::shared_ptr<std::atomic_bool> m_alive` 存活标志：VM 析构后任务在下一次循环检查处提前退出。
- 新增 Model/View/VM 字段均以 `this`（VM）/父对象为 parent。

### 3. 跨线程异常 — 通过
- 后台任务不抛异常：psig API 以返回错误字符串/空结果表达失败。
- `applyProcessIcon` / `startIconLoad` 的 `invokeMethod` 在目标已析构时 Qt 自动丢弃。

### 4. 输入校验 — 通过
- 「重新选择进程」保存提示（C-04）：仅当 `m_sigModel->rowCount()>0 && m_sigDirty` 时弹窗；`保存/不保存/取消` 三选项；`取消` → `askSaveBeforeReselect()` 返回 false → `onReselectProcess` 提前 return。
- 列管理新增列默认键取首项内置键；自定义键保留（即便不在选项中）。
- 列管理 `SwapRows` 交换下拉当前值（非 cellWidget 指针，避免 Qt 在替换时删除旧控件导致悬空引用）。

### 5. 内存管理 — 通过
- 新增控件（`QComboBox`、`QMenu`、`QAction`、`QDockWidget` 已有）均指定 parent；列管理下拉随表行 widget 生命周期管理，无 `new` 泄漏、无裸 `delete`。
- `applyLanguage` 中旧 `QTranslator` 显式 `removeTranslator` 后 `delete`（受父子机制兜底）。

### 6. 资源路径 — 通过
- `:/style.qss`、`:/app.png`、`:/i18n/psig_gui_<code>.qm` 均经 `.qrc` 资源访问，无硬编码磁盘路径。

### 7. 空指针 — 通过
- `install` 首行 `if (!view) return;`；`bindLogActions` 判空（`m_view->toggleLogAction()`/`logEdit()`/`clearLogAction()`）；`ColumnManagerDialog::columns()` 对 `cellWidget` 判空；`swapCombo` 判空；`askSaveBeforeReselect` 对 `clickedButton` 判空。

### 8. 嵌套深度 — 通过
- `askSaveBeforeReselect` 最深 3 层（按钮创建 → 弹窗 exec → 保存路径文件对话框），未超三重嵌套；其余槽函数 ≤ 2 层。

### 9. 提前返回 — 通过
- `onReselectProcess` 在 `askSaveBeforeReselect` 返回 false 时提前 `return`；列管理 `SwapRows` 在 row 范围不合法时早返；`buildRow` 用 `findText/findData` 失败回落默认。

### 10. 头文件越界 — 通过
- View 头文件仅依赖 Qt 与前置声明；`psig.h` 仅出现在 `src/viewmodel/mainviewmodel.h`（VM 层，允许）。
- 无 `#include "../`（grep 无命中）。

### 11. 单一职责 — 通过
- 三 Model 只负责数据/格式化/排序/图标承载 + 空名兜底；`MainViewModel` 只负责编排；页面/对话框只负责展示/存取。

## 结论

质量检查项全部通过；无需回退。
