# 09 模块变更（psig v0.2.3）

> 前置：`design/v0.1.0/gproto/09_模块设计.md`
> 说明：本版把 api 层由单文件按职责拆分为模块文件，落实 v0.1.0 模块设计「按职责拆分接口：进程/模式/数据交换模块」的要求。

## 模块结构（api 层）

| 模块文件 | 职责 | 导出能力（公共头 `psig.h`） |
| --- | --- | --- |
| `api/process_scan.cpp` | 进程枚举、图标、内存扫描、取消 | `EnumerateProcesses`/`ProcessIcon`/`DefaultProcessIcon`/`ScanProcesses`/`RequestCancel` |
| `api/pattern_api.cpp` | 模式解析、内置特征码列、结果列查询（转发） | `ParsePattern`/`BuiltinSignatureColumns`/`ResultColumnDefs`/`SelectResultKeys` |
| `api/exchange_signatures.cpp` | 特征码表 CSV/DB 导入导出 | `ImportSignaturesCsv/Db`/`ExportSignaturesCsv/Db` |
| `api/exchange_results.cpp` | 匹配结果 CSV/DB/TXT 导出 | `ExportResultsCsv/Db/Txt` |
| `api/api_internal.h` | 跨文件内部 glue（`psig::api::MakeColumn`），不外泄 | 无（内部） |

## 变更前后对照

| 项 | v0.2.2 | v0.2.3 |
| --- | --- | --- |
| api 层文件数 | 1（`api/psig.cpp`，554 行） | 4 职责文件 + 1 内部头（最大 196 行） |
| 符号下沉 | 匿名 namespace 内 `EncodeCells/DecodeCells` | 下沉 `data/codec`（公共编解码） |
| 宽窄转换 | `data/codec` 内（含 `windows.h`） | 下沉 `atomic/win_encoding`（R-05） |

## 约束满足说明

- 公共 ABI 不变：`psig.h` 未改签名，仅版本串更新 → 集成测试与 GUI 零改动。
- 跨文件共享仅经 `api/api_internal.h`（内部头），不进公共头。
