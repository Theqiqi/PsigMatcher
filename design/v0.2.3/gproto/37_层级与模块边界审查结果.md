# 37 层级与模块边界审查结果（静态库流程步骤 37，v0.2.3）

- 版本：v0.2.3
- 前置：`design/v0.1.0/gproto/09_模块设计.md`、`10_职责和边界说明.md`
- 审查对象：psig 全层（data / algorithm / atomic / api）

## 矩阵

| 检查项 | 判定标准（量化） | 结论 | 证据（文件:行号 / grep 命中） |
| --- | --- | --- | --- |
| 依赖方向单一 | data ← algorithm ← atomic/api，无反向依赖 | ✅ | `grep -rnE '#include "(algorithm\|atomic\|api)/' psig/src/data` 无命中；`grep -rnE '#include "(atomic\|api)/\|#include "psig.h"' psig/src/algorithm` 无命中 |
| 不跨层调用 | 只能调用紧邻下层 | ✅ | `data/codec.cpp` 仅自依赖；`algorithm/*` 仅依赖 `data/types.h`（`module_locate.h:7`）；`atomic/win_process.h` 依赖 `data/types.h`（`:8`）；`api/*` 依赖下层 `algorithm/atomic/data` |
| 模块间只经公共头 | 不访问非公开符号 | ✅ | `api/` 经 `algorithm/*.h`、`atomic/*.h`、`data/*.h` 内部头调用；GUI 只经 `psig/include/psig.h` |
| 模块边界：按职责拆分 | 进程/模式/数据交换分文件 | ✅ | `api/process_scan.cpp`（进程）、`api/pattern_api.cpp`（模式）、`api/exchange_signatures.cpp` + `api/exchange_results.cpp`（数据交换）；原单文件 `api/psig.cpp` 已删 |
| 平台调用边界 | WinAPI 只在 atomic | ✅ | `grep -rn "windows.h" psig/src` 仅命中 `atomic/win_encoding.cpp:4`、`atomic/win_icon.cpp:4`、`atomic/win_process.cpp:4` |
| 无 Qt 依赖 | 静态库不依赖 Qt | ✅ | `grep -rnE '#include <Q' psig/src psig/include` 无命中 |
| 公共头唯一契约 | 消费方只经 `psig.h` | ✅ | GUI 侧 `grep -rn "psig.h" gui/src` 仅命中 `viewmodel/mainviewmodel.h:18`、`viewmodel/viewmodel_helpers.h:14`（VM 层） |
| 内部 glue 不外泄 | 跨文件共享符号置于内部头 | ✅ | `api/api_internal.h`（`namespace psig::api { MakeColumn }`）未被公共头包含 |

## 结论

层级与模块边界全部通过（无 ❌），依赖方向单一、无跨层调用、无反向依赖；api 层按职责拆分落地。无需回退。
