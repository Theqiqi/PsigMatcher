# 02 跨流程需求接收（psig v0.2.4）

- 来源：GUI 流程步骤 16-21（`design/v0.2.4/gui/14_API能力需求.md`、`16_API充分性审查.md`、`17_API缺失需求.md`、`18_静态库流程交接记录.md`）。
- 目标静态库：`psig`（已存在；本轮为**能力修正/字段扩展**，非新建能力）。
- 跳转目标：静态库流程「跨流程需求接收」步骤。

## 需求清单（来自 gui/17_API缺失需求.md）

### R-01 进程名来源修正（C-01）
- 公共 API：`std::vector<ProcessInfo> EnumerateProcesses();`（**签名不变**，行为修正）。
- 行为：`ProcessInfo::name` 优先取 Toolhelp 快照 `PROCESSENTRY32W.szExeFile`；为空时回落 `QueryFullProcessImageNameW`；`path` 仍由映像路径提供（可空）。
- 验收：受保护进程（Registry / MemCompression / Secure System）名与任务管理器一致；`name` 一律非空。

### R-02 结果导出摘要随语言（C-03）
- 公共 API：`ResultExportOptions` 新增字段 `std::string summary;`（完整摘要文案，可空）。
- 行为：`ExportResultsTxt` 若 `summary` 非空 → 以其为摘要行；为空 → 回落现默认中文（向后兼容）。
- 验收：传英文摘要 → TXT 英文；不传 → 中文；CSV/DB 不变。

## 能力覆盖判定
- 静态库已存在，上述为对既有 API 的**行为修正 + 字段新增**；需改动 `atomic/win_process.{h,cpp}`、`api/process_scan.cpp`、`api/exchange_results.cpp`、`include/psig.h`。
- GUI 不自行实现上述能力、不调用平台 API；全部经修正后的 `psig` 公共 API。

## 交付契约（见 77_静态库完成契约.md）
- 公共头变更：`psig/include/psig.h`（`ResultExportOptions::summary`）。
- 行为变更：`EnumerateProcesses` 名称来源。
- 库产物：`psig/out/lib/<配置>/psig.lib`（Debug/Release 重建）。
- 验收：psig 单测 + 集成测试覆盖 R-01/R-02；Debug/Release 全绿。
