# 05 业务流程变更（psig v0.2.4）

> 前置：`04_需求点设计.md`

## RP-1 进程名枚举业务流程（变更）
1. 创建 Toolhelp 进程快照（`TH32CS_SNAPPROCESS`）。
2. 遍历 `PROCESSENTRY32W`：取 `th32ProcessID` 与 `szExeFile`。
3. 对每个 pid：`name = szExeFile`；若为空 → 回落 `ProcessNamePath` 取映像名。
4. `path` 由 `ProcessNamePath` 提供（可空）；`accessible` 由 `OpenForRead` 判定（不变）。
5. 按 pid 排序返回。

**变更点**：第 3 步名称来源由「仅映像路径」改为「快照名优先、映像名兜底」。

## RP-2 结果 TXT 导出业务流程（变更）
1. 调用方构造 `ResultExportOptions`（含 `columns`/`headers`，本次可含 `summary`）。
2. `ExportResultsTxt`：若有 `templateText` → 先写模板段（不变）。
3. **摘要行**：`summary` 非空 → 写 `summary`；否则写默认 `"匹配结果 (N 条)"`。
4. 写各结果行（不变）。

**变更点**：第 3 步摘要行文案来源由「写死中文」改为「调用方 `summary` 优先、默认中文兜底」。
