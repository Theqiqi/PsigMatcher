# 09 模块变更（psig v0.2.4）

> 前置：`08_功能设计.md`

## 分层（沿用）
`data/`（纯 std） ← `algorithm/`（纯算法） ← `atomic/`（WinAPI/SQLite/文件） / `api/`（组装）

## 受影响模块
| 模块 | 层 | 变更 |
| --- | --- | --- |
| `atomic/win_process.{h,cpp}` | atomic | `EnumProcessIds` → `EnumProcessEntries`（快照携带 `szExeFile` 名） |
| `api/process_scan.cpp` | api | `EnumerateProcesses` 用快照名优先 |
| `api/exchange_results.cpp` | api | `ExportResultsTxt` 摘要行取 `options.summary` |
| `include/psig.h` | 公共头 | `ResultExportOptions` 增 `summary` |

## 不变
- `data/`、`algorithm/` 无改动。
- `atomic` 仍为唯一平台调用层；`api` 仍只组装。
