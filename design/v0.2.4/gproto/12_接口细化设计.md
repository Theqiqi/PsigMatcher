# 12 接口细化设计（psig v0.2.4）

> 前置：`11_api接口分析.md`

## 数据结构列表
| 结构 | 变更 |
| --- | --- |
| `ResultExportOptions` | + `std::string summary;` |
| `ProcessInfo` | 无字段变化（`name` 取值语义修正） |
| `data::ProcessEntry` | **新增**（atomic 内部）：`{ uint32_t pid; std::wstring name; }` |

## 算法列表
| 算法 | 变更 |
| --- | --- |
| `algorithm/*` | 无新增（本轮无纯算法改动） |

## 原子化 api 列表
| 原子 api | 变更 |
| --- | --- |
| `EnumProcessEntries()` | **新增**（替换/包装 `EnumProcessIds`）：返回 `vector<data::ProcessEntry>` |
| `ProcessNamePath()` | 沿用（作为名称兜底与路径来源） |

## api 接口异常设计
- `EnumerateProcesses`：无异常，返回空表即无进程。
- `ExportResultsTxt`：`err` 承载写失败原因；`summary` 空走默认，不视为错误。
