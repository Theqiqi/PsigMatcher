# 13 数据结构变更（psig v0.2.4）

> 前置：`12_接口细化设计.md`

## 公共结构（`include/psig.h`）
```cpp
struct ResultExportOptions {
    std::string templateText;
    std::vector<std::string> columns;
    std::vector<std::string> headers;
    std::string summary;   // 新增：TXT 摘要文案（可空；非空时替换默认摘要行）
};
```

## 内部结构（`src/data/types.h`）
```cpp
namespace psig::data {
struct ProcessEntry {   // 新增：快照枚举条目
    uint32_t pid = 0;
    std::wstring name;  // 来自 PROCESSENTRY32W.szExeFile
};
}
```

## 独立性
- 均为纯 std 类型（`std::string`/`std::wstring`/`uint32_t`），无平台/框架依赖，可独立编译。
- `ProcessEntry` 位于 data 层，供 atomic 层返回、api 层消费。
