# 15 算法执行过程变更（psig v0.2.4）

> 前置：`13_数据结构变更.md`、`14_算法变更.md`

## 执行过程（取值分支）

### 进程名（`api/process_scan.cpp`）
1. `entries = atomic::EnumProcessEntries()`（快照 pid+name）。
2. 对每条 entry：
   - `ProcessNamePath(pid, pathName, path)` 取路径与映像名。
   - `info.name = entry.name.empty() ? pathName : entry.name`。
   - `info.path = path`；`info.accessible = (OpenForRead(pid) != nullptr)`。
3. 按 pid 排序返回。

### 结果摘要（`api/exchange_results.cpp`）
1. 写模板段（若有）。
2. `line = options.summary.empty() ? ("匹配结果 (" + n + " 条)") : options.summary`。
3. 写 `line` + 分隔线 + 结果行。

## 说明
- 无纯算法函数，故无「算法执行过程」独立描述；以上为 api 层取值过程。
