# 16 技术选型（psig v0.2.4）

> 前置：`02_跨流程需求接收.md`

## 结论：沿用
| 维度 | 选型 |
| --- | --- |
| 程序类型 | 静态库（进程特征码匹配） |
| 语言 | C++20 |
| 框架 | Windows 平台（WinAPI / Toolhelp） |
| 是否跨平台 | 否 |
| 静态库命名 | `psig`（依据程序类型命名，非 pmem） |
| 依赖 | 无 Qt；内置 SQLite amalgamation；系统库 kernel32/user32 等 |

## 说明
- 本版仅修正既有能力取值与扩展导出选项字段，不改变技术栈。
