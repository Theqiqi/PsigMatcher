# 19 代码规范（psig v0.2.4）

> 前置：统一要求、`design/v0.2.2/gproto/19_代码规范.md`（基线）

## 结论：沿用既有规范

- 命名：类型 PascalCase、函数 PascalCase；公共 API 沿用既有风格。
- 分层：data / algorithm / atomic / api，逐层依赖，禁止反向依赖。
- 算法层纯函数、无 I/O；原子化层无业务语义；接口层组装。
- 不抛异常，用返回值/出参表达错误。
- 头文件包含使用 `名字/名字` 形式，禁止 `../` 相对路径。
- 禁止依赖 Qt；平台调用集中在原子化层。

## 本次补充

- Toolhelp 快照句柄必须成对释放（`CloseHandle`）。
- 进程名取值：快照名（`szExeFile`）优先、映像名兜底；不得在 api 层直接调用 WinAPI。
- 导出摘要文案由调用方传入字符串，psig 内部不得内嵌任何 UI/语言判断。

## 约束满足说明

- 沿用既有规范，本次改动遵循之。
