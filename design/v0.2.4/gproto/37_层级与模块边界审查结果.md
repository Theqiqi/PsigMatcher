# 37 层级与模块边界审查结果（静态库流程步骤 37，v0.2.4）

- 版本：v0.2.4
- 前置：`design/v0.2.4/gproto/09_模块变更.md`、`10_职责和边界变更.md`
- 审查对象：psig 全层（data / algorithm / atomic / api）

## 矩阵

| 检查项 | 判定标准（量化） | 结论 | 证据（文件:行号 / grep 命中） |
| --- | --- | --- | --- |
| 依赖方向单一 | data ← algorithm ← atomic/api，无反向依赖 | ✅ | `grep -rnE '#include "(algorithm\|atomic\|api)/' psig/src/data` 无命中 |
| 不跨层调用 | 只能调用紧邻下层 | ✅ | `api/exchange_results.cpp:6-11` 依赖 `algorithm/`+`atomic/`+`data/`；`data/` 仅自依赖 |
| 模块间只经内部头 | 不访问非公开符号 | ✅ | `api/` 经 `algorithm/*.h`、`atomic/*.h`、`data/*.h` 调用；GUI 只经 `psig/include/psig.h` |
| 模块边界：按职责拆分 | 进程/模式/数据交换分文件 | ✅ | `api/process_scan.cpp`（进程，本版改动）、`api/exchange_results.cpp`（结果导出，本版改动）、`api/exchange_signatures.cpp`、`api/pattern_api.cpp` |
| 平台调用边界 | WinAPI 只在 atomic | ✅ | `grep -rln "windows.h" psig/src` 仅命中 `atomic/win_encoding.cpp`、`atomic/win_icon.cpp`、`atomic/win_process.cpp` |
| 无 Qt 依赖 | 静态库不依赖 Qt | ✅ | `grep -rnE '#include <Q' psig/src psig/include` 无命中 |
| 公共头唯一契约 | 消费方只经 `psig.h` | ✅ | 公共头 `psig/include/psig.h` 为唯一对外契约；本版仅新增字段 `summary` |
| 内部结构不外泄 | 内部结构置于 data 层 | ✅ | `data::ProcessEntry` 定义于 `data/types.h`，不出现在 `psig.h` |

## 结论

层级与模块边界全部通过（无 ❌），依赖方向单一、无跨层调用、无反向依赖；本版改动落在 atomic/api 两层的既有职责文件内。无需回退。
