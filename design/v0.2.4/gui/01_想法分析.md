# 01 想法分析（v0.2.4）

- 版本：v0.2.4
- 输入：`.idea/v0.2.4.md`
- 模式：**修改/添加功能**（对 v0.2.3 现有程序做增量修改；非新建程序）
- 涉及模块/界面：GUI（View / Model / ViewModel）、psig 静态库（进程枚举、结果导出、特征码导入导出）

## 一、输入模式判定

想法描述的是对现有 `psig_gui` + `psig` 的**缺陷修复与交互/格式调整**，不是全新程序。故本流程为**修改型流程**：
- 复用 `.flow/带GUI的单体程序的GUI入口系统.md` 与 `.flow/带GUI的单体程序的业务系统静态库.md` 中与改动相关的步骤（需求→设计→编码→审查→编译→测试），仅执行受影响部分。
- 每个分析文档标注「改动点」；未受影响的既有内容只引用既有文档，不重复分析。

## 三、逐条分析与期望行为

### C-01 进程页「未知进程」
- **现状**：`psig::EnumerateProcesses()` 经 `atomic::ProcessNamePath()`（`OpenProcess(PROCESS_QUERY_LIMITED_INFORMATION)` + `QueryFullProcessImageNameW`）取名字；对**受保护进程**（如 Registry / MemCompression / Secure System 等）打开或查询失败 → 名字为空。
- **表现**：`ProcessTableModel::data()` 对空名兜底为 `tr("未知进程")`（英文 `Unknown Process`），于是进程列表出现 "Unknown Process"。
- **期望**：进程列表应显示**真实进程名**（与任务管理器一致），不应出现 "Unknown Process"。
- **根因线索**：`EnumProcessIds()` 已用 `CreateToolhelp32Snapshot(TH32CS_SNAPPROCESS)`，其 `PROCESSENTRY32W.szExeFile` **无需打开进程即可拿到进程名**，正是任务管理器所示名字。应以其作为名字来源/兜底。

### C-02 表格整行 hover 高亮
- **现状**：表格无 hover 规则，Qt 默认只对**鼠标所在单元格**着色。
- **期望**：鼠标悬停时**整行**高亮；悬停色为**选中色（#3a6ea5）的同色系、更淡**的色调；单击选中色不变。
- **范围（已定）**：特征码 / 进程 / 结果**三张表统一**（共享一个自定义 delegate）。

### C-03 结果导出随界面语言
- **现状 1（TXT）**：`psig::ExportResultsTxt()` 的摘要行写死中文 `"匹配结果 (N 条)"`，与界面语言无关。
- **现状 2（CSV/TXT 列头）**：`vmhelp::resultHeaderForKey("custom")` 硬编码返回 `"备注"`（未走 `tr()`），故英文界面下「备注」列头仍是中文，其余列（经 `tr()`）是英文。
- **期望**：结果导出的**表头与摘要行**都随界面语言（英文界面 → 全英文）。

### C-04 特征码表与结果模板解耦
- **现状**：`MainViewModel::tableFromModel()` 导出特征码表时 `t.templateText = m_templateText`，而 `m_templateText` 是**结果页的模板文本**（结果页顶部输入框）→ 特征码 CSV/DB 文件最前被写入结果页的模板文字。导入时 `applyTableToModel()` 又把它回填到结果页。
- **溯源**：`.idea/v0.2.0.md:17` 说明模板文本属于**匹配结果页**（"匹配结果页…加上最前面可以添加一大段的多行自定义文字做成模板"）。v0.2.0 把它同时挂到特征码表上，导致本次问题。
- **期望（已定）**：**解耦** —— 特征码表导出/导入**不再携带**模板文本；模板文本仅属于匹配结果页。psig 能力保留（旧文件仍可导入不报错）。

### C-05 导出格式按族收敛 + 防误操作
- **现状**：特征码管理导出 `.db` / `.csv`；匹配结果导出 `.db` / `.csv` / `.txt`。两类 `.csv` 同名，用户可能把结果文件当特征码表导入，**覆盖并丢失**当前特征码表。
- **已定方案**：**按格式族彻底分开后缀**（不发明专有后缀）：
  - **特征码表 → `.db`**（界面导入/导出仅提供 .db）
  - **匹配结果 → `.csv` + `.txt`**（界面仅提供 .csv/.txt，去掉 .db 入口）
  - 两类后缀完全不重叠，用户从文件对话框就不可能拿错。
- **范围（已定）**：**仅界面收敛**；psig 的 `ImportSignaturesCsv` / `ExportSignaturesCsv` / `ExportResultsDb` 保留为通用能力（可编程调用），不在本次删除。
