# 02 领域模型（增量，v0.2.4）

- 模式：修改型。在 v0.2.3 领域模型基础上标注增量集合与操作。
- 数据集合（沿用）：进程集合、特征码集合、匹配结果集合。
- 增量：
  - **进程集合**：元素名称来源调整为「Toolhelp 快照 `szExeFile` 优先、映像路径兜底」，消除空名 → 列表不再出现「未知进程 / Unknown Process」（C-01）。展示属性（`accessible` / 图标）不变。
  - **特征码集合**：导出/导入格式收敛为 `.db`；**不再携带模板文本**（模板文本不属于特征码表）（C-04 / C-05）。
  - **匹配结果集合**：模板文本明确归属「匹配结果页」；导出格式收敛为 `.csv` / `.txt`（去掉 `.db`）；导出表头与摘要随界面语言（C-03 / C-05）。
  - **展示层**：三张表新增「整行 hover 高亮」视觉属性（悬停色 = 选中色同色系、更淡）（C-02，非数据语义）。
- 集合操作（沿用）：查看 / 复制 / 编辑 / 删除 / 批量。
- 不变：扫描只消费 `pattern` / `name`；列元数据不影响匹配（沿用 v0.2.2 结论）。
