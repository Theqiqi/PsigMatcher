## C-01 进程页「未知进程」

- **改动点 → 类型**：进程名来源调整 → **修改**（缺陷修复）。
- **现状**：`psig::EnumerateProcesses()` 经 `atomic::ProcessNamePath()`（`OpenProcess(PROCESS_QUERY_LIMITED_INFORMATION)` + `QueryFullProcessImageNameW`）取名；对受保护进程（Registry / MemCompression / Secure System 等）打开失败 → 名称为空 → `ProcessTableModel::data()` 兜底为 `tr("未知进程")`（英文 `Unknown Process`）。
- **新增/修改/删除**：**修改**进程名来源——以 Toolhelp 快照 `PROCESSENTRY32W.szExeFile` 为**主来源**（无需打开进程即可得名，与任务管理器一致），映像路径仅作兜底；空名兜底保留为极端情况但正常不再触发。
- **影响窗口/功能**：进程选择页 → 进程列表（名称列）。涉及 psig `EnumerateProcesses()`/`atomic` 进程枚举、GUI `ProcessTableModel`。
- **窗口布局**：不变（进程表列：名称 / PID / 可访问 / 路径）。
- **用户操作路径（点击流程）**：进入进程选择页（默认首页）→ 观察进程列表名称列；无需任何点击。
- **可视化反馈**：原先显示「未知进程 / Unknown Process」的行，改为显示真实进程名（如 `Registry`、`MemCompression`、`Secure System`）。
- **验收**：进程列表任意一行名称列均非空、非「未知进程 / Unknown Process」；名称与 Windows 任务管理器一致。

## C-02 表格整行 hover 高亮

- **改动点 → 类型**：表格悬停高亮范围与配色 → **修改**（交互改进）。
- **现状**：表格无 hover 规则，Qt 默认仅对**鼠标所在单元格**着色；选中色为 `#3a6ea5`（`style.qss` 的 `selection-background-color`）。
- **新增/修改/删除**：**修改**三张表（进程 / 特征码 / 结果）的悬停绘制——鼠标进入某单元格时**整行**高亮；悬停色为选中色**同色系、更淡**；单击选中色保持不变。
- **影响窗口/功能**：进程选择页、特征码编辑页、匹配结果页三张 `QTableView`（共享一个自定义 `QStyledItemDelegate` 或统一样式）。
- **窗口布局**：不变。
- **用户操作路径（点击流程）**：鼠标移入任意表格行 → 整行高亮 → 单击选中（颜色更深，为选中色）。
- **可视化反馈**：悬停整行显示**淡蓝**（选中色 `#3a6ea5` 同色系更淡，如 `#e8f0f8`/低透明度同色调）；单击后整行显示**深蓝**（`#3a6ea5`）。两者为同一种颜色的不同深浅，悬停更淡。
- **验收**：鼠标移到某行任意单元格 → 该行整行变淡蓝；单击 → 该行整行变深蓝；移出后恢复；三张表表现一致。

## C-03 结果导出随界面语言

- **改动点 → 类型**：导出结果 TXT 摘要行 + 结果表列头本地化 → **修改**（缺陷修复）。
- **现状 1（TXT 摘要）**：`psig::ExportResultsTxt()` 写死中文摘要 `"匹配结果 (N 条)"`，与界面语言无关。
- **现状 2（列头）**：`vmhelp::resultHeaderForKey("custom")` 硬编码返回 `"备注"`（未经 `tr()`），故英文界面下「备注」列头仍为中文，其余列（经 `tr()`）为英文。
- **新增/修改/删除**：**修改**结果导出的**表头与摘要行**跟随当前界面语言（英文界面 → 全英文，中文界面 → 全中文）。实现上由 GUI 侧把翻译后的表头与摘要文案传给 psig 导出函数（psig 保持无 UI 依赖）。
- **影响窗口/功能**：匹配结果页 → 导出结果（TXT / CSV）。涉及 psig `ExportResultsTxt`/`ResultExportOptions`、GUI `resultHeaderForKey`/`exportResultsToPath`。
- **窗口布局**：不变。
- **用户操作路径（点击流程）**：切换界面语言为英文 → 匹配结果页导出 TXT/CSV → 打开文件查看。
- **可视化反馈**：导出文件中摘要行与列头文字与界面语言一致。
- **验收**：英文界面导出结果文件为全英文（含摘要行、`备注`→`Note`）；中文界面为全中文。

## C-04 特征码表与结果模板解耦

- **改动点 → 类型**：特征码导出/导入不再携带结果页模板文本 → **修改**（缺陷修复）。
- **现状**：`MainViewModel::tableFromModel()` 导出特征码时 `t.templateText = m_templateText`，而 `m_templateText` 是**匹配结果页**顶部输入框的模板文字 → 特征码文件最前被写入该模板文字；导入时又回填到结果页。
- **溯源**：`.idea/v0.2.0.md` 说明模板文本属于**匹配结果页**；v0.2.0 误将其同时挂到特征码表。
- **新增/修改/删除**：**删除**特征码导出/导入对模板文本的读写（解耦）。模板文本仅属匹配结果页。psig 能力保留（旧文件仍可解析不报错）。
- **影响窗口/功能**：特征码编辑页 → 导出/导入特征码（CSV/DB）。涉及 GUI `MainViewModel::tableFromModel`/`applyTableToModel`；结果页模板文本不受影响。
- **窗口布局**：不变（特征码编辑页本无模板输入框，结果页保留模板输入框）。
- **用户操作路径（点击流程）**：在结果页填写模板文字 → 特征码编辑页导出特征码表 → 打开文件查看首行。
- **可视化反馈**：导出特征码文件不再出现结果页模板文字；导入特征码后结果页模板文字不被覆盖。
- **验收**：导出特征码 CSV/DB 首行为列头（无模板文字）；导入后结果页模板输入框内容不变。

## C-05 导出格式按族收敛 + 防误操作

- **改动点 → 类型**：导入/导出**界面入口**按格式族收敛 → **修改**（入口删除）。
- **现状**：特征码管理导出 `.db` / `.csv`；匹配结果导出 `.db` / `.csv` / `.txt`。两类 `.csv` 同名，用户可能把结果文件当特征码表导入，**覆盖并丢失**当前特征码表。
- **新增/修改/删除**：**修改/删除界面入口**——
  - **特征码表**：界面导入/导出**仅 `.db`**（移除 `.csv` 入口）。
  - **匹配结果**：界面导出**仅 `.csv` / `.txt`**（移除 `.db` 入口）。
  - 两类后缀完全不重叠，文件对话框不可能拿错。
- **范围**：**仅界面收敛**；psig 的 `ImportSignaturesCsv`/`ExportSignaturesCsv`/`ExportResultsDb` 作为通用能力保留，不在本次删除。
- **影响窗口/功能**：特征码编辑页（导出/导入菜单与文件对话框过滤器）、匹配结果页（导出菜单与文件对话框过滤器）。涉及 GUI 各导出/导入槽的过滤器与扩展名。
- **窗口布局**：不变。
- **用户操作路径（点击流程）**：特征码编辑页导出 → 文件对话框仅显示 `.db` 过滤项；匹配结果页导出 → 仅显示 `.csv` / `.txt` 过滤项。
- **可视化反馈**：文件对话框过滤器与生成文件后缀符合上述收敛规则。
- **验收**：特征码导入/导出对话框无 `.csv` 选项、生成 `.db`；结果导出对话框无 `.db` 选项、生成 `.csv`/`.txt`；psig 原 API 仍可编译调用。

## 优先级与依赖

- 静态库依赖：**C-01、C-03** 需先扩展 psig（进程枚举名称来源、结果导出选项/摘要本地化）；**C-04** 需调整 psig 模板记录读写约定。
- 纯 GUI：**C-02、C-05** 可独立实现。
- 建议顺序：C-01 → C-03 → C-04 → C-02 → C-05。

## 排除项（本步不做）

- 不新建窗口/页面、不改窗口层次。
- 不改技术栈。
- 不引入专有文件后缀。
- 不删除 psig 公共 API。
