# 05 GUI 功能列表与窗口定义（v0.2.4，增量）

> 窗口结构沿用 v0.2.3：主窗口（`QMainWindow`，栈式三页 + 菜单/工具栏 + 状态栏 + 日志停靠窗）。本版**不新增/不删除窗口**，仅调整既有窗口内的功能点行为与入口。

## 受影响功能点

| 功能 | 窗口/部件 | 变更 |
| --- | --- | --- |
| 进程列表 | 进程选择页 / `ProcessTableModel` | 名称来源改为 Toolhelp `szExeFile` 优先；消除「未知进程 / Unknown Process」（C-01） |
| 表格悬停 | 进程/特征码/结果 三张 `QTableView` | 整行 hover 高亮；悬停色为选中色 `#3a6ea5` 同色系更淡（C-02） |
| 导出结果（TXT/CSV） | 匹配结果页 → 导出结果 | 摘要行 + 列头（含「备注」）随界面语言（C-03） |
| 导出/导入特征码 | 特征码编辑页 → 导出/导入 | 不再携带结果页模板文本（C-04）；入口收敛为仅 `.db`（C-05） |
| 导出结果（格式） | 匹配结果页 → 导出结果 | 入口收敛为仅 `.csv` / `.txt`，移除 `.db`（C-05） |

## 窗口定义（不变部分）

- 三页（`QStackedWidget`）：
  1. **进程选择页** `ProcessSelectionPage`：进程表（名称/PID/可访问/路径）+ 刷新/重新选择。
  2. **特征码编辑页** `SignatureEditorPage`：特征码表 + 列管理 + 导入/导出。
  3. **匹配结果页** `ResultPage`：模板文本输入框 + 结果表 + 导出结果。
- 主窗口菜单：文件 / 编辑 / 扫描 / 视图 / 语言 / 帮助。
- 状态栏：持久状态 + 瞬时反馈；日志停靠窗：历史日志。

## 功能入口定义（本版变更）

| 入口 | 位置 | 本版后缀/行为 |
| --- | --- | --- |
| 导入特征码 | 特征码编辑页 文件菜单/按钮 | 文件对话框过滤器 **仅 `*.db`** |
| 导出特征码 | 特征码编辑页 文件菜单/按钮 | 生成 **`.db`**，不写模板文本 |
| 导出结果 CSV | 匹配结果页 导出 | 生成 **`.csv`**，表头/摘要随语言 |
| 导出结果 TXT | 匹配结果页 导出 | 生成 **`.txt`**，表头/摘要随语言 |
| 导出结果 DB | —— | **移除界面入口**（psig API 保留） |
