# 07 状态与反馈信息设计（v0.2.4，增量）

> 模式：修改型。三类反馈各自唯一显示位置（沿用）：**持久状态**（状态栏）、**瞬时反馈**（瞬时标签）、**历史日志**（日志停靠窗）。错误提示分派：**短暂性错误**→瞬时反馈；**需决策错误**→弹窗。

## 受影响反馈点（逐条补齐）

### C-01 进程名显示
- 反馈点：进程列表名称列文本（属正常数据显示，非反馈通道）。
- 结论：**不新增**反馈；名称来源修正后不再产生「未知进程」文案。

### C-02 悬停整行高亮
- 反馈点：表格悬停/选中着色（**纯视觉反馈**，不属三类文字反馈通道）。
- 结论：**不新增**文字反馈；仅视觉态。悬停不写入日志、不改状态栏。

### C-03 结果导出随语言
- 反馈点：导出结果（TXT/CSV）**成功/失败**提示。
- 分派：
  - 成功 → **瞬时反馈**（瞬时标签，如 `已导出结果`，随界面语言）+ **历史日志**一条（导出类，绿色）。
  - 失败（无权限/路径不可写）→ **需决策错误**？否——属**短暂性错误**，用**瞬时反馈**（红色）+ 日志（红色）。
- 关键要求：**导出文件内**的摘要行与列头文字随界面语言（此为文件内容，非界面反馈）。

### C-04 特征码导出/导入解耦
- 反馈点：特征码导出/导入成功/失败提示。
- 分派：
  - 成功 → 瞬时反馈 + 日志（导出/导入绿）。
  - 失败（旧文件含模板记录等）→ 属**短暂性错误**，瞬时反馈（红）+ 日志（红）；**不弹窗**（旧文件可正常解析，非阻断）。
- 要求：导入特征码后**不覆盖**结果页模板文本；无与此相关的额外提示（避免误导）。

### C-05 入口收敛
- 反馈点：文件对话框过滤器（无独立反馈文案）。
- 分派：若用户在结果导出对话框手动改后缀为 `.db`，不做拦截（属用户自担）；不新增弹窗。
- 结论：**不新增**反馈点。

## 唯一显示位置（复核）

| 反馈类型 | 唯一位置 | 本版新增 |
| --- | --- | --- |
| 持久状态 | 状态栏（如当前进程/行数） | 无 |
| 瞬时反馈 | 瞬时标签（成功/失败） | C-03/C-04 导出导入成功/失败随语言 |
| 历史日志 | 日志停靠窗 | C-03/C-04 导出导入记录 |

## 不受影响（引用既有文档）

- 日志开关/右键清空、进程权限图标、重新选择进程保存提示等反馈设计：见 `design/v0.2.2/gui/07_状态与反馈信息设计.md`，本版不重设计。
