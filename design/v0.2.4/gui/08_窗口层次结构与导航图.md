# 08 窗口层次结构与导航图（v0.2.4，增量）

> 模式：修改型。**窗口层次与导航图本版不变**，仅更新受影响窗口的部件与绑定关系。

## 层次（不变）

- `QMainWindow`
  - 中央 `QStackedWidget`：`ProcessSelectionPage` / `SignatureEditorPage` / `ResultPage`
  - 底部 `QDockWidget`：日志
- 菜单栏：文件 / 编辑 / 扫描 / 视图 / 语言 / 帮助
- 状态栏：持久状态 + 瞬时反馈

## 导航图（不变）

- 进程选择页 --(双击/选定进程)--> 特征码编辑页 --(开始扫描)--> 匹配结果页
- 任意页 --(重新选择进程)--> 进程选择页

## 变更点（仅部件级）

- **三张 `QTableView`**（进程表 / 特征码表 / 结果表）：共享一个自定义 `QStyledItemDelegate`（或统一 `style.qss` 规则），实现**整行 hover 高亮**（C-02）。控件类型与页面层次不变。
- **文件对话框过滤器**：特征码导入/导出对话框过滤器收敛为 `*.db`；结果导出对话框过滤器收敛为 `*.csv` / `*.txt`（C-05）。控件类型不变。
- 其余窗口/部件/导航关系沿用 v0.2.2 `08_窗口层次结构与导航图.md`。
