# 11 GUI 执行路径（v0.2.4，增量）

> 修改/新增功能的执行路径**必须补全正常/错误/取消三类**（事件驱动独立路径）。

## C-01 进程列表名称
- **正常**：刷新/进入进程页 → 枚举 → 每行名称列显示真实进程名。
- **错误**：个别进程打开失败 → 该进程仍以快照名显示（兜底路径），列表不中断。
- **取消**：无（刷新为非交互操作）。

## C-02 表格整行悬停
- **正常**：鼠标进入行 → 整行淡色高亮；移出 → 恢复。
- **错误**：无（纯绘制，无失败态）。
- **取消**：无。

## C-03 结果导出随语言
- **正常**：选格式（CSV/TXT）→ 导出 → 文件表头/摘要随界面语言 → 瞬时反馈成功 + 日志绿。
- **错误**：路径不可写 → 导出失败 → 瞬时反馈失败 + 日志红。
- **取消**：文件对话框 `rejected` → 不写文件、无反馈。

## C-04 特征码导出/导入解耦
- **正常（导出）**：导出 → 文件首行列头（无模板文本）→ 反馈成功。
- **正常（导入）**：导入 `.db` → 特征码表刷新、结果页模板文本不变 → 反馈成功。
- **错误**：文件损坏/不可读 → 导入失败 → 瞬时反馈失败 + 日志红（不阻断）。
- **取消**：文件对话框 `rejected` → 不读不写。

## C-05 导出格式入口收敛
- **正常**：打开对话框 → 过滤器仅列允许后缀（特征码 `*.db`；结果 `*.csv`/`*.txt`）。
- **错误**：用户手改后缀 → 不拦截（写入该后缀文件），属用户自担。
- **取消**：文件对话框 `rejected` → 无副作用。
