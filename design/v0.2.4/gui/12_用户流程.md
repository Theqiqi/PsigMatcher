# 12 用户流程（v0.2.4，增量）

> 模式：修改型。为改动点新增/更新对应用户流程，其余引用既有文档。每个用户操作对应一个用户流程，覆盖正常/错误/取消；作为用户流程测试与 E2E 测试依据。

## UF-01 进程列表显示真实进程名（C-01）
- 用户：启动程序 → 进入进程选择页（或点击刷新）。
- 正常：进程列表每行名称列显示真实进程名（与任务管理器一致），无「未知进程 / Unknown Process」。
- 错误：个别受保护进程枚举失败 → 仍显示快照名（不出现空白/未知）。
- 取消：无。
- 结果：全列表名称非空、非「未知进程 / Unknown Process」。

## UF-02 表格整行悬停高亮（C-02）
- 用户：鼠标移入任意一张表（进程/特征码/结果）的某行任意单元格 → 单击选中 → 移出。
- 正常：移入 → 整行淡蓝（选中色同色系更淡）；单击 → 整行深蓝（`#3a6ea5`）；移出 → 恢复。
- 错误：无。
- 取消：无。
- 结果：三张表表现一致；悬停不改变选中、不触发操作。

## UF-03 结果导出随界面语言（C-03）
- 用户：切换界面语言为英文 → 匹配结果页「导出结果」→ 选 TXT 或 CSV → 导出 → 打开文件。
- 正常：文件摘要行与列头均为英文（`备注`→`Note`），界面反馈亦为英文。
- 错误：目标路径不可写 → 界面提示失败（红）+ 日志（红）。
- 取消：文件对话框取消 → 不生成文件。
- 结果：英文 UI 导出全英文；中文 UI 全中文。

## UF-04 特征码导出/导入不含模板文本（C-04）
- 用户：结果页填写模板文字 → 特征码编辑页「导出特征码」（`.db`）→ 打开文件 → 再「导入特征码」。
- 正常：导出文件首行为列头（无模板文字）；导入后特征码表恢复，结果页模板文字**保持不变**。
- 错误：导入损坏文件 → 提示失败（红）+ 日志（红），不覆盖现有特征码表。
- 取消：文件对话框取消 → 无副作用。
- 结果：特征码文件与结果页模板彻底解耦。

## UF-05 导出格式入口收敛（C-05）
- 用户：特征码编辑页「导出/导入」→ 观察文件对话框过滤器；匹配结果页「导出结果」→ 观察过滤器。
- 正常：特征码对话框仅 `*.db`；结果对话框仅 `*.csv` / `*.txt`。
- 错误：用户手改后缀 → 不拦截（用户自担）。
- 取消：对话框取消 → 无副作用。
- 结果：两类后缀不重叠，用户无法经文件对话框误把结果文件当特征码表导入。
