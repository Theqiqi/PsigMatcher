# 13 技术选型分析（v0.2.4）

- **沿用既有技术栈**：C++20 / Qt6::Widgets / Qt6::Concurrent（异步）/ Windows / CMake + vcpkg（gtest）/ Ninja + MSVC。
- i18n：Qt 标准翻译体系（`tr()` + `.ts`/`.qm` + `QTranslator`），`lupdate`/`lrelease` 由 Qt 独立安装自带。
- 不重新选型；修改模式确认既有技术栈仍满足全部 5 个改动点（C-01..C-05）。
- 本版新增能力均为既有技术的既有用法：
  - C-01 进程名来源修正：psig 内部（WinAPI Toolhelp，`psig` 原子层已用）。
  - C-02 整行 hover：Qt 既有 `QStyledItemDelegate` / `QTableView::setMouseTracking` / `style.qss`。
  - C-03 导出随语言：Qt `tr()` + `ResultExportOptions.headers/summary`。
  - C-04 解耦：GUI 既有 `tableFromModel`/`applyTableToModel` 调整，无新技术。
  - C-05 入口收敛：Qt `QFileDialog` 过滤器字符串。
