# 18 静态库流程交接记录（v0.2.4）

> 前置：`17_API缺失需求.md`
> 跳转目标：`.flow/带GUI的单体程序的业务系统静态库.md` 的 **步骤 2「跨流程需求接收」**。

## 1. 交接原因

GUI 改动点 C-01（进程页「未知进程」）与 C-03（结果导出摘要随语言）需要「进程名来源修正」与「结果导出摘要字段」能力，`psig` 现有公共 API **不覆盖**（见 `16_API充分性审查.md`）。

## 2. 交接内容（逐项）

| 缺失能力 | 期望公共 API | 输入 | 输出 | 异常要求 | 验收标准 |
| --- | --- | --- | --- | --- | --- |
| M-1 进程名来源 | `EnumerateProcesses()`（签名不变，行为修正） | 无 | 进程列表，`name` 非空 | 取路径/权限失败不影响名称；不抛异常 | 受保护进程名与任务管理器一致；`accessible` 语义不变 |
| M-2 结果摘要随语言 | `ResultExportOptions.summary` 新字段 + `ExportResultsTxt` 优先用之 | 本地化摘要串 | TXT 摘要行为该串 | 空串走默认中文（兼容） | 传英文摘要 → TXT 英文；不传 → 中文；CSV/DB 不变 |

## 3. 约束

- 静态库实现必须使用真实底层能力（WinAPI Toolhelp / 真实导出），**禁止**模拟数据、硬编码结果或伪造 API。
- 静态库流程完成后必须输出**静态库完成契约**，并**跳回** GUI 流程的「静态库完成回退检查（步骤 21）」，不得直接跳到 GUI 接口实现。
- GUI 在契约返回前**停止 ViewModel 层相关编码**（C-01 名称显示、C-03 摘要本地化）。
