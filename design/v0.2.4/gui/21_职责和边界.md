# 21 职责和边界（v0.2.4，增量）

> 前置：`20_GUI模块分析.md`、`design/v0.2.2/gui/21_职责和边界.md`（上一版本）

## 各层职责与禁止项（本次适用点）

| 层 | 职责 | 禁止项 |
| --- | --- | --- |
| View | 构建控件（含三张表的 `HoverRowDelegate`、文件对话框过滤器）；暴露控件 getter；执行绘制（悬停整行）；`retranslateUi` | **不写 connect**、无 signals/private slots、不 include ViewModel/psig、不调业务；不调用平台 API |
| Model | `ProcessTableModel`：名称列直接返回 `r.name`（正常非空）；纯 Qt | 不依赖 psig、不含业务格式化、不自行实现兜底业务语义 |
| ViewModel | 持 `View*`；集中 connect；调 psig 公共 API（`EnumerateProcesses`、结果导出带 `summary`/`headers`）；构造本地化表头与摘要；特征码导出不写模板、导入不回填模板 | 不用 findChild 访问交互控件；不自行实现静态库能力；不直接调用 Win32 |
| 静态库 | psig 提供进程名（快照名）与 `ResultExportOptions.summary` | 不依赖 Qt |

## 边界确认（本次）

- **进程名（C-01）**：名称由 psig `EnumerateProcesses()` 提供（快照名优先）；`ProcessTableModel::data()` 直接展示，不再有「未知进程 / Unknown Process」兜底文案（极端空名仍保留兜底但不属正常路径）。GUI 生产代码不调用平台 API 取名。
- **整行悬停（C-02）**：`HoverRowDelegate` 仅负责**绘制**（`State_MouseOver` → 整行淡色背景）；不改变选中语义（`selectionBehavior=SelectRows` 不变）；不发射信号、不写 Model、不写日志。
- **结果导出随语言（C-03）**：VM 在 `exportOptions()` 中按当前语言构造 `headers`（含 `custom`→`tr("备注")`）与 `summary`（本地化摘要，如 `tr("匹配结果 (%1 条)").arg(n)`）传入 `psig::ResultExportOptions`；静态库优先使用。
- **特征码表解耦模板（C-04）**：`tableFromModel` 不再设置 `t.templateText`（保持空）；`applyTableToModel` 不再写结果页 `m_templateText`。模板文本仅属结果页。
- **格式入口收敛（C-05）**：特征码导入/导出对话框过滤器仅 `*.db`；结果导出仅 `*.csv`/`*.txt`（移除 `.db` 菜单项/过滤器）。psig 的 CSV/DB 通用 API 保留。

## 约束满足说明

- 每层禁止项清晰；View 不依赖 ViewModel/静态库；ViewModel 经 `View*` 指针操控 View。
- 平台能力（进程名）经 psig 提供，GUI 生产代码不调用平台 API。
