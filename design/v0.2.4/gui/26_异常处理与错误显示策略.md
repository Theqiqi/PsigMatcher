# 26 异常处理与错误显示策略（v0.2.4，增量）

> 前置：`24_ViewModel接口.md`、`design/v0.2.2/gui/26_异常处理与错误显示策略.md`（上一版本）

## 策略（沿用 + 本次适用点）

| 场景 | 分派 | 表现 |
| --- | --- | --- |
| 进程名展示（C-01） | **无错误** | psig 提供真实进程名，正常非空；不再出现「未知进程 / Unknown Process」 |
| 表格悬停（C-02） | **无错误** | 纯绘制，无失败态 |
| 结果导出成功（C-03） | 瞬时反馈 + 日志 | 「已导出: <path>」随语言；日志绿色 |
| 结果导出失败（C-03） | 瞬时反馈（错误）+ 日志 | 「导出失败: <err>」随语言；日志红色 |
| 无结果可导出（C-05） | 瞬时反馈（错误）+ 菜单项禁用 | 「无结果可导出」（沿用） |
| 特征码导出/导入成功（C-04） | 瞬时反馈 + 日志 | 「已导出/已导入」；日志绿色 |
| 特征码导入失败（C-04） | 瞬时反馈（错误）+ 日志 | 「导入失败: <err>」；**不弹窗**（旧文件可解析，非阻断） |
| 文件对话框取消（C-03/C-04/C-05） | **无动作**（取消路径） | 不读不写，不报错 |

## 后台线程异常

- 进程枚举/扫描在 `QtConcurrent::run` 执行；结果经 `QFutureWatcher::finished`（QueuedConnection）回主线程处理，**不跨线程抛异常**。
- psig 不抛异常（出参表达错误）；`EnumerateProcesses` 失败返回空表。

## 约束满足说明

- 短暂性错误走瞬时反馈；需决策/需确认走模态弹窗；错误提示位置唯一（状态栏右区/日志）。
- 本次 C-01..C-05 的异常路径已覆盖：名称非空非异常、悬停无失败态、导出/导入错误走瞬时反馈+日志、取消路径无副作用、`.db` 入口移除后无对应失败路径。
