# 27 Qt 技术选型（v0.2.4）

> 前置：`08_窗口层次结构与导航图.md`、`13_技术选型分析.md`、`design/v0.2.3/gui/28_QtGUI代码规范.md`

## 结论：沿用

| 维度 | 选型 |
| --- | --- |
| 程序类型 | Windows 桌面 exe |
| 语言 | C++20 |
| GUI | Qt6::Widgets（代码构建 Widget，无 .ui） |
| 异步 | Qt6::Concurrent（QtConcurrent::run + QFutureWatcher） |
| 国际化 | Qt6::LinguistTools（`lupdate`/`lrelease`）+ `QTranslator` + `.ts`/`.qm` |
| 测试 | gtest + QTest |
| 构建 | CMake + Ninja + MSVC；vcpkg manifest（gtest）；find_library 引用 psig |
| 静态库命名 | psig（依据程序类型命名） |

## 本次使用的既有控件/类（沿用 v0.2.3）

- `QFileDialog`（导入/导出文件对话框与过滤器，C-05）。
- `QObject::tr`（结果导出表头/摘要本地化，C-03）。
- **本次新增控件（仍属 Qt6::Widgets 既有能力）**：
  - `QStyledItemDelegate` 子类 `HoverRowDelegate`（整行悬停绘制，C-02）。
  - `QTableView::setMouseTracking(true)` + `setItemDelegate(...)`（三张表统一，C-02）。

## 构建要点（沿用）

- Release：`set_target_properties(psig_gui PROPERTIES WIN32_EXECUTABLE $<CONFIG:Release>)`（去控制台）；Debug 保留控制台。
- i18n：由 `lrelease` 生成 `.qm` 并加入 `.qrc`；本次需补充英文 `Note`（备注）、`Results (%1)`（匹配结果）等翻译条目。
- 新增源文件 `view/hoverrowdelegate.{h,cpp}` 加入 `gui/CMakeLists.txt` 的 GUI View 源列表。

## 约束满足说明

- 沿用既有 Qt 技术选型；静态库命名依据程序类型（psig）；i18n 用 Qt 官方组件，无 Qt 以外第三方；新增 delegate 属 Qt6::Widgets 既有能力。
