# 02 跨流程需求接收（psig v0.3.0）

- 来源：GUI 流程步骤 16-21（`design/v0.3.0/gui/14_API能力需求.md`、`16_API充分性审查.md`、`17_API缺失需求.md`、`18_静态库流程交接记录.md`）。
- 目标静态库：`psig`（已存在；本轮为**行为修正/实现改进**，非新建能力）。
- 跳转目标：静态库流程「跨流程需求接收」步骤。

## 需求清单（来自 gui/17_API缺失需求.md）

### R-01 进度语义修正（C-01）
- 公共 API：`ScanProcesses(const ScanRequest&, ProgressCallback, const std::atomic_bool*)`（**签名不变**）。
- 行为：`ScanProgress::total` = 总工作量（所有目标进程可读区域数之和）；`done` = 已完成工作量，单调递增，结束 `done == total`。
- 验收：单进程多区域扫描，进度值从 <100 单调增到 100；不再恒为 100。

### R-02 区域级并行扫描（C-02）
- 公共 API：`ScanProcesses(...)`（**签名不变**，内部并行化）。
- 行为：以内存区域为并行单位，多工作线程并发扫描；结果/进度/取消并发安全；并行度按 CPU 自适应；线程创建失败回落串行。
- 契约变更（非签名）：进度回调**可能被多线程并发调用**；结果**顺序不保证**；`maxResultsPerPattern` 沿用既有 per-buffer 语义（GUI 默认不设限）。
- 验收：多核机器同一任务并行版本耗时明显低于串行；命中集合与串行一致（数量/内容）。

### R-03 进度回调粒度粗化（C-04）
- 公共 API：`ProgressCallback`（**签名不变**，触发频率降低）。
- 行为：不再按 1MiB 分块触发；改为**每完成一个区域**触发一次。
- 验收：大区域扫描回调次数由「与 1MiB 块数同量级」降为「与区域数同量级」。

## 能力覆盖判定
- 静态库已存在，上述为对既有 API 的**行为修正 + 实现改进**；需改动 `api/process_scan.cpp`、`include/psig.h`（注释/语义）、`test/integration/test_scan.cpp`（新增用例）。
- GUI 不自行实现上述能力（尤其**不得**在 GUI 侧自建线程池）、不调用平台 API；全部经修正后的 `psig` 公共 API。

## 交付契约（见 77_静态库完成契约.md）
- 公共头变更：`psig/include/psig.h`（`ScanProgress` 字段注释语义修正；`ScanProcesses` 契约补充并发说明）。
- 行为变更：进度真实化、区域并行、回调粒度粗化。
- 库产物：`psig/out/lib/<配置>/psig.lib`（Debug/Release 重建）。
- 验收：psig 单测 + 集成测试覆盖 R-01/R-02/R-03；Debug/Release 全绿。
