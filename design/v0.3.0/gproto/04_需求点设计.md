# 04 需求点设计（psig v0.3.0）

> 前置：`03_需求分析.md`

| 需求点 | 描述 | 输入 | 输出 | 验收 |
| --- | --- | --- | --- | --- |
| RP-1 | 进度语义修正 | 无 | `ScanProgress{done,total}` 反映区域工作量 | 进度单调增到 100；不再恒 100 |
| RP-2 | 区域级并行 | `ScanRequest` | `vector<MatchResult>`（内容/数量同串行） | 多核更快；命中集合一致 |
| RP-3 | 回调粒度粗化 | 无 | 回调次数下降 | 回调次数与区域数同量级 |

## 边界
- RP-1 仅改 `ScanProgress` 取值，不改字段类型与回调签名。
- RP-2 不改命中判定/结果字段/导出；结果顺序可变（内容不变）。
- RP-3 仅改回调触发时机，不改回调语义。
