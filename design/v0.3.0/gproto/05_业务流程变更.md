# 05 业务流程变更（psig v0.3.0）

> 前置：`04_需求点设计.md`

## RP-1/RP-3 扫描进度业务流程（变更）
1. **规划阶段**：对每个目标 pid `OpenForRead` → `ProcessNamePath` → `EnumModules` → `EnumRegions`；收集为「区域任务」列表。
2. `total` = 区域任务总数。
3. **执行阶段**：并行扫描各区域；每完成一个区域：`done += 1`、累加命中、**触发一次进度回调**（携带 `done/total/hits/currentPid`）。
4. 扫描结束：`done == total`。

**变更点**：
- 第 1/2 步为**新增的规划阶段**（为进度提供分母，并产出并行任务）。
- 第 3 步回调由「每 1MiB 块触发且 done=total 写死」改为「每区域触发且 done 真实累加」。

## RP-2 区域并行业务流程（变更）
1. 规划阶段产出 `N` 个区域任务。
2. 线程数 = `min(hardware_concurrency(), N)`（`hardware_concurrency()==0` 或 `N<=1` → 串行）。
3. 多工作线程经**原子任务索引**领取任务；各自扫描并写入**线程局部结果向量**；原子累加 `done`/`hits`。
4. 取消：各线程在领取任务前后轮询 `IsCancelled`。
5. 汇合：`join` 后合并各线程结果 → 返回。

**变更点**：由「进程串行 → 区域串行」改为「规划 → 区域级并行执行 → 汇合」。
