# 06 功能点设计（psig v0.3.0）

> 前置：`05_业务流程变更.md`

## 功能点

| 功能点 | 描述 | 对应需求点 |
| --- | --- | --- |
| F-1 | 扫描规划（枚举区域任务并计总工作量） | RP-1 |
| F-2 | 区域级并行扫描（线程池 + 原子任务索引） | RP-2 |
| F-3 | 按区域的进度回调（真实 done/total） | RP-1、RP-3 |

## 业务流程与功能点对应
- 规划阶段 → F-1（为进度提供分母与并行任务）。
- 执行阶段 → F-2（并行扫描）+ F-3（每区域回调）。
- 汇合 → F-2 的结果合并。

## 说明
- 本轮不新增业务流程图（`businessflow/`）；F-1..F-3 为既有扫描流程的内部重组，对外 API 不变。
