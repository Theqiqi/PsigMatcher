# 07 功能流程变更（psig v0.3.0）

> 前置：`06_功能点设计.md`

## F-1 扫描规划（新增）
`ScanProcesses(req, ...)` 内：
- 对每个 pid：`h = OpenForRead(pid)`（失败跳过）；`ProcessNamePath`；`EnumModules(pid)`；`EnumRegions(h)`。
- 产出 `Plan{ pid, handle, name, modules, regions }` 列表；`total = Σ regions.size()`。
- 若 `total == 0`：关闭所有句柄，返回空结果。

## F-2 区域级并行扫描（变更）
- 线程数 `T = min(hardware_concurrency(), total)`（`0`/`1` → 串行）。
- 原子任务索引 `next`；线程 `i` 循环：`j = next++`；若 `j >= total` 退出；否则扫描第 `j` 个区域任务到 `local[i]`。
- 线程创建失败（`std::system_error`）→ 以更少线程继续（主线程始终参与）。

## F-3 按区域进度回调（变更）
- 每完成一个区域：`done = doneCount.fetch_add(1) + 1`；`hits` 原子累加。
- 若 `progress` 非空：构造 `ScanProgress{currentPid=plan.pid, done, total, hits}` 并调用（**可能并发调用**）。

## 汇合
- `join` 所有线程；按线程顺序拼接 `local[i]` → 返回（顺序不保证与串行一致）。

## 说明
- 无新增 `functionflow/` SVG；为既有 `ScanProcesses` 内部流程重组，公共签名不变。
