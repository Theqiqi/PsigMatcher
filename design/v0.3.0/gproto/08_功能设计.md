# 08 功能设计（psig v0.3.0）

> 前置：`07_功能流程变更.md`

## API 接口列表（本次受影响）
| 接口 | 变更 |
| --- | --- |
| `ScanProcesses(req, progress, cancel)` | 实现：区域级并行 + 真实进度 + 每区域回调（**签名不变**） |
| `struct ScanProgress` | `done`/`total` **语义修正**（工作量/区域计数），字段不变 |
| `using ProgressCallback` | 契约补充：**可能被多线程并发调用** |

## 说明
- 无新增功能流程图 SVG（`functionflow/`）；接口集合除上述语义/实现变更外不变。
- 未新增公共 API；`ScanRequest` 结构不变。
