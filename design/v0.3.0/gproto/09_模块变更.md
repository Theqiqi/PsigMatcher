# 09 模块变更（psig v0.3.0）

> 前置：`08_功能设计.md`

## 分层（沿用）
`data/`（纯 std） ← `algorithm/`（纯算法） ← `atomic/`（WinAPI/SQLite/文件） / `api/`（组装）

## 受影响模块
| 模块 | 层 | 变更 |
| --- | --- | --- |
| `api/process_scan.cpp` | api | `ScanProcesses` 内部：新增规划阶段、区域级并行、真实进度、每区域回调；`ScanRegion` 去掉进度参数 |
| `include/psig.h` | 公共头 | `ScanProgress` 注释语义修正；`ProgressCallback` 契约补充并发说明；版本 v0.3.0 |

## 不变
- `data/`、`algorithm/`、`atomic/` 无改动（复用既有原语）。
- `atomic` 仍为唯一平台调用层；`api` 仍只组装；**并行只用标准库线程，不引入 Qt**。
