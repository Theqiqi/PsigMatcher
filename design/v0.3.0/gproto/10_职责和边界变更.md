# 10 职责和边界变更（psig v0.3.0）

> 前置：`09_模块变更.md`

## 各模块职责（沿用，标注本次）
| 模块 | 职责 | 本次边界确认 |
| --- | --- | --- |
| `atomic/win_process` | 平台进程/内存/模块原语 | **不变**；并行扫描复用 `ReadMemory`（并发读安全） |
| `api/process_scan` | 组装扫描 | 新增「规划 + 区域并行 + 进度汇报」编排；**不**在此实现平台细节 |
| `include/psig.h` | 公共契约 | `ScanProgress` 语义与回调并发契约 |

## 禁止项
- 不得在 `data`/`algorithm` 引入平台 API 或线程。
- 不得在 `api` 层直接调用 WinAPI（平台调用仅在 `atomic`）。
- **不得**在 psig 内引入 Qt（并行只能用 `std::thread`/`std::atomic`/`std::mutex`）。
- 不得改变命中判定与结果字段语义（并行不改变结果内容）。
