# 12 接口细化设计（psig v0.3.0）

> 前置：`11_api接口分析.md`

## 数据结构列表
| 结构 | 变更 |
| --- | --- |
| `ScanProgress` | 字段不变；`done`/`total` 语义修正 |
| `ScanRequest` | 不变 |
| `Plan`（api 内部，**新增**） | `{ uint32_t pid; void* handle; std::wstring name; std::vector<ModuleInfo> modules; std::vector<Region> regions; }` |
| `RegionTask`（api 内部，**新增**） | `{ size_t plan; size_t region; }`（指向 `Plan` 中的区域） |

## 算法列表
| 算法 | 变更 |
| --- | --- |
| `algorithm/*` | 无新增（本轮无纯算法改动；`FindAll` 等沿用） |

## 原子化 api 列表
| 原子 api | 变更 |
| --- | --- |
| `OpenForRead` / `CloseProcessHandle` | 沿用（规划阶段打开、结束时关闭） |
| `EnumRegions` / `EnumModules` / `ReadMemory` | 沿用（并发调用 `ReadMemory` 安全） |

## api 接口异常设计
- `ScanProcesses`：无异常；无区域返回空；区域读取失败隔离；线程创建失败回落串行。
- 回调：异常不得跨线程抛出（调用方责任）；psig 不捕获回调异常。
