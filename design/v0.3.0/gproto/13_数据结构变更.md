# 13 数据结构变更（psig v0.3.0）

> 前置：`12_接口细化设计.md`

## 公共结构（`include/psig.h`）
```cpp
// 扫描进度（语义修正：done/total 为工作量/区域计数）
struct ScanProgress {
    uint32_t currentPid = 0;
    size_t done = 0;    // 已完成工作量（区域数）
    size_t total = 0;   // 总工作量（区域数）
    size_t hits = 0;    // 当前命中累计
};
```
> 字段与类型**不变**；仅语义修正（原：已处理模式数/总模式数）。

## 内部结构（`src/api/process_scan.cpp` 匿名命名空间）
```cpp
namespace {
struct Plan {                 // 单进程扫描计划（规划阶段产出）
    uint32_t pid = 0;
    void* handle = nullptr;   // OpenForRead 句柄（结束时关闭）
    std::wstring name;
    std::vector<data::ModuleInfo> modules;
    std::vector<data::Region> regions;
};
struct RegionTask {           // 并行任务：指向某个 Plan 的某个区域
    size_t plan = 0;
    size_t region = 0;
};
}
```

## 独立性
- 公共结构为纯 std 类型，可独立编译。
- 内部 `Plan`/`RegionTask` 仅依赖 data 层类型，位于 api 层实现文件内，不外泄。
