# 14 算法变更（psig v0.3.0）

> 前置：`13_数据结构变更.md`

## 结论：本轮无纯算法层（`algorithm/`）改动
- R-01 为进度取值语义修正（api 层）。
- R-02 为扫描执行并行化（api 层编排 + 标准库线程）。
- R-03 为回调触发时机变更（api 层）。
- 三者均不涉及 `algorithm/` 纯函数（`FindAll`/`LocateModule` 等），无需新增/修改算法。

## 受影响的取值/编排逻辑（非算法层）
| 逻辑 | 位置 | 说明 |
| --- | --- | --- |
| 进度计数 | `api/process_scan.cpp` | 原子累加 `done`/`hits`，`total` = 区域总数 |
| 任务分派 | `api/process_scan.cpp` | 原子任务索引 + 工作线程循环 |
| 回调触发 | `api/process_scan.cpp` | 每区域一次（原：每 1MiB 块一次） |
