# 15 算法执行过程变更（psig v0.3.0）

> 前置：`13_数据结构变更.md`、`14_算法变更.md`

## 执行过程（扫描编排）

### 规划（`api/process_scan.cpp`）
1. `patterns` 过滤（`valid && !bytes.empty()`）；`maxLen` = 最长模式字节数（沿用）。
2. 对每个 pid：`h = OpenForRead(pid)`；失败跳过。`ProcessNamePath`、`EnumModules`、`EnumRegions(h)`。
3. 收集 `Plan`；`total += regions.size()`；将 `(plan, region)` 展平为 `tasks`。
4. `total == 0` → 关闭句柄返回空。

### 并行执行
1. `T = min(hardware_concurrency(), tasks.size())`；`T<=1` 走串行（仍汇报进度）。
2. 原子 `next`、`doneCount`、`hitsCount`；`std::vector<std::vector<MatchResult>> local(T)`。
3. 工作线程 `i`：`j = next++`；`j>=tasks.size()` 退出；`ScanRegion(...)` 到 `local[i]`；`doneCount++`；`hitsCount += Δ`；回调。
4. 线程创建失败 → 以更少线程继续；主线程也参与。

### 汇合
- `join`；按 `local[0..T)` 顺序拼接 → 返回。

## 说明
- 无纯算法函数，故无「算法执行过程」独立描述；以上为 api 层扫描编排过程。
