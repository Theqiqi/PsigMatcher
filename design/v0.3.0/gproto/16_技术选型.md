# 16 技术选型（psig v0.3.0）

> 前置：`02_跨流程需求接收.md`

## 结论：沿用
| 维度 | 选型 |
| --- | --- |
| 程序类型 | 静态库（进程特征码匹配） |
| 语言 | C++20 |
| 框架 | Windows 平台（WinAPI / Toolhelp） |
| 是否跨平台 | 否 |
| 静态库命名 | `psig`（依据程序类型命名，非 pmem） |
| 依赖 | 无 Qt；内置 SQLite amalgamation；系统库 kernel32/user32 等 |
| 并行设施 | **标准库线程**（`std::thread` + `std::atomic`/`std::mutex`），不引入 Qt/第三方线程池 |

## 说明
- 本版仅改进既有扫描实现（并行 + 进度）与回调粒度，不改变技术栈。
- 因 psig 不依赖 Qt，并行必须使用标准库设施；C++20 标准库已提供所需原语。
