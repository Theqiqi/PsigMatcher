# 19 代码规范（psig v0.3.0）

> 前置：统一要求、`design/v0.2.4/gproto/19_代码规范.md`（基线）

## 结论：沿用既有规范

- 命名：类型 PascalCase、函数 PascalCase；公共 API 沿用既有风格。
- 分层：data / algorithm / atomic / api，逐层依赖，禁止反向依赖。
- 算法层纯函数、无 I/O；原子化层无业务语义；接口层组装。
- 不抛异常，用返回值/出参表达错误。
- 头文件包含使用 `名字/名字` 形式，禁止 `../` 相对路径。
- 禁止依赖 Qt；平台调用集中在原子化层。

## 本次补充（并发相关）

- **并行只允许标准库设施**（`std::thread`/`std::atomic`/`std::mutex`），禁止引入 Qt 线程或第三方线程池。
- 工作线程**只写线程局部数据**；跨线程共享仅经 `std::atomic`（计数/任务索引）。
- 进度回调可能被**多线程并发调用**：psig 内部不得假设回调串行；回调不得在 psig 内被 try/catch 吞并。
- 线程创建失败必须**回落串行**（不得因线程失败而使扫描整体失败）。
- 句柄打开/关闭成对（规划阶段打开 → 结束统一关闭），含提前返回路径。

## 约束满足说明

- 沿用既有规范，本次改动遵循之。
