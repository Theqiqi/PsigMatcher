# 37 层级与模块边界审查结果（静态库流程步骤 37，v0.3.0）

- 版本：v0.3.0
- 前置：`design/v0.3.0/gproto/10_职责和边界变更.md`
- 目标：确认依赖方向单一、不跨层、不跨模块访问非公开符号。

## 矩阵

| 检查项 | 判定标准 | 结论 | 证据 |
| --- | --- | --- | --- |
| 依赖方向单一 | data ← algorithm ← atomic/api，无反向 | ✅ | `process_scan.cpp` include 列表：`psig.h`+`algorithm/*`+`atomic/*`+`data/*`；data/algorithm 不 include api/atomic |
| 不跨层调用 | 各层只依赖其允许的下层 | ✅ | api 调 `algorithm::FindAll`/`LocateModule`、`atomic::*`、`data::*`；atomic 不反向调 api |
| 模块间经公共头交互 | 不访问非公开符号 | ✅ | 内部结构 `Plan`/`RegionTask`/`ScanJob` 定义于 `process_scan.cpp` 匿名命名空间，不外泄 |
| 平台调用集中 | 平台代码仅在 atomic | ✅ | `grep -rn "ReadProcessMemory\|OpenProcess\|VirtualQuery\|CreateToolhelp" psig/src/api` → 无命中 |
| 无 Qt 越界 | psig 不依赖 Qt | ✅ | `grep -rn "Qt\|QThread" psig/src psig/include` → 仅注释命中 |

## 结论

层级与模块边界审查通过（无 ❌）。
