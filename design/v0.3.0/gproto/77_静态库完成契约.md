# 77 静态库完成契约（psig v0.3.0）

- 需求来源：`design/v0.3.0/gui/17_API缺失需求.md`、`design/v0.3.0/gproto/02_跨流程需求接收.md`（R-01/R-02/R-03）。
- 交付范围：对既有 `psig` 的**行为修正 + 实现改进**，公共 API **签名不变**，向后兼容。

## 公共接口变更（psig/include/psig.h）
- `ScanProcesses(const ScanRequest&, ProgressCallback, const std::atomic_bool*)` —— **签名不变**；实现改为「规划 → 区域级并行 → 汇合」。
- `struct ScanProgress` —— 字段与类型不变；`done`/`total` **语义修正**：由「已处理模式数/总模式数」改为「已完成工作量/总工作量（内存区域数）」。
- `using ProgressCallback` —— 契约补充：**可能被多个工作线程并发调用**（调用方须线程安全、轻量）。
- 无新增公共 API；`ScanRequest`/`MatchResult`/`ResultExportOptions` 等不变。

## 行为变更与验收
| 能力 | 验收 |
| --- | --- |
| R-01 进度真实 | `total`=目标进程可读区域总数，`done` 单调递增至 `total`；单进程多区域扫描进度不再恒 100%。集成用例 `ScanProgressReportsRealWork`。 |
| R-02 区域并行 | 以内存区域为并行单位多线程扫描；并行度按 CPU 自适应；线程创建失败回落串行；命中集合内容/数量与串行一致（顺序可变）。集成用例 `ScanParallelFindsMarkerBothRuns`、`ScanEmptyRequest`。 |
| R-03 回调粒度 | 回调由「每 1MiB 块」改为「每区域」触发。集成用例断言回调次数 == 区域总数。 |

## 契约声明（并发语义）
- 进度回调可能被多线程并发调用；调用方仅做线程安全、轻量操作（GUI 侧写 `std::atomic`）。
- 返回结果顺序不保证与串行一致。
- `maxResultsPerPattern` 沿用既有 per-buffer 语义（并行不改变）；GUI 默认不设限（0）。
