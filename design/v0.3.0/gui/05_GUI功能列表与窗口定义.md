# 05 GUI 功能列表与窗口定义（v0.3.0，增量）

> 窗口结构沿用 v0.2.4：主窗口（`QMainWindow`，栈式三页 + 菜单/工具栏 + 状态栏 + 日志停靠窗）。本版**不新增/不删除窗口**，仅调整既有窗口内的功能点行为（扫描进度反馈）。

## 受影响功能点

| 功能 | 窗口/部件 | 变更 |
| --- | --- | --- |
| 扫描进度显示 | 状态栏 `QProgressBar` + 瞬时 `QLabel` | 由「恒 100%」改为真实进度（已完成/总工作量）（C-01） |
| 扫描执行 | psig `ScanProcesses`（无可见 UI） | 区域级并行，扫描更快（C-02） |
| 进度刷新 | 扫描 ViewModel | 由「逐块投递界面事件」改为「定时器采样」（C-03） |
| 进度投递 | 扫描 ViewModel / `MainWindow` | 工作线程只写原子变量；刷新不重设样式表（C-04） |
| 区域权限过滤 | —— | **不新增**（排除项）（C-05） |

## 窗口定义（不变部分）

- 三页（`QStackedWidget`）：
  1. **进程选择页** `ProcessSelectionPage`：进程表（名称/PID/可访问/路径）+ 刷新/重新选择。
  2. **特征码编辑页** `SignatureEditorPage`：特征码表 + 列管理 + 导入/导出。
  3. **匹配结果页** `ResultPage`：模板文本输入框 + 结果表 + 导出结果。
- 主窗口菜单：文件 / 编辑 / 扫描 / 视图 / 语言 / 帮助。
- 状态栏：持久状态（左）+ 进度条（中，扫描时显示）+ 瞬时反馈（右）。

## 功能入口定义（本版变更）

| 入口 | 位置 | 本版行为 |
| --- | --- | --- |
| 开始扫描 | 扫描菜单/工具栏 | 扫描期间状态栏进度条显示**真实进度**（C-01），刷新由定时器节拍驱动（C-03） |
| 取消扫描 | 扫描菜单/工具栏 | 语义不变；所有工作线程轮询取消标志 |
| 区域权限过滤 | —— | **不存在**（C-05） |
