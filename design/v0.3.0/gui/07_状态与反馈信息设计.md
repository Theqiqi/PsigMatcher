# 07 状态与反馈信息设计（v0.3.0，增量）

> 模式：修改型。三类反馈各自唯一显示位置（沿用）：**持久状态**（状态栏左）、**瞬时反馈**（状态栏右 瞬时标签）、**历史日志**（日志停靠窗）。错误提示分派：**短暂性错误**→瞬时反馈；**需决策错误**→弹窗。

## 受影响反馈点（逐条补齐）

### C-01 / C-03 / C-04 扫描进度反馈
- 反馈点：扫描过程中的**进度**与**瞬时状态文字**。
- 唯一位置（沿用）：
  - **进度条**：状态栏中部 `QProgressBar`（扫描时可见，非扫描隐藏）。
  - **瞬时文字**：状态栏右部 `m_transientLabel`（如 `扫描 pid=… 命中 N`）。
- 分派与刷新：
  - 进度值来源 = 工作线程维护的**原子变量**（已完成/总工作量），由主线程 `QTimer` 定时（约 100~200ms）读取并刷新（C-03/C-04）。
  - 进度条与瞬时文字**按定时器节拍刷新**，不再逐块刷新。
  - 扫描结束：进度条隐藏（`setProgress(-1)`），瞬时文字显示 `扫描完成，命中 N 条` / `已取消，命中 N 条`（沿用）。
- **样式表优化（C-04）**：`setTransientMessage` 仅在其**错误态发生变化**时才调用 `setStyleSheet`；同一错误态下的连续刷新不再重设样式表。
- **日志（不变）**：日志区仍仅记录扫描**开始/结束**两行；进度**不写入日志**（沿用 v0.2.4 结论）。

### C-02 区域并行
- 反馈点：无新增反馈。并行只改变扫描耗时，反馈通道与位置不变。
- 结论：**不新增**反馈点。

### C-05 不新增区域权限过滤
- 反馈点：无（不新增选项，故无相关反馈）。
- 结论：**不新增**反馈点。

## 唯一显示位置（复核）

| 反馈类型 | 唯一位置 | 本版变更 |
| --- | --- | --- |
| 持久状态 | 状态栏左（当前进程/行数等） | 无 |
| 进度 | 状态栏中 `QProgressBar` | 值语义修正为真实进度（C-01）；刷新改为定时器节拍（C-03） |
| 瞬时反馈 | 状态栏右 瞬时标签 | 刷新改为定时器节拍；样式表仅在错误态变化时重设（C-04） |
| 历史日志 | 日志停靠窗 | 无（进度不入日志） |

## 不受影响（引用既有文档）

- 结果导出/特征码导入导出的成功失败反馈、日志开关/右键清空、权限图标、重新选择进程保存提示等：见 `design/v0.2.4/gui/07_状态与反馈信息设计.md` 与 `design/v0.2.2/gui/07_状态与反馈信息设计.md`，本版不重设计。
