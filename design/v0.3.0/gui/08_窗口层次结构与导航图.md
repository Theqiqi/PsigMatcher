# 08 窗口层次结构与导航图（v0.3.0，增量）

> 模式：修改型。**窗口层次与导航图本版不变**，仅更新受影响窗口的部件（状态栏进度反馈链路）。

## 层次（不变）

- `QMainWindow`
  - 中央 `QStackedWidget`：`ProcessSelectionPage` / `SignatureEditorPage` / `ResultPage`
  - 底部 `QDockWidget`：日志
- 菜单栏：文件 / 编辑 / 扫描 / 视图 / 语言 / 帮助
- 状态栏：持久状态（左）+ 进度条（中，扫描时可见）+ 瞬时反馈（右）

## 导航图（不变）

- 进程选择页 --(双击/选定进程)--> 特征码编辑页 --(开始扫描)--> 匹配结果页
- 任意页 --(重新选择进程)--> 进程选择页

## 变更点（仅部件级/时序级）

- **状态栏进度条**：数值来源由「每次回调跨线程投递」改为「工作线程写原子变量 + 主线程 `QTimer` 定时读取」（C-01/C-03/C-04）。控件类型与层次不变。
- **扫描 ViewModel**：新增一个 `QTimer`（主线程）与一组进度原子变量；扫描期间启动定时器、结束停止（C-03/C-04）。
- 其余窗口/部件/导航关系沿用 v0.2.4 `08_窗口层次结构与导航图.md`。
