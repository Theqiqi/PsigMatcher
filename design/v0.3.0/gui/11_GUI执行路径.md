# 11 GUI 执行路径（v0.3.0，增量）

> 修改/新增功能的执行路径**必须补全正常/错误/取消三类**（事件驱动独立路径）。

## C-01/C-03/C-04 扫描进度

- **正常**：选择进程 → 开始扫描 → 进度条由 0% 按定时器节拍平滑增长 → 100% → 切结果页、进度条隐藏。
- **错误**：
  - 特征码非法 / 未选进程 / 特征码表为空 → **不启动扫描**，瞬时反馈（红）+ 日志（红）。
  - 扫描中个别进程/区域读取失败（`ReadProcessMemory` 返回空）→ 跳过该区域，继续其余区域（不中断整次扫描）。
- **取消**：扫描中点「取消」→ 取消标志置位 → 所有工作线程轮询后退出 → `timer->stop()` → 展示已完成命中 → 瞬时反馈 `已取消，命中 N 条`。

## C-02 区域并行

- **正常**：多个区域并发扫描 → 结果合并，与串行版本一致。
- **错误**：某区域读取失败 → 该区域贡献 0 命中，其余不受影响（错误隔离在区域粒度）。
- **取消**：每个区域扫描前后轮询取消标志，尽快退出。

## C-05 不新增区域权限过滤

- 无执行路径（不新增选项）。

## 不受影响
