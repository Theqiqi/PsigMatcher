# 13 技术选型分析（v0.3.0）

- **沿用既有技术栈**：C++20 / Qt6::Widgets / Qt6::Concurrent（异步）/ Windows / CMake + vcpkg（gtest）/ Ninja + MSVC。
- i18n：Qt 标准翻译体系（`tr()` + `.ts`/`.qm` + `QTranslator`），`lupdate`/`lrelease` 由 Qt 独立安装自带。
- 不重新选型；修改模式确认既有技术栈仍满足全部改动点（C-01..C-05）。
- 本版新增能力均为既有技术的既有用法：
  - C-01 进度语义修正：psig 内部（`ScanProgress` 取值），无新技术。
  - C-02 区域并行：psig 内部标准库线程（`std::thread` / `std::async` + `std::mutex`/`std::atomic`），**不引入外部线程池依赖**；QtConcurrent 仍只用于 GUI 侧整体任务异步。
  - C-03 定时采样：Qt `QTimer`（主线程）+ `std::atomic`（跨线程进度）。
  - C-04 回调削减：`std::atomic` + 粗化回调粒度 + 条件式 `setStyleSheet`。
  - C-05 范围界定：无技术变更。

## 说明（并行实现的技术边界）

- psig 静态库**不依赖 Qt**（既有约束），故区域并行只能使用标准库线程设施，**不得**使用 `QThread`/`QtConcurrent`。
- GUI 侧整体扫描仍用 `QtConcurrent::run`（既有），其内部再调用 psig 的并行实现；两层异步互不冲突（GUI 只有 1 个外层任务）。
