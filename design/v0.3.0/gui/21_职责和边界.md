# 21 职责和边界（v0.3.0，增量）

> 前置：`20_GUI模块分析.md`、`design/v0.2.4/gui/21_职责和边界.md`（上一版本）

## 各层职责与禁止项（本次适用点）

| 层 | 职责 | 禁止项 |
| --- | --- | --- |
| View | 构建控件（状态栏进度条/瞬时标签）；`setProgress` 显隐与取值；`setTransientMessage` 仅在错误态变化时重设样式表 | **不写 connect**、无 signals/private slots、不 include ViewModel/psig、不调业务；不调用平台 API |
| Model | 纯数据（本版无改动） | 不依赖 psig、不含业务逻辑 |
| ViewModel | 持 `View*`；集中 connect；持有 `QTimer` 与进度原子变量；`onStartScan` 的进度回调**只写原子变量**；`onProgressTick` 读原子变量并刷新 View；调 psig `ScanProcesses` | 不用 findChild；**不建线程池**（并行在 psig 内）；回调中不触碰界面对象；不直接调用 Win32 |
| 静态库 | psig 提供区域并行扫描与真实进度回调 | 不依赖 Qt |

## 边界确认（本次）

- **进度真实化（C-01）**：`ScanProgress` 由 psig 提供 `done/total`（区域工作量）；VM 仅做 `pct = total ? done*100/total : 0` 换算，不自行估算进度。
- **区域并行（C-02）**：并行完全在 psig 内部；GUI **不创建任何线程/线程池**，仍以单个 `QtConcurrent::run` 承载整次扫描。
- **定时采样（C-03）**：`QTimer`（主线程）定时读取进度原子变量并刷新状态栏；界面刷新与扫描循环解耦。
- **回调削减（C-04）**：
  - 进度回调（后台线程）**只写 `std::atomic`**，不投递界面事件；
  - `setTransientMessage` 仅在错误态变化时 `setStyleSheet`，连续同态刷新不重设样式表。
- **区域权限过滤（C-05）**：**不新增**任何界面选项或 API。

## 约束满足说明

- 每层禁止项清晰；View 不依赖 ViewModel/静态库；ViewModel 经 `View*` 指针操控 View。
- 并行与进度由 psig 提供，GUI 生产代码不建线程池、不调用平台 API。
