# 26 异常处理与错误显示策略（v0.3.0，增量）

> 前置：`24_ViewModel接口.md`、`design/v0.2.4/gui/26_异常处理与错误显示策略.md`（上一版本）

## 策略（沿用 + 本次适用点）

| 场景 | 分派 | 表现 |
| --- | --- | --- |
| 扫描进行中（C-01/C-03） | 持久进度 + 瞬时反馈 | 状态栏进度条按定时器节拍刷新；瞬时文字显示 `扫描 pid=… 命中 N` |
| 扫描完成/取消 | 瞬时反馈 + 日志 | `扫描完成/已取消，命中 N 条`；日志 `[scan]` |
| 未选进程 / 特征码非法 / 表为空 | 瞬时反馈（错误）+ 日志 | 不启动扫描（沿用） |
| 扫描中个别区域读取失败（C-02） | **无用户可见错误** | psig 在区域粒度隔离失败，继续其余区域（不中断） |
| 无区域可扫 | **无错误** | 进度条快速到 100% 并隐藏，结果为空（沿用） |

## 后台线程异常

- 扫描在 `QtConcurrent::run` 执行；结果经 `QFutureWatcher::finished`（QueuedConnection）回主线程，**不跨线程抛异常**。
- 进度回调在 psig 工作线程触发，**可能并发**；VM 回调只写 `std::atomic`（线程安全），不触碰 Qt 对象，因此不产生跨线程异常。
- `QTimer`（主线程）读取原子变量刷新界面，避免后台直接操作 UI。

## 约束满足说明

- 短暂性错误走瞬时反馈；错误提示位置唯一（状态栏右区/日志）。
- 本次改动的异常路径已覆盖：扫描错误沿用瞬时反馈；区域失败隔离无用户可见错误；进度刷新不跨线程操作 UI。
