# 27 Qt 技术选型（v0.3.0）

> 前置：`08_窗口层次结构与导航图.md`、`13_技术选型分析.md`、`design/v0.2.4/gui/28_QtGUI代码规范.md`

## 结论：沿用

| 维度 | 选型 |
| --- | --- |
| 程序类型 | Windows 桌面 exe |
| 语言 | C++20 |
| GUI | Qt6::Widgets（代码构建 Widget，无 .ui） |
| 异步 | Qt6::Concurrent（QtConcurrent::run + QFutureWatcher） |
| 国际化 | Qt6::LinguistTools（`lupdate`/`lrelease`）+ `QTranslator` + `.ts`/`.qm` |
| 测试 | gtest + QTest |
| 构建 | CMake + Ninja + MSVC；vcpkg manifest（gtest）；find_library 引用 psig |
| 静态库命名 | psig（依据程序类型命名） |

## 本次使用的既有控件/类（沿用既有能力）

- **本次新增**：
  - `QTimer`（`Qt6::Core`）：进度定时采样（约 150ms，`Qt::CoarseTimer`）（C-03）。
  - `std::atomic`（C++20 标准库）：跨线程进度计数（VM 持有，回调写入，定时器读取）（C-04）。
- 沿用：`QProgressBar`/`QLabel`（状态栏进度/瞬时文字）、`QtConcurrent::run` + `QFutureWatcher`（整次扫描异步）。

## 构建要点（沿用）

- Release：`WIN32_EXECUTABLE`（去控制台）；Debug 保留控制台。
- i18n：`.qm` 由 `lrelease` 生成并加入 `.qrc`；本次仅更新版本串翻译条目。
- 本版**未新增源文件**，`gui/CMakeLists.txt` 无需变更（仅源内容改动）。

## 约束满足说明

- 沿用既有 Qt 技术选型；静态库命名依据程序类型（psig）；`QTimer`/`std::atomic` 均为既有标准能力，无 Qt 以外第三方库。
- 区域并行在 psig 内用标准库线程实现，GUI 侧不引入线程设施。
