## 需求清单（来自 gui/17_API缺失需求.md）

### R-01 特征码库库级目标进程元数据（C-05）

- 公共 API：
  - `struct Table` **新增字段** `std::string targetProcess;`（库级目标进程名，可空）。
  - `bool ExportSignaturesDb(const std::string&, const Table&, std::string&)` —— **签名不变**。
  - `Table ImportSignaturesDb(const std::string&, std::string&)` —— **签名不变**。
- 行为：
  - 导出：`table.targetProcess` 非空时写入 `sig_meta(key='target_process', value=...)`。
  - 导入：读取该键填入 `Table::targetProcess`；缺表/缺键 → 空串，不报错。
- 验收：往返一致；旧库兼容（空串且无 err）；空值不写键；列/行往返不变；CSV 路径不变。

## 能力覆盖判定

- 静态库已存在；R-01 为对既有交换 API 的**结构扩展 + 实现补充**；需改动 `include/psig.h`、`src/api/exchange_signatures.cpp`、`test/` 相关用例。
- GUI 不自行实现 `.db` 读写或元数据；全部经扩展后的 `psig` 公共 API。
