# 05 业务流程变更（psig v0.3.1，增量）

> 前置：`04_需求点设计.md`。仅列出受影响业务流程；其余沿用 v0.3.0。

## 特征码库导出（变更）

```
调用方构造 Table{columns, rows, targetProcess}
    → ExportSignaturesDb(path, table, err)
        → 建表 sig_columns / sig_rows / sig_meta
        → targetProcess 非空 ? 写 sig_meta('target_process') : 跳过
        → 写列、写行
    → 返回 ok/err
```

## 特征码库导入（变更）

```
ImportSignaturesDb(path, err)
    → 打开库；校验 sig_columns 存在（否则 err）
    → 读 sig_columns / sig_rows
    → sig_meta 存在 ? 读 'target_process' → table.targetProcess : 空串
    → 返回 table
```

## 不受影响

- 扫描、进程枚举、结果导出、CSV 交换等业务流程：不变。
