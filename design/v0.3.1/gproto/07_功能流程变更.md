# 07 功能流程变更（psig v0.3.1，增量）

> 前置：`06_功能点设计.md`

## F-02 导出写入（正常/错误）

| 路径 | 步骤 | 结果 |
| --- | --- | --- |
| 正常 | 打开库 → 建表 → `targetProcess` 非空写 `sig_meta` → 写列/行 → 关闭 | 返回 true |
| 错误 | 打开失败 / SQL 执行失败 | 置 err，返回 false |

## F-03 导入读取（正常/兼容）

| 路径 | 步骤 | 结果 |
| --- | --- | --- |
| 正常 | 打开 → 校验 → 读列/行 → 读 `sig_meta.target_process` | `table.targetProcess` = 记录值 |
| 兼容 | `sig_meta` 缺表或键缺失 | `table.targetProcess` = 空串，**无 err** |
| 错误 | 打开失败 / 缺 `sig_columns` / 查询失败 | 置 err，返回空表 |

## 不受影响

- 其余功能流程（扫描/枚举/结果导出）不变。
