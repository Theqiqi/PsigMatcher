# 08 功能设计（psig v0.3.1，增量）

> 前置：`07_功能流程变更.md`

## 设计

- 复用既有 `sig_meta(key TEXT PRIMARY KEY, value TEXT)` 表：`target_process` 键与既有 `template` 键并列。
- 导出：沿用 `SqliteRun("INSERT INTO sig_meta(key,value) VALUES(?,?);", {...})`。
- 导入：沿用 `SqliteQuery("SELECT value FROM sig_meta WHERE key='target_process';", ...)`，与 `template` 读取同构。

## 关键点

- **非空才写**：`targetProcess` 为空串时不写键，保持旧库语义与最小化。
- **缺省不报错**：读取失败/无键 → 空串（与 `template` 一致）。
- 无并发要求（同步文件 I/O）。

## 约束满足

- 不抛异常；用返回值/出参表达错误；复用既有 atomic/sqlite 能力。
