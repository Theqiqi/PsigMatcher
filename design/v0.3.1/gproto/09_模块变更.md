# 09 模块变更（psig v0.3.1，增量）

> 前置：`08_功能设计.md`。psig 分层：data / algorithm / atomic / api。

| 层 | 本版变更 |
| --- | --- |
| data | **未受影响**（`Table` 为公共结构，定义在 `include/psig.h`，不属 data 内部类型） |
| algorithm | **未受影响** |
| atomic | **未受影响**（复用既有 `sqlite_io` 能力） |
| api | **修改**：`exchange_signatures.cpp` 的 `ExportSignaturesDb`/`ImportSignaturesDb` 增加 `target_process` 元数据读写 |
| 公共头 | **修改**：`include/psig.h` 的 `Table` 增字段 `targetProcess` |

## 受影响文件

- `psig/include/psig.h`
- `psig/src/api/exchange_signatures.cpp`
- `psig/test/unit/`（新增 R-01 用例）
