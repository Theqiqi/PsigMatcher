# 10 职责和边界变更（psig v0.3.1，增量）

> 前置：`09_模块变更.md`

| 层 | 职责（沿用） | 本版相关边界 |
| --- | --- | --- |
| api | 组合 data/algorithm/atomic，暴露公共 API；不直接写 SQL 细节之外的东西 | `exchange_signatures.cpp` 负责把 `Table::targetProcess` 映射到 `sig_meta` 键；**不新增** Qt 依赖 |
| atomic | 提供 SQLite 原子能力（打开/执行/查询/关闭） | **不变**；`sig_meta` 读写经既有 `SqliteRun`/`SqliteQuery` |
| data | 内部数据结构 | **不变**；公共 `Table` 在 `include/psig.h` |
| 公共头 | 对外契约 | `Table` 增字段属**向后兼容**扩展（新增字段，不破坏既有聚合初始化？见下） |

## 边界注意

- `Table` 现为聚合类型（`{columns, rows, templateText}`）。新增字段追加在末尾，**不破坏**既有 `table.templateText = ...` 式赋值；但既有 `Table{cols, rows, tmpl}` 聚合初始化若存在需改为按成员赋值（psig 内部无此用法，GUI 侧为按成员赋值）。
