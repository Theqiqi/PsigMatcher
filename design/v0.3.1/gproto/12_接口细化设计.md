# 12 接口细化设计（psig v0.3.1）

> 前置：`11_api接口分析.md`

## 公共头（`include/psig.h`）

```cpp
// 动态列表格
struct Table {
    std::vector<ColumnDef> columns;
    std::vector<TableRow> rows;
    std::string templateText;    // 表级模板文本（多行，可空；随导入/导出携带）
    std::string targetProcess;   // 库级目标进程名（可空；随 .db 导出/导入携带）  [v0.3.1 新增]
};
```

## 导出细化（`ExportSignaturesDb`）

```cpp
if (ok && !table.templateText.empty())
    ok = SqliteRun(db, "INSERT INTO sig_meta(key,value) VALUES('template',?);", {table.templateText}, err);
if (ok && !table.targetProcess.empty())
    ok = SqliteRun(db, "INSERT INTO sig_meta(key,value) VALUES('target_process',?);", {table.targetProcess}, err);
```

## 导入细化（`ImportSignaturesDb`）

```cpp
if (SqliteTableExists(db, "sig_meta")) {
    // template（既有）
    // target_process（新增）
    std::vector<std::vector<std::string>> tp;
    std::string e;
    if (SqliteQuery(db, "SELECT value FROM sig_meta WHERE key='target_process';", tp, e) &&
        !tp.empty() && !tp[0].empty())
        table.targetProcess = tp[0][0];
}
```

## 约束

- 复用既有 `SqliteRun`/`SqliteQuery`/`SqliteTableExists`；不新增 atomic API。
