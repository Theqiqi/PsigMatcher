# 13 数据结构变更（psig v0.3.1）

> 前置：`12_接口细化设计.md`

## 公共结构（`include/psig.h`）

```cpp
struct Table {
    std::vector<ColumnDef> columns;
    std::vector<TableRow> rows;
    std::string templateText;    // 不变
    std::string targetProcess;   // v0.3.1 新增：库级目标进程名（可空）
};
```

## 独立性

- `targetProcess` 为纯 std 类型（`std::string`），可独立编译；不引入新依赖。

## 存储映射

- `.db` 持久化于既有 `sig_meta(key,value)` 表，键 `target_process`；与 `template` 键并列，互不影响。

## 无内部结构变更

- data/algorithm/atomic 层无新增结构。
