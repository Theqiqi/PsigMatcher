# 19 代码规范（psig v0.3.1）

> 模式：修改型，沿用既有规范（`design/v0.3.0/gproto/19_代码规范.md`）。

## 沿用要点（与本版相关）

- 分层：data / algorithm / atomic / api；api 组合下层，不反向依赖。
- 不依赖 Qt；不抛异常（用返回值/出参表达错误）。
- `#include` 只用 `目录/文件.h` 形式；命名空间 `psig` / `psig::atomic` / `psig::api`。
- 量化：控制流嵌套 ≤3 层、函数体 ≤80 行、文件 ≤400 行。

## 本版符合点

- 仅改 `include/psig.h`（加字段 + 版本串）与 `src/api/exchange_signatures.cpp`（两处 SQL 读写），无新增文件、无分层变化。
