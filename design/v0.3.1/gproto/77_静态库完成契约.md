# 77 静态库完成契约（psig v0.3.1）

- 需求来源：`design/v0.3.1/gui/17_API缺失需求.md`、`design/v0.3.1/gproto/02_跨流程需求接收.md`（R-01）。
- 交付范围：对既有 `psig` 的**公共结构扩展 + api 层实现**；公共函数签名不变，向后兼容。

## 公共接口变更（psig/include/psig.h）

- `struct Table` —— **新增字段** `std::string targetProcess;`（库级目标进程名，可空）。既有字段不变。
- `ExportSignaturesDb(const std::string&, const Table&, std::string&)` —— **签名不变**；行为增强：`targetProcess` 非空时写 `sig_meta('target_process')`。
- `ImportSignaturesDb(const std::string&, std::string&)` —— **签名不变**；行为增强：读回 `sig_meta('target_process')` 到 `Table::targetProcess`。
- 无新增公共函数；CSV 交换（`ExportSignaturesCsv`/`ImportSignaturesCsv`）不变。
- 版本串：`psig.h` v0.3.0 → v0.3.1。

## 行为变更与验收

| 能力 | 验收 | 用例 |
| --- | --- | --- |
| R-01 往返携带 | 导出含目标进程名 → 导入读回一致 | `SignaturesExchange.DbRoundTripCarriesTargetProcess` |
| R-01 旧库兼容 | 空目标进程名不写键；导入空串且无 err | `SignaturesExchange.DbEmptyTargetProcessYieldsEmpty` |

| 回归 | CSV 往返不受影响 | `SignaturesExchange.CsvRoundTripUnchanged` |
