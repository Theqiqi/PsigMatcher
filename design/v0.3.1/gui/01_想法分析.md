## 三、逐条分析与期望行为

### C-01 / C-02 / C-03 悬停整行高亮的绘制缺陷（同一根因）

- **现状**：三张表（进程/特征码/结果）统一使用 `HoverRowDelegate`（`view/hoverrowdelegate.cpp`）。其 `paint()` 在检测到 `QStyle::State_MouseOver` 时执行：
  ```cpp
  QRect rowRect = opt.rect;
  rowRect.setLeft(0);
  rowRect.setRight(view->viewport()->width() - 1);   // 横向扩展到整行
  painter->fillRect(rowRect, kHoverColor);           // 在「当前单元格」之外绘制
  QStyledItemDelegate::paint(painter, opt, index);   // 基类再画当前单元格
  ```
  根因：**委托在自身单元格矩形之外绘制**。Qt 的 item view 逐单元格绘制，某单元格的委托只应绘制自己的 `opt.rect`；跨越到同行其它列填充，会在该列**已经画好文字之后**把其像素覆盖（悬停色为不透明浅蓝），而这些列不会因此重绘。
- **表现**：
  - C-03：悬停到某列时，其**左侧列的文字被悬停色覆盖**（消失/发虚）。
  - C-01：被覆盖/未覆盖的不一致使**悬停列看起来单独变深**；选中色条同样被越界绘制干扰。
  - C-02：单击后整行选中本应由 `SelectRows` 一次性铺满，但越界填充把已铺好的选中色覆盖，**需再移动鼠标触发重绘才整行变色**。
- **期望**：悬停整行高亮**逐单元格、在各自 `opt.rect` 内**绘制；不覆盖相邻列文字/选中色；单击后整行选中色**即时**铺满；悬停态为淡色提示、不改变选中语义（沿用 `design/v0.2.4/gui/06_交互模式设计.md` 的 C-02 规则）。

### C-04 左上角角落按钮触发全选

- **现状**：`QTableView` 默认启用角落按钮（`cornerButtonEnabled=true`），点击表头交汇处的角落按钮会 `selectAll()`。
- **表现**：在进程选择页，用户点击左上角空白即全选所有进程行，非预期。
- **决策（用户确认）**：**禁用角落按钮**（`setCornerButtonEnabled(false)`）。角落不再触发全选；进程页不新增「取消全选」入口。
- **范围**：仅进程选择页（该页以「选一个进程作目标」为主，全选无意义）。特征码/结果页的角落全选对批量操作有正面价值，**不改**。

### C-05 特征码库未记录目标进程信息

- **现状**：特征码表导出为 `.db`（`psig::ExportSignaturesDb`）时，仅写入 `sig_columns` / `sig_rows` / `sig_meta(template)`；**不记录该表是针对哪个目标进程编制的**。导入（`ImportSignaturesDb`）也只还原列与行。
- **风险**：用户对 A 进程编制特征码并导出；下次对 B 进程导入同一份库并扫描，可能因进程选错而得到无意义结果却毫无提示。另一方面，**同一程序的进程名/模块名可能变化**，因此不能简单地按名严格拒绝。
- **决策（用户确认）**：**携带+提示**——
  - 导出时把**当前目标进程名**写入 `.db` 库级元数据（`sig_meta`）。
  - 导入时若库中记录了目标进程名、且与**当前目标进程名不一致**，弹窗提示（需决策错误 → 弹窗），用户可选择**继续导入**或取消。
  - 库未记录进程名（旧库）或当前无目标进程时不提示。
- **范围**：`.db` 库级元数据；不改特征码表的列定义；CSV 往返语义不变（用户可选的 `.csv` 保存路径不携带该元数据，属已知边界）。

## 四、本轮已澄清的设计决策（用户确认）

| 议题 | 决策 |
| --- | --- |
| C-01/02/03 修复方向 | 委托只在本单元格 `opt.rect` 内绘制；整行悬停由**视图**按行重绘驱动（不再跨列填充） |
| C-04 角落全选 | **禁用角落按钮**（`setCornerButtonEnabled(false)`），仅进程页 |

## 五、不做的事（排除项）

- 不新建程序、不新增窗口/页面。
- 不改技术栈（沿用 Qt6::Widgets / Qt6::Concurrent / MSVC+Ninja / vcpkg）。
- 不改变扫描语义（命中判定、结果字段、结果导出格式均不变）。
- 不改变特征码表列定义与 CSV 往返语义。
- 不删除 psig 公共 API。
- 不为特征码/结果页禁用角落按钮（仅进程页）。
