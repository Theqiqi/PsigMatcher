# 02 领域模型（v0.3.1，增量）

> 模式：修改型。对既有领域模型做增量更新，仅标注本版**新增/修改**的集合与操作；其余沿用
> `design/v0.1.0/gui/02_领域模型.md` 与 `design/v0.2.0/gui/02_领域模型.md`。

## 一、业务对象（增量）

| 对象 | 本版变化 | 说明 |
| --- | --- | --- |
| 进程（Process） | 无数据字段变化 | 展示层的悬停/选中着色属**视图交互**，不改对象模型（C-01~C-04） |
| 特征码（Signature） | 无变化 | 行/列结构不变 |
| 匹配结果（MatchResult） | 无变化 | 字段与导出不变 |
| **特征码库（SignatureLibrary）** | **新增元数据字段：目标进程（targetProcess）** | 该库编制时所针对的目标进程名；导出携带、导入比对（C-05） |
| 目标进程（TargetProcess） | 无字段变化 | 沿用 `pid` + `name`；其 `name` 参与导入比对（C-05） |

## 二、数据集合及其元素操作（增量）

沿用既有「数据集合 + 元素操作（查看/复制/编辑/删除/批量）」建模；本版仅列出受影响项。

### 进程集合（进程选择页）

| 元素操作 | 变化 |
| --- | --- |
| 查看（悬停/选中着色） | **修改**：整行悬停高亮改为「逐单元格、各画各的矩形」；单击整行选中色即时铺满；悬停态与选中态共存（沿用 v0.2.4 C-02 规则） |
| 选择（多选 + 双击/右键确认目标） | 不变 |
| 全选（角落按钮） | **删除**：禁用角落按钮，不再提供「点左上角空白即全选」入口（C-04） |

> 说明：进程集合的**元素集合本身不变**（仍是系统进程快照）；变化在**展示与选择入口**，不改数据。

### 特征码库（导入/导出产物）

| 元素操作 | 变化 |
| --- | --- |
| 导出 | **修改**：`.db` 写出时把「目标进程名」写入库级元数据 `sig_meta`（键 `target_process`）（C-05） |
| 导入 | **修改**：`.db` 读入时还原库级「目标进程名」；若与当前目标进程名不一致 → 触发**需决策提示**（继续/取消）（C-05） |

## 三、参与者

| 参与者 | 本版变化 |
| --- | --- |
| 用户 | 无 |
| GUI 进程（psig_gui） | 悬停/选中绘制改由视图按行重绘驱动；导入时新增比对与提示 |
| psig 静态库 | 特征码 `.db` 交换新增库级元数据读写 |

## 四、操作流程（增量，高层）

1. **进程浏览与选择（C-01~C-04）**：用户移动鼠标 → 视图整行淡色悬停（逐单元格绘制）→ 单击 → 整行深色选中（即时）→ 双击/右键「以此进程为目标」确认。角落按钮不再触发全选。
2. **特征码库往返（C-05）**：用户对目标进程编制特征码 → 导出 `.db`（写入目标进程名）→ 换环境导入 → 若当前目标进程名与库记录不一致 → 提示 → 用户选择继续/取消 → 应用特征码表。

## 五、不受影响（引用既有文档）

- 进程枚举/权限图标、特征码行/列增删改、匹配结果批量复制/删除、结果导出列选择等：沿用既有领域模型，不重复分析。
