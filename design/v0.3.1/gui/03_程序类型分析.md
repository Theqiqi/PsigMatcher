# 03 程序类型分析（v0.3.1）

> 模式：修改型。

## 结论：沿用既有 GUI 类型

本版为对既有 `psig_gui` 的增量修改，**程序类型不变**，不做重复判断。

- 上一版本类型判定见 `design/v0.2.4/gui/03_程序类型分析.md`（v0.3.0 沿用）。
- 本版改动全部发生在**既有 Qt GUI 程序内部**：表格绘制（View）、角落按钮（View）、导入/导出提示（ViewModel）+ 静态库数据交换元数据。
- 无新增窗口、无新增程序形态，不涉及是否适合 GUI 的重新评估。

## 约束满足说明

- 修改模式：程序类型不变，标注「沿用既有 GUI 类型」。
