# 04 GUI 需求分析（v0.3.1，需求变更文档）

> 模式：修改型。本文件为**需求变更文档**，逐条列出「改动点 → 新增/修改/删除 → 影响窗口/功能」。
> 未受影响的既有需求引用 `design/v0.2.4/gui/04_GUI需求分析.md`（v0.3.0 沿用），不重复分析。

## 一、改动点 → 变更类型 → 影响窗口/功能

| 编号 | 改动点 | 变更类型 | 影响窗口/功能 | 需求描述 |
| --- | --- | --- | --- | --- |
| C-01 | 悬停列变深、悬停色条异常 | **修改** | 进程选择页（及沿用同委托的特征码/结果页）表格绘制 | 悬停整行高亮必须**逐单元格在各自矩形内**绘制；悬停态为淡色提示，不覆盖相邻列文字，不改变选中语义 |
| C-02 | 单击后整行选中色不即时 | **修改** | 同上 | 左键单击后整行选中色**即时铺满**（无需移动鼠标） |
| C-03 | 悬停覆盖前面列字体 | **修改** | 同上 | 悬停不得覆盖/擦除同行其它列的文字与背景 |
| C-04 | 角落按钮点空白全选 | **删除** | 进程选择页表格 | 进程选择页**禁用角落按钮**，点击左上角空白不再全选；进程页不新增「取消全选」入口 |
| C-05 | 特征码库未记录进程信息 | **修改/新增** | 特征码导入/导出（全局动作）、psig 特征码 `.db` 交换 | 导出 `.db` 时写入当前**目标进程名**；导入 `.db` 时若库记录的目标进程名与当前目标进程名不一致，弹窗提示并可**继续/取消** |

## 二、窗口布局（受影响部分）

### 进程选择页（`ProcessSelectionPage`）

- 布局**不变**：`QTableView`（上，拉伸）+ 筛选框（下）。
- 表格控件替换为支持整行悬停重绘的视图子类（见设计文档 22）；`setCornerButtonEnabled(false)`。
- 选择行为不变：`SelectRows` + `ExtendedSelection`；双击/右键确认目标不变。

### 特征码导入/导出（无新窗口）

- 不新增窗口/对话框；仅在既有导入流程中**插入一次提示弹窗**（`QMessageBox`，需决策错误）。
- 文件对话框过滤器不变（导入/导出均 `.db`）。

## 三、用户操作路径（变更部分）

1. **进程悬停/选中（C-01~C-04）**
   - 移动鼠标进入某行任一单元格 → 整行淡色悬停（各单元格在自身矩形内绘制）。
   - 左键单击 → 整行深色选中，**即时**。
   - 点击表格左上角空白 → **无反应**（角落按钮已禁用）。
2. **特征码导出（C-05）**
   - 文件菜单「导出特征码」→ 选择 `.db` 路径 → 写出（含目标进程名元数据）→ 瞬时反馈 + 日志。
3. **特征码导入（C-05）**
   - 文件菜单「导入特征码」→（若当前表非空，先询问是否保存，沿用）→ 选择 `.db` →
     - 若库记录目标进程名 ≠ 当前目标进程名 → **提示弹窗**（继续/取消）；
     - 取消 → 中止导入；继续 → 应用特征码表 → 瞬时反馈 + 日志。

## 四、可视化反馈要求（变更部分）

- 悬停/选中着色：**纯视觉反馈**，不写日志、不改状态栏（沿用 v0.2.4 C-02）。
- 角落按钮禁用：无反馈文案。
- 导入进程名不一致：**需决策错误 → 弹窗**（非瞬时反馈）。

- 需求包含窗口布局（受影响页布局不变）、用户操作路径（点击流程）、可视化反馈要求。
