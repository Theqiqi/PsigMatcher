# 05 GUI 功能列表与窗口定义（v0.3.1，增量）

> 模式：修改型。仅列出受本版改动影响的功能点与窗口；其余沿用
> `design/v0.2.4/gui/05_GUI功能列表与窗口定义.md`。

## 一、窗口定义（增量）

| 窗口/页面 | 本版变化 |
| --- | --- |
| 主窗口 `MainWindow` | 无变化（不新增控件/菜单） |
| 进程选择页 `ProcessSelectionPage` | 表格改用支持整行悬停重绘的视图子类；**禁用角落按钮** |
| 特征码编辑页 `SignatureEditorPage` | 表格改用同一视图子类（悬停修复统一生效）；角落按钮保留 |
| 匹配结果页 `ResultPage` | 表格改用同一视图子类；角落按钮保留 |
| 导入提示弹窗 | **新增（复用 `QMessageBox`，非新窗口类）**：特征码导入时进程名不一致的提示 |

## 二、功能列表（增量）

| 功能编号 | 功能 | 变更类型 | 入口 | 反馈 |
| --- | --- | --- | --- | --- |
| F-01 | 表格整行悬停高亮（进程/特征码/结果三表统一） | 修改 | 鼠标进入单元格 | 视觉（淡色整行） |
| F-02 | 整行选中着色即时铺满 | 修改 | 左键单击 | 视觉（深色整行） |
| F-03 | 进程页角落按钮全选 | 删除 | 原：左上角角落按钮 | 无 |
| F-04 | 特征码导出携带目标进程名 | 修改 | 文件菜单「导出特征码」 | 瞬时反馈 + 日志 |
| F-05 | 特征码导入比对目标进程名并提示 | 新增 | 文件菜单「导入特征码」 | **弹窗**（继续/取消） |

## 三、功能点细节

- **F-01/F-02**：整行悬停与选中均为视图绘制职责；悬停态淡、选中态深，二者共存；悬停不改选中（沿用 v0.2.4 C-02）。
- **F-03**：仅进程页 `setCornerButtonEnabled(false)`；特征码/结果页保留角落全选（对批量操作有用）。
- **F-04**：导出 `.db` 时把当前目标进程名写入库级元数据；无目标进程（空串）时不写入。
- **F-05**：导入 `.db` 后，若库记录目标进程名非空且与当前目标进程名不同 → 弹窗；选择「继续」则应用表，选择「取消」则中止。

## 四、不受影响（引用既有文档）

- 进程枚举/筛选/刷新/图标、特征码行列增删改/列管理、扫描开始/取消、结果导出与列选择、日志、语言切换等：沿用既有功能列表。
