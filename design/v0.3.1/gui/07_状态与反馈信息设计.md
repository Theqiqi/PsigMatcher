# 07 状态与反馈信息设计（v0.3.1，增量）

> 模式：修改型。三类反馈各自唯一显示位置（沿用）：**持久状态**（状态栏）、**瞬时反馈**（瞬时标签）、**历史日志**（日志停靠窗）。错误分派：**短暂性错误**→瞬时反馈；**需决策错误**→弹窗。

## 一、受影响反馈点（逐条补齐）

### C-01~C-03 悬停/选中着色

- 反馈点：表格悬停/选中着色（**纯视觉反馈**，不属三类文字反馈通道）。
- 结论：**不新增**文字反馈；仅视觉态。悬停不写日志、不改状态栏。修复仅纠正绘制范围，不引入新反馈。

### C-04 角落按钮禁用

- 反馈点：无（点击角落空白由「全选」变为「无反应」）。
- 结论：**不新增**反馈文案。

### C-05 特征码导出携带目标进程名

- 反馈点：导出成功/失败提示（沿用既有）。
- 分派：
  - 成功 → 瞬时反馈（瞬时标签）+ 日志一条（导出类，绿）。
  - 失败（路径不可写等）→ 短暂性错误 → 瞬时反馈（红）+ 日志（红）。
- 结论：**不新增**反馈点；仅导出内容增加库级元数据（文件内容，非界面反馈）。

### C-05 特征码导入比对目标进程名（**新增反馈点**）

- 触发：导入 `.db` 时，库记录目标进程名非空且 ≠ 当前目标进程名。
- 分派：属**需决策错误** → **弹窗**（`QMessageBox`，按钮「继续导入」/「取消」）。
  - 文案（随语言）：标题「进程不一致」；正文「该特征码库记录的目标进程为“X”，当前目标进程为“Y”。是否仍要导入？」。
- 后续：
  - 「继续导入」→ 应用表 → 瞬时反馈（已导入 N 条）+ 日志（导入绿，附「进程不一致，已确认继续」说明）。
  - 「取消」→ 中止导入 → 瞬时反馈（已取消导入，非错误态）+ 日志（普通）。
- 边界：
  - 库未记录进程名（旧库）→ 不提示，直接导入。
  - 当前无目标进程（`m_targetName` 为空）→ 不提示（无从比对）。

## 二、唯一显示位置（复核）

| 反馈类型 | 唯一位置 | 本版新增 |
| --- | --- | --- |
| 持久状态 | 状态栏 | 无 |
| 瞬时反馈 | 瞬时标签（成功/失败/取消） | C-05 导入成功/失败/取消沿用；新增「取消导入」文案 |
| 历史日志 | 日志停靠窗 | C-05 导入比对结果记一条 |
| 需决策弹窗 | `QMessageBox` | **C-05 进程不一致提示**（新增） |

## 三、不受影响（引用既有文档）

- 日志开关/右键清空、进程权限图标、扫描进度、重新选择进程保存提示等反馈设计：见 `design/v0.3.0/gui/07_状态与反馈信息设计.md`、`design/v0.2.4/gui/07_状态与反馈信息设计.md`，本版不重设计。
