# 08 窗口层次结构与导航图（v0.3.1，增量）

> 模式：修改型。仅更新受影响窗口的层次/导航/绑定关系；其余沿用
> `design/v0.2.4/gui/08_窗口层次结构与导航图.md`。

## 一、窗口层次（受影响部分）

```
MainWindow (QMainWindow)
└── QStackedWidget (central)
    ├── SignatureEditorPage (QWidget)
    │   └── QTableView  ──►  HoverRowTableView  (本版替换)   [委托: HoverRowDelegate]
    ├── ProcessSelectionPage (QWidget)
    │   ├── QTableView  ──►  HoverRowTableView  (本版替换)   [委托: HoverRowDelegate]
    │   │                     └── setCornerButtonEnabled(false)   [C-04]
    │   └── QLineEdit (筛选框)
    └── ResultPage (QWidget)
        ├── QPlainTextEdit (模板)
        └── QTableView  ──►  HoverRowTableView  (本版替换)   [委托: HoverRowDelegate]
```

- 三张表由 `QTableView` 替换为 `HoverRowTableView`（`QTableView` 子类，新增 `view/hoverrowtableview.{h,cpp}`）。
- 其余控件/页面结构不变。
- 导航图不变（进程页 → 特征码页 → 结果页，经 `QStackedWidget`）。

## 二、导航图（不变）

```
[进程选择页] --确认目标--> [特征码编辑页] --开始扫描--> [匹配结果页]
     ^                         |                             |
     +------重新选择进程-------+                             |
                              +---------清空结果------------+
```

本版不新增/删除导航边，不改页面切换入口。

## 三、Qt 控件术语

- `QMainWindow` / `QWidget` / `QStackedWidget` / `QTableView`（子类 `HoverRowTableView`）/ `QStyledItemDelegate`（子类 `HoverRowDelegate`）/ `QLineEdit` / `QPlainTextEdit` / `QMessageBox`。
- 无新增 `QDockWidget` / 无新增窗口类。

## 四、约束满足说明

- 修改模式：只更新受影响窗口的层次/绑定关系（三张表的视图类型 + 进程页角落按钮）。
- 使用 Qt 控件术语描述层次。
