# 21 职责和边界（v0.3.1，增量）

> 模式：修改型。仅列本版受影响模块的职责/禁止项；其余沿用 `design/v0.2.4/gui/21_职责和边界.md`。

| 层/模块 | 职责 | 禁止项 |
| --- | --- | --- |
| View `HoverRowTableView` | 跟踪「悬停行」；在悬停行变化时重绘受影响行；构造时装配 `HoverRowDelegate`、启用鼠标跟踪 | **不发射信号、无 private slots、不 connect、不写 Model、不调业务/静态库、不 include viewmodel/** |
| View `HoverRowDelegate` | 仅绘制：`initStyleOption` 后，对悬停行非选中单元格设淡色 `backgroundBrush`；清除单格 `State_MouseOver` | **不跨越 `opt.rect` 绘制**、不发射信号、不写 Model、不 include 业务头 |
| View `ProcessSelectionPage` | 创建表格（`HoverRowTableView`）与控件；禁用角落按钮 | 不写 connect、不调业务 |
| ViewModel `MainViewModel` | 导出时把 `m_targetName` 写入 `table.targetProcess`；导入时比对并弹窗（需决策） | 不在 GUI 自行实现 `.db` 读写；不编造元数据 |
| 静态库 `psig` | 特征码 `.db` 库级目标进程名的持久化与读回 | 不依赖 Qt；不抛异常 |

## 关键边界

- **View 零 connect/零 signals/零 private slots**：悬停重绘经 `mouseMoveEvent`/`leaveEvent`（虚函数重写）驱动，不经信号槽。
- **ViewModel 经 View 公开 getter 读控件、公开方法更新 UI**：沿用（本版未新增 findChild 访问）。
- **每层禁止项**：见上表。

## 约束满足说明

- 每层定义清晰禁止项；View 不依赖 ViewModel/静态库；ViewModel 经 `View*` 操控 View。
