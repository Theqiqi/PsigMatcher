# 04 GUI 需求分析（v0.3.2，增量）

- 版本：v0.3.2
- 模式：修改型。仅列**需求变更点**；其余沿用 `design/v0.3.1/gui/04_GUI需求分析.md`。

## 一、需求变更清单

| 编号 | 改动点 | 新增/修改/删除 | 影响窗口/功能 |
| --- | --- | --- | --- |
| C-01 | 特征码表「未保存改动」由**真实改动**判定（单元格编辑、增删行、改列定义均计入；导入/导出成功清除） | 修改 | 特征码编辑页（`SignatureEditorPage`）+ 状态栏持久状态区 |

| C-04 | 程序名改为 `PsigMatcher.exe`；界面标题版本号 → v0.3.2 | 修改 | 构建目标/入口/资源/脚本（用户可见：exe 名、关于框、日志） |

## 二、窗口布局（本版不新增窗口）

- 主窗口 `QMainWindow` 布局不变（中央 `QStackedWidget` 三页 + 底部「历史日志」dock + 状态栏持久/瞬时区 + 进度条）。详见 `08_窗口层次结构与导航图.md`。
- 本版仅**新增/修改模态对话框的文案与按钮集合**：
  - 导入覆盖确认（C-02）：`QMessageBox`，按钮 [继续导入 / 取消]。
  - 关闭保存提示（C-03）：`QMessageBox`，按钮 [保存 / 不保存 / 取消]。
- 状态栏持久状态区（C-01）：未保存时在末尾追加 `*` 标记。

## 三、用户操作路径（点击流程）

### 路径 1：编辑后导入（C-01/C-02）

1. 特征码编辑页：双击单元格修改内容 / `Ctrl+N` 新增行 / 右键删除行 / `Ctrl+M` 改列 → **进入未保存状态**（持久状态区出现 `*`）。
2. 「文件→导入特征码」（或导入按钮 / `Ctrl+O`）。
3. 若未保存 → 弹「导入前确认：当前特征码表有未保存改动，导入将覆盖它。是否继续？」：
   - 继续导入 → 选择 `.db` 文件 → 导入成功后未保存标记清除；
   - 取消 → 中止导入，当前表不变。
4. 若已保存（无未保存改动）→ 直接进入选择文件。

### 路径 2：关闭程序（C-03）

1. 存在未保存改动时，点标题栏关闭按钮 / 菜单「退出」。
2. 弹「保存特征码：当前特征码表尚未保存，是否保存？」：
   - 保存 → 另存为（默认 `.db`）→ 成功或用户取消文件对话框 → 关闭；
   - 不保存 → 直接关闭（改动丢弃）；
   - 取消 → 阻止关闭，窗口保持打开。

### 路径 3：重新选择进程（沿用）

1. 有未保存改动时点「重新选择进程」→ 弹「保存 / 不保存 / 取消」；取消则中止重选。语义不变。

## 四、可视化反馈要求

| 时机 | 反馈形式 | 位置 |
| --- | --- | --- |
| 进入/退出未保存状态 | 持久状态区末尾 `*` 出现/消失 | 状态栏左侧持久状态区 |
| 导入覆盖确认 | 模态对话框（需决策） | 屏幕居中（父窗口主窗口） |
| 关闭保存提示 | 模态对话框（需决策） | 屏幕居中（父窗口主窗口） |
| 导入/导出成功或失败 | 瞬时消息 + 历史日志（沿用） | 状态栏右侧瞬时区 / 底部日志 dock |

## 五、验收标准

- **C-01**：`SignatureTableModel::setData` 修改单元格后，持久状态区出现 `*`；导出成功或导入成功后 `*` 消失。
- **C-02**：有未保存改动时触发导入 → 弹窗按钮集合**不含**「保存」「不保存」，含「继续导入」「取消」；选「取消」不改变当前表；选「继续导入」才进入文件选择。
- **C-03**：有未保存改动时 `close()` 返回 `false`（窗口不关闭）当且仅当用户选「取消」；选「不保存」后 `close()` 成功；选「保存」并完成另存为后 `close()` 成功；无未保存改动时 `close()` 直接成功。菜单「退出」触发的行为与关闭按钮一致。
- **C-04**：编译产物为 `gui/out/bin/<配置>/PsigMatcher.exe`；`QApplication::applicationName()=="PsigMatcher"`；标题为「进程特征码批量匹配器 v0.3.2」。
