# 05 GUI 功能列表与窗口定义（v0.3.2，增量）

- 版本：v0.3.2
- 模式：修改型。仅列**受影响功能与对话框**；完整功能列表沿用 `design/v0.3.1/gui/05_GUI功能列表与窗口定义.md`。

## 一、功能变更清单

| 编号 | 功能 | 入口 | 变化 |
| --- | --- | --- | --- |
| F-05 | 导入特征码 | 文件菜单「导入特征码」/导入按钮/`Ctrl+O` | **变更**：未保存时仅弹覆盖确认 [继续导入/取消]（原为 [保存/不保存/取消] 并内嵌另存为） |
| F-06 | 导出特征码 | 文件菜单「导出特征码」/导出按钮/`Ctrl+S` | 不变（成功后清除未保存标记） |
| F-14 | 更新特征码未保存状态 | 特征码页任意编辑（单元格编辑/增行/删行/列管理） | **新增**：真实脏标记（含单元格编辑）+ 持久状态区 `*` |
| F-15 | 关闭保存提示 | 标题栏关闭 / 文件菜单「退出」 | **新增**：未保存时 [保存/不保存/取消]；取消阻止关闭 |
| F-16 | 退出程序 | 文件菜单「退出」 | **变更**：由「无效果」改为真正关闭程序（复用 F-15 提示） |

## 二、窗口/对话框定义

| 窗口/对话框 | 类型 | 本版变化 |
| --- | --- | --- |
| 主窗口 `MainWindow` | `QMainWindow` | 标题版本号 v0.3.2；`close()` 行为受 C-03 影响（由 ViewModel 事件过滤器裁决） |
| 导入前覆盖确认 | `QMessageBox`（模态） | **按钮集合变更**：`[继续导入][取消]`；文案「当前特征码表有未保存改动，导入将覆盖它。是否继续？」 |
| 关闭保存提示 | `QMessageBox`（模态） | **新增**：`[保存][不保存][取消]`；文案「当前特征码表尚未保存，是否保存？」 |
| 重新选择进程保存提示 | `QMessageBox`（模态） | 不变（复用同一实现 `askSaveSignatureChanges`） |
| 关于 `AboutDialog` | 自定义对话框 | 文案版本号 v0.3.2 |

## 三、快捷键（沿用 + 本版新增）

- 沿用：`Ctrl+O` 导入、`Ctrl+S` 导出、`Ctrl+N` 新增行、`Ctrl+M` 列管理、`Ctrl+1/2/3` 切页、`Ctrl+R` 刷新、`F5` 扫描、`Shift+Esc` 取消扫描、`Ctrl+Return` 确认选择、`Ctrl+L` 清空日志（日志右键菜单）、`F1` 关于。
- **新增（仅作用于对应模态对话框，作为确定性键盘入口/可访问性）**：
  - 保存提示 / 关闭提示：`Ctrl+S` = 保存、`Ctrl+D` = 不保存、`Esc` = 取消。
  - 导入覆盖确认：`Enter` = 继续导入、`Esc` = 取消。

> 说明：为对话框按钮提供确定性键盘入口沿用既有约定（见 `gui/src/view/mainwindow.cpp` 中「键盘快捷键：作为可确定性注入的操作入口（E2E 与快捷键用户）」），亦使关闭提示可被 E2E 驱动脚本注入验证。

## 四、约束满足说明

- 功能列表覆盖本版全部改动点，标注入口与变化；窗口定义覆盖受影响的对话框。
