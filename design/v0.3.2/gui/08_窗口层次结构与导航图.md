# 08 窗口层次结构与导航图（v0.3.2，增量）

- 版本：v0.3.2
- 模式：修改型。仅列受影响窗口的层次/导航；其余沿用 `design/v0.3.1/gui/08_窗口层次结构与导航图.md`。

## 一、窗口层次（本版无结构变化）

```
QMainWindow (MainWindow)                       ← 标题「进程特征码批量匹配器 v0.3.2」
├── menuBar(): 文件 / 编辑 / 扫描 / 视图 / 语言 / 帮助
├── QToolBar (m_toolbar)                        ← 按页显隐
├── QStackedWidget (centralWidget)
│   ├── SignatureEditorPage   (index 0)         ← C-01/C-02 影响
│   ├── ProcessSelectionPage  (index 1)
│   └── ResultPage            (index 2)
├── QDockWidget「历史日志」(m_logDock) → QPlainTextEdit
└── statusBar(): persistentLabel + progressBar + transientLabel
```

- 无新增窗口/页面/停靠面板；仅 `MainWindow` 的**关闭行为**与状态栏**文本内容**受影响。
- 模态对话框均为临时顶层窗口（父窗口 = `MainWindow`），不进入导航栈：
  - 导入覆盖确认（C-02）
  - 关闭保存提示 / 重选进程保存提示（C-03，同一实现）

## 二、导航图

```
[进程选择页] --确认选择--> [特征码编辑页] --开始扫描--> [匹配结果页]
      ^                        |                              |
      |                        +--Ctrl+1/2/3 直接切页---------+
      +--重新选择进程（未保存时提示）--+
```

- 本版导航路径不变；「重新选择进程」提示、切页快捷键沿用。
- **新增导航终点语义**：`MainWindow::close()`（标题栏关闭 / 菜单「退出」）在未保存时可能被 ViewModel 事件过滤器**否决**（不进入关闭）。这是导航图中的「回退边」：`关闭请求 --取消--> 保持当前页`。

## 三、约束满足说明

- 使用 Qt 控件术语（`QMainWindow`、`QStackedWidget`、`QDockWidget`、`QPlainTextEdit`、`QMessageBox`）。
- 修改模式：只更新受影响窗口（主窗口）的层次/导航/关闭关系；页面内部结构与其余窗口引用既有文档。
