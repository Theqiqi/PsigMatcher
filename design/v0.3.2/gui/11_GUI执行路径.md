# 11 GUI 执行路径（v0.3.2，增量）

- 版本：v0.3.2
- 模式：修改型。仅列本版改动点的正常/错误/取消三类路径；其余沿用 `design/v0.3.1/gui/11_GUI执行路径.md`。

## C-01 未保存状态

| 路径 | 触发 | 行为 |
| --- | --- | --- |
| 正常 | 单元格编辑 / 增行 / 删行 / 列管理 | `m_sigDirty=true`；持久状态区出现 `*` |
| 正常（清除） | 导出成功 / 导入成功 | `m_sigDirty=false`；`*` 消失 |
| 错误 | 导出失败 / 导入失败 | 状态不变（仍为脏），瞬时红 + 日志红 |
| 取消 | 导出/导入文件对话框取消 | 状态不变 |

## C-02 导入特征码

| 路径 | 触发 | 行为 |
| --- | --- | --- |
| 正常 | 无未保存改动 | 直接弹文件选择 → 导入 → 应用表 + `m_sigDirty=false` + 瞬时「已导入 N 条」/日志（绿） |
| 正常（有未保存） | 有未保存改动 → 覆盖确认选「继续导入」 | 弹文件选择 → 导入 → 应用表 + `m_sigDirty=false` |
| 错误 | 文件不存在 / 解析失败 | 瞬时红 + 日志红；当前表**不变**（`m_sigDirty` 不变） |
| 取消（覆盖确认前） | 有未保存改动 → 覆盖确认选「取消」 | 瞬时「已取消导入」+ 日志；当前表不变，**不弹**文件对话框 |
| 取消（文件选择） | 文件对话框取消 | 无副作用 |

> 本版删除的旧路径：「保存」→ 另存为 → 保存成功 → 紧接着弹导入文件对话框（心智模型错位路径，不再存在）。

## C-03 关闭程序 / 退出

| 路径 | 触发 | 行为 |
| --- | --- | --- |
| 正常（无未保存） | 关闭按钮 / 菜单「退出」 | 直接关闭，进程退出码 0 |
| 正常（不保存） | 未保存 → 提示选「不保存」 | 关闭，改动丢弃，退出码 0 |
| 正常（保存） | 未保存 → 提示选「保存」→ 另存为成功 | 文件写出，随后关闭，退出码 0 |
| 错误 | 未保存 → 「保存」→ 导出失败 | 瞬时红 + 日志红；随后仍关闭（导出失败不阻断关闭） |
| 取消 | 未保存 → 提示选「取消」，或「保存」但另存为对话框取消 | `event->ignore()`，**阻止关闭**，窗口保持打开 |

## C-04 程序改名

| 路径 | 触发 | 行为 |
| --- | --- | --- |
| 正常 | 构建 / 启动 | 产物 `PsigMatcher.exe`；`applicationName()=="PsigMatcher"`；标题含 `v0.3.2`；翻译资源从 `:/i18n/PsigMatcher_<lang>.qm` 装载 |

## 约束满足说明

- 每个改动点均给出正常、错误、取消路径（事件驱动独立路径）。
- 无管理员权限前置（本版均为界面内操作），不涉及 `33_admin_capture_guide.md`。
