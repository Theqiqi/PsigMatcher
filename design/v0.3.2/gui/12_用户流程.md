# 12 用户流程（v0.3.2，增量）

- 版本：v0.3.2
- 模式：修改型。仅为改动点新增/更新用户流程；其余沿用 `design/v0.3.1/gui/12_用户流程.md`。
- 每个流程：用户操作 → View 发射信号 → VM 接收事件 → 业务流程 → 结果反馈 → View 刷新；覆盖正常/错误/取消路径。作为用户流程测试与 E2E 测试依据。

## UF-14 编辑特征码后出现未保存标记（C-01）

| 步骤 | 内容 |
| --- | --- |
| 用户操作 | 双击特征码单元格改内容（或 `Ctrl+N` 增行 / 删行 / 列管理） |
| View 信号 | `QAbstractItemModel::dataChanged`（编辑）/ `QAction::triggered`（增删/列管理） |
| VM 事件 | `markSignatureDirty()` |
| 业务流程 | `m_sigDirty=true`；`refreshPersistentStatus()` |
| 结果反馈 | 持久状态区末尾出现 `*` |
| View 刷新 | `persistentLabel` 文本更新 |
| 错误 | 无（纯状态） |
| 取消 | 无 |

## UF-02b 重新选择进程保存提示（沿用，实现统一）

| 步骤 | 内容 |
| --- | --- |
| 用户操作 | 点「重新选择进程」 |
| 结果 | 未保存时弹 [保存/不保存/取消]：保存→另存为→切回进程页；不保存→直接切回；取消→中止切换 |
| 错误 | 另存为导出失败 → 日志报错（红），仍切回进程页（不阻断） |
| 取消 | 提示选「取消」→ 停留当前页 |

## UF-15 导入覆盖确认（C-02）

| 步骤 | 内容 |
| --- | --- |
| 用户操作 | 有未保存改动时点「文件→导入特征码」（或导入按钮/`Ctrl+O`） |
| View 信号 | `QAction::triggered` |
| VM 事件 | `onImportSignatures()` |
| 业务流程 | `m_sigDirty` 为真 → 弹覆盖确认 |
| 正常 | 选「继续导入」→ 文件选择 → `psig::ImportSignatures*` → `applyTableToModel` → `m_sigDirty=false` |
| 结果反馈 | 瞬时「已导入 N 条」；日志 `[import] N 条`（绿）；`*` 消失 |
| 错误 | 导入失败 → 瞬时红「导入失败: …」+ 日志红；当前表不变 |
| 取消 | 选「取消」→ 瞬时「已取消导入」+ 日志；**不弹**文件对话框；当前表不变 |

## UF-16 关闭程序保存提示（C-03）

| 步骤 | 内容 |
| --- | --- |
| 用户操作 | 有未保存改动时点标题栏关闭按钮 / 菜单「退出」 |
| View 信号 | `QEvent::Close`（`MainWindow` 的关闭请求）→ 经事件过滤器进入 VM（View 不发射自定义信号） |
| VM 事件 | `eventFilter()` → `askSaveSignatureChanges(saveCancelAborts=true)` |
| 业务流程 | 弹 [保存/不保存/取消] |
| 正常 | 不保存 → 关闭（退出码 0）；保存 → 另存为成功 → 关闭（退出码 0） |
| 错误 | 保存导出失败 → 日志红，随后仍关闭 |
| 取消 | 选「取消」或「保存」后取消另存为 → 阻止关闭，窗口保持打开 |
