# 15 静态库存在性匹配（v0.3.2，增量）

- 版本：v0.3.2
- 模式：修改型

## 一、判断：**存在静态库 `psig`，且能力已覆盖**

- 存在性：`psig/include/psig.h`（公共头）与 `psig/out/lib/{Debug,Release}/psig.lib`（既有产物）均存在。
- 改动点所需能力（见 `14_API能力需求.md`）在 v0.3.1 已全部具备，公共 API 签名不变。

## 二、是否进入静态库流程

| 条件 | 判定 |
| --- | --- |
| 改动点需要新 API？ | 否 |
| 静态库能力不足？ | 否 |
| 是否有静态库？ | 是 |

- → **跳过**「静态库流程调用」，直接继续 API 充分性审查。

## 三、约束满足说明

- 有静态库且能力已覆盖 → 继续 API 充分性审查；未触发 `.flow/带GUI的单体程序的业务系统静态库.md` 流程。
