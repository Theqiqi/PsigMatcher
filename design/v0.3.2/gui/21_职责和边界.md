# 21 职责和边界（v0.3.2，增量）

> 模式：修改型。仅列本版受影响模块的职责/禁止项；其余沿用 `design/v0.3.1/gui/21_职责和边界.md`。

| 层/模块 | 职责 | 禁止项 |
| --- | --- | --- |
| View `MainWindow` | 创建控件/布局/样式；暴露动作与控件 getter（含本版新增的 `quitAction()`）；设置标题（含版本号） | **不发射自定义信号、无 private slots、不 connect、不处理事件逻辑**（关闭判定不放 View）、不 include `viewmodel/` 或静态库头 |
| Model `SignatureTableModel` | 只管理数据；`setData` 发 `dataChanged` | 不含业务/格式化逻辑；不 include `view/`、`viewmodel/`、静态库头；不直接调用静态库 |
| ViewModel `MainViewModel` | 集中 `connect`（含 `dataChanged → 脏标记`、`quitAction → close`）；维护真实未保存状态 `m_sigDirty`；经 `installEventFilter` 裁决关闭；弹「导入覆盖确认」「保存提示」 | 不在 GUI 自行实现 `.db` 读写；不编造数据；不 `findChild` 访问交互控件；不跨线程抛异常 |
| 静态库 `psig` | — | 本版**无改动**，不依赖 Qt；不抛异常 |

## 关键边界

- **View 零 connect / 零 signals / 零 private slots** 不变：标题与 getter 为纯 UI 暴露。
- **关闭事件处理归属 ViewModel**：`m_view->installEventFilter(this)` + `eventFilter()` 拦截 `QEvent::Close`（ViewModel 允许「持 View 指针链接事件」；View 不含事件处理逻辑）。
- **未保存状态的唯一来源**：`m_sigDirty`（ViewModel 私有），由 Model 信号与 VM 槽共同维护；View 不感知。
- **弹窗在主线程**：`QMessageBox`/`QFileDialog` 均在主线程；无后台任务新增。
- **命名**：生产 exe = `PsigMatcher`；界面标题仍为「进程特征码批量匹配器」。

## 约束满足说明

- 每层定义清晰禁止项；View 不依赖 ViewModel/静态库；ViewModel 经 `View*` 指针操控 View。
