# 26 异常处理与错误显示策略（v0.3.2，增量）

- 版本：v0.3.2
- 模式：修改型。仅列本版新增/变更的提示与错误策略；其余沿用 `design/v0.3.1/gui/26_异常处理与错误显示策略.md`。

## 一、提示分派表（本版相关行）

| 场景 | 类型 | 显示方式 | 内容 |
| --- | --- | --- | --- |
| 特征码表未保存 | 状态 | 持久状态区标记 | 持久状态文本末尾 `*` |
| 导入前有未保存改动（C-02） | **需决策 / 破坏性前置** | **模态弹窗** `QMessageBox` | 「当前特征码表有未保存改动，导入将覆盖它。是否继续？」按钮 `[继续导入][取消]` |
| 关闭/退出前有未保存改动（C-03） | **需决策 / 破坏性前置** | **模态弹窗** `QMessageBox` | 「当前特征码表尚未保存，是否保存？」按钮 `[保存][不保存][取消]` |
| 重新选择进程前有未保存改动 | 需决策 | 模态弹窗（复用同一实现） | 同上 `[保存][不保存][取消]` |
| 导入失败 / 导出失败 | 短暂性错误 | 瞬时反馈（红）+ 日志（红） | 「导入失败: …」「导出失败: …」 |
| 保存（关闭/重选路径）导出失败 | 短暂性错误 | 日志（红）；**不阻断**后续关闭/切换 | 「导出失败: …」 |

## 二、策略

- **需决策一律模态**，且在主线程执行；弹窗父窗口为 `MainWindow`（保证居中与模态遮挡）。
- **短暂性错误不阻断**：导入/导出失败仅反馈，不改变当前表与未保存状态。
- **未保存状态在失败/取消后保持不变**：导入失败或取消导入不改变 `m_sigDirty`；导出失败不置 `false`。
- **关闭路径的取消语义**：「取消」或「保存」后取消另存为 → 阻止关闭（`event->ignore()`），不产生副作用。
- 无后台线程新增，故无跨线程异常传递问题；沿用既有「后台异常经信号回主线程」约定。

## 三、约束满足说明

- 三类反馈各有唯一显示位置（见 `07_状态与反馈信息设计.md`）；错误提示按短暂性/需决策分派。
- 修改模式：新增功能（导入覆盖确认、关闭提示、未保存标记）产生的反馈信息点已补齐。
