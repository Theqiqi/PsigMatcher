# 27 Qt 技术选型（v0.3.2，增量）

- 版本：v0.3.2
- 前置：`08_窗口层次结构与导航图.md`、`13_技术选型分析.md`
- 模式：修改型。沿用既有选型，仅记录本版相关项的变化。

| 项 | 选型 | 本版变化 |
| --- | --- | --- |
| 程序类型 | Windows 桌面应用程序（exe），名 **`PsigMatcher.exe`** | **改名**（原 `psig_gui.exe`） |
| 语言 | C++20 | 不变 |
| 窗口框架 | Qt6 Widgets（代码构建 Widget） | 不变 |
| Qt 版本 | Qt6（6.10.2）：Debug 共享版、Release 静态版（独立安装，非 vcpkg） | 不变 |
| Qt 模块 | Qt6::Widgets、Qt6::Concurrent | 不变 |
| 异步 | `QtConcurrent::run` + `QFutureWatcher` | 不变 |
| 事件过滤 | `QObject::installEventFilter` + `QEvent::Close`（ViewModel 侧） | 本版新增用法 |
| 资源 | `res/resources.qrc`（图标 + .qss）；i18n 经 CMake `lrelease` 嵌入 `/i18n/PsigMatcher_*.qm` | **资源名改名** |
| 测试 | gtest + Qt6::Test（QSignalSpy/QTRY_VERIFY） | 不变 |
| 包管理 | vcpkg manifest（gtest；Qt 独立安装） | 不变 |
| 静态库链接 | `find_library` 引用 `../psig/out/lib/<配置>/psig.lib`，公共头 `../psig/include/psig.h` | 不变 |

## CMake 目标名

- 生产目标：`PsigMatcher`（`qt_add_executable`），产物 `gui/out/bin/<配置>/PsigMatcher.exe`。
- 测试目标：`psig_target`（原 `psig_gui_target`）、`psig_test_view`/`psig_test_model`/`psig_test_viewmodel`/`psig_test_mvvm`/`psig_test_userflow`（不变）。
- i18n 资源函数：`gui_embed_i18n(PsigMatcher PsigMatcher_i18n)`。

## 约束满足说明

- 默认技术选型（Windows 桌面 exe、C++20、Qt6、Qt6::Widgets+Qt6::Concurrent、vcpkg manifest、`find_library` 引用静态库产物）全部满足。
- 静态库命名依据程序类型命名（`psig`，非 pmem 等既有名称）；本版不改静态库名。
