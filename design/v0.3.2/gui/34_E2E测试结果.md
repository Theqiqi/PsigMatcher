## 本版改动点的 E2E 实证

| 改动点 | 实证 |
| --- | --- |
| **C-04 程序改名/版本** | 驱动打印 `hwnd=… title='Process Signature Batch Matcher v0.3.2'`（被测机器系统语言为英文，故显示英文标题）——同时证明 exe 名 `PsigMatcher.exe` 可启动、程序名/版本已生效 |
| **C-03 关闭未保存提示** | E2E-04（Ctrl+N 增行）产生真实未保存改动后，`WM_CLOSE` **未**立即关闭窗口（驱动实测 `hasExited=False`、主窗口客户区仍为 `1100x720`）；`shot_07_close_prompt.png` 与无弹窗的结果页差异 3.79% → 模态提示确实弹出；随后注入 `Ctrl+D`（提示按钮「不保存」的确定性键盘入口）→ 进程退出码 `0`（E2E-08） |
| **C-01 真实未保存检测** | E2E-07 的触发条件即 `m_sigDirty==true`（由 Ctrl+N 置位）；若仍用旧固定条件/未置脏，则 `WM_CLOSE` 不会出现提示，E2E-07/08 均会失败。另由单元/集成测试覆盖单元格编辑置脏、导出/导入清脏 |
| **C-02 导入与保存解耦** | 弹窗为 GUI 模态交互，E2E 不驱动导入文件对话框；由单元测试 `ViewModel.ImportPromptsOverwriteWithoutSaveOptions` 断言按钮集合不含「保存/不保存」、选「取消」中止且表不变（见下） |
