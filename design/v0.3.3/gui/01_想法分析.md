## 三、逐条分析与期望行为

### C-01 给二进制编译的程序文件加上图标资源

- **现状（三处缺口）**：
  1. **exe 无图标资源**。生产目标 `PsigMatcher` 的源文件只有 `main.cpp`/各层 `.cpp`/`resources.qrc`（`gui/src/CMakeLists.txt:2-7`），**没有任何 `.rc`/`.ico`**；`grep -rn '\.rc\|\.ico' gui --include=CMakeLists.txt` → 无命中。因此编译出的 `PsigMatcher.exe` 在资源管理器/任务栏固定项里显示**通用 exe 图标**（PE 资源目录无 `RT_ICON`/`RT_GROUP_ICON`）。
  2. **仅有 32×32 单尺寸窗口图标**。`gui/res/app.png` 经 `file` 实测为 **“PNG image data, 32 x 32, 8-bit/color RGB, non-interlaced”**；`main.cpp:16` 以 `QIcon(":/app.png")` 设置窗口图标。Qt 把该 `QIcon` 通过 `WM_SETICON` 交给 Windows 后，高 DPI（150%/200%）下任务栏/Alt-Tab 会把 32×32 放大，图标发虚。
  3. **图标设计不可复现**。`app.png` 是仓库里一个来源不明的 32×32 位图（实测仅 2 种颜色），没有生成脚本，无法在其它尺寸上保持一致的识别度。
- **期望**：
  - 为生产 exe 内嵌**多尺寸图标资源**：`RT_GROUP_ICON` + 多个 `RT_ICON`，尺寸覆盖 `16/24/32/48/64/128/256`（标题栏 16、小图标 24/32、任务栏 32/48、Alt-Tab 48/64、资源管理器大图标 256）。
  - 窗口图标同步升级为**多尺寸 `QIcon`**，使运行期在任意 DPI 下取到原生尺寸。
  - 图标资源**可复现**：由仓库内脚本从几何规则重新生成，二进制不是黑盒。
  - 图标**沿用既有视觉识别**（深蓝底 `#2A4A7A` + 亮蓝对角带 `#6FA8E0`），不引入与本项目无关的新视觉。

### C-02 更新 README.md

- **现状**：`README.md` 已存在并在 v0.3.2 前被纳入跟踪（该文件的历史见 `git log -- README.md`），内容停留在早期版本描述；与当前实际状态存在偏差：
  - 未反映 **v0.3.2 的程序改名**（`psig_gui.exe` → `PsigMatcher.exe`）。
  - 未反映 **v0.3.2 的未保存检测/关闭提示/导入解耦**等行为变化。
  - 未提到**图标资源**与本版新增的图标生成脚本。
  - 验证/构建命令与脚本清单需按现状核对。
- **期望**：README 与仓库现状**逐项核对后更新**：版本号、程序名、产品结构（`psig/` 静态库 + `gui/` GUI 单体程序）、构建/测试/E2E 命令、许可证、语言切换入口。**不得写入未经实测的命令或路径**。

### C-03 中英双语 README（默认英文）

- **现状**：仅有单份中文 `README.md`；GitHub 仓库首页直接渲染它。
- **期望（用户确认）**：
  - **`README.md` = 英文版**（GitHub 默认渲染英文）。
  - **`README.zh-CN.md` = 简体中文版**。
  - **两版开头互相表示与引用**：英文版首行形如 `English | [简体中文](README.zh-CN.md)`（当前语言加粗/非链接），中文版首行形如 `[English](README.md) | 简体中文`。
  - 两版内容**一一对应**（同一结构、同一命令、同一版本号），避免一版过期。

## 四、本轮已澄清的设计决策

| 议题 | 决策 |
| --- | --- |
| 图标资源形式 | **PE 资源**：`app.ico` + `app.rc`（`IDI_APPICON`），由 MSVC 的 `rc.exe` 编译进 exe；CMake 侧 `enable_language(RC)` |
| 图标尺寸集合 | `16/24/32/48/64/128/256` |
| 图标设计 | 沿用 `app.png` 既有识别（深蓝底 + 亮蓝对角带）；**32×32 与既有 `app.png` 逐像素一致**，更大尺寸按同一几何规则重绘 |
| 图标可复现 | 新增 `gui/script/gen_app_icon.py`（Python + Pillow）；`app.ico`/`app.png` 均由脚本生成 |
| 窗口图标 | `.qrc` 收录 `app.png` + `app_<N>.png` 多尺寸；`main.cpp` 逐个 `QIcon::addFile` |
| 留空/零宽语义 | 不适用（本版无数据语义改动） |
| README 默认语言 | **英文**（`README.md`）；中文版 `README.zh-CN.md` |
| 语言互链位置 | 两版**正文最前方**（标题下、首个章节前）各一行互链 |
| 版本号 | 界面标题随本版更新为 **v0.3.3** |

## 五、不做的事（排除项）

- 不新建程序、不新增窗口/页面、不改交互与界面文案语义。
- 不改技术栈（沿用 Qt6::Widgets / Qt6::Concurrent / MSVC+Ninja / vcpkg）。
- **不改静态库 `psig`**（无新 API、无源码改动；仅 `psig.h` 版本注释随版本号更新）。
- 不变更特征码/结果的导入导出格式与往返语义。
- 不提交无法复现的二进制来源；图标只由仓库内脚本生成。
- 不引入安装包、资源编辑器、第三方图标库等新依赖。
- 不做与「图标资源 / README」无关的仓库整理（例如不改 `.idea/` 的忽略策略）。
