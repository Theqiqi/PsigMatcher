## 二、本版新增的领域元素

本版的想法落在「程序外壳」与「仓库文档」，不引入新的**业务**数据集合；但其产物本身是可被建模的资源集合，按同一格式列出以便审查与验证：

### 2.1 图标资源集合（新增，C-01）

| 项 | 内容 |
| --- | --- |
| 集合 | 图标资源集合（`gui/res/app.ico` 内的多尺寸帧 + `gui/res/app_<N>.png`） |
| 元素 | 图标帧（`frame`），属性：`size ∈ {16,24,32,48,64,128,256}`、`format（PVR/PNG）`、`payload（字节）` |
| 参与者 | 生成脚本（`gui/script/gen_app_icon.py`）、MSVC 资源编译器（`rc.exe`）、Qt 资源系统（`rcc` → `:/app*.png`）、Windows 外壳（资源管理器/任务栏） |
| 元素操作 | **查看** ✅（审查脚本解析并打印尺寸/字节数）／**复制** ✅（`QIcon` 直接消费）／**编辑** ✅（改脚本后重新生成）／**删除** ✅（删除帧后重新生成）／**批量** ✅（脚本一次性生成全部尺寸） |
| 只读性 | 生成物（`app.ico`/`app_<N>.png`）为**派生产物**：唯一可写入口是生成脚本，禁止手工改二进制 |
| 校验规则 | ① 尺寸集合恰为上述 7 个；② 每帧可被独立解码；③ 32×32 帧与 `app.png` **逐像素一致**；④ PE 内嵌资源含 `RT_GROUP_ICON(14)` 与对应数量的 `RT_ICON(3)` |

### 2.2 仓库文档集合（修改，C-02/C-03）

| 项 | 内容 |
| --- | --- |
| 集合 | 仓库根文档集合（`README.md` = 英文默认版、`README.zh-CN.md` = 简体中文版） |
| 元素 | 文档（`doc`），属性：`language ∈ {en, zh-CN}`、`isDefault`、`peerLink`（对端链接） |
| 参与者 | 仓库访问者（GitHub 网页渲染）、维护者 |
| 元素操作 | **查看** ✅（网页渲染）／**复制** ✅／**编辑** ✅／**删除** ❌（两份都在用）／**批量** ✅（两份需成对更新） |
| 只读性 | 可写（人工维护文本） |
| 校验规则 | ① 两版语言互链存在且指向正确文件；② `README.md` 为英文、`README.zh-CN.md` 为中文；③ 两版章节结构一一对应；④ 文中每条命令/路径均在仓库中真实存在 |
