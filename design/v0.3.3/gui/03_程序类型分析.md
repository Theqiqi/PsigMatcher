# 03 程序类型分析（v0.3.3，增量）

- 版本：v0.3.3
- 模式：修改型

## 结论：**沿用既有 GUI 类型**

- 本版是对既有程序的**外壳资源与文档**增量，**程序类型不变**：Windows 桌面 Qt6 GUI 单体程序 + 业务静态库。
- 不做重复的 GUI 适用性判断（需可视化窗口/鼠标键盘交互/实时反馈/多控件协作的判定见 `design/v0.1.0/gui/03_程序类型分析.md`）。
- 无新增窗口/页面；改动仅落在资源文件（`.ico`/`.rc`/`.qrc`/`.png`）、入口 `main.cpp` 的图标装配、构建配置与仓库文档。

## 改动点与程序类型的适配性

| 改动点 | 与既有类型的适配性 |
| --- | --- |
| C-01 exe 图标资源 | 图标是 **Windows GUI 子系统（`WINDOWS`/`WIN32_EXECUTABLE`）程序**的标准外壳资源；PE 资源节属可执行文件本身，不引入新进程/新交互 |
| C-02/C-03 README | 仓库文档，与程序类型无关 |

## 边界说明

- 本版**不**引入控制台子系统（Release 仍为 `WIN32_EXECUTABLE`，见 `gui/src/CMakeLists.txt:26`）、不引入服务/后台进程、不改变窗口数量与导航结构。
- 程序类型不变，未做重复判断，已标注「沿用既有 GUI 类型」。

## 约束满足说明

- 修改模式：沿用既有类型，未做重复的 GUI 适用性判定。产物落盘后按流程提交。
