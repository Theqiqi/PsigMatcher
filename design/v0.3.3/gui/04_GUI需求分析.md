## 二、窗口布局（本版的影响）

- **无新增/删除窗口**：仍为 `MainWindow`（`QMainWindow`）+ 三个页面（进程选择页 / 特征码编辑页 / 结果页）+ 既有对话框（关于、列管理、导出列、保存提示）。
- **窗口布局唯一可见变化**：标题栏左侧出现 16×16 程序图标（由 `QApplication::setWindowIcon` 驱动）；任务栏按钮、Alt-Tab 缩略图使用 32/48/64 尺寸。
- 布局、控件位置、尺寸策略、样式表（`gui/res/style.qss`）**均不变**。

## 三、用户操作路径（本版新增/修改的操作）

本版**不增加任何用户操作入口**（无新菜单项、无新按钮、无新快捷键）。图标是「零操作可见」的标识：

| 路径 | 触发 | 结果 |
| --- | --- | --- |
| 启动程序 → 观察标题栏 | 双击 `PsigMatcher.exe` | 标题栏图标为程序图标（16×16 帧） |
| 启动程序 → 观察任务栏 | 同上 | 任务栏按钮图标为程序图标（32/48 帧，按 DPI） |
| 未启动 → 观察文件 | 资源管理器打开 `gui/out/bin/Release/` | `PsigMatcher.exe` 显示程序图标（32/48/256 帧，按视图大小） |
| 未启动 → 查看文件属性 | 右键 → 属性 | 「更改图标」显示内嵌图标；`.exe` 常规页显示程序图标 |
| 阅读文档 | 打开仓库首页 | 默认英文 `README.md`，首行可点进 `README.zh-CN.md` |
