# 06 交互模式设计（v0.3.3，增量）

- 版本：v0.3.3
- 模式：修改型。仅重设计**受改动影响**的集合/窗口；其余沿用 `design/v0.3.2/gui/06_交互模式设计.md`。

## 一、受影响的「集合」及其交互

本版没有新的**业务数据集合**，受影响的是 `02_领域模型.md` 定义的两组资源集合。按「选择模式 / 操作入口 / 可写性 / 集合形态」四项展开：

### 1. 图标资源集合（C-01）

| 维度 | 设计 | 依据 |
| --- | --- | --- |
| 集合形态 | **派生只读集合**：`app.ico`（含 7 帧）+ `app_<N>.png`（7 个文件）在磁盘上是一批独立文件，但**唯一写入方是生成脚本** | 派生资源不应手工编辑（否则与脚本漂移） |
| 选择模式 | **不存在用户选择**：无界面选择器；「选择」发生在系统侧（Windows 按显示场景自动挑尺寸，Qt 按 DPI 挑尺寸） | 图标是外壳资源，不参与业务交互 |
| 操作入口分级 | **无高频/元素级/低频入口**；唯一入口为命令行（生成脚本）与构建系统（`rc.exe` 编译 `.rc`） | 图标不由终端用户操作 |
| 可写性 | 生成物**只读**；脚本**可写**（编辑脚本 → 重新生成 → 提交） | 保证可复现 |
| 批量 | 生成/校验一律**批量处理全部 7 个尺寸**（脚本循环），不支持单尺寸手工编辑 | 避免尺寸集合残缺 |

### 2. 仓库文档集合（C-02/C-03）

| 维度 | 设计 | 依据 |
| --- | --- | --- |
| 集合形态 | 2 个固定元素（`README.md`、`README.zh-CN.md`），**成对存在** | 双语需求 R-06 |
| 选择模式 | 语言互链（单元素级跳转）：在任一版首行点对端语言名即切到另一版；`README.md` 为**默认**（首页直接渲染） | 用户确认「默认英文 + 开头互相引用」 |
| 操作入口分级 | 低频（文档维护，非程序内交互）；入口为文本编辑 + git 提交 | 文档类集合 |
| 可写性 | 可写（人工维护） | — |
| 批量 | **成对更新**：任一事实变化须同时改两版，并在提交中一并纳入 | 避免一版过期 |

## 二、用户侧交互（程序内）的变化：**无**

- 主窗口、三页、菜单、工具栏、右键菜单、快捷键、对话框按钮集合：**与 v0.3.2 逐条相同**（不新增也不删除入口）。
- 图标为**零操作可见**：不需要用户做任何事即可在标题栏/任务栏/资源管理器看到程序标识（见 `04_GUI需求分析.md` 三节）。

## 三、入口分级复核（确认无违反）

| 分级原则 | 复核结论 |
| --- | --- |
| 高频全局操作 → 按钮 | 本版无新增高频操作 ✅ |
| 元素级操作 → 双击 + 右键 | 本版无新增元素级操作 ✅ |
| 低频操作 → 菜单 | 本版无新增菜单项 ✅ |
| 可批量操作必须支持多选与批量执行 | 本版不适用（无新的可批量业务数据） ✅ |

## 四、约束满足说明

- 集合性质决定可写性与交互入口（图标资源=派生只读、文档集合=成对可写），已逐项给出。
- 修改模式：只重设计受改动影响的集合，其余引用 `design/v0.3.2/gui/06_交互模式设计.md`。
