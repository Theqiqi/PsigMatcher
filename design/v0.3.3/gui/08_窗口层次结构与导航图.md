# 08 窗口层次结构与导航图（v0.3.3，增量）

- 版本：v0.3.3
- 模式：修改型。仅更新受改动影响的窗口层次/导航；其余沿用 `design/v0.3.2/gui/08_窗口层次结构与导航图.md`。

## 一、窗口层次（增量标注）

```
QApplication (app)
 ├─ 应用级：setApplicationName("PsigMatcher")        [不变]
 ├─ 应用级：setStyleSheet(style.qss)                  [不变]
 ├─ 应用级：setWindowIcon(QIcon)  ← ★修改（C-01/R-02）
 │            └─ 7 帧：:/app_16|24|32|48|64|128|256.png（QIcon::addFile 逐个加入）
 └─ MainWindow (QMainWindow)                          [不变]
     ├─ 菜单栏 / 工具栏 / 状态栏                        [不变]
     ├─ 中央 QStackedWidget                           [不变]
     │   ├─ ProcessSelectionPage   (QWidget)          [不变]
     │   ├─ SignatureEditorPage    (QWidget)          [不变]
     │   └─ ResultPage             (QWidget)          [不变]
     └─ 模态对话框（按需）                             [不变]
         ├─ AboutDialog / ColumnManagerDialog / ExportColumnsDialog
         └─ 未保存提示 QMessageBox（v0.3.2 新增）

可执行文件 PsigMatcher.exe
 └─ PE 资源节  ← ★新增（C-01/R-01）
     ├─ RT_GROUP_ICON (14)  IDI_APPICON → 7 条 GRPICONDIRENTRY
     └─ RT_ICON (3)         RT_ICON #1..#7（16/24/32/48/64/128/256）
```

- ★ 本版唯一的结构变化在**应用级图标装配**与**可执行文件的 PE 资源节**；窗口树本身（父子关系、容器类型）**未变**。

## 二、导航图（未变）

```
                    ┌───────────────────────────────┐
   启动 ─────────►  │ MainWindow（进程选择页为默认）  │
                    └───────────────┬───────────────┘
        视图菜单 / 快捷键 Ctrl+1/2/3 │ （QStackedWidget 切页，单向，无嵌套）
                    ┌───────────────┴───────────────┐
                    ▼               ▼               ▼
             进程选择页 ──────► 特征码编辑页 ──────► 结果页
                    │                                ▲
                    └──── F5 扫描（需已选目标进程） ──┘
   任意页面 ──► 模态对话框（关于 F1 / 列管理 Ctrl+M / 导出列 / 未保存提示）
                └─ 关闭后回到原页面（模态，无导航跳转）
```

- 本版**不新增/删除任何导航边**（无新页面、无新对话框）。
- 图标相关：无导航交互（零操作可见）。

## 三、资源路径（`.qrc` 一致）

| 资源 | 来源文件 | 资源路径 | 使用方 |
| --- | --- | --- | --- |
| 样式表 | `gui/res/style.qss` | `:/style.qss` | `main.cpp` |
| 窗口图标（32 兼容帧） | `gui/res/app.png` | `:/app.png` | 保留（兼容既有引用与测试） |
| 窗口图标（多尺寸） | `gui/res/app_{16,24,32,48,64,128,256}.png` | `:/app_<N>.png` | `main.cpp`（`QIcon::addFile`） |
| 图标资源（PE） | `gui/res/app.ico`（经 `gui/res/app.rc`） | 非 Qt 资源（PE 资源节） | Windows 外壳 / `rc.exe` |
| 翻译 | `PsigMatcher_{zh_CN,en_US}.ts` → `.qm` | `:/i18n/<name>.qm` | `QTranslator` |

## 四、约束满足说明

- 使用 Qt 控件术语（`QApplication`/`QMainWindow`/`QStackedWidget`/`QWidget`/`QDialog`/`QMessageBox`）。
- 修改模式：只更新受影响窗口（`MainWindow` 的图标装配）层次；导航图逐条核对为「未变」，未受影响内容引用既有文档。
