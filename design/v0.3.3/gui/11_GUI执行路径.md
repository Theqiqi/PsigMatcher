# 11 GUI 执行路径（v0.3.3，增量）

- 版本：v0.3.3
- 模式：修改型。仅为本版改动点补全**正常路径 / 错误路径 / 取消路径**；其余沿用 `design/v0.3.2/gui/11_GUI执行路径.md`。
- 说明：本版改动点触发者在**构建期/启动期/验证期**，不在事件循环内的用户交互路径上，故「取消路径」以「放弃该开发动作/放弃构建」形式表达（不存在用户点击「取消」按钮的场景）。

## 一、EP-01 exe 图标资源（构建期）

| 路径 | 步骤 | 期望结果 |
| --- | --- | --- |
| **正常** | ① 运行生成脚本 → ② CMake 配置（`enable_language(RC)` 成功） → ③ 构建（`rc.exe` 编译 `app.rc`） → ④ `link.exe` 嵌入 → ⑤ 校验脚本解析 PE | exe 含 `RT_GROUP_ICON`(7 条) + 7 个 `RT_ICON`；校验退出码 0；资源管理器显示程序图标 |
| **错误** | ③' `rc.exe` 未找到/`.rc` 语法错/`app.ico` 缺失 | **构建失败并停止**（CMake/MSVC 报错），不产出「无图标但看似成功」的 exe |
| **错误** | ⑤' PE 无图标节 / 条目数 ≠ 7 / 帧字节与 `app.ico` 不一致 | 校验脚本打印 FAIL 与实测值，退出码非 0；按 `29`–`33` 矩阵跳回资源或构建步骤修复后重跑 |
| **取消** | 放弃本次资源改动 | `git restore gui/res gui/src gui/CMakeLists.txt` 后重配构建；exe 回到「无图标资源」的 v0.3.2 状态（不影响其它功能） |

## 二、EP-02 多尺寸窗口图标（启动期）

| 路径 | 步骤 | 期望结果 |
| --- | --- | --- |
| **正常** | ① `.qrc` 收录 7 个 `app_<N>.png` → ② `rcc` 生成资源 → ③ `main.cpp` 逐个 `QIcon::addFile` → ④ `setWindowIcon` → ⑤ `MainWindow::show()` | 标题栏/任务栏/Alt-Tab 显示原生尺寸图标，无放大模糊 |
| **错误** | ①' `resources.qrc` 漏写某个尺寸 | 单元测试 `View.WindowIconHasAllSizes` 失败（`availableSizes()` 不含缺失尺寸） → 补齐 `.qrc` 后重跑 |
| **错误** | ③' 资源路径写错（如 `:/icons/app_16.png` 与实际不一致） | `QIcon::addFile` 返回空/该尺寸缺失，同上被单元测试捕获；`grep` 校验 `.qrc` 路径与代码一致 |
| **错误** | ⑤' 某个 PNG 损坏 | `rcc` 编译失败或该帧缺失 → 由生成脚本重新生成（脚本幂等） |
| **取消** | 放弃多尺寸、仅保留单尺寸 | 回退 `main.cpp` 的装配为单个文件（如 `QIcon(":/app_32.png")`），并从 `.qrc` 移除多余尺寸；PE 图标资源（EP-01）独立生效，不受影响 |

## 三、EP-03 图标生成/校验（开发期脚本）

| 路径 | 步骤 | 期望结果 |
| --- | --- | --- |
| **正常** | `python3 gui/script/gen_app_icon.py` → 写出 `app.ico` + 7 个 PNG | 退出码 0；`git status` 显示生成物与提交内容一致（幂等、确定） |
| **错误** | Pillow 未安装（`import PIL` 失败） | 脚本打印「缺少 Pillow」并**非零退出**，不写出半成品；不静默降级 |
| **错误** | 写盘失败（只读/权限） | 同上，非零退出并指明路径 |
| **取消** | 不执行生成步骤 | 仓库中已提交的 `app.ico`/`app_<N>.png` 仍可用；构建不受影响（生成脚本非构建前置） |
