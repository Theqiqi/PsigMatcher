# 12 用户流程（v0.3.3，增量）

- 版本：v0.3.3
- 模式：修改型。仅为改动点新增/更新用户流程；其余沿用 `design/v0.3.2/gui/12_用户流程.md`。
- 每个流程：用户操作 → View 发射信号 → VM 接收事件 → 业务流程 → 结果反馈 → View 刷新；覆盖正常/错误/取消路径。作为用户流程测试与 E2E 测试依据。
- 编号续接 v0.3.2（其最后编号为 `UF-18`）。

## UF-19 启动后看到程序图标（C-01 / R-02）

| 步骤 | 内容 |
| --- | --- |
| 用户操作 | 双击 `gui/out/bin/Release/PsigMatcher.exe`（或在资源管理器中查看该文件） |
| View 信号 | 无（应用级图标在 `QApplication` 装配阶段设定，不经 View 信号） |
| VM 接收事件 | 无（不涉及 ViewModel） |
| 业务流程 | `main.cpp`：`QIcon` 逐个 `addFile(":/app_<N>.png")`（N=16..256）→ `app.setWindowIcon(icon)`；Qt 按 DPI/场景选帧后 `WM_SETICON`；Windows 外壳对文件本身读取 PE `RT_GROUP_ICON` |
| 结果反馈 | ① 标题栏 16×16 程序图标；② 任务栏按钮图标；③ Alt-Tab 缩略图图标；④ 资源管理器中 exe 显示程序图标（非通用图标） |
| View 刷新 | `MainWindow::show()` 后由窗口系统绘制图标（Qt 自动） |
| **正常路径** | 上述五步全部成立，图标清晰（原生帧） |
| **错误路径** | 某尺寸 PNG 缺失/路径错 → 该帧不进 `QIcon`；由单元测试 `View.WindowIconHasMultipleSizes` 与 E2E 像素断言捕获，按 `11_GUI执行路径.md` EP-02 修复 |
| **取消路径** | 无（启动期一次性装配，不存在用户取消） |
| 验证 | 单元：`View.WindowIconHasMultipleSizes`（`availableSizes()` 含 7 尺寸）；E2E：`check_exe_icon.py` 校验 PE 资源节（见 `34_E2E测试结果.md`） |

## UF-20 构建产物携带图标资源（C-01 / R-01）

| 步骤 | 内容 |
| --- | --- |
| 用户操作（开发者） | `bash gui/script/build_release_wsl.sh` |
| View 信号 | 无（开发期流程） |
| VM 接收事件 | 无 |
| 业务流程 | CMake 配置启用 RC → `rc.exe` 编译 `gui/res/app.rc`（`IDI_APPICON ICON "app.ico"`） → `link.exe` 把资源嵌入 `PsigMatcher.exe` |
| 结果反馈 | `out/bin/Release/PsigMatcher.exe` 的 PE 资源节含 `RT_GROUP_ICON`(7) + 7 个 `RT_ICON`；资源管理器显示程序图标 |
| View 刷新 | 无（无界面） |
| **正常路径** | 构建退出码 0；校验脚本 PASS |
| **错误路径** | `rc.exe` 失败/`.ico` 缺失 → **构建失败**（不产出无图标 exe），按 EP-01 修复后重跑 |
| **取消路径** | 放弃改动 → `git restore` 资源与构建文件，重配构建回到 v0.3.2 状态 |
| 验证 | `python3 gui/script/verify/check_exe_icon.py gui/out/bin/Release/PsigMatcher.exe`（Debug/Release 各一次） |

## UF-21 图标资源可重建（C-01 / R-03）

| 步骤 | 内容 |
| --- | --- |
| 用户操作（开发者） | `python3 gui/script/gen_app_icon.py` |
| View 信号 / VM 事件 | 无（纯命令行工具） |
| 业务流程 | 按几何规则 `\|u − v\| ≤ 5/32` 渲染 7 个尺寸 → 写 `app.ico` 与 `app_<N>.png` |
| 结果反馈 | 脚本打印生成的尺寸与字节数；退出码 0 |
| View 刷新 | 无 |
| **正常路径** | `git status` 显示 `gui/res/app.ico`、`gui/res/app_<N>.png` 与已提交内容**无差异**（确定性生成） |
| **错误路径** | 缺 Pillow / 写盘失败 → 非零退出并说明原因（不静默降级） |
| **取消路径** | 不运行生成脚本；已提交的生成物继续可用 |
| 验证 | 幂等性检查：重新生成后 `git diff --stat gui/res` 为空 |

## UF-22 切换 README 语言（C-03 / R-06）

| 步骤 | 内容 |
| --- | --- |
| 用户操作 | 打开 <https://github.com/Theqiqi/PsigMatcher>（默认渲染英文）→ 点正文最前方 `简体中文` 链接 |
| View 信号 / VM 事件 | 无（仓库文档，不经程序） |
| 业务流程 | GitHub 按链接路径渲染 `README.zh-CN.md` |
| 结果反馈 | 页面显示简体中文文档；其最前方有 `[English](README.md) | 简体中文` 可返回 |
| View 刷新 | 浏览器页面切换 |
| **正常路径** | 双向跳转均成功，两版内容等价 |
| **错误路径** | 文件名拼错 → 404；由验证阶段比对链接目标与 `git ls-files` 捕获 |
| **取消路径** | 不点击链接，停留在英文版（默认语言即英文） |
| 验证 | 两版首行互链字符串断言 + 链接目标文件存在性（`git ls-files`） |
