## 二、本版新增的技术点（逐项论证）

### 2.1 图标资源编译：MSVC 资源编译器（`rc.exe`）+ CMake `enable_language(RC)`（C-01）

| 候选方案 | 说明 | 结论 |
| --- | --- | --- |
| **A. `.rc` + `rc.exe`（选用）** | Windows 原生资源脚本；CMake 对 MSVC 原生支持；`link.exe` 自动嵌入 `.res`；无新依赖 | ✅ **选用**：最标准、最小实现、与既有 MSVC 工具链零冲突 |
| B. Qt 的 `qt_add_executable(... WIN32 ...)` + `set_target_properties(ICON)` | CMake 只在 Apple/Windows 上对 `MACOSX_BUNDLE`/部分生成器支持；MSVC+Ninja 下不生成 PE 资源 | ❌ 不能达成本版目标（无法产生 `RT_GROUP_ICON`） |
| C. `windres`/`llvm-rc` | 需额外工具链 | ❌ 违背「工具链只允许 MSVC」，且本机无 windres |
| D. 运行期用 `WM_SETICON` 代替 PE 资源 | 只影响运行期窗口，资源管理器中 exe 仍显示通用图标 | ❌ 不满足 R-01 |

### 2.2 图标生成：Python3 + Pillow（C-01 / R-03）

| 候选方案 | 说明 | 结论 |
| --- | --- | --- |
| **A. Python3 + Pillow 脚本（选用）** | WSL 侧可用（实测 Python 3.14.4 / Pillow 12.3.0）；直接写多尺寸 ICO；脚本入库可复现 | ✅ **选用**：跨平台、无 Windows 依赖、易审查 |
| B. 手工提交二进制 `.ico` | 无来源、不可复现 | ❌ 违背 R-03 |
| C. 构建期用 CMake 生成 | CMake 无图像处理能力，需再引第三方 | ❌ 过度设计；图标是低频变更资源，提交生成物更简单 |
| D. 依赖 PowerShell/`System.Drawing` 生成 | 仅 Windows 可用，脚本脆弱 | ❌ |

> 说明：Pillow 仅用于**开发期生成图标**，**不是**程序的运行期/构建期依赖；未加入 `gui/vcpkg.json`（不进入产品依赖树）。

### 2.3 多尺寸窗口图标：`QIcon` + `.qrc` 多 PNG（C-01 / R-02）

| 候选方案 | 说明 | 结论 |
| --- | --- | --- |
| **A. `.qrc` 收录 7 个 PNG + `QIcon::addFile`（选用）** | 只依赖 Qt 自带 `rcc`/PNG 插件；静态 Qt（Release）无插件加载风险；尺寸可控 | ✅ **选用** |
| B. `.qrc` 收录 `app.ico` 并 `QIcon(":/app.ico")` | 需 Qt 的 ICO 图像格式插件（`qico`）；Release 为**静态 Qt**，插件需显式 `qt_import_plugins`，漏配则运行期无图标 | ❌ 风险高、收益相同 |
| C. 仅用 32×32 `app.png`（现状） | 高 DPI 任务栏放大模糊 | ❌ 即本版要修复的问题 |

### 2.4 双语文档：Markdown + 语言互链（C-02/C-03）

| 候选方案 | 说明 | 结论 |
| --- | --- | --- |
| **A. `README.md`(en, 默认) + `README.zh-CN.md`(zh)（选用）** | GitHub 天然渲染 `README.md` 为首页；`.zh-CN.md` 是社区通行命名；纯文本，无构建步骤 | ✅ **选用** |
| B. 单文件内中英混排（折叠区块） | 默认显示无法只出英文；首页冗长 | ❌ 不满足「默认英文」 |
| C. `docs/` + 分支/子目录多语言 | 首页仍需 `README.md` 跳转；结构复杂化 | ❌ 过度设计 |
| D. 引入文档站点生成器（mkdocs 等） | 新增依赖与构建步骤 | ❌ 违背「只用 README」 |
