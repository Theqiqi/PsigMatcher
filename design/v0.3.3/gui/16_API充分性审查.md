# 16 API 充分性审查（v0.3.3）

- 版本：v0.3.3
- 模式：修改型
- 前置：`14_API能力需求.md`、`psig/include/psig.h`

## 一、审查对象

- 审查范围：**本版改动点涉及的全部功能需求**（`04_GUI需求分析.md` 的 R-01–R-07）。
- 判据：这些需求是否需要静态库公共 API，以及（若需要）现有 API 是否充分且支持并发调用。

## 二、审查结果：**满足**（无调用点）

| 需求 | 是否需静态库 API | 现有 API 是否充分 | 并发要求 | 结论 |
| --- | --- | --- | --- | --- |
| R-01 exe 图标资源 | 否 | 不适用 | 不适用 | 满足（由 `rc.exe`/`link.exe` 与 Windows 外壳承担） |
| R-02 多尺寸窗口图标 | 否 | 不适用 | 不适用 | 满足（由 Qt `QIcon`/`rcc` 承担） |
| R-03 图标可复现 | 否 | 不适用 | 不适用 | 满足（开发期 Python 脚本） |
| R-04 图标视觉一致 | 否 | 不适用 | 不适用 | 满足（生成脚本几何规则） |
| R-05 README 更新 | 否 | 不适用 | 不适用 | 满足 |
| R-06 双语 README | 否 | 不适用 | 不适用 | 满足 |
| R-07 两版一致 | 否 | 不适用 | 不适用 | 满足 |

## 三、规则符合性复核

| 规则 | 复核结果 |
| --- | --- |
| 满足 → 继续 GUI 设计 | ✅ 继续（见 `20`–`28`） |
| 不足 → 跳转静态库流程补充 API | ❌ 不触发（无需求条目依赖 API） |
| ViewModel 直接调静态库 API | ✅ 复核既有实现未变（`gui/src/viewmodel/*.cpp` 未纳入本版 diff） |
| 匹配对象只能是静态库公共 API，禁止用 OS API 充当能力提供方 | ✅ 本版未新增任何 OS API 调用充当「能力提供方」；`rc.exe`/`rcc`/`QIcon` 属**构建/外壳设施**，不冒充静态库能力（且本版无静态库能力需求） |
| 禁止在 GUI 中自行实现缺失功能或编造数据 | ✅ 本版无缺失功能；未编造任何 API 或数据 |

## 四、约束满足说明

- 已审查公开 API 是否满足全部功能需求：结论为「满足」（本版无需求依赖公共 API）。
- 并发调用支持：本版不适用（无新增调用点；既有并发实现未改动）。
