## 二、判定依据

静态库无法满足的能力清单为空，依据如下（逐条核对 `04_GUI需求分析.md` 的 7 条需求）：

1. R-01/R-02/R-03/R-04 是**程序外壳资源**需求：由 MSVC `rc.exe`（PE 资源）、Qt `rcc`/`QIcon`（运行期图标）、开发期 Python 脚本承担。它们**不是**业务能力，不应由 `psig` 静态库提供（若强行让静态库「返回图标」反而是职责错位）。
2. R-05/R-06/R-07 是**仓库文档**需求：与静态库无任何交集。
3. 故不存在「静态库无法满足的能力」——因为不存在任何需要静态库参与的能力。
