# 21 职责和边界（v0.3.3，增量）

- 版本：v0.3.3
- 模式：修改型。仅补充本版新引入的职责归属；既有各层职责与禁止项沿用 `design/v0.3.2/gui/21_职责和边界.md`。

## 一、本版新增职责的归属判定（关键）

| 本版改动 | 归属层 | 职责 | 禁止项（本版新增约束） |
| --- | --- | --- | --- |
| 多尺寸窗口图标装配 | **入口（`main.cpp`）** | 创建 `QIcon`、逐个 `addFile(":/app_<N>.png")`、`app.setWindowIcon` | ❌ 不得在 View/Model/ViewModel 层创建或设置应用级图标；❌ 不得用 `findChild`/硬编码路径绕过 `.qrc`；❌ 不得在入口加入业务逻辑（`main()` 仍只做「创建 View → 创建 ViewModel → install → show → exec」） |
| 图标文件与 `.qrc` 路径 | **资源层（`gui/res/`）** | 提供 `:/app_<N>.png`（7 尺寸）、`.rc`/`.ico` 源 | ❌ 生成物不得手工编辑（唯一写入方是生成脚本）；❌ 不得把 `.ico` 塞进 `.qrc` 让 `QIcon` 依赖 ICO 插件（静态 Qt 风险，见 `13_技术选型分析.md` 2.3） |
| PE 图标资源 | **构建层（CMake）** | 启用 RC、把 `app.rc` 编入生产目标 | ❌ 不得让 GUI 生产代码包含任何 Windows 平台 API 调用（`.rc` 是构建期资源，不算代码依赖）；❌ 测试目标不嵌入 PE 图标（仅生产 exe 需要） |
| 标题版本号 | **View（`mainwindow.cpp`）** | `retranslateUi` 中的标题字符串 | ❌ View 不得因图标/版本引入任何事件处理逻辑（v0.3.2 的关闭裁决仍在 ViewModel） |
| 启动日志/关于框版本号 | **ViewModel（`mainviewmodel.cpp`、`result.cpp`）** | 既有文案中的版本号字符串（仅文本，无逻辑） | ❌ ViewModel 不得为图标新增任何控件访问（不用 `findChild`）或静态库调用；❌ 不得在 ViewModel 中装配应用级图标 |
| 图标生成/校验脚本 | **开发期工具（`gui/script/`）** | 生成与校验图标资源；非零退出码报告失败 | ❌ 脚本不得成为构建/运行期依赖（不加入 `gui/vcpkg.json`、不被 CMake 调用） |
| 双语 README | **仓库文档** | 提供中英两版与语言互链 | ❌ 不得写入未实测的命令/路径；❌ 两版不得长期不一致 |

## 二、各层禁止项复核（本版）

| 层 | 既有禁止项 | 本版复核 |
| --- | --- | --- |
| View | 不依赖 ViewModel / 静态库；只画 UI；无 signals/无 private slots | ✅ 本版 View 改动仅一处标题字符串；`grep -n 'signals\|private slots\|viewmodel\|psig' gui/src/view/mainwindow.*` 无新增命中 |
| Model | 不 include `view/`/`viewmodel/`；不 include 静态库头；无业务逻辑 | ✅ 本版 Model 零改动 |
| ViewModel | 经 `View*` 指针操控 View；**不用 `findChild`**；不在后台线程操作 UI | ✅ 本版 ViewModel 仅改两处文案字符串（`mainviewmodel.cpp` 启动日志、`result.cpp` 关于框），无新增 `findChild`/控件访问/静态库调用 |
| 静态库 | 不引用任何 Qt 头；GUI 只经公共 API 调用 | ✅ 本版静态库零源码改动 |

## 三、边界图（本版视角）

```
Windows 外壳 ──读 PE RT_GROUP_ICON──► PsigMatcher.exe ──(构建期 rc.exe 嵌入)── gui/res/app.rc ─► app.ico
                                              ▲
Qt 资源系统 ──rcc──► :/app_<N>.png ──► main.cpp（QIcon 装配）──► QApplication ──► MainWindow
                                              ▲
开发期脚本 ──gen_app_icon.py──► app.ico / app_<N>.png（唯一写入方）
开发期脚本 ──check_exe_icon.py──► 解析 PE，断言尺寸集合与帧一致性
```

- View / Model / ViewModel / 静态库 四层的依赖方向**未变**（View → VM → 静态库，Model 仅依赖 Qt）；本版新增的边全部在**构建期/启动期/开发期**，不进入 MVVM 依赖链。

## 四、约束满足说明

- 已为每层定义清晰禁止项（第一节表格逐条），并复核既有禁止项未被破坏（第二节）。
- View 不依赖 ViewModel/静态库 ✅；ViewModel 经 `View*` 指针操控 View ✅（本版未改）。
