# 26 异常处理与错误显示策略（v0.3.3，增量）

- 版本：v0.3.3
- 前置：`07_状态与反馈信息设计.md`、`11_GUI执行路径.md`
- 既有策略（错误弹窗 `ErrorDialog`、瞬时反馈、日志三级、后台异常经信号回主线程）见 `design/v0.3.2/gui/26_异常处理与错误显示策略.md`，本版**不修改**。

## 一、本版新增的错误点与分派策略

本版改动全部发生在**运行期之前**（构建期/验证期）或**启动期一次性装配**，因此错误分派遵循同一原则：**能在构建/验证期暴露的错误绝不留到运行期，且不以弹窗形式打扰终端用户**。

| 错误点 | 发生阶段 | 性质 | 分派 | 用户可见性 |
| --- | --- | --- | --- | --- |
| `gen_app_icon.py` 失败（缺 Pillow / 写盘失败 / 参数错） | 开发期 | 需决策错误 | 脚本打印原因 + **非零退出码**；不产出半成品 `.ico` | 仅开发者（终端） |
| `app.rc` 引用的 `app.ico` 缺失/损坏 | 构建期 | 需决策错误 | `rc.exe` 报错 → **构建失败并停止**；不产出「无图标的 exe」 | 仅开发者（构建日志） |
| `enable_language(RC)` 失败（无 Windows SDK） | 配置期 | 需决策错误 | CMake 配置失败并停止 | 仅开发者 |
| `.qrc` 漏写某尺寸 / 路径不一致 | 构建期或测试期 | 需决策错误 | `rcc` 编译失败，或单元测试 `View.WindowIconHasAllSizes` 失败 | 开发者（测试输出） |
| PE 无图标资源 / 尺寸集合不符 / 帧与 `app.ico` 不一致 | 验证期 | 需决策错误 | `check_exe_icon.py` 打印逐项实测值 + **非零退出码** | 开发者（验证输出） |
| README 互链目标不存在 / 两版事实不一致 | 验证期 | 需决策错误 | 验证步骤比对链接目标与 `git ls-files`；不一致即视为 ❌ | 开发者 |

## 二、明确**不**做的处理（避免滥用反馈通道）

| 不做的事 | 理由 |
| --- | --- |
| 为「图标缺失」加运行期 `QMessageBox` 警告 | 图标缺失属构建缺陷，应在构建/验证期失败；运行期弹窗无意义且打扰用户 |
| 为「图标缺失」加瞬时标签/日志行 | 图标在 `exec()` 前已确定，不产生运行期事件；日志面板不承担构建期问题 |
| 静默降级为「无图标继续运行」 | 违背「错误后必须暴露」；`check_exe_icon.py` 与构建失败共同保证不会静默通过 |
| 在 ViewModel 中捕获/吞掉异常 | 本版 ViewModel 无相关逻辑（仅两处文案字符串） |

## 三、既有错误链路复核（未改动）

| 链路 | 本版结论 |
| --- | --- |
| 静态库返回错误码 → VM 转 `ErrorDialog`/瞬时反馈 | **未受影响**（VM 逻辑未改） |
| 后台线程异常/失败 → 信号回主线程 → UI 反馈 | **未受影响**（无线程改动） |
| 日志三级着色（info/warn/error） | **未受影响** |

## 四、约束满足说明

- 错误提示按「短暂性错误 / 需决策错误」分派：本版全部为需决策错误，统一以**非零退出码 + 构建失败**分派；无任何短暂性错误需要瞬时反馈。
- 未新增未被分派的错误路径（`11_GUI执行路径.md` 的错误路径与本文一一对应）。
