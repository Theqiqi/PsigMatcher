# 27 Qt 技术选型（v0.3.3，增量）

- 版本：v0.3.3
- 模式：修改型。**沿用既有选型**，仅记录本版新增的构建/资源细节。

## 一、既有选型（沿用）

| 项 | 取值 | 本版结论 |
| --- | --- | --- |
| 程序类型 | Windows 桌面 exe（x64） | 沿用 |
| 语言 | C++20 | 沿用 |
| GUI 库 | Qt6::Widgets（代码构建 Widget，无 `.ui`） | 沿用 |
| 异步 | Qt6::Concurrent | 沿用 |
| 测试 | gtest + Qt6::Test | 沿用 |
| 构建 | CMake ≥ 3.20 + CMakePresets + Ninja + MSVC | 沿用 |
| 依赖 | vcpkg manifest（gtest）；Qt6 独立安装 | 沿用 |
| 静态库命名 | `psig`（依据程序类型命名，未沿用 pmem 等既有名称） | 沿用 |

## 二、本版新增/变更的构建选型

| 项 | 取值 | 说明 |
| --- | --- | --- |
| **RC 语言** | `enable_language(RC)`（MSVC 自带 `rc.exe`） | 编译 `gui/res/app.rc` → `app.res` → 由 `link.exe` 嵌入 PE 资源节 |
| 资源清单 | `GUI_ICON_RESOURCES`（`gui/CMakeLists.txt`）→ 生产目标 `psig_gui`/`PsigMatcher` 引用 | 只给**生产目标**嵌入 PE 图标；测试目标不嵌入（避免测试产物与生产同图标造成混淆，且测试不需要） |
| 图标资源文件 | `gui/res/app.ico`（7 帧）、`gui/res/app_<N>.png`（7 个，均由 `gui/script/gen_app_icon.py` 生成）；`gui/res/app.rc`（手写，10 行） | 生成物可逐字节重建；单尺寸 `app.png` 已删除 |
| `.qrc` | `gui/res/resources.qrc` 增加 7 个 `app_<N>.png` | 供 `QIcon::addFile`；**不**把 `.ico` 交给 `QIcon`（静态 Qt 下 ICO 插件风险，见 `13_技术选型分析.md` 2.3） |
| 运行期装配 | `main.cpp` 逐个 `QIcon::addFile` → `app.setWindowIcon` | 无新增 Qt 模块依赖（`Qt6::Widgets` 已含 `QIcon`） |

## 三、约束满足说明

- 默认技术选型（Windows 桌面 exe / C++20 / Qt6 / Qt6::Widgets + Qt6::Concurrent / vcpkg manifest / `find_library` 引用静态库产物）**全部沿用**，无偏离。
- 静态库命名依据程序类型命名（`psig`），未使用 pmem 等既有名称 ✅。
- 本版未引入任何新的 Qt 模块、第三方运行期库或平台 API 代码依赖。
