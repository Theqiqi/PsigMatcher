# 28 Qt GUI 代码规范（v0.3.3，增量）

- 版本：v0.3.3
- 模式：修改型。**沿用既有规范**（`design/v0.3.2/gui/28_QtGUI代码规范.md`），本文件仅补充本版新增资源/脚本的规范条款。

## 一、既有规范（沿用，复核项）

| 规范 | 本版复核 |
| --- | --- |
| View 只画 UI（不 `connect`、不发 signals、无 private slots、无事件逻辑） | ✅ 本版 View 仅改 1 处标题字符串 |
| View 可单独编译（`psig_test_view` 目标） | ✅ 目标未改，随回归重新编译通过 |
| VM 持 `View*` 链接事件；`connect` 集中在 `install()`/`bind*` | ✅ 本版 VM 仅改 2 处文案字符串 |
| Model 纯净（无业务/格式化；无 signals 之外的逻辑） | ✅ 本版 Model 零改动 |
| `Q_OBJECT` 宏（QObject 派生类） | ✅ 本版未新增 QObject 派生类 |
| UI 线程不阻塞；后台不直接操作 UI | ✅ 本版无线程相关改动 |
| `.qrc` 管理资源 | ✅ 本版 `.qrc` 收录新增 PNG；样式表/图标路径与代码一致 |
| GUI 生产代码禁止平台 API / 第三方库 | ✅ 生产代码未新增任何平台 API 调用（`.rc` 是**资源脚本**，非 C++ 代码，且仅参与构建） |

## 二、本版新增规范条款

### 2.1 资源生成物规范

| 条款 | 内容 |
| --- | --- |
| R-资源-1 | 图标二进制（`app.ico`、`app_<N>.png`、`app.png`）**只能由** `gui/script/gen_app_icon.py` 生成；禁止手工编辑或从外部下载替换 |
| R-资源-2 | 生成必须是**确定性的**：同一次输入（脚本 + 参数）重复执行产出逐字节相同的文件 |
| R-资源-3 | 新增/删除图标尺寸时，必须同步三处：生成脚本的尺寸集合、`gui/res/resources.qrc`、`gui/src/main.cpp` 的 `addFile` 尺寸循环 |
| R-资源-4 | `.rc` 只包含**资源声明**（`ICON`），不写 `VERSIONINFO` 等含版本号的块（避免版本号出现第二处维护点；版本号统一由 `main.cpp`/`mainwindow.cpp`/`psig.h` 承担） |
| R-资源-5 | PE 图标只嵌入**生产目标**；测试目标不嵌入 |

### 2.2 脚本规范（配合 `gui/script/README.md` 四类管理）

| 条款 | 内容 |
| --- | --- |
| R-脚本-1 | `gen_app_icon.py` 属「**核心**」类（图标可能随版本重新生成，长期保留） |
| R-脚本-2 | `verify/check_exe_icon.py` 属「**验证**」类（构建后可复用的校验手段） |
| R-脚本-3 | 脚本必须**非零退出码**报告失败，禁止静默降级产出半成品 |
| R-脚本-4 | 脚本依赖（Python3 + Pillow）**只允许出现在开发期**，不得加入 `gui/vcpkg.json` 或任何构建/运行期依赖 |

### 2.3 文案与版本号规范

| 条款 | 内容 |
| --- | --- |
| R-文案-1 | 版本号出现在三处界面文案（标题、启动日志、关于框），改版时**必须同时更新**对应 `.ts` 的 `<source>` 与 `<translation>`，否则英文界面会回退成中文源串 |
| R-文案-2 | 版本号注释同步：`psig/include/psig.h` 首行注释 |

### 2.4 文档规范

| 条款 | 内容 |
| --- | --- |
| R-文档-1 | `README.md` = 英文（默认），`README.zh-CN.md` = 简体中文；两版开头必须互相链接 |
| R-文档-2 | 两版章节一一对应；任一事实变更必须成对更新 |
| R-文档-3 | README 中出现的每条命令/路径必须在本仓库中真实存在且实测可用 |

## 三、约束满足说明

- 既有规范逐条沿用并复核（第一节）；本版新增条款集中在**资源生成、脚本、文案版本号、双语文档**四类，与既有规范无冲突。
- 未放宽任何既有约束（未新增懒加载/静默降级等违规写法）。
