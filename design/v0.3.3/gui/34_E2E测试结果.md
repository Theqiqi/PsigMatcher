## 二、本版改动点的 E2E 实证

### C-01 exe 图标资源（R-01）

驱动启动的 exe 即 `out/bin/Release/PsigMatcher.exe`；其 PE 资源节实测：

| 项 | 实测 |
| --- | --- |
| PE 资源类型 | `[3, 14, 24]`（`RT_ICON`=3、`RT_GROUP_ICON`=14、`RT_MANIFEST`=24（CMake 默认清单）） |
| 组图标 | `#101：7 条目 -> [(16,16),(24,24),(32,32),(48,48),(64,64),(128,128),(256,256)]` |
| `RT_ICON` 条目数 | 7（期望 7） |
| 逐帧字节一致 | 16→1128B、24→2440B、32→4264B、48→9640B、64→16936B、128→596B、256→1119B，全部与 `gui/res/app.ico` **逐字节一致** |
| Windows 外壳关联图标 | `ExtractAssociatedIcon` 返回 32×32，与 `gui/res/app_32.png` **差异像素 0**（`out/verify/exe_associated_icon.png`） |
| Debug 配置 | `python3 gui/script/verify/check_exe_icon.py gui/out/bin/Debug/PsigMatcher.exe` → 同样 PASSED；`verify_all.sh Debug` 整体 `rc=0`（8/8 像素断言 + E2E-09/10） |

> 对照实验（证明断言非恒真）：把 `app_256.png`（256×256）当作「外壳关联图标」喂入 → `FAIL Windows 外壳关联图标与 app_32.png 逐像素一致 — 外壳图标 256x256，差异像素 -1`，退出码 1。

## 六、说明

- 无需管理员权限（本版全部为构建期资源、启动期装配与界面内操作），未触发提权路径。
- 被测机器系统语言为英文，故标题/界面显示英文；`test/unit/test_app.h` 固定测试默认语言为 `zh_CN`，保证单元断言与机器语言无关。
