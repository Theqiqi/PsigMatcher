# 35 编译环境与包管理（GUI 流程步骤 37–38，v0.3.3）

- 版本：v0.3.3
- 模式：修改型。**沿用既有编译环境与脚本**；本版新增 1 个开发期脚本（图标生成）与 2 个验证脚本，按四类管理归档。

## 一、编译环境需求（沿用）

| 项 | 取值 |
| --- | --- |
| 生成器 | 仅 Ninja |
| 工具链 | 仅 MSVC（`cl.exe`），`gui/CMakeLists.txt` 对非 MSVC 直接 `FATAL_ERROR` |
| 资源编译器 | MSVC 自带 `rc.exe`（Windows SDK），由 `enable_language(RC)` 接入——**本版新增使用**，仍属既有工具链 |
| Qt6 | 独立安装，不纳入 vcpkg manifest：`QT6_DEBUG_DIR`=`C:/d/ccpplib/qt6.10.2-windows-x86_64-msvc2022-shared_debug`（Debug 共享 /MDd）、`QT6_RELEASE_DIR`=`C:/d/ccpplib/Qt_6.10.2-static-Release_msvc2022_64/msvc2022_64`（Release 静态 /MT） |
| 包管理 | vcpkg manifest 管 gtest：Debug=`x64-windows`、Release=`x64-windows-static`（与运行时匹配） |
| 静态库 | `find_library(psig … ../psig/out/lib/<配置>)`，公共头 `../psig/include/psig.h` |
| 开发期工具（非构建依赖） | Python 3 + Pillow（图标生成/校验）、PowerShell（外壳图标提取） |

## 二、包管理选型结果（沿用 + 本版说明）

- gtest 走 `gui/vcpkg.json`；Qt6 独立安装（`CMAKE_PREFIX_PATH` 由预设注入）。
- **本版未新增任何构建/运行期依赖**：Pillow 只用于开发期生成图标与校验（未加入 `gui/vcpkg.json`，CMake 不调用 Python）。
- `enable_language(RC)` 使用工具链自带能力，无需安装新包。

## 三、编译脚本（沿用，四类管理）

| 类别 | 脚本 |
| --- | --- |
| 核心 | `build_debug.bat` / `build_release.bat` / `build_debug_wsl.sh` / `build_release_wsl.sh`；`run_debug_tests*.{bat,sh}` / `run_release_tests*.{bat,sh}`；**新增** `gen_app_icon.py`（图标生成） |
| 验证 | `dump_dependents.bat`、`dump_directives.bat`；**新增** `check_app_icon.py`（源侧一致性）、`check_exe_icon.py`（PE 产物侧）、`extract_exe_icon.ps1`（Windows 外壳关联图标提取） |
| 排查 / 一次性 | 空 |

- `gui/script/README.md` 已同步新增 3 个条目与「Python 脚本仅开发期依赖 / 失败必须非零退出码」两条约定。
- WSL → `cmd.exe` → `.bat` → MSVC；`.bat` 设 `VCPKG_ROOT`、调 `vcvars64.bat`、兜底 `QT6_DEBUG_DIR`/`QT6_RELEASE_DIR`（本版**未修改**任何 `.bat`/`.sh`）。
- 构建配置改动仅 2 处：`gui/CMakeLists.txt` 增加 `enable_language(RC)` 与 `GUI_ICON_RESOURCES`（含 `INCLUDE_DIRECTORIES` 让 `rc.exe` 解析到 `res/app.ico`）；`gui/src/CMakeLists.txt` 的 `PsigMatcher` 目标源增加 `${GUI_ICON_RESOURCES}`。

## 五、约束满足说明

- 生成器只允许 Ninja、工具链只允许 MSVC；Qt6 独立安装不纳入 vcpkg manifest；gtest 走 vcpkg manifest 且 triplet 与运行时匹配——全部沿用。
- 新增脚本已归入既有四类管理并同步 `gui/script/README.md`。
- 开发期依赖（Python3 + Pillow、PowerShell）与产品依赖树**完全隔离**。
