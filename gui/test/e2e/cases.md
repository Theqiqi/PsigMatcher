# psig_gui E2E 测试用例清单

- 版本：v0.2.0
- 前置：`design/v0.2.0/gui/11_GUI执行路径.md`、`12_用户流程.md`、`06_交互模式设计.md`、`05_GUI功能列表与窗口定义.md`、`08_窗口层次结构与导航图.md`
- 产物对应：`drive.ps1`（驱动）、`analyze.py`（断言）、`verify_all.sh`（编排）
- 说明：每个用例的操作步骤均对应真实可执行入口（菜单/工具栏/快捷键）；驱动脚本按步骤注入，断言脚本按预期断言，脚本与用例一一对应。

## 入口与注入方式

- 程序：`gui/out/bin/Release/psig_gui.exe`（静态 Qt，自包含）。
- 注入：`keybd_event`（Win32 原始输入）注入快捷键；`PostMessage(WM_CLOSE)` 关闭窗口。
- 截图：客户区（排除标题栏），保存至 `gui/out/verify/shot_xx.png`。
- 快捷键入口：Ctrl+1/2/3 切页（视图菜单）、Ctrl+N 新增行、Ctrl+R 刷新进程、F5 扫描、Ctrl+M 列管理、Ctrl+O/Ctrl+S 导入/导出、F1 关于。

## v0.2.0 变更点（相对 v0.1.0）

- 启动落点由「特征码编辑页」改为「进程选择页」（`08_窗口层次结构与导航图.md`）。
- 工具栏图标化并按页显隐；行操作（新增/删除/列管理/导出）改为表格右键菜单。
- 「关于」改为 F1 弹窗（`AboutDialog`），不再占用状态栏。
- 匹配结果页新增「地址(十进制)」列与可编辑「自定义」末列、模板文本区。
- 窗口标题更新为「进程特征码批量匹配器 v0.2.0」。

## E2E-01 启动主界面（进程页）

- 场景：冷启动，主窗口渲染，默认落在进程选择页。
- 前置：已编译 `psig_gui.exe`；无残留实例。
- 操作步骤：
  1. 启动 `psig_gui.exe`。
  2. 等待主窗口句柄就绪并置前。
  3. 截取客户区 → `shot_01_start.png`。
- 预期结果：窗口标题为「进程特征码批量匹配器 v0.2.0」；客户区尺寸 ≥ 600×400；画面非黑屏（平均亮度 > 30）；含 UI 元素（非背景像素占比 > 2%）。

## E2E-02 刷新进程（扫描菜单 / Ctrl+R）

- 场景：枚举系统进程并填充进程表（启动即为进程页）。
- 前置：E2E-01 通过。
- 操作步骤：
  1. 按 Ctrl+R → 触发异步枚举，等待 2.5s。
  2. 截图 `shot_02_process_refreshed.png`。
- 预期结果：刷新后画面与启动画面存在差异（差异像素比例 > 0.5%），证明进程表被数据填充。

## E2E-03 页面导航（视图菜单）

- 场景：在特征码编辑页 / 匹配结果页之间切换（进程页为启动落点）。
- 前置：E2E-01 通过。
- 操作步骤：
  1. 按 Ctrl+1 → 特征码编辑页，截图 `shot_03_signature.png`。
  2. 按 Ctrl+3 → 匹配结果页，截图 `shot_05_result.png`。
- 预期结果：特征码页与启动（进程）页画面不同、结果页与特征码页画面不同（差异像素比例 > 1%），证明页面确实切换。

## E2E-04 新增特征码行（编辑菜单 / Ctrl+N）

- 场景：在特征码编辑页新增一行。
- 前置：处于特征码编辑页。
- 操作步骤：
  1. 按 Ctrl+N → 表格新增一行。
  2. 截图 `shot_04_addrow.png`。
- 预期结果：`shot_04_addrow.png` 与新增前的 `shot_03_signature.png` 存在差异（差异像素比例 > 0.1%），证明表格内容变化。

## E2E-05 列管理对话框（编辑菜单 / Ctrl+M）

- 场景：打开列管理对话框并取消。
- 前置：任意页面。
- 操作步骤（人工/可选，自动化默认不纳入必过断言）：
  1. 按 Ctrl+M → 弹出列管理对话框。
  2. 按 Esc 取消。
- 预期结果：弹出对话框后主窗口被模态遮挡；取消后回到主界面。

## E2E-06 关于弹窗（帮助菜单 / F1）

- 场景：按 F1 弹出关于对话框，确认其为模态弹窗而非状态栏文本。
- 前置：处于匹配结果页（`shot_05_result.png` 已截取）。
- 操作步骤：
  1. 按 F1 → 弹出 `AboutDialog`（模态）。
  2. 截图 `shot_06_about.png`。
  3. 按 Esc 关闭对话框。
- 预期结果：`shot_06_about.png` 与 `shot_05_result.png` 存在差异（差异像素比例 > 0.4%），证明弹窗确实覆盖在主窗口之上。

## E2E-07 关闭程序

- 场景：正常退出。
- 前置：程序运行中（关于弹窗已关闭）。
- 操作步骤：
  1. 向主窗口发送 `WM_CLOSE`。
  2. 等待进程退出（≤ 8s）。
- 预期结果：进程正常退出，退出码为 `0`（写入 `out/verify/exit_code.txt`）。
