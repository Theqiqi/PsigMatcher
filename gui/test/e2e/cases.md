# psig_gui E2E 测试用例清单

- 版本：v0.1.0
- 前置：`11_GUI执行路径.md`、`12_用户流程.md`、`06_交互模式设计.md`、`05_GUI功能列表与窗口定义.md`
- 产物对应：`drive.ps1`（驱动）、`analyze.py`（断言）、`verify_all.sh`（编排）
- 说明：每个用例的操作步骤均对应真实可执行入口（菜单/工具栏/快捷键）；驱动脚本按步骤注入，断言脚本按预期断言，脚本与用例一一对应。

## 入口与注入方式

- 程序：`gui/out/bin/Release/psig_gui.exe`（静态 Qt，自包含）。
- 注入：`keybd_event`（Win32 原始输入）注入快捷键；`PostMessage(WM_CLOSE)` 关闭窗口。
- 截图：客户区（排除标题栏），保存至 `gui/out/verify/shot_xx.png`。
- 快捷键入口：Ctrl+1/2/3 切页（视图菜单）、Ctrl+N 新增行、Ctrl+R 刷新进程、F5 扫描、Ctrl+M 列管理、Ctrl+O/Ctrl+S 导入/导出。

---

## E2E-01 启动主界面

- 场景：冷启动，主窗口渲染。
- 前置：已编译 `psig_gui.exe`；无残留实例。
- 操作步骤：
  1. 启动 `psig_gui.exe`。
  2. 等待主窗口句柄就绪并置前。
  3. 截取客户区 → `shot_01_start.png`。
- 预期结果：窗口标题为「进程特征码批量匹配器 v0.1.0」；客户区尺寸 ≥ 600×400；画面非黑屏（平均亮度 > 30）；含 UI 元素（非背景像素占比 > 2%）。

## E2E-02 页面导航（视图菜单）

- 场景：在特征码编辑页 / 进程选择页 / 匹配结果页之间切换。
- 前置：E2E-01 通过。
- 操作步骤：
  1. 按 Ctrl+2 → 进程选择页，截图 `shot_02_process.png`。
  2. 按 Ctrl+1 → 特征码编辑页，截图 `shot_04_signature.png`。
  3. 按 Ctrl+3 → 匹配结果页，截图 `shot_06_result.png`。
- 预期结果：三个页面画面互不相同（差异像素比例 > 1%），证明页面确实切换。

## E2E-03 新增特征码行（编辑菜单）

- 场景：在特征码编辑页新增一行。
- 前置：处于特征码编辑页。
- 操作步骤：
  1. 按 Ctrl+N → 表格新增一行。
  2. 截图 `shot_05_addrow.png`。
- 预期结果：`shot_05_addrow.png` 与新增前的 `shot_04_signature.png` 存在差异（差异像素比例 > 0.1%），证明表格内容变化。

## E2E-04 刷新进程（扫描菜单）

- 场景：枚举系统进程并填充进程表。
- 前置：E2E-01 通过。
- 操作步骤：
  1. 处于进程选择页，截图 `shot_02_process.png`（刷新前）。
  2. 按 Ctrl+R → 触发异步枚举，等待 2.5s。
  3. 截图 `shot_03_process_refreshed.png`。
- 预期结果：刷新后画面与刷新前存在差异（差异像素比例 > 0.5%），证明进程表被数据填充。

## E2E-05 列管理对话框（编辑菜单）

- 场景：打开列管理对话框并取消。
- 前置：任意页面。
- 操作步骤（人工/可选，自动化默认不纳入必过断言）：
  1. 按 Ctrl+M → 弹出列管理对话框。
  2. 按 Esc 取消。
- 预期结果：弹出对话框后主窗口被模态遮挡；取消后回到主界面。

## E2E-06 关闭程序

- 场景：正常退出。
- 前置：程序运行中。
- 操作步骤：
  1. 向主窗口发送 `WM_CLOSE`。
  2. 等待进程退出（≤ 8s）。
- 预期结果：进程正常退出，退出码为 `0`（写入 `out/verify/exit_code.txt`）。

以上用例均操作自身进程/界面，不需要管理员权限。详见 `design/v0.1.0/gui/33_admin_privilege_guide.md`。
